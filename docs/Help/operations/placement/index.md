# Placement Operations
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Placement operations help you precisely position objects relative to each other or within specific boundaries. The **Placement** group of the toolbar holds Align, Align in Place, Fit to Bounds and Bounds.

## Operations

- [Align](align.md) - Align objects to each other along any axis
- [Align in Place](align-in-place.md) - Put parts back where their own files placed them, so parts made together fit again
- [Fit to Bounds](fit-to-bounds.md) - Scale an object to fit within a specified bounding box
- [Fit to Cylinder](fit-to-cylinder.md) - Scale an object to fit within a specified cylinder (no toolbar button; found in designs that already use it)
- [Bounds](bounds.md) - Make a solid box the size of the selected parts
