# Combine

Combine is now one setting of the [Boolean](boolean.md) operation rather than an operation of its own. The toolbar button still says Combine -- it creates a Boolean with the Combine operation already chosen.

See **[Boolean](boolean.md)** for how to use it, and for the Subtract, Intersect and Subtract & Replace operations that share the same object.

This page also covers the older Combine objects still found in designs saved before the operations were merged. They keep working exactly as they did; new designs use [Boolean](boolean.md).
