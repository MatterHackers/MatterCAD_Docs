# Padbewerkingen
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

Padbewerkingen werken met 2D-paden om 3D-vormen te maken en aan te passen. Gebruik deze om padgebaseerde geometrie te extruderen, te wentelen en te verfijnen.

## Bewerkingen

- [Lineaire extrusie](linear-extrude.md) - Geef een 2D-pad hoogte om een 3D-object te maken
- [Wentelen](revolve.md) - Draai een 2D-pad om een as om een omwentelingslichaam te maken
- [Pad gladmaken](smooth-path.md) - Maak de curven van een pad glad
- [Pad opblazen](inflate-path.md) - Vouw een pad naar buiten uit
- [Contourpad](outline-path.md) - Maak een contour van een gevuld pad
- [Randpad](border-path.md) - Voeg een randafstand rond een pad toe
- [Paden selecteren](select-paths.md) - Selecteer specifieke paden uit complexe objecten met meerdere paden
