# Passend maken aan cilinder

Passend maken aan cilinder schaalt een object zodat het binnen een opgegeven cilindrische begrenzing past, gedefinieerd door een diameter en hoogte.

## Gebruik

1. Selecteer een object
2. Pas de bewerking **Passend maken aan cilinder** toe via het menu Plaatsing
3. Stel de gewenste Diameter en Hoogte in

## Parameters

- **Diameter** - De diameter van de doelcilinder
- **Hoogte** - De hoogte van de doelcilinder
- **Z uitrekken** - Indien ingeschakeld wordt het object geschaald zodat het overeenkomt met de hoogte van de cilinder
- **Alternatief centreren** - Indien ingeschakeld wordt gecentreerd op basis van het visuele zwaartepunt van het onderdeel in plaats van de omsluitende cirkel
