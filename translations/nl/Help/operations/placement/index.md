# Plaatsingsbewerkingen
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Plaatsingsbewerkingen helpen je objecten nauwkeurig te positioneren ten opzichte van elkaar of binnen specifieke grenzen.

## Bewerkingen

- [Uitlijnen](align.md) - Lijn objecten langs een willekeurige as op elkaar uit
- [Dubbele extrusie uitlijnen](dual-extrusion-align.md) - Lijn objecten uit op hun gedeelde modelleerposities
- [Passend maken aan grenzen](fit-to-bounds.md) - Schaal een object zodat het binnen een opgegeven begrenzingsvak past
- [Passend maken aan cilinder](fit-to-cylinder.md) - Schaal een object zodat het binnen een opgegeven cilinder past
