# Transformeren-bewerkingen
<!-- AUTO_IMAGE: type=toolbar_icons group=Transform -->
![Transform toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Transform.png)

Transformeren-bewerkingen wijzigen de positie, oriëntatie en grootte van objecten zonder de geometrie ervan te veranderen.

## Bewerkingen

- [Verplaatsen](translate.md) - Verplaats een object met een specifieke offset in X, Y of Z
- [Roteren](rotate.md) - Roteer een object om een as over een opgegeven hoek
- [Schalen](scale.md) - Wijzig de grootte van een object met opties voor uniform schalen of schalen per as
- [Spiegelen](mirror.md) - Maak een gespiegelde kopie van een object over een as
