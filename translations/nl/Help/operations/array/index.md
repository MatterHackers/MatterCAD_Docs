# Reeksbewerkingen
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Reeks maakt meerdere kopieën van een object die in een patroon worden gerangschikt. Dit is handig voor het maken van herhalende elementen zoals boutgaten, hekpalen, tandwieltanden of decoratieve elementen.

De bewerking Reeks ondersteunt vier modi — Lineair, Radiaal, Curve en Transformeren — allemaal in één gereedschap.
