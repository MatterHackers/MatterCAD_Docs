# Hervormen-bewerkingen
<!-- AUTO_IMAGE: type=toolbar_icons group=Reshape -->
![Reshape toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Reshape.png)

Hervormen-bewerkingen vervormen en wijzigen de geometrie van uw objecten, waardoor u organische en complexe vormen kunt maken vanuit eenvoudige vormen.

## Bewerkingen

- [Kromming](curve.md) - Buig een object langs een curve
- [Draaien](twist.md) - Roteer een object geleidelijk over de hoogte
- [Knijpen](pinch.md) - Comprimeer een object naar de middenas toe
- [Radiale knijp](radial-pinch.md) - Knijp een object radiaal rond een as
- [Vlaksnede](plane-cut.md) - Snijd een object met een vlak op een opgegeven hoogte
- [Uithollen](hollow-out.md) - Maak een holle schaal van een massief object
