# Knijpen

Knijpen drukt de achterkant van een object naar binnen, waarbij het effect naar boven toe sterker wordt. Zo ontstaat een taps toelopend of samengeknepen uiterlijk.

<!--  Before and after showing an object being pinched -->
![20260506 155449 paste 20260506 155449](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-155449-paste-20260506-155449.jpg)

## Gebruik

1. Selecteer een object
2. Pas de bewerking **Knijpen** toe via het menu Hervormen
3. Pas het knijppercentage aan

## Parameters

- **Achterverhouding** - Hoever de achterkant van het onderdeel naar binnen wordt geknepen (0-300%, standaard: 50%). Hogere waarden = meer compressie

## Tips

- Knijpen werkt van achter naar voren en drukt de achterzijde van het object samen
- Gebruik dit om taps toelopende, versmallende vormen te maken van rechthoekige of cilindrische objecten
- Gebruik voor radiale (rondom) compressie in plaats daarvan [Radiale knijp](radial-pinch.md)
