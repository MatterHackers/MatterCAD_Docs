# Ringpad

Een 2D-ringvorm -- een cirkel met een cirkelvormig gat in het midden. Gebruik dit met [Lineaire extrusie](../operations/path/linear-extrude.md) om buis- of ringvormen te maken.

<!-- Screenshot of a Ring Path on the workspace -->
![20260506 080211 paste 20260506 080211](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080211-paste-20260506-080211.jpg)

## Parameters

- **Buitendiameter** - De buitendiameter van de ring
- **Binnendiameter** - De diameter van het gat in het midden

## Tips

- De wanddikte van de ring is (Buitendiameter - Binnendiameter) / 2
- Het extruderen van een Ringpad levert een buis op die vergelijkbaar is met de primitieve [Ring](../primitives/ring.md)

## Gerelateerd

- [Cirkelpad](circle-path.md) - Een massieve cirkel (zonder gat)
- [Ring](../primitives/ring.md) - Een kant-en-klare 3D-buisvorm
- [Lineaire extrusie](../operations/path/linear-extrude.md) - Geef paden hoogte
