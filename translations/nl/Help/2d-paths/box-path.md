# Kubuspad

Een rechthoekig 2D-pad. Gebruik dit met [Lineaire extrusie](../operations/path/linear-extrude.md) om kubusvormen te maken, of als basis voor andere padbewerkingen.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parameters

- **Breedte** - De breedte van de rechthoek (standaard: 20mm)
- **Hoogte** - De hoogte van de rechthoek (standaard: 20mm)

## Tips

- Een Kubuspad met Lineaire extrusie levert een vorm op die lijkt op een [Kubus](../primitives/cube.md), maar je kunt vóór het extruderen padbewerkingen toepassen zoals [Opblazen](../operations/path/inflate-path.md) of [Gladmaken](../operations/path/smooth-path.md)
