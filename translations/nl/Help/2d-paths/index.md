# 2D-paden

2D-paden zijn platte vormen die je kunt gebruiken als startpunt voor 3D-objecten. Gebruik [Lineaire extrusie](../operations/path/linear-extrude.md) om een pad hoogte te geven, of [Wentelen](../operations/path/revolve.md) om een pad rond een as te draaien en zo een 3D-vorm te maken.
