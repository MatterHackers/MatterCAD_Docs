# Muisbesturing

Volledig overzicht van de muisbesturing in de 3D-viewport van MatterCAD.

## Navigatie

| Actie | Muisbesturing |
|--------|--------------|
| **Weergave roteren** | Rechtsklikken + slepen |
| **Weergave pannen** | Middelklikken + slepen |
| **Zoomen** | Scrollwiel |

## Alternatieve navigatie

| Actie | Muisbesturing |
|--------|--------------|
| **Weergave roteren** | Ctrl + linksklikken + slepen |
| **Weergave pannen** | Ctrl + Shift + linksklikken + slepen |
| **Zoomen** | Ctrl + Alt + linksklikken + slepen |

## Interactie met objecten

| Actie | Muisbesturing |
|--------|--------------|
| **Object selecteren** | Linksklikken op het object |
| **Meervoudige selectie** | Shift + linksklikken op extra objecten |
| **Meervoudige selectie** | Ctrl + linksklikken op extra objecten |
| **Alles deselecteren** | Linksklikken op een lege plek |
| **Selectiekader slepen** | Linksklikken + slepen op een lege plek |
| **Object verplaatsen** | Linksklikken + slepen op het geselecteerde object |
| **Contextmenu** | Rechtsklikken op het object |

## Objectbesturing

Wanneer een object is geselecteerd, verschijnen er interactieve grepen:

| Actie | Besturing |
|--------|---------|
| **Verplaatsen over het bed** | Sleep het object |
| **Omhoog/omlaag verplaatsen** | Sleep de verticale pijl boven het object |
| **Roteren** | Klikken en slepen op een rotatiegreep in de hoek |
| **Schalen** | Klikken en slepen op een schaalgreep in de hoek |

## Tips

- Zoomen met het scrollwiel is gecentreerd op de positie van de muisaanwijzer -- wijs naar het gebied waarop je wilt inzoomen
- De alternatieve besturing (Ctrl + linksklikken) is handig als je geen middelste muisknop hebt of als rechtsklikken onhandig is
- Houd bij het roteren met de hoekgrepen de muisaanwijzer boven de hoekindicatoren om in stappen van 45 graden te klikken
