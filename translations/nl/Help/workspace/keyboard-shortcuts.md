# Sneltoetsen

Snel overzicht van alle sneltoetsen die beschikbaar zijn in MatterCAD.

## Bewerken

| Sneltoets | Actie |
|----------|--------|
| Ctrl + Z | Ongedaan maken |
| Ctrl + Y | Opnieuw uitvoeren |
| Ctrl + Shift + Z | Opnieuw uitvoeren (alternatief) |
| Ctrl + A | Alle objecten selecteren |
| Ctrl + C | Geselecteerde objecten kopiëren |
| Ctrl + X | Geselecteerde objecten knippen |
| Ctrl + V | Objecten plakken |
| Spatie | Selectie wissen |
| Escape | Huidige sleepbewerking annuleren |
| Delete | Geselecteerde objecten verwijderen |

## Weergave

| Sneltoets | Actie |
|----------|--------|
| W | Weergave resetten (alle objecten in de viewport passen) |
| Z | Zoomen naar geselecteerd object |
| Ctrl + Plus (+) | Inzoomen |
| Ctrl + Min (-) | Uitzoomen |
| Pijltoetsen | De weergave roteren |
| Shift + pijltoetsen | De weergave pannen |

## Muisbesturing

| Actie | Besturing |
|--------|---------|
| Weergave roteren | Rechtsklikken + slepen |
| Weergave pannen | Middelklikken + slepen |
| Zoomen | Scrollwiel |
| Object selecteren | Linksklikken op object |
| Meerdere selecteren | Shift + linksklikken of Ctrl + linksklikken |
| Selecteren met selectiekader | Linksklikken + slepen op lege ruimte |
| Contextmenu | Rechtsklikken op object |

## Alternatieve muisbesturing

| Actie | Besturing |
|--------|---------|
| Weergave roteren | Ctrl + linksklikken + slepen |
| Weergave pannen | Ctrl + Shift + linksklikken + slepen |
| Zoomen | Ctrl + Alt + linksklikken + slepen |

## Applicatie

| Sneltoets | Actie |
|----------|--------|
| Ctrl + Shift + T | Laatst gesloten ontwerp opnieuw openen |
| F1 | Help openen |
