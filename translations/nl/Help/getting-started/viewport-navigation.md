# Viewport-navigatie

In de 3D-viewport bekijk je je ontwerpen en werk je ermee. MatterCAD gebruikt een trackball-cameramodel waarmee je vrij om je objecten heen kunt draaien, pannen en zoomen.

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## Muisbesturing

### De weergave roteren

- **Rechtsklikken + slepen** - Draai de camera om je ontwerp heen
- **Ctrl + linksklikken + slepen** - Alternatieve manier om te roteren

### De weergave pannen

- **Middelklikken + slepen** - Schuif de weergave naar links, rechts, boven of beneden
- **Ctrl + Shift + linksklikken + slepen** - Alternatieve manier om te pannen

### In- en uitzoomen

- **Scrollwiel** - Scroll omhoog om in te zoomen, scroll omlaag om uit te zoomen
- **Ctrl + Alt + linksklikken + slepen** - Alternatieve manier om te zoomen

## Toetsenbordbesturing

### Sneltoetsen voor de weergave

- **W** - Reset de weergave zodat alle objecten in de viewport passen
- **Z** - Zoom naar het momenteel geselecteerde object

### Navigeren met de pijltoetsen

- **Pijltoetsen** - Roteer de weergave
- **Shift + pijltoetsen** - Pan de weergave

### Sneltoetsen voor zoomen

- **Ctrl + plus (+)** - Inzoomen
- **Ctrl + min (-)** - Uitzoomen

## Tips

- Als je je model uit het oog verliest, druk je op **W** om de weergave te resetten en alles weer in beeld te brengen
- Gebruik **Z** nadat je een object hebt geselecteerd om er snel op te focussen
- Het zoomen met het scrollwiel is gecentreerd op de positie van je muiscursor, dus wijs naar het gebied waarop je wilt inzoomen
- Je kunt roteren en pannen combineren om je ontwerp vanuit elke hoek te bekijken
