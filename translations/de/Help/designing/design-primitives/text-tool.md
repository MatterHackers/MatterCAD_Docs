 - **Name:** Geben Sie den Text ein, der angezeigt werden soll
 - **Punktgröße:** Legen Sie die Größe der Schriftart fest. Diese ist maßgenau, wenn sie in derselben Größe wie bei einem 2D-Drucker gedruckt wird.
 - **Höhe:** Legen Sie die Höhe fest, bis zu der der Text reichen soll
 - **Schriftart:** Wählen Sie die gewünschte Schriftart aus
