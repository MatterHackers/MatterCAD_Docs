Mit dem Image Converter können Sie ganz einfach Bauteile aus Bildern erstellen

### Image Converter hinzufügen
- Ziehen Sie den Image Converter aus der Seitenleiste auf das Druckbett
- Ändern Sie das verwendete Bild, indem Sie auf 'Change' klicken  
![Image Converter](https://www.matterhackers.com/r/zrXG9u)
### Höhe ändern
- Sobald sich ein Bild auf dem Druckbett befindet, können Sie dessen Höhe ändern  
![Change Height](https://www.matterhackers.com/r/MOtISv)
### Nach neuen Bildern suchen
- Der Image Converter kann Ihnen auch dabei helfen, bei Google nach Bildern zu suchen, die Sie verwenden möchten (stellen Sie sicher, dass Sie die Rechte für jedes verwendete Bild besitzen).  
![Search Image](https://www.matterhackers.com/r/p3lA0F)
### Eine Basis hinzufügen
- Sobald Sie das gewünschte Bild haben, können Sie Ihrer Kreation problemlos eine Basis hinzufügen.  
![Add Base](https://www.matterhackers.com/r/LBiZnR)
### Bilder können auch direkt verwendet werden
- Sie können Bilder auch direkt auf das Druckbett ziehen und mit den Werkzeugen aus dem Rechtsklick-Menü alle Funktionen des Image Converters (und mehr) nutzen.

Probieren Sie es aus und haben Sie Spaß – die einzige Grenze ist Ihre Vorstellungskraft
