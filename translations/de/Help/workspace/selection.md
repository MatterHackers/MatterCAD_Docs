# Auswahl

Das Auswählen von Objekten ist grundlegend für das Arbeiten in MatterCAD. Sie müssen Objekte auswählen, bevor Sie sie verschieben, ändern oder Operationen auf sie anwenden können.

<!--  Screenshot showing multiple selected objects with selection highlights -->
![20260318 192323 paste 20260318 192323](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192323-paste-20260318-192323.jpg)


## Einzelauswahl

- **Linksklick auf ein Objekt** wählt es aus. Das zuvor ausgewählte Objekt wird abgewählt.
- **Linksklick auf eine leere Fläche** hebt die gesamte Auswahl auf.

## Mehrfachauswahl

- **Umschalt + Linksklick** auf weitere Objekte fügt diese Ihrer Auswahl hinzu
- **Strg + Linksklick** fügt Objekte ebenfalls Ihrer Auswahl hinzu
- **Strg + A** wählt alle Objekte in der Szene aus

## Auswahlrahmen

Klicken und ziehen Sie auf einer leeren Fläche des Ansichtsfensters, um ein Auswahlrechteck aufzuziehen. Alle Objekte innerhalb des Rechtecks werden ausgewählt.

## Auswahl aufheben

- **Linksklick auf eine leere Fläche** hebt die Auswahl auf
- **Leertaste** hebt die Auswahl auf
- **Escape** bricht einen Ziehvorgang ab

## Arbeiten mit Auswahlen

Sobald Objekte ausgewählt sind:

- **Verschieben** Sie sie durch Ziehen im Ansichtsfenster
- **Wenden Sie Operationen an** über die Symbolleiste (Boolesche Operationen, Transformieren, Array usw.)
- **Bearbeiten Sie Eigenschaften** im Eigenschaften-Panel (wenn ein einzelnes Objekt ausgewählt ist)
- **Rechtsklick** öffnet das Kontextmenü mit den verfügbaren Aktionen

## Tipps

- Wenn mehrere Objekte ausgewählt sind, werden sie für Operationen vorübergehend gruppiert. Das Eigenschaften-Panel zeigt die gemeinsamen Eigenschaften an.
- Verwenden Sie den Designbaum, um Objekte auszuwählen, die im Ansichtsfenster schwer anzuklicken sind – ein Klick auf einen Eintrag im Baum wählt das Objekt in der Ansicht aus.
