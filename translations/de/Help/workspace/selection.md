# Auswahl

Das Auswählen von Objekten ist grundlegend für die Arbeit in MatterCAD. Sie müssen Objekte auswählen, bevor Sie sie verschieben, ändern oder Operationen auf sie anwenden können.

<!--  Screenshot showing multiple selected objects with selection highlights -->
![20260318 192323 paste 20260318 192323](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192323-paste-20260318-192323.jpg)


## Einzelauswahl

- **Linksklick auf ein Objekt**, um es auszuwählen. Das zuvor ausgewählte Objekt wird abgewählt.
- **Linksklick auf eine leere Fläche**, um die Auswahl aufzuheben.

## Mehrfachauswahl

- **Umschalt + Linksklick** auf weitere Objekte, um sie zur Auswahl hinzuzufügen
- **Strg + Linksklick** fügt Objekte ebenfalls zur Auswahl hinzu
- **Strg + A** wählt alle Objekte in der Szene aus

## Gummiband-Auswahl

Klicken und ziehen Sie auf einer leeren Fläche des Ansichtsfensters, um ein Auswahlrechteck aufzuziehen. Alle Objekte innerhalb des Rechtecks werden ausgewählt.

## Auswahl löschen

- **Linksklick auf eine leere Fläche** löscht die Auswahl
- **Leertaste** löscht die Auswahl
- **Escape** bricht einen Ziehvorgang ab

## Arbeiten mit Auswahlen

Sobald Objekte ausgewählt sind:

- **Verschieben** Sie sie durch Ziehen im Ansichtsfenster
- **Wenden Sie Operationen an** über die Werkzeugleiste (Boolesch, Transformieren, Array usw.)
- **Bearbeiten Sie Eigenschaften** im Bedienfeld **Eigenschaften** (wenn ein einzelnes Objekt ausgewählt ist)
- **Rechtsklick**, um das Kontextmenü mit den verfügbaren Aktionen zu öffnen

## Tipps

- Wenn mehrere Objekte ausgewählt sind, werden sie für Operationen vorübergehend gruppiert. Das Bedienfeld **Eigenschaften** zeigt die gemeinsamen Eigenschaften an.
- Verwenden Sie den Konstruktionsbaum, um Objekte auszuwählen, die im Ansichtsfenster schwer anzuklicken sind – ein Klick auf einen Eintrag im Baum wählt ihn in der Ansicht aus.
