# Komponenten

Komponenten sind wiederverwendbare, parametrisierte Gruppen von Objekten. Wenn Sie eine Komponente erstellen, wird sie zu einer eigenständigen Einheit, die Sie mehrfach in Ihren Entwurf einfügen können. Beim Bearbeiten der Komponente werden alle Instanzen aktualisiert.

## Verwendung

### Eine Komponente erstellen

1. Wählen Sie ein oder mehrere Objekte aus
2. Klicken Sie mit der rechten Maustaste und wählen Sie **Komponente erstellen** (oder verwenden Sie das Menü)
3. Die ausgewählten Objekte werden in einem Komponenten-Container zusammengefasst

### Eine Komponente bearbeiten

1. Wählen Sie die Komponente aus
2. Die freigegebenen Parameter der Komponente erscheinen im Eigenschaften-Panel
3. Ändern Sie die Parameter, um die Form der Komponente anzupassen

## Tipps

- Komponenten eignen sich hervorragend, um wiederverwendbare Bausteine für komplexe Entwürfe zu erstellen
- Parameteränderungen sind nicht-destruktiv und können jederzeit angepasst werden
- Komponenten helfen dabei, komplexe Entwürfe zu strukturieren, indem zusammengehörige Objekte gruppiert werden
- Verwenden Sie Komponenten für Teile, die Sie mehrfach mit leichten Abweichungen platzieren müssen
