# Komponenten

Komponenten sind wiederverwendbare, parametrisierte Gruppen von Objekten. Wenn Sie eine Komponente erstellen, wird sie zu einer in sich geschlossenen Einheit, die Sie mehrfach in Ihrem Entwurf einfügen können; beim Bearbeiten der Komponente werden alle Instanzen aktualisiert.

## Verwendung

### Eine Komponente erstellen

1. Wählen Sie ein oder mehrere Objekte aus
2. Klicken Sie mit der rechten Maustaste und wählen Sie **Komponente erstellen** (oder verwenden Sie das Menü)
3. Die ausgewählten Objekte werden in einen Komponentencontainer eingeschlossen

### Eine Komponente bearbeiten

1. Wählen Sie die Komponente aus
2. Die freigegebenen Parameter der Komponente erscheinen im Bereich **Eigenschaften**
3. Ändern Sie die Parameter, um die Form der Komponente anzupassen

## Tipps

- Komponenten eignen sich hervorragend, um wiederverwendbare Bausteine in komplexen Entwürfen zu erstellen
- Parameteränderungen sind nicht-destruktiv und können jederzeit angepasst werden
- Komponenten helfen dabei, komplexe Entwürfe durch das Gruppieren zusammengehöriger Objekte zu organisieren
- Verwenden Sie Komponenten für Teile, die Sie mehrfach mit leichten Variationen platzieren müssen
