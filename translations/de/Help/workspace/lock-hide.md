# Sperren und Ausblenden

Mit Sperren und Ausblenden steuern Sie, welche Objekte in Ihrer Konstruktion ausgewählt werden können und welche sichtbar sind. Diese Funktionen helfen Ihnen, effizienter an komplexen Konstruktionen zu arbeiten, indem sie versehentliche Änderungen verhindern und die visuelle Überladung verringern.

## Sperren
![20260318 193003 paste 20260318 193003](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-193003-paste-20260318-193003.jpg)


Das Sperren eines Objekts verhindert, dass es im Ansichtsfenster ausgewählt oder verschoben werden kann. Das Objekt bleibt sichtbar, kann aber nicht versehentlich geändert werden.

- Klicken Sie im Konstruktionsbaum auf das **Schloss-Symbol** neben einem Objekt, um dessen Sperrstatus umzuschalten
- Gesperrte Objekte werden weiterhin bei booleschen Operationen und anderen Berechnungen berücksichtigt

## Ausblenden

![20260318 192834 paste 20260318 192834](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192834-paste-20260318-192834.jpg)

Durch das Ausblenden wird ein Objekt im Ansichtsfenster unsichtbar, bleibt aber Teil der Konstruktion. Das Objekt existiert weiterhin und wird bei Operationen berücksichtigt.

- Klicken Sie im Konstruktionsbaum auf das **Augensymbol** neben einem Objekt, um die Sichtbarkeit umzuschalten
- Ausgeblendete Objekte werden weiterhin exportiert, sofern Sie sie nicht entfernen

## Tipps

- Sperren Sie Ihre Basis- oder Referenzobjekte, während Sie an Details arbeiten, um ein versehentliches Verschieben zu vermeiden
- Blenden Sie Objekte aus, die den Bereich verdecken, an dem Sie gerade arbeiten
- Sowohl der Sperr- als auch der Sichtbarkeitsstatus werden mit der Konstruktion gespeichert
- Sie können Objekte im Konstruktionsbaum auch dann sperren und ausblenden, wenn sie sich innerhalb von Gruppen oder Komponenten befinden
