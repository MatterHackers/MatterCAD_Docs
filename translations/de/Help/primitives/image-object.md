# Bildobjekt

Importieren Sie ein Bild und wandeln Sie es in ein 3D-Reliefobjekt um, bei dem die Helligkeitswerte die Höhe jedes Pixels bestimmen. So können Sie Fotografien, Logos und Grafiken in 3D-druckbare Objekte verwandeln.

## Verwendung

1. Fügen Sie einen **Bildkonverter** aus dem Bedienfeld Primitive hinzu, oder ziehen Sie eine Bilddatei direkt in den Arbeitsbereich
2. Wählen oder ändern Sie das Bild über die Eigenschaften
3. Passen Sie die Höhe an, um festzulegen, wie stark die hellen Bereiche angehoben werden

## Parameter

- **Höhe** – Wie hoch die erhabenen Bereiche des Bildes sind
- Die Bildvorschau wird im Bedienfeld Eigenschaften angezeigt

## Tipps

- Kontrastreiche Bilder mit klaren Formen eignen sich am besten
- Sie können Bilder direkt von Ihrem Desktop in den MatterCAD-Arbeitsbereich ziehen
- Nutzen Sie die Werkzeuge im Überlaufmenü eines importierten Bildes für weitere Umwandlungsoptionen
- Für pfadbasierte Umrisse aus Bildern siehe [Bild zu Pfad](../operations/image/image-to-path.md)
- Für hinterleuchtete Bilddarstellungen siehe [Lithophanie](../operations/image/lithophane.md)
- Fügen Sie eine Basis hinzu, indem Sie das Bildobjekt mit einem [Würfel](cube.md) kombinieren

## Verwandte Themen

- [Bild zu Pfad](../operations/image/image-to-path.md) – Bildumrisse als 2D-Pfade nachzeichnen
- [Lithophanie](../operations/image/lithophane.md) – Bilder erstellen, die bei Hinterleuchtung sichtbar werden
- [SVG-Objekt](svg-object.md) – Vektorgrafiken importieren
