# Ringpfad

Eine 2D-Ringform – ein Kreis mit einer kreisförmigen Bohrung in der Mitte. Verwenden Sie sie zusammen mit [Lineare Extrusion](../operations/path/linear-extrude.md), um Rohr- oder Scheibenformen zu erzeugen.

<!-- Screenshot of a Ring Path on the workspace -->
![20260506 080211 paste 20260506 080211](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080211-paste-20260506-080211.jpg)

## Parameter

- **Außendurchmesser** – Der Außendurchmesser des Rings
- **Innendurchmesser** – Der Durchmesser der Bohrung in der Mitte

## Tipps

- Die Wandstärke des Rings beträgt (Außendurchmesser – Innendurchmesser) / 2
- Das Extrudieren eines Ringpfads erzeugt ein Rohr, das dem Grundkörper [Ring](../primitives/ring.md) ähnelt

## Verwandte Themen

- [Kreispfad](circle-path.md) – Ein voller Kreis (ohne Bohrung)
- [Ring](../primitives/ring.md) – Eine fertige 3D-Rohrform
- [Lineare Extrusion](../operations/path/linear-extrude.md) – Pfaden eine Höhe geben
