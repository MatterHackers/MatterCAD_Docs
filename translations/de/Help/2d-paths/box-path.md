# Box Path

Ein rechteckiger 2D-Pfad. Verwenden Sie ihn zusammen mit [Linear Extrude](../operations/path/linear-extrude.md), um Quaderformen zu erzeugen, oder als Grundlage für andere Pfadoperationen.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parameter

- **Width** – Die Breite des Rechtecks (Standard: 20 mm)
- **Height** – Die Höhe des Rechtecks (Standard: 20 mm)

## Tipps

- Ein Box Path in Kombination mit Linear Extrude erzeugt eine Form, die einem [Cube](../primitives/cube.md) ähnelt, allerdings können Sie vor dem Extrudieren Pfadoperationen wie [Inflate](../operations/path/inflate-path.md) oder [Smooth](../operations/path/smooth-path.md) anwenden

## Verwandte Themen

- [Circle Path](circle-path.md) – Ein kreisförmiger 2D-Pfad
- [Star Path](star-path.md) – Ein sternförmiger 2D-Pfad
- [Linear Extrude](../operations/path/linear-extrude.md) – Verleiht Pfaden Höhe
