# Box-Pfad

Ein rechteckiger 2D-Pfad. Verwenden Sie ihn mit [Linear extrudieren](../operations/path/linear-extrude.md), um Boxformen zu erzeugen, oder als Grundlage für andere Pfadoperationen.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parameter

- **Breite** – Die Breite des Rechtecks (Standard: 20mm)
- **Höhe** – Die Höhe des Rechtecks (Standard: 20mm)

## Tipps

- Ein Box-Pfad zusammen mit Linear extrudieren erzeugt eine Form ähnlich einem [Würfel](../primitives/cube.md), allerdings können Sie vor dem Extrudieren Pfadoperationen wie [Aufblasen](../operations/path/inflate-path.md) oder [Glätten](../operations/path/smooth-path.md) anwenden

## Verwandte Themen

- [Kreis-Pfad](circle-path.md) – Ein kreisförmiger 2D-Pfad
- [Stern-Pfad](star-path.md) – Ein sternförmiger 2D-Pfad
- [Linear extrudieren](../operations/path/linear-extrude.md) – Pfaden Höhe geben
