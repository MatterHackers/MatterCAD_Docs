# 2D-Pfade

2D-Pfade sind flache Formen, die Sie als Ausgangspunkt für 3D-Objekte verwenden können. Verwenden Sie [Linear extrudieren](../operations/path/linear-extrude.md), um einem Pfad Höhe zu geben, oder [Rotieren](../operations/path/revolve.md), um einen Pfad um eine Achse zu drehen und so eine 3D-Form zu erzeugen.

## Verfügbare Pfade

- [Kreis-Pfad](circle-path.md) – Eine kreisförmige 2D-Kontur
- [Box-Pfad](box-path.md) – Eine rechteckige 2D-Kontur
- [Ring-Pfad](ring-path.md) – Ein 2D-Ring (Kreis mit Loch)
- [Stern-Pfad](star-path.md) – Eine sternförmige 2D-Kontur mit einstellbarer Zackenanzahl
- [Benutzerdefinierter Pfad](custom-path.md) – Zeichnen Sie Ihren eigenen 2D-Pfad mit Kontrollpunkten
