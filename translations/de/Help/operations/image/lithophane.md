# Lithophanie

Eine Lithophanie ist eine dünne 3D-Platte, in der ein Bild als variierende Materialstärke codiert ist. Bei Hinterleuchtung lassen die dünneren Bereiche mehr Licht durch und geben so das Bild wieder. Das ergibt eine wunderschöne Möglichkeit, Fotografien und Kunstwerke zu präsentieren.

![20260324 080310 paste 20260324 080310](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080310-paste-20260324-080310.jpg)


## Verwendung

1. Importieren Sie ein Bild oder wählen Sie ein vorhandenes Bildobjekt aus
2. Wenden Sie die Operation **Lithophanie** an
3. Passen Sie Auflösung und Abmessungen an
4. Drucken Sie das Ergebnis in einem hellen Material und platzieren Sie es vor einer Lichtquelle

## Parameter

- **Pixel pro mm** – Auflösung der Lithophanie (Standard: 1,5, Bereich: 0,5–3). Höhere Werte erfassen mehr Details, erzeugen aber größere Dateien
- **Höhe** – Maximale Dicke der Lithophanie-Platte (Standard: 2,5 mm, Bereich: 0,5–3 mm)
- **Breite** – Gesamtbreite der Lithophanie in Pixeln (Standard: 150)
- **Invertieren** – Kehrt die Hell-Dunkel-Zuordnung um (Standard: ein). Wird für eine korrekte Darstellung bei Hinterleuchtung normalerweise aktiviert gelassen

## Tipps

- Drucken Sie in weißem oder hellem Material, um die besten Ergebnisse zu erzielen
- Eine Höhe von 2–3 mm eignet sich für die meisten Lithophanien
- Höhere Werte für Pixel pro mm erfassen mehr Details, erhöhen aber Druckzeit und Dateigröße
- Montieren Sie den fertigen Druck für beste Sichtbarkeit in einem Rahmen mit LED-Hinterleuchtung
- Porträtfotos mit gutem Kontrast eignen sich besonders gut
