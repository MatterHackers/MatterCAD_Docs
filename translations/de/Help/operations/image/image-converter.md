# Bildkonverter

Der Bildkonverter wandelt ein Rasterbild in ein 3D-Relief um, bei dem die Pixelhelligkeit die Höhe bestimmt. Helle Bereiche werden erhaben, dunkle Bereiche werden flach (oder umgekehrt).

![20260323 210414 paste 20260323 210414](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210414-paste-20260323-210414.jpg)


## Verwendung

1. Fügen Sie einen Bildkonverter aus dem Panel Primitive hinzu, oder ziehen Sie eine Bilddatei in den Arbeitsbereich
2. Das Bild wird in eine 3D-Höhenkarte umgewandelt
3. Passen Sie die Höhe und weitere Parameter an

## Tipps

- Kontrastreiche Bilder mit klaren Formen liefern die besten Ergebnisse
- Um Bildkonturen als flache Pfade statt als Höhenkarten nachzuzeichnen, verwenden Sie [Bild zu Pfad](image-to-path.md)
- Für hinterleuchtete Bilddarstellungen verwenden Sie [Lithophanie](lithophane.md)
- Sie können Bilder direkt von Ihrem Desktop in den Arbeitsbereich ziehen
- Fügen Sie eine Basis hinzu, indem Sie das Bildrelief mit einem [Würfel](../../primitives/cube.md) kombinieren

## Verwandte Themen

- [Bild zu Pfad](image-to-path.md) – Konturen nachzeichnen, statt eine Höhenkarte zu erzeugen
- [Lithophanie](lithophane.md) – Hinterleuchtete Bilddarstellungen erstellen
- [Bildobjekt](../../primitives/image-object.md) – Die Primitiv-Variante des Bildimports
