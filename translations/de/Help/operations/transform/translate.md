# Verschieben

Mit „Verschieben“ bewegen Sie ein Objekt um eine bestimmte Distanz entlang der X-, Y- und/oder Z-Achse. Anders als beim Ziehen eines Objekts mit der Maus können Sie beim Verschieben exakte Versatzwerte eingeben.

## Anwendung

1. Wählen Sie ein Objekt aus
2. Wenden Sie die Operation **Verschieben** aus dem Menü „Transformieren“ an
3. Geben Sie im Eigenschaften-Bereich die gewünschten Versatzwerte für X, Y und Z ein

## Parameter

- **X, Y, Z** (Verschiebung) – Die Distanz, um die das Objekt entlang der jeweiligen Achse bewegt wird, in Millimetern. Unterstützt [Ausdrücke](../../workspace/expressions.md) für berechnete Werte.

## Tipps

- Verwenden Sie „Verschieben“, wenn Sie eine präzise, wiederholbare Positionierung benötigen, die Sie später anpassen können
- Die Verschiebungswerte beziehen sich auf die aktuelle Position des Objekts – die Eingabe von 10 für X bewegt es von seiner aktuellen Position aus um 10 mm nach rechts
- Für eine schnelle Neupositionierung können Sie Objekte auch direkt im Ansichtsfenster ziehen. Siehe [Objekte bearbeiten](../../getting-started/editing-objects.md)
