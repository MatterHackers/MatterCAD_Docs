# Transformieren-Operationen
<!-- AUTO_IMAGE: type=toolbar_icons group=Transform -->
![Transform toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Transform.png)

Transformieren-Operationen ändern Position, Ausrichtung und Größe von Objekten, ohne deren Geometrie zu verändern.

## Operationen

- [Verschieben](translate.md) – Ein Objekt um einen bestimmten Versatz in X, Y oder Z verschieben
- [Drehen](rotate.md) – Ein Objekt um eine Achse um einen angegebenen Winkel drehen
- [Skalieren](scale.md) – Die Größe eines Objekts ändern, mit Optionen für gleichmäßiges oder achsenweises Skalieren
- [Spiegeln](mirror.md) – Eine gespiegelte Kopie eines Objekts über eine Achse erstellen
