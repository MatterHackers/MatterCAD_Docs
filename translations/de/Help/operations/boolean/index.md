# Boolesche Operationen
<!-- AUTO_IMAGE: type=toolbar_icons group=Merge -->
![Merge toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Merge.png)

Mit booleschen Operationen erstellen Sie komplexe Formen, indem Sie einfachere miteinander kombinieren. Wählen Sie zwei oder mehr Objekte aus und wenden Sie eine boolesche Operation an, um sie zu vereinigen, voneinander abzuziehen oder ihre Überschneidung zu ermitteln.

Alle vier Operationen werden von einem einzigen Boolean-Objekt ausgeführt. Die untenstehenden Symbolleisten-Schaltflächen legen lediglich vor, mit welcher Operation es startet; Sie können sie anschließend in der Symbolreihe **Operation** oben im Eigenschaften-Panel ändern.

## Operationen

- [Vereinigen](combine.md) - Mehrere Objekte zu einer einzigen massiven Form zusammenführen
- [Subtrahieren](subtract.md) - Eine Form aus einer anderen ausschneiden
- [Schnittmenge](intersect.md) - Nur das Volumen behalten, in dem sich die Objekte überschneiden
- [Subtrahieren und Ersetzen](subtract-and-replace.md) - Eine Form von einer anderen abziehen und den ausgeschnittenen Bereich ersetzen
