# Boolesche Operationen
<!-- AUTO_IMAGE: type=toolbar_icons group=Merge -->
![Merge toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Merge.png)

Mit booleschen Operationen erstellen Sie komplexe Formen, indem Sie einfachere Formen kombinieren. Wählen Sie zwei oder mehr Objekte aus und wenden Sie eine boolesche Operation an, um sie zusammenzuführen, auszuschneiden oder ihre Überlappung zu ermitteln.

Alle vier Operationen werden von einem booleschen Objekt ausgeführt. Die Schaltflächen in der Symbolleiste legen lediglich vorab fest, mit welcher Operation begonnen wird; Sie können sie anschließend über die Symbolreihe **Operation** oben im Bedienfeld Eigenschaften ändern.

## Operationen

- [Vereinen](combine.md) – Mehrere Objekte zu einer einzigen festen Form zusammenführen
- [Subtrahieren](subtract.md) – Eine Form aus einer anderen ausschneiden
- [Verschneiden](intersect.md) – Nur das Volumen behalten, in dem sich die Objekte überlappen
- [Subtrahieren & Ersetzen](subtract-and-replace.md) – Eine Form von einer anderen subtrahieren und den ausgeschnittenen Bereich ersetzen
