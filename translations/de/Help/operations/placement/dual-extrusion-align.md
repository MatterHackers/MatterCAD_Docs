# Doppelextruder-Ausrichtung

![20260506 160531 paste 20260506 160531](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-160531-paste-20260506-160531.jpg)


Die Doppelextruder-Ausrichtung positioniert zwei oder mehr ausgewählte Objekte so neu, dass ihre Mittelpunkte am gemeinsamen Modellierungsursprung ausgerichtet werden — also an der Position, die sie relativ zueinander für den Doppelextruder-Druck einnehmen sollten.

## Verwendung

1. Wählen Sie zwei oder mehr Objekte aus
2. Wenden Sie **Doppelextruder-Ausrichtung** aus dem Menü Platzierung an

## Wann anzuwenden

Verwenden Sie diese Operation, wenn Sie Teile haben, die gemeinsam auf einem Doppelextruder-Drucker gedruckt werden sollen, aber aus ihren relativen Positionen verschoben wurden. Die Doppelextruder-Ausrichtung stellt ihren vorgesehenen gemeinsamen Koordinatenraum wieder her.

## Verwandte Themen

- [Ausrichten](align.md) - Objekte entlang einer beliebigen Achse relativ zueinander positionieren
- [An Grenzen anpassen](fit-to-bounds.md) - Ein Objekt so skalieren, dass es in eine rechteckige Begrenzung passt
