# Platzierungsoperationen
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Platzierungsoperationen helfen Ihnen, Objekte präzise zueinander oder innerhalb bestimmter Grenzen zu positionieren.

## Operationen

- [Ausrichten](align.md) - Objekte entlang einer beliebigen Achse aneinander ausrichten
- [Doppelextruder-Ausrichtung](dual-extrusion-align.md) - Objekte an ihren gemeinsamen Modellierpositionen ausrichten
- [An Grenzen anpassen](fit-to-bounds.md) - Ein Objekt so skalieren, dass es in einen angegebenen Begrenzungsrahmen passt
- [An Zylinder anpassen](fit-to-cylinder.md) - Ein Objekt so skalieren, dass es in einen angegebenen Zylinder passt
