# Randpfad

Randpfad fügt einen Randversatz um einen vorhandenen Pfad hinzu und erzeugt so eine größere Version der Form, die das Original umschließt.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Verwendung

1. Wählen Sie einen 2D-Pfad aus
2. Wenden Sie **Randpfad** aus dem Menü der Pfadoperationen an
3. Passen Sie die Randbreite an

## Tipps

- Verwenden Sie dies, um einen Rand oder Abstand um Formen zu erzeugen
- Kombinieren Sie es mit dem ursprünglichen Pfad und [Subtrahieren](../boolean/subtract.md), um Rahmenformen zu erstellen
- Ähnlich wie [Pfad aufweiten](inflate-path.md), jedoch speziell für die Erzeugung von Rändern ausgelegt

## Verwandte Themen

- [Pfad aufweiten](inflate-path.md) – Einen Pfad nach außen erweitern
- [Pfadkontur](outline-path.md) – Aus einem gefüllten Pfad eine Kontur erzeugen
- [Lineare Extrusion](linear-extrude.md) – Dem umrandeten Pfad Höhe geben
