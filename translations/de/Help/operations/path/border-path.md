# Randpfad

Randpfad fügt einen Randversatz um einen vorhandenen Pfad hinzu und erzeugt so eine größere Version der Form, die das Original umgibt.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Verwendung

1. Wählen Sie einen 2D-Pfad aus
2. Wenden Sie **Randpfad** aus dem Menü der Pfad-Operationen an
3. Passen Sie die Randbreite an

## Tipps

- Damit erzeugen Sie einen Rand oder Abstand um Formen herum
- Kombinieren Sie den ursprünglichen Pfad mit [Subtrahieren](../boolean/subtract.md), um Rahmenformen zu erstellen
- Ähnlich wie [Pfad aufblasen](inflate-path.md), jedoch speziell für die Randerzeugung ausgelegt

## Verwandte Themen

- [Pfad aufblasen](inflate-path.md) – Einen Pfad nach außen erweitern
- [Umrisspfad](outline-path.md) – Einen Umriss aus einem gefüllten Pfad erstellen
- [Linear extrudieren](linear-extrude.md) – Dem umrandeten Pfad Höhe geben
