# Musekontroller

Komplet oversigt over musekontroller i MatterCAD's 3D-viewport.

## Navigation

| Handling | Musekontrol |
|--------|--------------|
| **Roter visning** | Højreklik + træk |
| **Panorer visning** | Midterklik + træk |
| **Zoom** | Rullehjul |

## Alternativ navigation

| Handling | Musekontrol |
|--------|--------------|
| **Roter visning** | Ctrl + venstreklik + træk |
| **Panorer visning** | Ctrl + Shift + venstreklik + træk |
| **Zoom** | Ctrl + Alt + venstreklik + træk |

## Interaktion med objekter

| Handling | Musekontrol |
|--------|--------------|
| **Vælg objekt** | Venstreklik på objektet |
| **Vælg flere** | Shift + venstreklik på yderligere objekter |
| **Vælg flere** | Ctrl + venstreklik på yderligere objekter |
| **Fravælg alle** | Venstreklik på tomt område |
| **Rammemarkering** | Venstreklik + træk på tomt område |
| **Flyt objekt** | Venstreklik + træk på det valgte objekt |
| **Kontekstmenu** | Højreklik på objektet |

## Objektkontroller

Når et objekt er valgt, vises interaktive kontroller:

| Handling | Kontrol |
|--------|---------|
| **Flyt på pladen** | Træk i objektet |
| **Flyt op/ned** | Træk i den lodrette pil over objektet |
| **Roter** | Klik og træk i en rotationskontrol i hjørnet |
| **Skalér** | Klik og træk i en skaleringskontrol i hjørnet |

## Tips

- Zoom med rullehjulet centreres om musemarkørens position -- peg på det område, du vil zoome ind på
- De alternative kontroller (Ctrl + venstreklik) er nyttige, hvis du ikke har en midterste museknap, eller hvis højreklik er upraktisk
- Når du roterer med hjørnekontrollerne, kan du holde musen over vinkelindikatorerne for at låse til trin på 45 grader
