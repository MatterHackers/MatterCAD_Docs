# Tastaturgenveje

Hurtig oversigt over alle tastaturgenveje i MatterCAD.

## Rediger

| Genvej | Handling |
|----------|--------|
| Ctrl + Z | Fortryd |
| Ctrl + Y | Gentag |
| Ctrl + Shift + Z | Gentag (alternativ) |
| Ctrl + A | Vælg alle objekter |
| Ctrl + C | Kopiér markerede objekter |
| Ctrl + X | Klip markerede objekter |
| Ctrl + V | Indsæt objekter |
| Mellemrum | Ryd markering |
| Escape | Annuller den aktuelle trækhandling |
| Delete | Slet markerede objekter |

## Vis

| Genvej | Handling |
|----------|--------|
| W | Nulstil visningen (tilpas alle objekter i viewporten) |
| Z | Zoom ind på det markerede objekt |
| Ctrl + Plus (+) | Zoom ind |
| Ctrl + Minus (-) | Zoom ud |
| Piletaster | Roter visningen |
| Shift + piletaster | Panorer visningen |

## Musekontroller

| Handling | Kontrol |
|--------|---------|
| Roter visningen | Højreklik + træk |
| Panorer visningen | Midterklik + træk |
| Zoom | Rullehjul |
| Vælg objekt | Venstreklik på objektet |
| Multimarkering | Shift + venstreklik eller Ctrl + venstreklik |
| Markeringsramme | Venstreklik + træk på tomt område |
| Kontekstmenu | Højreklik på objektet |

## Alternative musekontroller

| Handling | Kontrol |
|--------|---------|
| Roter visningen | Ctrl + venstreklik + træk |
| Panorer visningen | Ctrl + Shift + venstreklik + træk |
| Zoom | Ctrl + Alt + venstreklik + træk |

## Applikation

| Genvej | Handling |
|----------|--------|
| Ctrl + Shift + T | Genåbn det sidst lukkede design |
| F1 | Åbn Hjælp |
