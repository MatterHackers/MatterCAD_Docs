# Bibliotek

Biblioteket lader dig organisere, gemme og dele dine 3D-designs. Du kan gennemse lokale filer, tilgå skylagring og dele designs med andre.

## Emner

- [Lokalt bibliotek](local-library.md) - Administrer dine designs, der er gemt på din computer
- [Skybibliotek](cloud-library.md) - Gem og tilgå designs i din MatterHackers-skykonto
- [Deling](sharing.md) - Del designs med andre MatterCAD-brugere
