# Array-handlinger
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Array opretter flere kopier af et objekt arrangeret i et mønster. Det er nyttigt til at skabe gentagne elementer som bolthuller, hegnspæle, tandhjulstænder eller dekorative detaljer.

Array-handlingen understøtter fire tilstande — Lineær, Radial, Kurve og Transformér — alle sammen i ét værktøj.
