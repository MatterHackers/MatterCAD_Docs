# Navigation i viewporten

3D-viewporten er der, hvor du ser og arbejder med dine designs. MatterCAD bruger en trackball-kameramodel, der lader dig frit rotere, panorere og zoome omkring dine objekter.

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## Musekontroller

### Roter visningen

- **Højreklik + træk** - Roter kameraet omkring dit design
- **Ctrl + venstreklik + træk** - Alternativ rotationsmetode

### Panorer visningen

- **Midterklik + træk** - Flyt visningen til venstre, højre, op eller ned
- **Ctrl + Shift + venstreklik + træk** - Alternativ panoreringsmetode

### Zoom ind og ud

- **Rullehjul** - Rul op for at zoome ind, rul ned for at zoome ud
- **Ctrl + Alt + venstreklik + træk** - Alternativ zoommetode

## Tastaturkontroller

### Genveje til visning

- **W** - Nulstil visningen, så alle objekter passer i viewporten
- **Z** - Zoom ind på det aktuelt valgte objekt

### Navigation med piletaster

- **Piletaster** - Roter visningen
- **Shift + piletaster** - Panorer visningen

### Zoomgenveje

- **Ctrl + plus (+)** - Zoom ind
- **Ctrl + minus (-)** - Zoom ud

## Tips

- Hvis du mister din model af syne, skal du trykke på **W** for at nulstille visningen og få alt tilbage i billedet
- Brug **Z**, efter du har valgt et objekt, for hurtigt at fokusere på det
- Zoom med rullehjulet er centreret om musemarkørens position, så peg på det område, du vil zoome ind på
- Du kan kombinere rotation og panorering for at inspicere dit design fra enhver vinkel
