# Engrenage 2D

Un chemin d'engrenage 2D qui crée uniquement le profil de denture sous forme de chemin plat. Utilisez-le avec [Extrusion linéaire](../operations/path/linear-extrude.md) ou [Révolution](../operations/path/revolve.md) pour mieux contrôler la façon dont l'engrenage est transformé en forme 3D.

<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->
![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)

## Utilisation

1. Ajoutez un **Engrenage 2D** depuis les outils mécaniques
2. Configurez les paramètres de denture
3. Appliquez une [Extrusion linéaire](../operations/path/linear-extrude.md) pour lui donner de la hauteur

## Astuces

- Utilisez Engrenage 2D lorsque vous devez combiner un profil d'engrenage avec d'autres opérations de chemin avant l'extrusion
- Pour un engrenage 3D prêt à l'emploi, consultez plutôt [Engrenages](gears.md)
- Les mêmes règles d'engrènement s'appliquent : un Pas circulaire et un Angle de pression identiques pour les engrenages destinés à fonctionner ensemble
