# Pièces mécaniques

MatterCAD inclut des outils spécialisés pour créer des composants mécaniques tels que des engrenages et des fixations filetées.

- [Engrenage 2D](gear-2d.md) - Créez un tracé d'engrenage 2D à utiliser avec l'extrusion ou d'autres opérations sur les tracés
