# Chemins 2D

Les chemins 2D sont des formes planes qui peuvent servir de point de départ à des objets 3D. Utilisez [Extrusion linéaire](../operations/path/linear-extrude.md) pour donner une hauteur à un chemin, ou [Révolution](../operations/path/revolve.md) pour faire tourner un chemin autour d'un axe et créer une forme 3D.

## Chemins disponibles

- [Chemin Cercle](circle-path.md) - Un contour 2D circulaire
- [Chemin Boîte](box-path.md) - Un contour 2D rectangulaire
- [Chemin Anneau](ring-path.md) - Un anneau 2D (cercle percé d'un trou)
- [Chemin Étoile](star-path.md) - Un contour 2D en forme d'étoile avec un nombre de branches configurable
- [Chemin personnalisé](custom-path.md) - Dessinez votre propre chemin 2D à l'aide de points de contrôle
