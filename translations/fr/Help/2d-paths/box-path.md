# Chemin Boîte

Un chemin 2D rectangulaire. À utiliser avec [Extrusion linéaire](../operations/path/linear-extrude.md) pour créer des formes de boîte, ou comme base pour d'autres opérations de chemin.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Paramètres

- **Largeur** - La largeur du rectangle (par défaut : 20mm)
- **Hauteur** - La hauteur du rectangle (par défaut : 20mm)

## Astuces

- Un Chemin Boîte associé à une Extrusion linéaire crée une forme semblable à un [Cube](../primitives/cube.md), mais vous pouvez appliquer des opérations de chemin comme [Dilater](../operations/path/inflate-path.md) ou [Lisser](../operations/path/smooth-path.md) avant l'extrusion
