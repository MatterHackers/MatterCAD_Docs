Depuis votre ordinateur
=======================

![](https://lh3.googleusercontent.com/32sfdux7Fo64mrzY9hHBcWLoc8SKwTKuof6tEntzDbhKG27Y5Ow3NPEuwYGUJ9GR64tVk6h7MRY5T_UUIbi4a1NEeA)  
Cliquez sur le bouton Ouvrir dans la barre d'outils pour ajouter des fichiers depuis votre ordinateur. MatterCAD prend en charge les formats de fichier suivants :

* STL - Format de modèle 3D standard de l'industrie
* AMF - Format avancé prenant en charge les couleurs et les objets multi-matériaux
* OBJ - Format graphique 3D Wavefront (maillages uniquement, sans textures ni données de couleur)
* MCX - Format natif de MatterCAD

Glisser-déposer
---------------

Vous pouvez glisser-déposer des fichiers directement depuis votre bureau ou votre explorateur de fichiers dans MatterCAD.

![](https://lh3.googleusercontent.com/LkdsfkXvR_8jftgAZ2846W_WCuV9qt7C50slNRrB6y8-nE2I8ZqVCuI2ieThVqLyZTFWdnC7y_3p7Lqktmk_pWz5LQ)

Depuis la Bibliothèque
======================

La barre latérale Bibliothèque
------------------------------

![](https://lh3.googleusercontent.com/crGYrE83PyWb-hntQ8d-RhEeoiN_S8OI7uUnCS1oOm-8eMT5ExkDRSYZCr3IiT7Bx42HzrmFcg4yHhrv_GgzmbyfRA)  
Cliquez sur le bouton Ajouter du contenu dans la barre d'outils pour ouvrir le navigateur de bibliothèque. De là, vous pouvez glisser-déposer n'importe quel contenu de la bibliothèque dans votre espace de travail.

![](https://lh3.googleusercontent.com/926cpzNy9wQBIxRHCBUCaUJhIpWdHVp8FRXpr5sC07rIBiIOO_Ryh2PGX6_mW9Ooe4i8TBR5XlejcqL6B0cJupT4)

L'onglet Bibliothèque
---------------------

Dans l'onglet Bibliothèque, vous pouvez faire un clic droit sur n'importe quel objet et sélectionner Ajouter à la scène pour l'importer dans votre espace de travail de conception actuel.

![](https://lh3.googleusercontent.com/nv6037mkmlGpm9M_q5uyaTSnHtFOoXXDxm6niLI1fCXPr2EODWPcbAnP71xGr19npSz2RO1CeLZOvNrFtlUjMLJBpg)
