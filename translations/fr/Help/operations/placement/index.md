# Opérations de placement
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Les opérations de placement vous aident à positionner précisément des objets les uns par rapport aux autres ou à l'intérieur de limites définies.

## Opérations

- [Aligner](align.md) - Alignez des objets les uns sur les autres selon n'importe quel axe
- [Alignement double extrusion](dual-extrusion-align.md) - Alignez des objets sur leurs positions de modélisation communes
- [Ajuster aux limites](fit-to-bounds.md) - Mettez un objet à l'échelle pour l'ajuster dans une boîte englobante définie
- [Ajuster au cylindre](fit-to-cylinder.md) - Mettez un objet à l'échelle pour l'ajuster dans un cylindre défini
