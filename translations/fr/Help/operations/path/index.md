# Opérations de chemin
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

Les opérations de chemin s'appliquent aux chemins 2D pour créer et modifier des formes 3D. Utilisez-les pour extruder, faire une révolution et affiner une géométrie basée sur des chemins.

## Opérations

- [Extrusion linéaire](linear-extrude.md) - Donner de la hauteur à un chemin 2D pour créer un objet 3D
- [Révolution](revolve.md) - Faire tourner un chemin 2D autour d'un axe pour créer un solide de révolution
- [Lisser le chemin](smooth-path.md) - Lisser les courbes d'un chemin
- [Dilater le tracé](inflate-path.md) - Développer un chemin vers l'extérieur
- [Chemin de contour](outline-path.md) - Créer un contour à partir d'un chemin plein
- [Tracé de bordure](border-path.md) - Ajouter un décalage de bordure autour d'un chemin
- [Sélectionner des trajectoires](select-paths.md) - Sélectionner des chemins précis dans des objets complexes à chemins multiples
