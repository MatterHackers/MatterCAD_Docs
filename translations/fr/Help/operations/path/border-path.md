# Tracé de bordure

Tracé de bordure ajoute un décalage de bordure autour d'un chemin existant, créant ainsi une version agrandie de la forme qui entoure l'originale.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Utilisation

1. Sélectionnez un chemin 2D
2. Appliquez **Tracé de bordure** depuis le menu des opérations Chemin
3. Ajustez la largeur de la bordure

## Astuces

- Utilisez cette opération pour créer une marge ou un espacement autour des formes
- Combinez avec le chemin d'origine et [Soustraire](../boolean/subtract.md) pour créer des formes de cadre
- Semblable à [Dilater le tracé](inflate-path.md), mais spécialement conçu pour la génération de bordures
