# Lisser le chemin

Lisser le chemin arrondit les angles et les courbes d'un chemin 2D, créant des formes plus douces et plus organiques à partir d'entrées anguleuses.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Utilisation

1. Sélectionnez un chemin 2D
2. Appliquez **Lisser le chemin** depuis le menu des opérations de Chemin
3. Les angles du chemin sont adoucis en courbes

## Conseils

- Appliquez cette opération avant [Extrusion linéaire](linear-extrude.md) pour créer des formes extrudées aux arêtes douces
- Utilisez-la sur un [Chemin en étoile](../../2d-paths/star-path.md) pour créer une étoile arrondie
- Plusieurs applications de Lisser le chemin augmentent l'effet de lissage
