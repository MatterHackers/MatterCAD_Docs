# Chemin de contour

Chemin de contour crée une version en contour d'un tracé plein, convertissant une forme pleine en son seul anneau de bordure doté d'une épaisseur définie.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Utilisation

1. Sélectionnez un chemin 2D
2. Appliquez **Chemin de contour** depuis le menu des opérations de Chemin
3. Ajustez l'épaisseur du contour

## Astuces

- Utilisez cette opération pour créer des formes de type cadre à partir de tracés pleins
- Combinez-la avec [Extrusion linéaire](linear-extrude.md) pour créer des cadres et des bordures en 3D
- Un [Cercle] (../../2d-paths/circle-path.md) mis en contour équivaut à un [Anneau](../../2d-paths/ring-path.md)
