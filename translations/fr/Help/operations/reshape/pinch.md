# Pincement

Le pincement comprime l'arrière d'un objet vers l'intérieur, l'effet augmentant vers le haut. Cela crée un aspect effilé ou resserré.

<!--  Before and after showing an object being pinched -->
![20260506 155449 paste 20260506 155449](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-155449-paste-20260506-155449.jpg)

## Utilisation

1. Sélectionnez un objet
2. Appliquez l'opération **Pincement** depuis le menu Remodeler
3. Ajustez le pourcentage de pincement

## Paramètres

- **Ratio arrière** - Détermine à quel point l'arrière de la pièce est pincé vers l'intérieur (0-300 %, valeur par défaut : 50 %). Des valeurs plus élevées = davantage de compression

## Conseils

- Le pincement agit de l'arrière vers l'avant, en comprimant la partie arrière de l'objet
- Utilisez-le pour créer des formes effilées qui se rétrécissent à partir d'objets rectangulaires ou cylindriques
- Pour une compression radiale (tout autour), utilisez plutôt [Pincement radial](radial-pinch.md)
