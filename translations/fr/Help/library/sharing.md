# Partager

MatterCAD vous permet de partager vos conceptions avec d'autres utilisateurs grâce aux codes de partage. Il est ainsi facile de collaborer sur des conceptions ou de diffuser votre travail.

![20260323 210309 paste 20260323 210309](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210309-paste-20260323-210309.jpg)


## Partager une conception

1. Faites un clic droit sur une conception dans votre [Bibliothèque cloud](cloud-library.md)
2. Sélectionnez **Partager**
3. Un code de partage est généré : vous pouvez l'envoyer à d'autres personnes

## Recevoir une conception partagée

1. Procurez-vous un code de partage auprès de quelqu'un
2. Utilisez l'option **Utiliser un code de partage** dans la bibliothèque
3. La conception partagée est ajoutée à votre bibliothèque

## Astuces

- Les codes de partage fonctionnent avec les conceptions stockées dans la Bibliothèque cloud
- Le destinataire reçoit une copie de la conception : les modifications qu'il apporte n'affectent pas votre original
- Les codes de partage peuvent être diffusés par n'importe quel canal : e-mail, messagerie, réseaux sociaux, etc.
