# Bibliothèque

La bibliothèque vous permet d'organiser, de stocker et de partager vos conceptions 3D. Vous pouvez parcourir des fichiers locaux, accéder au stockage cloud et partager vos conceptions avec d'autres personnes.

## Rubriques

- [Bibliothèque locale](local-library.md) - Gérez les conceptions stockées sur votre ordinateur
- [Bibliothèque cloud](cloud-library.md) - Stockez et consultez vos conceptions dans votre compte cloud MatterHackers
- [Partager](sharing.md) - Partagez vos conceptions avec d'autres utilisateurs de MatterCAD
