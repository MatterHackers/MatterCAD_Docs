# Bibliothèque cloud

La Bibliothèque cloud stocke vos conceptions en ligne dans votre compte MatterHackers. Cela vous permet d'accéder à vos conceptions depuis n'importe quel ordinateur et de conserver une sauvegarde dans le cloud.

![20260323 210141 paste 20260323 210141](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210141-paste-20260323-210141.jpg)

## Premiers pas

1. Connectez-vous à votre compte MatterHackers depuis le menu de l'application
2. La Bibliothèque cloud apparaît dans votre navigateur de bibliothèque
3. Téléversez des conceptions en les faisant glisser dans le dossier cloud, ou enregistrez-les directement dans le cloud

## Fonctions

- **Accès partout** - Vos conceptions sont disponibles sur tout ordinateur où vous vous connectez
- **Sauvegarde cloud** - Votre travail est stocké en toute sécurité en ligne
- **Organisation en dossiers** - Créez des dossiers pour organiser vos conceptions cloud, tout comme dans la Bibliothèque locale
- **Partage** - Partagez vos conceptions avec d'autres utilisateurs de MatterCAD. Voir [Partage](sharing.md)

## Astuces

- Les conceptions sont synchronisées automatiquement lorsque vous les enregistrez dans la bibliothèque cloud
- Une connexion Internet est nécessaire pour accéder au contenu de la bibliothèque cloud
- Les fichiers volumineux peuvent mettre un moment à être téléversés ou téléchargés
- Conservez vos conceptions importantes à la fois dans la bibliothèque locale et dans la bibliothèque cloud, par redondance
