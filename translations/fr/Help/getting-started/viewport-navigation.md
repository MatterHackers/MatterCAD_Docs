# Navigation dans la vue 3D

La vue 3D est l'endroit où vous visualisez vos conceptions et interagissez avec elles. MatterCAD utilise un modèle de caméra de type trackball qui vous permet d'orbiter, de faire un panoramique et de zoomer librement autour de vos objets.

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## Commandes de la souris

### Pivoter la vue

- **Clic droit + Glisser** - Faire orbiter la caméra autour de votre conception
- **Ctrl + Clic gauche + Glisser** - Autre méthode de rotation

### Panoramique de la vue

- **Clic milieu + Glisser** - Faire glisser la vue vers la gauche, la droite, le haut ou le bas
- **Ctrl + Maj + Clic gauche + Glisser** - Autre méthode de panoramique

### Zoom avant et arrière

- **Molette de défilement** - Faites défiler vers le haut pour un zoom avant, vers le bas pour un zoom arrière
- **Ctrl + Alt + Clic gauche + Glisser** - Autre méthode de zoom

## Commandes du clavier

### Raccourcis d'affichage

- **W** - Réinitialiser la vue pour cadrer tous les objets dans la vue 3D
- **Z** - Zoomer sur l'objet actuellement sélectionné

### Navigation avec les touches fléchées

- **Touches fléchées** - Pivoter la vue
- **Maj + Touches fléchées** - Panoramique de la vue

### Raccourcis de zoom

- **Ctrl + Plus (+)** - Zoom avant
- **Ctrl + Moins (-)** - Zoom arrière

## Astuces

- Si vous perdez votre modèle de vue, appuyez sur **W** pour réinitialiser la vue et tout ramener dans le cadre
- Utilisez **Z** après avoir sélectionné un objet pour vous concentrer rapidement dessus
- Le zoom à la molette est centré sur la position de votre curseur de souris : pointez donc la zone que vous souhaitez agrandir
- Vous pouvez combiner rotation et panoramique pour inspecter votre conception sous n'importe quel angle
