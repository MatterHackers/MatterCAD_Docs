# Composants

Les composants sont des groupes d'objets réutilisables et paramétrés. Lorsque vous créez un composant, celui-ci devient une unité autonome que vous pouvez insérer plusieurs fois dans votre conception, et la modification du composant met à jour toutes ses instances.

## Utilisation

### Créer un composant

1. Sélectionnez un ou plusieurs objets
2. Faites un clic droit et choisissez **Créer un composant** (ou utilisez le menu)
3. Les objets sélectionnés sont regroupés dans un conteneur de composant

### Modifier un composant

1. Sélectionnez le composant
2. Les paramètres exposés du composant apparaissent dans le panneau **Propriétés**
3. Modifiez les paramètres pour changer la forme du composant

## Astuces

- Les composants sont utiles pour créer des blocs de construction réutilisables dans des conceptions complexes
- Les modifications de paramètres sont non destructives et peuvent être ajustées à tout moment
- Les composants aident à organiser les conceptions complexes en regroupant les objets associés
- Utilisez des composants pour les pièces que vous devez placer plusieurs fois avec de légères variations
