# Outil de mesure

L'Outil de mesure vous permet de mesurer les distances entre des points de votre conception. Placez des points de mesure n'importe où dans la fenêtre 3D pour vérifier les dimensions.

<!--  Screenshot showing the Measure Tool with a distance measurement displayed between two points -->
![20260318 192711 paste 20260318 192711](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192711-paste-20260318-192711.jpg)


## Utilisation

1. Ajoutez l'**Outil de mesure** depuis le menu des outils
2. Faites glisser les points de mesure jusqu'aux emplacements entre lesquels vous souhaitez mesurer
3. La distance s'affiche dans la fenêtre

## Conseils

- Utilisez cette fonction pour vérifier les dimensions avant l'exportation en vue d'une impression 3D
- L'Outil de mesure affiche la distance en ligne droite entre les deux points de contrôle
- Vous pouvez laisser l'Outil de mesure dans votre conception pendant que vous travaillez et le supprimer avant l'exportation
