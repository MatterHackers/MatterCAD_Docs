# Sélection

La sélection des objets est fondamentale pour travailler dans MatterCAD. Vous devez sélectionner des objets avant de pouvoir les déplacer, les modifier ou leur appliquer des opérations.

<!--  Screenshot showing multiple selected objects with selection highlights -->
![20260318 192323 paste 20260318 192323](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192323-paste-20260318-192323.jpg)


## Sélection simple

- **Clic gauche sur un objet** pour le sélectionner. L'objet précédemment sélectionné est désélectionné.
- **Clic gauche dans une zone vide** pour tout désélectionner.

## Sélection multiple

- **Maj + clic gauche** sur d'autres objets pour les ajouter à votre sélection
- **Ctrl + clic gauche** ajoute également des objets à votre sélection
- **Ctrl + A** sélectionne tous les objets de la scène

## Sélection par rectangle

Cliquez-glissez dans une zone vide de la fenêtre de visualisation pour tracer un rectangle de sélection. Tous les objets situés à l'intérieur du rectangle sont sélectionnés.

![20260318 192357 paste 20260318 192357](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192357-paste-20260318-192357.jpg)


## Effacer la sélection

- **Clic gauche dans une zone vide** efface la sélection
- **Espace** efface la sélection
- **Échap** annule une opération de glissement

## Travailler avec les sélections

Une fois des objets sélectionnés :

- **Déplacer** : faites-les glisser dans la fenêtre de visualisation
- **Appliquer des opérations** depuis la barre d'outils (booléenne, transformation, réseau, etc.)
- **Modifier les propriétés** dans le panneau Propriétés (lorsqu'un seul objet est sélectionné)
- **Clic droit** pour accéder au menu contextuel avec les actions disponibles

## Astuces

- Lorsque plusieurs objets sont sélectionnés, ils sont temporairement groupés pour les opérations. Le panneau Propriétés affiche les propriétés communes.
- Utilisez l'arbre de conception pour sélectionner les objets difficiles à cliquer dans la fenêtre de visualisation : cliquer sur un élément de l'arbre le sélectionne dans la vue.
