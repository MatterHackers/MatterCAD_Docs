# Commandes de la souris

Référence complète des commandes de la souris dans la fenêtre 3D de MatterCAD.

## Navigation

| Action | Commande de la souris |
|--------|--------------|
| **Pivoter la vue** | Clic droit + Glisser |
| **Panoramique de la vue** | Clic milieu + Glisser |
| **Zoom** | Molette de défilement |

## Navigation alternative

| Action | Commande de la souris |
|--------|--------------|
| **Pivoter la vue** | Ctrl + Clic gauche + Glisser |
| **Panoramique de la vue** | Ctrl + Maj + Clic gauche + Glisser |
| **Zoom** | Ctrl + Alt + Clic gauche + Glisser |

## Interaction avec les objets

| Action | Commande de la souris |
|--------|--------------|
| **Sélectionner un objet** | Clic gauche sur l'objet |
| **Sélection multiple** | Maj + Clic gauche sur les objets supplémentaires |
| **Sélection multiple** | Ctrl + Clic gauche sur les objets supplémentaires |
| **Tout désélectionner** | Clic gauche sur une zone vide |
| **Sélection par rectangle élastique** | Clic gauche + Glisser sur une zone vide |
| **Déplacer un objet** | Clic gauche + Glisser sur l'objet sélectionné |
| **Menu contextuel** | Clic droit sur l'objet |

## Commandes de l'objet

Lorsqu'un objet est sélectionné, des commandes interactives apparaissent :

| Action | Commande |
|--------|---------|
| **Déplacer sur le plateau** | Faire glisser l'objet |
| **Déplacer vers le haut/bas** | Faire glisser la flèche verticale au-dessus de l'objet |
| **Pivoter** | Cliquer-glisser une commande de rotation d'angle |
| **Échelle** | Cliquer-glisser une commande de mise à l'échelle d'angle |

## Astuces

- Le zoom à la molette est centré sur la position du curseur de la souris -- pointez la zone dans laquelle vous souhaitez zoomer
- Les commandes alternatives (Ctrl + Clic gauche) sont utiles si vous n'avez pas de bouton central ou si le clic droit est peu pratique
- Lors d'une rotation avec les commandes d'angle, survolez les indicateurs d'angle pour aligner par incréments de 45 degrés
