# Annuler et Rétablir

MatterCAD conserve un historique complet de vos modifications afin que vous puissiez annuler vos erreurs et rétablir les actions que vous avez annulées.

## Utilisation

- **Ctrl + Z** - Annuler la dernière action
- **Ctrl + Y** ou **Ctrl + Maj + Z** - Rétablir la dernière action annulée
- Vous pouvez aussi utiliser les boutons **Annuler** et **Rétablir** de la barre d'outils

## Ce qui peut être annulé

Toutes les opérations de conception sont enregistrées dans l'historique d'annulation, notamment :

- L'ajout ou la suppression d'objets
- Le déplacement, la rotation et la mise à l'échelle des objets
- L'application d'opérations (booléenne, transformation, remodelage, etc.)
- La modification des paramètres d'un objet
- Le groupement et le dégroupement

## Astuces

- Vous pouvez annuler plusieurs étapes en appuyant plusieurs fois sur Ctrl + Z
- L'historique d'annulation est conservé pour la session en cours. Fermer puis rouvrir une conception démarre un nouvel historique.
- Si vous annulez plusieurs étapes puis effectuez une nouvelle modification, l'historique de rétablissement au-delà de ce point est effacé
