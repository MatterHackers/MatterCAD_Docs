# Raccourcis clavier

Référence rapide de tous les raccourcis clavier disponibles dans MatterCAD.

## Modifier

| Raccourci | Action |
|----------|--------|
| Ctrl + Z | Annuler |
| Ctrl + Y | Rétablir |
| Ctrl + Maj + Z | Rétablir (autre méthode) |
| Ctrl + A | Tout sélectionner |
| Ctrl + C | Copier les objets sélectionnés |
| Ctrl + X | Couper les objets sélectionnés |
| Ctrl + V | Coller les objets |
| Espace | Effacer la sélection |
| Échap | Annuler l'opération de glissement en cours |
| Suppr | Supprimer les objets sélectionnés |

## Affichage

| Raccourci | Action |
|----------|--------|
| W | Réinitialiser la vue (ajuster tous les objets dans la fenêtre) |
| Z | Zoom sur l'objet sélectionné |
| Ctrl + Plus (+) | Zoom avant |
| Ctrl + Moins (-) | Zoom arrière |
| Touches fléchées | Pivoter la vue |
| Maj + Touches fléchées | Panoramique de la vue |

## Commandes de la souris

| Action | Commande |
|--------|---------|
| Pivoter la vue | Clic droit + Glisser |
| Panoramique de la vue | Clic milieu + Glisser |
| Zoom | Molette de défilement |
| Sélectionner un objet | Clic gauche sur l'objet |
| Sélection multiple | Maj + Clic gauche ou Ctrl + Clic gauche |
| Sélection par rectangle élastique | Clic gauche + Glisser sur une zone vide |
| Menu contextuel | Clic droit sur l'objet |

## Autres commandes de la souris

| Action | Commande |
|--------|---------|
| Pivoter la vue | Ctrl + Clic gauche + Glisser |
| Panoramique de la vue | Ctrl + Maj + Clic gauche + Glisser |
| Zoom | Ctrl + Alt + Clic gauche + Glisser |

## Application

| Raccourci | Action |
|----------|--------|
| Ctrl + Maj + T | Rouvrir la dernière conception fermée |
| F1 | Ouvrir l'Aide |
