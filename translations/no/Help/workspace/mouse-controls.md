# Musekontroller

Komplett referanse for musekontroller i MatterCAD 3D-visningsområdet.

## Navigasjon

| Handling | Musekontroll |
|--------|--------------|
| **Roter visning** | Høyreklikk + dra |
| **Panorer visning** | Midtklikk + dra |
| **Zoom** | Rullehjul |

## Alternativ navigasjon

| Handling | Musekontroll |
|--------|--------------|
| **Roter visning** | Ctrl + venstreklikk + dra |
| **Panorer visning** | Ctrl + Shift + venstreklikk + dra |
| **Zoom** | Ctrl + Alt + venstreklikk + dra |

## Objektinteraksjon

| Handling | Musekontroll |
|--------|--------------|
| **Velg objekt** | Venstreklikk på objektet |
| **Flervalg** | Shift + venstreklikk på flere objekter |
| **Flervalg** | Ctrl + venstreklikk på flere objekter |
| **Opphev alt utvalg** | Venstreklikk på tomt område |
| **Utvalg med markeringsramme** | Venstreklikk + dra på tomt område |
| **Flytt objekt** | Venstreklikk + dra på det valgte objektet |
| **Kontekstmeny** | Høyreklikk på objektet |

## Objektkontroller

Når et objekt er valgt, vises interaktive kontroller:

| Handling | Kontroll |
|--------|---------|
| **Flytt på plattformen** | Dra objektet |
| **Flytt opp/ned** | Dra den loddrette pilen over objektet |
| **Roter** | Klikk og dra en rotasjonskontroll i hjørnet |
| **Skaler** | Klikk og dra en skaleringskontroll i hjørnet |

## Tips

- Zooming med rullehjulet sentreres på musepekerens posisjon – pek på området du vil zoome inn på
- De alternative kontrollene (Ctrl + venstreklikk) er nyttige hvis du ikke har en midtre museknapp eller hvis høyreklikk er upraktisk
- Når du roterer med hjørnekontrollene, kan du holde pekeren over vinkelindikatorene for å feste til trinn på 45 grader
