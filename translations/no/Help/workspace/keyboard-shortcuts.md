# Hurtigtaster

Rask oversikt over alle hurtigtaster som er tilgjengelige i MatterCAD.

## Rediger

| Hurtigtast | Handling |
|----------|--------|
| Ctrl + Z | Angre |
| Ctrl + Y | Gjør om |
| Ctrl + Shift + Z | Gjør om (alternativ) |
| Ctrl + A | Velg alle objekter |
| Ctrl + C | Kopier valgte objekter |
| Ctrl + X | Klipp ut valgte objekter |
| Ctrl + V | Lim inn objekter |
| Mellomrom | Fjern utvalg |
| Escape | Avbryt gjeldende dra-operasjon |
| Delete | Slett valgte objekter |

## Vis

| Hurtigtast | Handling |
|----------|--------|
| W | Tilbakestill visningen (tilpass alle objekter i visningsvinduet) |
| Z | Zoom til valgt objekt |
| Ctrl + Pluss (+) | Zoom inn |
| Ctrl + Minus (-) | Zoom ut |
| Piltaster | Roter visningen |
| Shift + piltaster | Panorer visningen |

## Kontroller for mus

| Handling | Kontroll |
|--------|---------|
| Roter visningen | Høyreklikk + dra |
| Panorer visningen | Midtklikk + dra |
| Zoom | Rullehjul |
| Velg objekt | Venstreklikk på objektet |
| Flervalg | Shift + venstreklikk eller Ctrl + venstreklikk |
| Rammevalg | Venstreklikk + dra i tomt område |
| Kontekstmeny | Høyreklikk på objektet |

## Alternative kontroller for mus

| Handling | Kontroll |
|--------|---------|
| Roter visningen | Ctrl + venstreklikk + dra |
| Panorer visningen | Ctrl + Shift + venstreklikk + dra |
| Zoom | Ctrl + Alt + venstreklikk + dra |

## Applikasjon

| Hurtigtast | Handling |
|----------|--------|
| Ctrl + Shift + T | Åpne sist lukkede design på nytt |
| F1 | Åpne Hjelp |
