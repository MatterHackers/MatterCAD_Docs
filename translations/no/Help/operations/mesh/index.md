# Nettoperasjoner
<!-- AUTO_IMAGE: type=toolbar_icons group=Mesh -->
![Mesh toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Mesh.png)

Nettoperasjoner hjelper deg med å rydde opp i og optimalisere trekantnettgeometrien i modellene dine.

## Operasjoner

- [Reparer](repair.md) – Rett opp problemer i nettgeometrien, som hull, ikke-manifolde kanter og inverterte flater
- [Reduser](decimate.md) – Reduser antall polygoner i et nett for å forenkle det samtidig som formen bevares
