# Matriseoperasjoner
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Matrise oppretter flere kopier av et objekt ordnet i et mønster. Dette er nyttig for å lage gjentakende detaljer som boltehull, gjerdestolper, tannhjulstenner eller dekorative elementer.

Operasjonen Matrise støtter fire moduser – Lineær, Radiell, Kurve og Transformer – alt i ett enkelt verktøy.
