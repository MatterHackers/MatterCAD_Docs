Fra datamaskinen din
====================

![](https://lh3.googleusercontent.com/32sfdux7Fo64mrzY9hHBcWLoc8SKwTKuof6tEntzDbhKG27Y5Ow3NPEuwYGUJ9GR64tVk6h7MRY5T_UUIbi4a1NEeA)  
Klikk på Åpne-knappen i verktøylinjen for å legge til filer fra datamaskinen din. MatterCAD støtter følgende filformater:

* STL - Bransjestandard for 3D-modellformat
* AMF - Avansert format som støtter farger og objekter med flere materialer
* OBJ - Wavefront 3D-grafikkformat (kun masker, ingen teksturer eller fargedata)
* MCX - MatterCADs eget format

Dra og slipp
------------

Du kan dra og slippe filer direkte fra skrivebordet eller filutforskeren inn i MatterCAD.

Fra Bibliotek
=============

Sidefeltet Bibliotek
--------------------

![](https://lh3.googleusercontent.com/crGYrE83PyWb-hntQ8d-RhEeoiN_S8OI7uUnCS1oOm-8eMT5ExkDRSYZCr3IiT7Bx42HzrmFcg4yHhrv_GgzmbyfRA)  
Klikk på Legg til innhold-knappen i verktøylinjen for å åpne bibliotekutforskeren. Herfra kan du dra og slippe hvilket som helst innhold fra biblioteket inn i arbeidsområdet ditt.

![](https://lh3.googleusercontent.com/926cpzNy9wQBIxRHCBUCaUJhIpWdHVp8FRXpr5sC07rIBiIOO_Ryh2PGX6_mW9Ooe4i8TBR5XlejcqL6B0cJupT4)

Fanen Bibliotek
---------------

I fanen Bibliotek kan du høyreklikke på et hvilket som helst objekt og velge Legg til i scene for å importere det til det gjeldende designarbeidsområdet ditt.
