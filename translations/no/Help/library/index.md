# Bibliotek

Biblioteket lar deg organisere, lagre og dele 3D-designene dine. Du kan bla gjennom lokale filer, få tilgang til skylagring og dele design med andre.

## Emner

- [Lokalt bibliotek](local-library.md) - Administrer designene som er lagret på datamaskinen din
- [Skybibliotek](cloud-library.md) - Lagre og få tilgang til design i MatterHackers-skykontoen din
- [Deling](sharing.md) - Del design med andre MatterCAD-brukere
