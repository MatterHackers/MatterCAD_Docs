# Skróty klawiaturowe

Szybki przegląd wszystkich skrótów klawiaturowych dostępnych w MatterCAD.

## Edytuj

| Skrót | Akcja |
|----------|--------|
| Ctrl + Z | Cofnij |
| Ctrl + Y | Ponów |
| Ctrl + Shift + Z | Ponów (alternatywnie) |
| Ctrl + A | Zaznacz wszystkie obiekty |
| Ctrl + C | Kopiuj zaznaczone obiekty |
| Ctrl + X | Wytnij zaznaczone obiekty |
| Ctrl + V | Wklej obiekty |
| Spacja | Wyczyść zaznaczenie |
| Escape | Anuluj bieżącą operację przeciągania |
| Delete | Usuń zaznaczone obiekty |

## Widok

| Skrót | Akcja |
|----------|--------|
| W | Resetuj widok (dopasuj wszystkie obiekty do okna widoku) |
| Z | Powiększ do zaznaczonego obiektu |
| Ctrl + Plus (+) | Powiększ |
| Ctrl + Minus (-) | Pomniejsz |
| Klawisze strzałek | Obróć widok |
| Shift + klawisze strzałek | Przesuń widok |

## Sterowanie myszą

| Akcja | Sterowanie |
|--------|---------|
| Obróć widok | Prawy przycisk myszy + przeciągnięcie |
| Przesuń widok | Środkowy przycisk myszy + przeciągnięcie |
| Powiększenie | Kółko przewijania |
| Wybierz obiekt | Lewy przycisk myszy na obiekcie |
| Zaznaczanie wielokrotne | Shift + lewy przycisk myszy lub Ctrl + lewy przycisk myszy |
| Zaznaczanie prostokątem | Lewy przycisk myszy + przeciągnięcie po pustym obszarze |
| Menu kontekstowe | Prawy przycisk myszy na obiekcie |

## Alternatywne sterowanie myszą

| Akcja | Sterowanie |
|--------|---------|
| Obróć widok | Ctrl + lewy przycisk myszy + przeciągnięcie |
| Przesuń widok | Ctrl + Shift + lewy przycisk myszy + przeciągnięcie |
| Powiększenie | Ctrl + Alt + lewy przycisk myszy + przeciągnięcie |

## Aplikacja

| Skrót | Akcja |
|----------|--------|
| Ctrl + Shift + T | Otwórz ponownie ostatnio zamknięty projekt |
| F1 | Otwórz Pomoc |
