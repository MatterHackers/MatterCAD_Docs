# Sterowanie myszą

Pełne omówienie sterowania myszą w widoku 3D programu MatterCAD.

## Nawigacja

| Akcja | Sterowanie myszą |
|--------|--------------|
| **Obróć widok** | Prawy przycisk + przeciągnięcie |
| **Przesuń widok** | Środkowy przycisk + przeciągnięcie |
| **Powiększenie** | Koło przewijania |

## Alternatywna nawigacja

| Akcja | Sterowanie myszą |
|--------|--------------|
| **Obróć widok** | Ctrl + lewy przycisk + przeciągnięcie |
| **Przesuń widok** | Ctrl + Shift + lewy przycisk + przeciągnięcie |
| **Powiększenie** | Ctrl + Alt + lewy przycisk + przeciągnięcie |

## Interakcja z obiektami

| Akcja | Sterowanie myszą |
|--------|--------------|
| **Wybierz obiekt** | Lewy przycisk na obiekcie |
| **Wybór wielokrotny** | Shift + lewy przycisk na kolejnych obiektach |
| **Wybór wielokrotny** | Ctrl + lewy przycisk na kolejnych obiektach |
| **Odznacz wszystko** | Lewy przycisk na pustym obszarze |
| **Zaznaczanie ramką** | Lewy przycisk + przeciągnięcie po pustym obszarze |
| **Przesuń obiekt** | Lewy przycisk + przeciągnięcie na wybranym obiekcie |
| **Menu kontekstowe** | Prawy przycisk na obiekcie |

## Sterowanie obiektem

Po wybraniu obiektu pojawiają się interaktywne uchwyty sterujące:

| Akcja | Sterowanie |
|--------|---------|
| **Przesuń po stole** | Przeciągnij obiekt |
| **Przesuń w górę/w dół** | Przeciągnij pionową strzałkę nad obiektem |
| **Obróć** | Kliknij i przeciągnij narożny uchwyt obrotu |
| **Skaluj** | Kliknij i przeciągnij narożny uchwyt skalowania |

## Wskazówki

- Powiększenie kołem przewijania jest wyśrodkowane na pozycji kursora myszy -- wskaż obszar, który chcesz przybliżyć
- Alternatywne sterowanie (Ctrl + lewy przycisk) przydaje się, gdy nie masz środkowego przycisku myszy lub kliknięcie prawym przyciskiem jest niewygodne
- Podczas obracania za pomocą narożnych uchwytów najedź kursorem na wskaźniki kąta, aby przyciągać obrót do wielokrotności 45 stopni
