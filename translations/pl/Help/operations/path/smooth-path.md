# Wygładź ścieżkę

Wygładź ścieżkę zaokrągla narożniki i krzywe ścieżki 2D, tworząc łagodniejsze, bardziej organiczne kształty z kanciastych danych wejściowych.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Sposób użycia

1. Wybierz ścieżkę 2D
2. Zastosuj operację **Wygładź ścieżkę** z menu operacji Ścieżka
3. Narożniki ścieżki zostają wygładzone do krzywych

## Wskazówki

- Zastosuj przed operacją [Wyciągnięcie liniowe](linear-extrude.md), aby tworzyć wyciągnięte kształty o łagodnych krawędziach
- Użyj na ścieżce [Gwiazda](../../2d-paths/star-path.md), aby utworzyć zaokrągloną gwiazdę
- Wielokrotne zastosowanie operacji Wygładź ścieżkę zwiększa efekt wygładzenia
