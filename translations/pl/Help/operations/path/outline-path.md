# Ścieżka konturu

Ścieżka konturu tworzy konturową wersję wypełnionej ścieżki, zamieniając kształt pełny w sam pierścień jego obrysu o określonej grubości.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Sposób użycia

1. Wybierz ścieżkę 2D
2. Zastosuj operację **Ścieżka konturu** z menu operacji Ścieżka
3. Dostosuj grubość konturu

## Wskazówki

- Użyj tej operacji, aby tworzyć kształty przypominające ramy z pełnych ścieżek
- Połącz z operacją [Wyciągnięcie liniowe](linear-extrude.md), aby tworzyć trójwymiarowe ramy i obramowania
- Ścieżka [Okrąg](../../2d-paths/circle-path.md) z zastosowanym konturem odpowiada ścieżce [Pierścień](../../2d-paths/ring-path.md)
