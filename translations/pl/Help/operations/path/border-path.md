# Ścieżka obramowania

Ścieżka obramowania dodaje odsunięcie obramowania wokół istniejącej ścieżki, tworząc większą wersję kształtu otaczającą oryginał.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Sposób użycia

1. Wybierz ścieżkę 2D
2. Zastosuj **Ścieżka obramowania** z menu operacji Ścieżka
3. Dostosuj szerokość obramowania

## Wskazówki

- Używaj tej operacji, aby utworzyć margines lub wypełnienie wokół kształtów
- Połącz z oryginalną ścieżką i operacją [Odejmij](../boolean/subtract.md), aby utworzyć kształty ramek
- Podobne do operacji [Rozszerz ścieżkę](inflate-path.md), ale zaprojektowane specjalnie do generowania obramowań
