# Operacje szyku
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Szyk tworzy wiele kopii obiektu rozmieszczonych we wzorze. Jest to przydatne przy tworzeniu powtarzalnych elementów, takich jak otwory na śruby, słupki ogrodzenia, zęby kół zębatych czy detale dekoracyjne.

Operacja Szyk obsługuje cztery tryby — Liniowy, Promieniowy, Krzywa i Przekształć — wszystkie w jednym narzędziu.
