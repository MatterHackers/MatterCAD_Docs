# Ścieżka prostopadłościanu

Prostokątna ścieżka 2D. Użyj jej z operacją [Wyciągnięcie liniowe](../operations/path/linear-extrude.md), aby utworzyć kształty pudełkowe, albo jako podstawę innych operacji na ścieżkach.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parametry

- **Szerokość** - Szerokość prostokąta (domyślnie: 20mm)
- **Wysokość** - Wysokość prostokąta (domyślnie: 20mm)

## Wskazówki

- Ścieżka prostopadłościanu wraz z operacją Wyciągnięcie liniowe tworzy kształt podobny do bryły [Sześcian](../primitives/cube.md), ale przed wyciągnięciem możesz zastosować operacje na ścieżkach, takie jak [Rozszerz](../operations/path/inflate-path.md) lub [Wygładź](../operations/path/smooth-path.md)

## Powiązane

- [Ścieżka okręgu](circle-path.md) - Kołowa ścieżka 2D
- [Ścieżka gwiazdy](star-path.md) - Ścieżka 2D w kształcie gwiazdy
- [Wyciągnięcie liniowe](../operations/path/linear-extrude.md) - Nadaje ścieżkom wysokość
