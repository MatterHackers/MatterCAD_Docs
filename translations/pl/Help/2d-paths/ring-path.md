# Ścieżka pierścienia

Płaski kształt pierścienia -- okrąg z kołowym otworem pośrodku. Używaj razem z [Wyciągnięcie liniowe](../operations/path/linear-extrude.md), aby tworzyć kształty rur lub podkładek.

<!-- Screenshot of a Ring Path on the workspace -->
![20260506 080211 paste 20260506 080211](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080211-paste-20260506-080211.jpg)

## Parametry

- **Średnica zewnętrzna** - Zewnętrzna średnica pierścienia
- **Średnica wewnętrzna** - Średnica otworu pośrodku

## Wskazówki

- Grubość ścianki pierścienia wynosi (Średnica zewnętrzna - Średnica wewnętrzna) / 2
- Wyciągnięcie Ścieżki pierścienia tworzy rurę podobną do prymitywu [Pierścień](../primitives/ring.md)

## Powiązane

- [Ścieżka okręgu](circle-path.md) - Pełny okrąg (bez otworu)
- [Pierścień](../primitives/ring.md) - Gotowy kształt 3D rury
- [Wyciągnięcie liniowe](../operations/path/linear-extrude.md) - Nadaj ścieżkom wysokość
