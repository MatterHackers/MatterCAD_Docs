# Ścieżki 2D

Ścieżki 2D to płaskie kształty, których możesz użyć jako punktu wyjścia dla obiektów 3D. Użyj [Wyciągnięcie liniowe](../operations/path/linear-extrude.md), aby nadać ścieżce wysokość, lub [Obrót (Revolve)](../operations/path/revolve.md), aby obrócić ścieżkę wokół osi i utworzyć bryłę 3D.

## Dostępne ścieżki

- [Ścieżka Okrąg](circle-path.md) - Kołowy zarys 2D
- [Ścieżka Prostopadłościan](box-path.md) - Prostokątny zarys 2D
- [Ścieżka Pierścień](ring-path.md) - Pierścień 2D (okrąg z otworem)
- [Ścieżka Gwiazda](star-path.md) - Zarys 2D w kształcie gwiazdy z konfigurowalną liczbą ramion
- [Ścieżka niestandardowa](custom-path.md) - Narysuj własną ścieżkę 2D za pomocą punktów kontrolnych
