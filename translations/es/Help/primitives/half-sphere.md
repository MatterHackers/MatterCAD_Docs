# Media esfera

El hemisferio superior de una esfera: una forma de cúpula. Útil para crear partes superiores abovedadas, formas de lente y cubiertas redondeadas.

## Parámetros

- **Diámetro** - El ancho de la base de la cúpula (valor predeterminado: 20mm)
- **Lados en longitud** - Número de segmentos alrededor del perímetro (valor predeterminado: 40)
- **Lados de latitud** - Número de segmentos desde la base hasta la parte superior (valor predeterminado: 10). Más = cúpula más suave

## Consejos

- Combina dos medias esferas con un cilindro para obtener una forma de cápsula
- Colócala sobre un cilindro para crear una tapa abovedada o un botón
- Úsala con [Restar](../operations/boolean/subtract.md) para crear cavidades con forma de cúpula
