# Pirámide

Una forma piramidal de cuatro caras con base rectangular y altura ajustables.

<!--  Screenshot of a Pyramid primitive on the workspace -->
![20260318 183743 paste 20260318 183743](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183743-paste-20260318-183743.jpg)


## Parámetros

- **Anchura** - Tamaño de la base a lo largo del eje X (valor predeterminado: 20mm)
- **Profundidad** - Tamaño de la base a lo largo del eje Y (valor predeterminado: 20mm)
- **Altura** - Altura de la pirámide desde la base hasta el vértice (valor predeterminado: 20mm)

## Consejos

- Asigna el mismo valor a Anchura y Profundidad para obtener una pirámide regular de base cuadrada
- Usa valores distintos de Anchura y Profundidad para una pirámide de base rectangular
- Útil para elementos decorativos, cubiertas a dos aguas y detalles puntiagudos
