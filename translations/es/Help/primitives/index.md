# Primitivas

MatterCAD incluye una biblioteca de formas primitivas 3D que sirven como bloques de construcción para tus diseños. Puedes añadir cualquier primitiva a tu espacio de trabajo desde el panel Primitivas y luego modificar sus parámetros para obtener exactamente la forma que necesitas.

## Formas básicas

- [Cubo](cube.md) - Una caja con anchura, profundidad y altura ajustables y redondeo opcional
- [Cilindro](cylinder.md) - Una columna redonda con diámetro, altura y número de lados configurables
- [Esfera](sphere.md) - Una bola redonda con diámetro y nivel de detalle ajustables
- [Cono](cone.md) - Un cilindro que se estrecha hasta terminar en punta
- [Toro](torus.md) - Una forma de rosquilla con control de diámetro interior y exterior
- [Anillo](ring.md) - Una forma de tubo (cilindro hueco) con diámetros interior y exterior
- [Pirámide](pyramid.md) - Una pirámide de cuatro caras con base y altura ajustables
- [Cuña](wedge.md) - Una forma de prisma triangular
- [Media esfera](half-sphere.md) - La mitad superior de una esfera
- [Medio cilindro](half-cylinder.md) - Un cilindro cortado por la mitad a lo largo
- [Media cuña](half-wedge.md) - Una cuña cortada por la mitad
- [Agujero](hole.md) - Un agujero con forma de cubo que se usa con operaciones booleanas de sustracción
