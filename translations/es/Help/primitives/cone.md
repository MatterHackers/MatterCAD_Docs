# Cono

Un cilindro cónico que termina en punta en la parte superior. Útil para crear elementos puntiagudos, embudos y chaflanes.

<!--  Screenshot of a Cone primitive on the workspace -->

## Parámetros

- **Diámetro** - El ancho de la base (predeterminado: 20mm)
- **Altura** - La altura del cono (predeterminado: 20mm)
- **Lados** - Número de segmentos alrededor del perímetro (predeterminado: 40)

## Consejos

- Para obtener un cono truncado (con la parte superior plana en lugar de una punta), utiliza un [Cilindro](cylinder.md) con el modo Avanzado y establece valores distintos de Diámetro y Diámetro superior
- Los conos son útiles para crear aristas achaflanadas cuando se combinan con [Restar](../operations/boolean/subtract.md)
