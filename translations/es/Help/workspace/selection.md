# Selección

Seleccionar objetos es fundamental para trabajar en MatterCAD. Debe seleccionar los objetos antes de poder moverlos, modificarlos o aplicarles operaciones.

<!--  Screenshot showing multiple selected objects with selection highlights -->
![20260318 192323 paste 20260318 192323](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192323-paste-20260318-192323.jpg)


## Selección simple

- **Haga clic con el botón izquierdo sobre un objeto** para seleccionarlo. El objeto seleccionado anteriormente se deselecciona.
- **Haga clic con el botón izquierdo en un espacio vacío** para deseleccionar todo.

## Selección múltiple

- **Mayús + clic izquierdo** sobre otros objetos para añadirlos a la selección
- **Ctrl + clic izquierdo** también añade objetos a la selección
- **Ctrl + A** selecciona todos los objetos de la escena

## Selección por recuadro

Haga clic y arrastre en un área vacía de la ventana gráfica para dibujar un rectángulo de selección. Se seleccionan todos los objetos que queden dentro del rectángulo.

## Borrar la selección

- **Hacer clic con el botón izquierdo en un espacio vacío** borra la selección
- **Espacio** borra la selección
- **Escape** cancela una operación de arrastre

## Trabajar con selecciones

Una vez que tenga objetos seleccionados:

- **Muévalos** arrastrándolos en la ventana gráfica
- **Aplique operaciones** desde la barra de herramientas (booleanas, transformación, matriz, etc.)
- **Edite las propiedades** en el panel Propiedades (cuando hay un solo objeto seleccionado)
- **Haga clic con el botón derecho** para acceder al menú contextual con las acciones disponibles

## Consejos

- Cuando hay varios objetos seleccionados, se agrupan temporalmente para las operaciones. El panel Propiedades muestra las propiedades compartidas.
- Utilice el Árbol de diseño para seleccionar objetos que resulten difíciles de pulsar en la ventana gráfica: al hacer clic en un elemento del árbol, este se selecciona en la vista.
