# Atajos de teclado

Referencia rápida de todos los atajos de teclado disponibles en MatterCAD.

## Editar

| Atajo | Acción |
|----------|--------|
| Ctrl + Z | Deshacer |
| Ctrl + Y | Rehacer |
| Ctrl + Mayús + Z | Rehacer (alternativa) |
| Ctrl + A | Seleccionar todos los objetos |
| Ctrl + C | Copiar los objetos seleccionados |
| Ctrl + X | Cortar los objetos seleccionados |
| Ctrl + V | Pegar objetos |
| Espacio | Borrar selección |
| Escape | Cancelar la operación de arrastre actual |
| Suprimir | Eliminar los objetos seleccionados |

## Vista

| Atajo | Acción |
|----------|--------|
| W | Restablecer la vista (ajustar todos los objetos en la ventana gráfica) |
| Z | Zoom al objeto seleccionado |
| Ctrl + Más (+) | Acercar |
| Ctrl + Menos (-) | Alejar |
| Teclas de flecha | Rotar la vista |
| Mayús + Teclas de flecha | Desplazar la vista |

## Controles del ratón

| Acción | Control |
|--------|---------|
| Rotar la vista | Clic derecho + Arrastrar |
| Desplazar la vista | Clic central + Arrastrar |
| Zoom | Rueda de desplazamiento |
| Seleccionar un objeto | Clic izquierdo sobre el objeto |
| Selección múltiple | Mayús + Clic izquierdo o Ctrl + Clic izquierdo |
| Selección por recuadro | Clic izquierdo + Arrastrar en un espacio vacío |
| Menú contextual | Clic derecho sobre el objeto |

## Controles alternativos del ratón

| Acción | Control |
|--------|---------|
| Rotar la vista | Ctrl + Clic izquierdo + Arrastrar |
| Desplazar la vista | Ctrl + Mayús + Clic izquierdo + Arrastrar |
| Zoom | Ctrl + Alt + Clic izquierdo + Arrastrar |

## Aplicación

| Atajo | Acción |
|----------|--------|
| Ctrl + Mayús + T | Volver a abrir el último diseño cerrado |
| F1 | Abrir la Ayuda |
