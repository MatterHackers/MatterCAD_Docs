# Componentes

Los componentes son grupos de objetos reutilizables y parametrizados. Cuando creas un componente, este se convierte en una unidad independiente que puedes insertar varias veces en tu diseño, y al editar el componente se actualizan todas las instancias.

## Cómo se usa

### Crear un componente

1. Selecciona uno o varios objetos
2. Haz clic con el botón derecho y elige **Crear componente** (o usa el menú)
3. Los objetos seleccionados se encapsulan en un contenedor de componente

### Editar un componente

1. Selecciona el componente
2. Los parámetros expuestos del componente aparecen en el panel Propiedades
3. Modifica los parámetros para cambiar la forma del componente

## Consejos

- Los componentes son útiles para crear bloques reutilizables en diseños complejos
- Los cambios de parámetros no son destructivos y se pueden ajustar en cualquier momento
- Los componentes ayudan a organizar diseños complejos agrupando objetos relacionados
- Usa componentes para piezas que necesites colocar varias veces con ligeras variaciones
