# Controles del ratón

Referencia completa de los controles del ratón en la ventana gráfica 3D de MatterCAD.

## Navegación

| Acción | Control del ratón |
|--------|--------------|
| **Rotar la vista** | Clic derecho + Arrastrar |
| **Desplazar la vista** | Clic central + Arrastrar |
| **Zoom** | Rueda de desplazamiento |

## Navegación alternativa

| Acción | Control del ratón |
|--------|--------------|
| **Rotar la vista** | Ctrl + Clic izquierdo + Arrastrar |
| **Desplazar la vista** | Ctrl + Mayús + Clic izquierdo + Arrastrar |
| **Zoom** | Ctrl + Alt + Clic izquierdo + Arrastrar |

## Interacción con objetos

| Acción | Control del ratón |
|--------|--------------|
| **Seleccionar un objeto** | Clic izquierdo sobre el objeto |
| **Selección múltiple** | Mayús + Clic izquierdo sobre objetos adicionales |
| **Selección múltiple** | Ctrl + Clic izquierdo sobre objetos adicionales |
| **Deseleccionar todo** | Clic izquierdo en un espacio vacío |
| **Selección por recuadro** | Clic izquierdo + Arrastrar en un espacio vacío |
| **Mover un objeto** | Clic izquierdo + Arrastrar sobre el objeto seleccionado |
| **Menú contextual** | Clic derecho sobre el objeto |

## Controles de objeto

Cuando se selecciona un objeto, aparecen controles interactivos:

| Acción | Control |
|--------|---------|
| **Mover sobre la cama** | Arrastre el objeto |
| **Mover arriba/abajo** | Arrastre la flecha vertical situada sobre el objeto |
| **Rotar** | Haga clic y arrastre un control de rotación de esquina |
| **Escalar** | Haga clic y arrastre un control de escala de esquina |

## Consejos

- El zoom con la rueda de desplazamiento se centra en la posición del cursor del ratón: apunte a la zona a la que desea acercarse
- Los controles alternativos (Ctrl + Clic izquierdo) son útiles si no dispone de botón central del ratón o si el clic derecho le resulta incómodo
- Al rotar con los controles de esquina, pase el cursor sobre los indicadores de ángulo para ajustar en incrementos de 45 grados
