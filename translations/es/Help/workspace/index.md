# Espacio de trabajo

Aprende a navegar por el espacio de trabajo de MatterCAD, a usar los atajos de teclado y a gestionar tu flujo de trabajo de diseño.

## Temas

- [Atajos de teclado](keyboard-shortcuts.md) - Referencia rápida de todos los atajos de teclado
- [Controles del ratón](mouse-controls.md) - Cómo navegar por la vista 3D con el ratón
- [Selección](selection.md) - Cómo seleccionar, hacer selecciones múltiples y gestionar la selección de objetos
- [Deshacer y rehacer](undo-redo.md) - Deshacer y rehacer cambios en tu diseño
- [Agrupar](grouping.md) - Agrupa y desagrupa objetos para gestionarlos más fácilmente
- [Componentes](components.md) - Crea componentes y ensamblajes reutilizables
- [Expresiones](expressions.md) - Usa expresiones matemáticas para el diseño paramétrico
- [Hoja de variables](variable-sheet.md) - Almacena valores y fórmulas compartidos para diseños paramétricos
- [Herramienta de medición](measure-tool.md) - Mide distancias entre puntos de tu diseño
- [Bloquear y ocultar](lock-hide.md) - Bloquea objetos para evitar cambios y ocúltalos para reducir el desorden
