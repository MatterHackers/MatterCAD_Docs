# Compartir

MatterCAD te permite compartir tus diseños con otros usuarios mediante códigos para compartir. Esto facilita colaborar en diseños o distribuir tu trabajo.

![20260323 210309 paste 20260323 210309](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210309-paste-20260323-210309.jpg)


## Compartir un diseño

1. Haz clic derecho en un diseño de tu [Biblioteca en la nube](cloud-library.md)
2. Selecciona **Compartir**
3. Se genera un código para compartir que puedes enviar a otras personas

## Recibir un diseño compartido

1. Consigue un código para compartir de alguien
2. Usa la opción **Canjear compartir código** en la biblioteca
3. El diseño compartido se añade a tu biblioteca

## Consejos

- Los códigos para compartir funcionan con diseños almacenados en la Biblioteca en la nube
- El destinatario obtiene una copia del diseño: los cambios que haga no afectan a tu original
- Los códigos para compartir se pueden distribuir por cualquier canal: correo electrónico, chat, redes sociales, etc.
