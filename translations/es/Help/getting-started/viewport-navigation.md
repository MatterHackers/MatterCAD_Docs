# Navegación en la ventana gráfica

La ventana gráfica 3D es donde visualizas tus diseños e interactúas con ellos. MatterCAD utiliza un modelo de cámara tipo trackball que te permite orbitar, desplazar y hacer zoom libremente alrededor de tus objetos.

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## Controles del ratón

### Rotar la vista

- **Clic derecho + arrastrar** - Orbita la cámara alrededor de tu diseño
- **Ctrl + clic izquierdo + arrastrar** - Método de rotación alternativo

### Desplazar la vista

- **Clic central + arrastrar** - Desliza la vista a la izquierda, a la derecha, arriba o abajo
- **Ctrl + Mayús + clic izquierdo + arrastrar** - Método de desplazamiento alternativo

### Acercar y alejar

- **Rueda del ratón** - Gira hacia arriba para acercar y hacia abajo para alejar
- **Ctrl + Alt + clic izquierdo + arrastrar** - Método de zoom alternativo

## Controles del teclado

### Atajos de vista

- **W** - Restablece la vista para ajustar todos los objetos en la ventana gráfica
- **Z** - Hace zoom sobre el objeto seleccionado actualmente

### Navegación con las teclas de flecha

- **Teclas de flecha** - Rotan la vista
- **Mayús + teclas de flecha** - Desplazan la vista

### Atajos de zoom

- **Ctrl + Más (+)** - Acercar
- **Ctrl + Menos (-)** - Alejar

## Consejos

- Si pierdes de vista tu modelo, pulsa **W** para restablecer la vista y volver a encuadrarlo todo
- Usa **Z** después de seleccionar un objeto para enfocarlo rápidamente
- El zoom con la rueda del ratón se centra en la posición del cursor, así que apunta a la zona a la que quieras acercarte
- Puedes combinar la rotación y el desplazamiento para inspeccionar tu diseño desde cualquier ángulo
