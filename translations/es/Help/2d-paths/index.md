# Rutas 2D

Las rutas 2D son formas planas que puede usar como punto de partida para objetos 3D. Use [Extrusión lineal](../operations/path/linear-extrude.md) para dar altura a una ruta, o [Revolución](../operations/path/revolve.md) para girar una ruta alrededor de un eje y crear una forma 3D.

## Rutas disponibles

- [Ruta de círculo](circle-path.md) - Un contorno 2D circular
- [Ruta de caja](box-path.md) - Un contorno 2D rectangular
- [Ruta de anillo](ring-path.md) - Un anillo 2D (círculo con un agujero)
- [Ruta de estrella](star-path.md) - Un contorno 2D en forma de estrella con puntas configurables
- [Ruta personalizada](custom-path.md) - Dibuje su propia ruta 2D con puntos de control
