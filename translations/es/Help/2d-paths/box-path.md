# Ruta de caja

Una ruta 2D rectangular. Úsala con [Extrusión lineal](../operations/path/linear-extrude.md) para crear formas de caja, o como base para otras operaciones de ruta.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parámetros

- **Anchura** - La anchura del rectángulo (predeterminado: 20mm)
- **Altura** - La altura del rectángulo (predeterminado: 20mm)

## Consejos

- Una Ruta de caja más Extrusión lineal crea una forma similar a un [Cubo](../primitives/cube.md), pero puedes aplicar operaciones de ruta como [Inflar](../operations/path/inflate-path.md) o [Suavizar](../operations/path/smooth-path.md) antes de extruir
