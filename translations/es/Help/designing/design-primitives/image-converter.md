El Convertidor de imágenes le ayuda a crear piezas fácilmente a partir de imágenes

### Agregar el Convertidor de imágenes
- Arrastre el Convertidor de imágenes desde la barra lateral hasta la plataforma
- Cambie la imagen que está usando haciendo clic en 'Cambiar'  
![Image Converter](https://www.matterhackers.com/r/zrXG9u)
### Cambiar la altura
- Una vez que tenga una imagen en la plataforma, puede cambiar su altura  
![Change Height](https://www.matterhackers.com/r/MOtISv)
### Buscar nuevas imágenes
- El Convertidor de imágenes también puede ayudarle a buscar en Google las imágenes que quiera usar (asegúrese de tener permiso para cualquier imagen que utilice).  
![Search Image](https://www.matterhackers.com/r/p3lA0F)
### Agregar una base
- Una vez que tenga la imagen que desea, puede agregar fácilmente una base a su creación.  
![Add Base](https://www.matterhackers.com/r/LBiZnR)
### Las imágenes también se pueden usar directamente
- También puede arrastrar imágenes directamente a la plataforma y usar las herramientas del menú contextual (clic derecho) para crear todas las funciones (y más) del Convertidor de imágenes.

Explore y diviértase: los únicos límites son los de su imaginación
