La Aplicación de diseño Braille permite crear etiquetas en braille imprimibles en 3D para personas con discapacidad visual, y sirve tanto como herramienta práctica como recurso educativo para comprender el braille. La aplicación admite braille inglés de grado 1 y 2.

Accede a ella desde la sección Aplicaciones de diseño.
