# Suavizar trayectoria

Suavizar trayectoria redondea las esquinas y curvas de una ruta 2D, creando formas más suaves y orgánicas a partir de entradas angulares.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Cómo se usa

1. Selecciona una ruta 2D
2. Aplica **Suavizar trayectoria** desde el menú de operaciones de Ruta
3. Las esquinas de la ruta se suavizan convirtiéndose en curvas

## Consejos

- Aplícala antes de [Extrusión lineal](linear-extrude.md) para crear formas extruidas con bordes suaves
- Úsala en una [Ruta de estrella](../../2d-paths/star-path.md) para crear una estrella redondeada
- Varias aplicaciones de Suavizar trayectoria aumentan el efecto de suavizado

## Relacionado

- [Inflar trayectoria](inflate-path.md) - Expande una ruta hacia fuera
- [Trazado del contorno](outline-path.md) - Crea un contorno a partir de una ruta
- [Extrusión lineal](linear-extrude.md) - Da altura a la ruta suavizada
