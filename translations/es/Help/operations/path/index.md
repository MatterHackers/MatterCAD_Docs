# Operaciones de rutas
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

Las operaciones de rutas trabajan con rutas 2D para crear y modificar formas 3D. Úsalas para extruir, revolucionar y refinar geometría basada en rutas.

## Operaciones

- [Extrusión lineal](linear-extrude.md) - Da altura a una ruta 2D para crear un objeto 3D
- [Revolución](revolve.md) - Gira una ruta 2D alrededor de un eje para crear un sólido de revolución
- [Suavizar trayectoria](smooth-path.md) - Suaviza las curvas de una ruta
- [Inflar trayectoria](inflate-path.md) - Expande una ruta hacia fuera
- [Trazado del contorno](outline-path.md) - Crea un contorno a partir de una ruta rellena
- [Trayectoria del borde](border-path.md) - Agrega un desplazamiento de borde alrededor de una ruta
- [Seleccionar trayectorias](select-paths.md) - Selecciona rutas específicas de objetos complejos con varias rutas
