# Trazado del contorno

Trazado del contorno crea una versión de contorno de una ruta rellena, convirtiendo una forma sólida únicamente en su anillo perimetral con un grosor determinado.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Cómo se usa

1. Seleccione una ruta 2D
2. Aplique **Trazado del contorno** desde el menú de operaciones de Ruta
3. Ajuste el grosor del contorno

## Consejos

- Úselo para crear formas tipo marco a partir de rutas sólidas
- Combínelo con [Extrusión lineal](linear-extrude.md) para crear marcos y bordes 3D
- Una [Ruta de círculo](../../2d-paths/circle-path.md) con contorno equivale a una [Ruta de anillo](../../2d-paths/ring-path.md)
