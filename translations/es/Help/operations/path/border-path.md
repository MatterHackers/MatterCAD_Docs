# Trayectoria del borde

Trayectoria del borde añade un desfase de borde alrededor de una ruta existente, creando una versión más grande de la forma que rodea a la original.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Cómo se usa

1. Seleccione una ruta 2D
2. Aplique **Trayectoria del borde** desde el menú de operaciones de Ruta
3. Ajuste el ancho del borde

## Consejos

- Úselo para crear un margen o relleno alrededor de las formas
- Combínelo con la ruta original y [Restar](../boolean/subtract.md) para crear formas de marco
- Similar a [Inflar trayectoria](inflate-path.md), pero diseñado específicamente para generar bordes
