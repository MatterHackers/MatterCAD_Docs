# Operaciones de Matriz
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Matriz crea varias copias de un objeto dispuestas siguiendo un patrón. Resulta útil para crear elementos repetidos como agujeros para pernos, postes de valla, dientes de engranaje o elementos decorativos.

La operación Matriz admite cuatro modos —Lineal, Radial, Curva y Transformar— todos en una sola herramienta.
