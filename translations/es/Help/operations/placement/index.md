# Operaciones de colocación
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Las operaciones de colocación te ayudan a posicionar objetos con precisión unos respecto a otros o dentro de límites específicos.

## Operaciones

- [Alinear](align.md) - Alinea objetos entre sí a lo largo de cualquier eje
- [Alineación de extrusión doble](dual-extrusion-align.md) - Alinea objetos según sus posiciones de modelado compartidas
- [Ajustar a los límites](fit-to-bounds.md) - Escala un objeto para que quepa dentro de un cuadro delimitador especificado
- [Ajustar a cilindro](fit-to-cylinder.md) - Escala un objeto para que quepa dentro de un cilindro especificado
