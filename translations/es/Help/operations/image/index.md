# Operaciones de imagen
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

Las operaciones de imagen convierten imágenes 2D en objetos o rutas 3D, lo que le permite incorporar fotografías, logotipos y obras de arte en sus diseños.

## Operaciones

- [Convertidor de imágenes](image-converter.md) - Convierte una imagen en un relieve 3D basado en el brillo o el color
- [Imagen a trazado](image-to-path.md) - Traza una imagen para crear un contorno de ruta 2D
- [Litofanía](lithophane.md) - Crea una litofanía que revela una imagen al iluminarse por detrás
