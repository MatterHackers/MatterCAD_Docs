# Vyhladit cestu

Vyhladit cestu zaobluje rohy a křivky 2D cesty a vytváří tak z hranatých vstupů měkčí, organičtější tvary.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Jak postupovat

1. Vyberte 2D cestu
2. Použijte **Vyhladit cestu** z nabídky operací Cesta
3. Rohy cesty se vyhladí do křivek

## Tipy

- Použijte před operací [Lineární extruze](linear-extrude.md) a vytvořte vytažené tvary s měkkými hranami
- Použijte na [Hvězdicovou cestu](../../2d-paths/star-path.md) a vytvořte zaoblenou hvězdu
- Vícenásobné použití operace Vyhladit cestu zesiluje efekt vyhlazení
