# Obrysová cesta

Obrysová cesta vytvoří obrysovou verzi vyplněné cesty – převede plný tvar pouze na jeho hraniční prstenec se zadanou tloušťkou.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Použití

1. Vyberte 2D cestu
2. Použijte **Obrysová cesta** z nabídky operací s cestami
3. Upravte tloušťku obrysu

## Tipy

- Použijte tuto operaci k vytvoření rámových tvarů z plných cest
- Zkombinujte ji s operací [Lineární extruze](linear-extrude.md) pro tvorbu 3D rámů a okrajů
- Obrys [Cesty kruhu](../../2d-paths/circle-path.md) odpovídá [Cestě prstence](../../2d-paths/ring-path.md)
