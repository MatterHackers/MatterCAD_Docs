# Cesta okraje

Cesta okraje přidává kolem stávající cesty odsazení okraje a vytváří tak větší verzi tvaru, která obklopuje původní tvar.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Použití

1. Vyberte 2D cestu
2. Použijte **Cesta okraje** z nabídky operací s cestami
3. Upravte šířku okraje

## Tipy

- Použijte tuto operaci k vytvoření okraje nebo odstupu kolem tvarů
- Zkombinujte s původní cestou a operací [Odečíst](../boolean/subtract.md) pro vytvoření rámečkových tvarů
- Podobné jako [Nafouknout cestu](inflate-path.md), ale specificky navržené pro generování okrajů
