# Operace se síťovinou
<!-- AUTO_IMAGE: type=toolbar_icons group=Mesh -->
![Mesh toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Mesh.png)

Operace se síťovinou vám pomáhají vyčistit a optimalizovat trojúhelníkovou síťovinu vašich modelů.

## Operace

- [Opravit](repair.md) - Opraví problémy v geometrii síťoviny, jako jsou díry, nekorektní (non-manifold) hrany a obrácené plochy
- [Zmenšit](decimate.md) - Sníží počet polygonů síťoviny, čímž ji zjednoduší při zachování tvaru
