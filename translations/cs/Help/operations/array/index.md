# Operace Pole
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Pole vytvoří několik kopií objektu uspořádaných do vzoru. To se hodí pro tvorbu opakujících se prvků, jako jsou díry pro šrouby, sloupky plotu, zuby ozubených kol nebo dekorativní prvky.

Operace Pole podporuje čtyři režimy — Lineární, Radiální, Křivka a Transformace — vše v jediném nástroji.
