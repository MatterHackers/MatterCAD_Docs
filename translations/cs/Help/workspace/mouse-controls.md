# Ovládání myší

Úplný přehled ovládání myší ve 3D pohledu MatterCAD.

## Navigace

| Akce | Ovládání myší |
|--------|--------------|
| **Otočit pohled** | Kliknutí pravým tlačítkem + tažení |
| **Posun pohledu** | Kliknutí prostředním tlačítkem + tažení |
| **Přiblížení** | Kolečko myši |

## Alternativní navigace

| Akce | Ovládání myší |
|--------|--------------|
| **Otočit pohled** | Ctrl + kliknutí levým tlačítkem + tažení |
| **Posun pohledu** | Ctrl + Shift + kliknutí levým tlačítkem + tažení |
| **Přiblížení** | Ctrl + Alt + kliknutí levým tlačítkem + tažení |

## Práce s objekty

| Akce | Ovládání myší |
|--------|--------------|
| **Vybrat objekt** | Kliknutí levým tlačítkem na objekt |
| **Vícenásobný výběr** | Shift + kliknutí levým tlačítkem na další objekty |
| **Vícenásobný výběr** | Ctrl + kliknutí levým tlačítkem na další objekty |
| **Zrušit celý výběr** | Kliknutí levým tlačítkem do prázdného prostoru |
| **Výběr gumovým rámečkem** | Kliknutí levým tlačítkem + tažení v prázdném prostoru |
| **Přesunout objekt** | Kliknutí levým tlačítkem + tažení vybraného objektu |
| **Kontextová nabídka** | Kliknutí pravým tlačítkem na objekt |

## Ovládání objektu

Když je objekt vybraný, zobrazí se interaktivní ovládací prvky:

| Akce | Ovládání |
|--------|---------|
| **Přesun po podložce** | Táhněte objekt |
| **Přesun nahoru/dolů** | Táhněte svislou šipku nad objektem |
| **Otočit** | Klikněte a přetáhněte rohový ovládací prvek otáčení |
| **Měřítko** | Klikněte a přetáhněte rohový ovládací prvek měřítka |

## Tipy

- Přiblížení kolečkem myši se vztahuje k poloze kurzoru myši -- namiřte na oblast, kterou chcete přiblížit
- Alternativní ovládání (Ctrl + kliknutí levým tlačítkem) je užitečné, pokud nemáte prostřední tlačítko myši nebo je kliknutí pravým tlačítkem nepohodlné
- Při otáčení pomocí rohových ovládacích prvků najeďte na indikátory úhlu, čímž přichytíte otáčení po 45stupňových krocích
