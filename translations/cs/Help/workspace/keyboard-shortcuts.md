# Klávesové zkratky

Rychlý přehled všech klávesových zkratek dostupných v MatterCAD.

## Upravit

| Zkratka | Akce |
|----------|--------|
| Ctrl + Z | Zpět |
| Ctrl + Y | Znovu |
| Ctrl + Shift + Z | Znovu (alternativa) |
| Ctrl + A | Vybrat vše objektů |
| Ctrl + C | Kopírovat vybrané objekty |
| Ctrl + X | Vyjmout vybrané objekty |
| Ctrl + V | Vložit objekty |
| Mezerník | Zrušit výběr |
| Escape | Zrušit probíhající operaci tažení |
| Delete | Odstranit vybrané objekty |

## Zobrazit

| Zkratka | Akce |
|----------|--------|
| W | Resetovat pohled (přizpůsobit všechny objekty výřezu) |
| Z | Přiblížit na vybraný objekt |
| Ctrl + Plus (+) | Přiblížit |
| Ctrl + Mínus (-) | Oddálit |
| Šipky | Otočit pohled |
| Shift + šipky | Posunout pohled |

## Ovládání myší

| Akce | Ovládání |
|--------|---------|
| Otočit pohled | Kliknutí pravým tlačítkem + tažení |
| Posunout pohled | Kliknutí prostředním tlačítkem + tažení |
| Přiblížení | Kolečko myši |
| Vybrat objekt | Kliknutí levým tlačítkem na objekt |
| Vícenásobný výběr | Shift + kliknutí levým tlačítkem nebo Ctrl + kliknutí levým tlačítkem |
| Výběr gumovým obdélníkem | Kliknutí levým tlačítkem + tažení v prázdném prostoru |
| Kontextová nabídka | Kliknutí pravým tlačítkem na objekt |

## Alternativní ovládání myší

| Akce | Ovládání |
|--------|---------|
| Otočit pohled | Ctrl + kliknutí levým tlačítkem + tažení |
| Posunout pohled | Ctrl + Shift + kliknutí levým tlačítkem + tažení |
| Přiblížení | Ctrl + Alt + kliknutí levým tlačítkem + tažení |

## Aplikace

| Zkratka | Akce |
|----------|--------|
| Ctrl + Shift + T | Znovu otevřít naposledy zavřený návrh |
| F1 | Otevřít Nápovědu |
