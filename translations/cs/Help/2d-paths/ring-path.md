# Cesta prstenec

Dvourozměrný tvar prstence -- kruh s kruhovým otvorem uprostřed. Použijte jej spolu s operací [Lineární extruze](../operations/path/linear-extrude.md) k vytvoření trubek nebo podložek.

<!-- Screenshot of a Ring Path on the workspace -->
![20260506 080211 paste 20260506 080211](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080211-paste-20260506-080211.jpg)

## Parametry

- **Vnější průměr** - Vnější průměr prstence
- **Vnitřní průměr** - Průměr otvoru uprostřed

## Tipy

- Tloušťka stěny prstence je (Vnější průměr - Vnitřní průměr) / 2
- Vytažením cesty prstenec vznikne trubka podobná primitivu [Prstenec](../primitives/ring.md)
