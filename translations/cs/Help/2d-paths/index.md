# 2D cesty

2D cesty jsou ploché tvary, které můžete použít jako výchozí bod pro 3D objekty. Použijte [Lineární extruze](../operations/path/linear-extrude.md), chcete-li cestě dát výšku, nebo [Rotovat](../operations/path/revolve.md), chcete-li cestu otočit kolem osy a vytvořit tak 3D tvar.

## Dostupné cesty

- [Cesta Kruh](circle-path.md) – kruhový 2D obrys
- [Cesta Kvádr](box-path.md) – obdélníkový 2D obrys
- [Cesta Prstenec](ring-path.md) – 2D prstenec (kruh s otvorem)
- [Cesta Hvězda](star-path.md) – 2D obrys ve tvaru hvězdy s nastavitelným počtem cípů
- [Vlastní cesta](custom-path.md) – nakreslete vlastní 2D cestu pomocí řídicích bodů
