# Cesta Kruh

Kruhová 2D cesta. Použijte ji s operací [Lineární extruze](../operations/path/linear-extrude.md) pro vytvoření válců nebo s operací [Rotovat](../operations/path/revolve.md) pro vytvoření tvarů podobných torusu.

![20260506 080110 paste 20260506 080110](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080110-paste-20260506-080110.jpg)


## Parametry

- **Průměr** - Průměr kruhu (výchozí: 20 mm)
- **Segmenty** - Počet úseček tvořících kruh. Více = hladší

## Tipy

- Cesta Kruh v kombinaci s operací Lineární extruze vytvoří válec, podobný primitivu [Válec](../primitives/cylinder.md), ale s větší volností v tom, jak na něm dále stavíte
- Použijte ji jako základ pro operaci Rotovat k vytvoření prstencových tvarů
