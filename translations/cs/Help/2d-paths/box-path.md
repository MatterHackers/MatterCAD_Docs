# Cesta Kvádr

Obdélníková 2D cesta. Použijte ji spolu s operací [Lineární extruze](../operations/path/linear-extrude.md) pro vytvoření kvádrových tvarů nebo jako základ pro další operace s cestami.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parametry

- **Šířka** - Šířka obdélníku (výchozí: 20mm)
- **Výška** - Výška obdélníku (výchozí: 20mm)

## Tipy

- Cesta Kvádr spolu s operací Lineární extruze vytvoří tvar podobný objektu [Kvádr](../primitives/cube.md), ale před vytažením můžete na cestu použít operace jako [Nafouknout](../operations/path/inflate-path.md) nebo [Vyhladit](../operations/path/smooth-path.md)
