# Ozubené kolo 2D

2D cesta ozubeného kola, která vytvoří pouze profil zubů jako plochou cestu. Použijte ji spolu s operací [Lineární extruze](../operations/path/linear-extrude.md) nebo [Rotovat](../operations/path/revolve.md) pro větší kontrolu nad tím, jak se ozubené kolo převede do 3D tvaru.

<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->
![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)

## Použití

1. Přidejte **Ozubené kolo 2D** z mechanických nástrojů
2. Nakonfigurujte parametry zubů
3. Použijte [Lineární extruze](../operations/path/linear-extrude.md), abyste mu dodali výšku

## Tipy

- Ozubené kolo 2D použijte, když potřebujete profil ozubeného kola zkombinovat s dalšími operacemi s cestami ještě před vytažením
- Pokud chcete hotové 3D ozubené kolo, podívejte se místo toho na [Ozubená kola](gears.md)
- Platí stejná pravidla záběru: ozubená kola, která mají spolupracovat, musí mít shodnou Roztečnou vzdálenost a Úhel záběru
