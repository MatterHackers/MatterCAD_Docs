# Objekt SVG

Importujte soubory SVG (Scalable Vector Graphics) a použijte je ve svém návrhu jako 2D cesty. SVG lze následně vytáhnout do 3D tvarů pomocí operace [Lineární extruze](../operations/path/linear-extrude.md) nebo [Rotovat](../operations/path/revolve.md).

## Jak na to

1. Importujte soubor SVG přetažením do pracovní plochy nebo pomocí tlačítka Otevřít
2. SVG se importuje jako 2D cesta
3. Použijte [Lineární extruze](../operations/path/linear-extrude.md), abyste mu dali výšku, nebo využijte další [Operace s cestami](../operations/path/index.md)

## Tipy

- Nejlepších výsledků dosáhnete, pokud soubory SVG obsahují vyplněné tvary nebo uzavřené cesty
- Zpracování složitých SVG s mnoha cestami může trvat déle
- Pomocí [Vybrat cesty](../operations/path/select-paths.md) můžete pracovat s konkrétními částmi SVG s více cestami
- Online je k dispozici mnoho volně dostupných souborů SVG s logy, ikonami a dekorativními vzory
