# Klavye Kısayolları

MatterCAD'de kullanılabilen tüm klavye kısayolları için hızlı başvuru.

## Düzenle

| Kısayol | Eylem |
|----------|--------|
| Ctrl + Z | Geri Al |
| Ctrl + Y | Yinele |
| Ctrl + Shift + Z | Yinele (alternatif) |
| Ctrl + A | Tüm nesneleri seç |
| Ctrl + C | Seçili nesneleri kopyala |
| Ctrl + X | Seçili nesneleri kes |
| Ctrl + V | Nesneleri yapıştır |
| Space | Seçimi temizle |
| Escape | Geçerli sürükleme işlemini iptal et |
| Delete | Seçili nesneleri sil |

## Görünüm

| Kısayol | Eylem |
|----------|--------|
| W | Görünümü sıfırla (tüm nesneleri görünüm alanına sığdır) |
| Z | Seçili nesneye yakınlaştır |
| Ctrl + Artı (+) | Yakınlaştır |
| Ctrl + Eksi (-) | Uzaklaştır |
| Ok Tuşları | Görünümü döndür |
| Shift + Ok Tuşları | Görünümü kaydır |

## Fare Kontrolleri

| Eylem | Kontrol |
|--------|---------|
| Görünümü döndür | Sağ tık + Sürükle |
| Görünümü kaydır | Orta tık + Sürükle |
| Yakınlaştır | Kaydırma tekerleği |
| Nesne seç | Nesneye sol tık |
| Çoklu seçim | Shift + Sol tık veya Ctrl + Sol tık |
| Seçim çerçevesiyle seçim | Boş alanda sol tık + Sürükle |
| Bağlam menüsü | Nesneye sağ tık |

## Alternatif Fare Kontrolleri

| Eylem | Kontrol |
|--------|---------|
| Görünümü döndür | Ctrl + Sol tık + Sürükle |
| Görünümü kaydır | Ctrl + Shift + Sol tık + Sürükle |
| Yakınlaştır | Ctrl + Alt + Sol tık + Sürükle |

## Uygulama

| Kısayol | Eylem |
|----------|--------|
| Ctrl + Shift + T | Son kapatılan tasarımı yeniden aç |
| F1 | Yardımı aç |
