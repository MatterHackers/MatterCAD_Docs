# Fare Kontrolleri

MatterCAD 3D görünüm alanındaki fare kontrolleri için eksiksiz başvuru kaynağı.

## Gezinme

| Eylem | Fare Kontrolü |
|--------|--------------|
| **Görünümü döndür** | Sağ tıklama + Sürükleme |
| **Görünümü kaydır** | Orta tıklama + Sürükleme |
| **Yakınlaştır** | Kaydırma tekerleği |

## Alternatif Gezinme

| Eylem | Fare Kontrolü |
|--------|--------------|
| **Görünümü döndür** | Ctrl + Sol tıklama + Sürükleme |
| **Görünümü kaydır** | Ctrl + Shift + Sol tıklama + Sürükleme |
| **Yakınlaştır** | Ctrl + Alt + Sol tıklama + Sürükleme |

## Nesne Etkileşimi

| Eylem | Fare Kontrolü |
|--------|--------------|
| **Nesne seç** | Nesneye sol tıklama |
| **Çoklu seçim** | Shift + ek nesnelere sol tıklama |
| **Çoklu seçim** | Ctrl + ek nesnelere sol tıklama |
| **Tüm seçimi kaldır** | Boş alana sol tıklama |
| **Çerçeveyle seçim** | Boş alanda sol tıklama + Sürükleme |
| **Nesneyi taşı** | Seçili nesne üzerinde sol tıklama + Sürükleme |
| **Bağlam menüsü** | Nesneye sağ tıklama |

## Nesne Kontrolleri

Bir nesne seçildiğinde etkileşimli kontroller görünür:

| Eylem | Kontrol |
|--------|---------|
| **Tabla üzerinde taşı** | Nesneyi sürükleyin |
| **Yukarı/aşağı taşı** | Nesnenin üzerindeki dikey oku sürükleyin |
| **Döndür** | Bir döndürme köşe kontrolünü tıklayıp sürükleyin |
| **Ölçekle** | Bir ölçekleme köşe kontrolünü tıklayıp sürükleyin |

## İpuçları

- Kaydırma tekerleğiyle yakınlaştırma, fare imlecinin konumunu merkez alır -- yakınlaştırmak istediğiniz alanı işaret edin
- Alternatif kontroller (Ctrl + Sol tıklama), orta fare düğmeniz yoksa veya sağ tıklama kullanışsızsa işinize yarar
- Köşe kontrolleriyle döndürürken, 45 derecelik artışlara kenetlenmek için açı göstergelerinin üzerine gelin
