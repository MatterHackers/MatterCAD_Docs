# Kutu Yolu

Dikdörtgen bir 2B yol. Kutu şekilleri oluşturmak için [Doğrusal Ekstrüzyon](../operations/path/linear-extrude.md) ile birlikte kullanın veya diğer yol işlemleri için temel olarak kullanın.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parametreler

- **Genişlik** - Dikdörtgenin genişliği (varsayılan: 20mm)
- **Yükseklik** - Dikdörtgenin yüksekliği (varsayılan: 20mm)

## İpuçları

- Kutu Yolu ile Doğrusal Ekstrüzyon birlikte [Küp](../primitives/cube.md) şekline benzer bir şekil oluşturur, ancak ekstrüzyon öncesinde [Şişir](../operations/path/inflate-path.md) veya [Yumuşat](../operations/path/smooth-path.md) gibi yol işlemlerini uygulayabilirsiniz
