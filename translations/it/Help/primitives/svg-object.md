# Oggetto SVG

Importa file SVG (Scalable Vector Graphics) e utilizzali come percorsi 2D nel tuo progetto. Gli SVG possono poi essere estrusi in forme 3D con [Estrusione lineare](../operations/path/linear-extrude.md) o [Rivoluzione](../operations/path/revolve.md).

## Come si usa

1. Importa un file SVG trascinandolo nell'area di lavoro oppure usando il pulsante Apri
2. L'SVG viene importato come percorso 2D
3. Applica [Estrusione lineare](../operations/path/linear-extrude.md) per dargli altezza, oppure usa altre [Operazioni sui percorsi](../operations/path/index.md)

## Suggerimenti

- Per risultati ottimali, i file SVG dovrebbero contenere forme piene o percorsi chiusi
- Gli SVG complessi con molti percorsi possono richiedere più tempo per l'elaborazione
- Usa [Seleziona percorsi](../operations/path/select-paths.md) per lavorare su parti specifiche di un SVG con più percorsi
- Online sono disponibili molti file SVG gratuiti per loghi, icone e motivi decorativi
