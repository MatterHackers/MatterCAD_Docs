# Oggetto immagine

Importa un'immagine e convertila in un oggetto 3D in rilievo in cui i valori di luminosità determinano l'altezza di ogni pixel. In questo modo puoi trasformare fotografie, loghi e illustrazioni in oggetti stampabili in 3D.

## Come si usa

1. Aggiungi un **Convertitore immagini** dal pannello Primitive, oppure trascina un file immagine direttamente nell'area di lavoro
2. Seleziona o cambia l'immagine tramite le proprietà
3. Regola l'altezza per controllare quanto vengono sollevate le aree chiare

## Parametri

- **Altezza** - Quanto sono alte le porzioni in rilievo dell'immagine
- L'anteprima dell'immagine viene mostrata nel pannello Proprietà

## Suggerimenti

- Le immagini ad alto contrasto con forme nitide danno i risultati migliori
- Puoi trascinare le immagini direttamente dal desktop nell'area di lavoro di MatterCAD
- Usa gli strumenti del menu di overflow su un'immagine importata per ulteriori opzioni di conversione
- Per ottenere contorni basati su percorsi a partire dalle immagini, vedi [Da immagine a percorso](../operations/image/image-to-path.md)
- Per visualizzazioni di immagini retroilluminate, vedi [Litofania](../operations/image/lithophane.md)
- Aggiungi una base combinando l'oggetto immagine con un [Cubo](cube.md)

## Correlati

- [Da immagine a percorso](../operations/image/image-to-path.md) - Traccia i contorni dell'immagine come percorsi 2D
- [Litofania](../operations/image/lithophane.md) - Crea immagini che appaiono in controluce
