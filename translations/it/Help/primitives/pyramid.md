# Piramide

Una forma piramidale a quattro facce con base rettangolare e altezza regolabili.

<!--  Screenshot of a Pyramid primitive on the workspace -->
![20260318 183743 paste 20260318 183743](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183743-paste-20260318-183743.jpg)


## Parametri

- **Larghezza** - Dimensione della base lungo l'asse X (predefinito: 20mm)
- **Profondità** - Dimensione della base lungo l'asse Y (predefinito: 20mm)
- **Altezza** - Quanto è alta la piramide dalla base all'apice (predefinito: 20mm)

## Suggerimenti

- Imposta Larghezza e Profondità sullo stesso valore per ottenere una piramide regolare a base quadrata
- Usa valori diversi di Larghezza e Profondità per una piramide a base rettangolare
- Utile per elementi decorativi, profili di tetti e dettagli appuntiti
