# Semisfera

L'emisfero superiore di una sfera, ovvero una forma a cupola. Utile per creare sommità a cupola, forme a lente e coperture arrotondate.

## Parametri

- **Diametro** - La larghezza della base della cupola (valore predefinito: 20mm)
- **Lati longitudine** - Numero di segmenti lungo il perimetro (valore predefinito: 40)
- **Lati di latitudine** - Numero di segmenti dalla base alla sommità (valore predefinito: 10). Più segmenti = cupola più liscia

## Suggerimenti

- Combina due semisfere con un cilindro per ottenere una forma a capsula
- Posizionala sopra un cilindro per creare un coperchio a cupola o un pulsante
- Usala con [Sottrai](../operations/boolean/subtract.md) per creare cavità a forma di cupola
