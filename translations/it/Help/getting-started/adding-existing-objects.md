# Aggiungere oggetti esistenti

Puoi importare in MatterCAD modelli 3D esistenti caricando file dal tuo computer oppure aggiungendo contenuti dalla libreria integrata.

## Dal tuo computer

![20260324 081143 paste 20260324 081143](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081143-paste-20260324-081143.jpg)

![20260324 081240 paste 20260324 081240](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081240-paste-20260324-081240.jpg)


Fai clic sul pulsante **Apri** nella barra degli strumenti per sfogliare e aggiungere file dal tuo computer. MatterCAD supporta i seguenti formati di importazione:

- **STL** (.stl) - Formato di modello 3D standard del settore, ampiamente utilizzato per la stampa 3D
- **AMF** (.amf) - Formato avanzato che supporta colori e oggetti multi-materiale
- **OBJ** (.obj) - Formato grafico 3D Wavefront (solo geometria mesh)
- **3MF** (.3mf) - 3D Manufacturing Format con ampio supporto per i metadati
- **MCX** (.mcx) - Formato nativo di MatterCAD, che conserva tutti i dati e i parametri del progetto
- **SVG** (.svg) - Scalable Vector Graphics, importato come percorsi 2D
- **TTF / OTF** (.ttf, .otf) - File di caratteri da utilizzare con lo strumento Testo

## Trascinamento della selezione

Puoi anche trascinare i file direttamente dal desktop o dal gestore file nell'area di lavoro di MatterCAD. I tipi di file supportati verranno importati automaticamente.

![20260324 081416 paste 20260324 081416](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081416-paste-20260324-081416.jpg)

## Dalla Libreria

### La Barra laterale della Libreria

Fai clic sul pulsante **Aggiungi contenuto** nella barra degli strumenti per aprire il pannello del browser della libreria. Da qui puoi:

- Sfogliare i progetti salvati
- Passare alla libreria Primitive per le forme integrate
- Accedere alla tua Libreria cloud se hai effettuato l'accesso
- Trascinare qualsiasi elemento della libreria direttamente nella tua area di lavoro

![20260324 081446 paste 20260324 081446](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081446-paste-20260324-081446.jpg)

### La scheda Libreria

Puoi anche usare la scheda Libreria per sfogliare le tue raccolte. Fai clic con il pulsante destro su un oggetto qualsiasi nella libreria e seleziona **Aggiungi alla scena** per importarlo nell'area di lavoro del progetto corrente.

![20260324 081536 paste 20260324 081536](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081536-paste-20260324-081536.jpg)

## Suggerimenti

- MCX è il formato migliore per rimettere mano ai progetti in seguito, poiché conserva tutti i parametri e l'albero di progettazione
- I file STL contengono solo la geometria mesh. Se importi un file STL, puoi comunque applicarvi delle operazioni, ma non puoi modificare i parametri originali
- Quando importi più file, ciascuno di essi diventa un oggetto separato nella scena. Usa [Raggruppa](../workspace/grouping.md) per organizzarli
