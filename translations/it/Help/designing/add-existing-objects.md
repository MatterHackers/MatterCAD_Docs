Dal tuo computer
================

![](https://lh3.googleusercontent.com/32sfdux7Fo64mrzY9hHBcWLoc8SKwTKuof6tEntzDbhKG27Y5Ow3NPEuwYGUJ9GR64tVk6h7MRY5T_UUIbi4a1NEeA)  
Fai clic sul pulsante Apri nella barra degli strumenti per aggiungere file dal tuo computer. MatterCAD supporta i seguenti formati di file:

* STL - Formato di modello 3D standard del settore
* AMF - Formato avanzato che supporta i colori e gli oggetti multi-materiale
* OBJ - Formato di grafica 3D Wavefront (solo mesh, senza texture o dati di colore)
* MCX - Formato nativo di MatterCAD

Trascina e rilascia
-------------------

Puoi trascinare e rilasciare i file direttamente dal desktop o dall'esplora file in MatterCAD.

![](https://lh3.googleusercontent.com/LkdsfkXvR_8jftgAZ2846W_WCuV9qt7C50slNRrB6y8-nE2I8ZqVCuI2ieThVqLyZTFWdnC7y_3p7Lqktmk_pWz5LQ)

Dalla Libreria
==============

La Barra laterale Libreria
--------------------------

![](https://lh3.googleusercontent.com/crGYrE83PyWb-hntQ8d-RhEeoiN_S8OI7uUnCS1oOm-8eMT5ExkDRSYZCr3IiT7Bx42HzrmFcg4yHhrv_GgzmbyfRA)  
Fai clic sul pulsante Aggiungi contenuto nella barra degli strumenti per aprire il browser della libreria. Da qui puoi trascinare e rilasciare qualsiasi contenuto della libreria nel tuo spazio di lavoro.

![](https://lh3.googleusercontent.com/926cpzNy9wQBIxRHCBUCaUJhIpWdHVp8FRXpr5sC07rIBiIOO_Ryh2PGX6_mW9Ooe4i8TBR5XlejcqL6B0cJupT4)

La scheda Libreria
------------------

Nella scheda Libreria puoi fare clic con il tasto destro su qualsiasi oggetto e selezionare Aggiungi alla scena per importarlo nello spazio di lavoro del progetto corrente.

![](https://lh3.googleusercontent.com/nv6037mkmlGpm9M_q5uyaTSnHtFOoXXDxm6niLI1fCXPr2EODWPcbAnP71xGr19npSz2RO1CeLZOvNrFtlUjMLJBpg)
