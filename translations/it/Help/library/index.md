# Libreria

La libreria consente di organizzare, archiviare e condividere i tuoi progetti 3D. Puoi sfogliare i file locali, accedere all'archiviazione cloud e condividere i progetti con altri utenti.

## Argomenti

- [Libreria locale](local-library.md) - Gestisci i progetti archiviati sul tuo computer
- [Libreria cloud](cloud-library.md) - Archivia e accedi ai progetti nel tuo account cloud MatterHackers
- [Condivisione](sharing.md) - Condividi i progetti con altri utenti MatterCAD
