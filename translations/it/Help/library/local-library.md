# Libreria locale

La Libreria locale conserva i tuoi progetti 3D sul computer. Puoi organizzare i progetti in cartelle, cercare i file e aggiungerli rapidamente al tuo spazio di lavoro.

![20260323 210208 paste 20260323 210208](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210208-paste-20260323-210208.jpg)


## Esplorare la libreria

1. Apri il pannello **Libreria** dalla barra laterale o dalla scheda Libreria
2. Naviga tra le cartelle per trovare i tuoi progetti
3. Fai doppio clic su un progetto per aprirlo, oppure trascinalo nello spazio di lavoro per aggiungerlo alla scena corrente

## Organizzare i file

- **Creare cartelle** - Fai clic con il pulsante destro nella libreria e scegli Crea cartella per organizzare i tuoi progetti
- **Rinominare gli elementi** - Fai clic con il pulsante destro su un elemento qualsiasi e scegli Rinomina
- **Eliminare gli elementi** - Fai clic con il pulsante destro e scegli Elimina per rimuovere gli elementi
- **Spostare gli elementi** - Trascina gli elementi tra le cartelle per riorganizzarli

## Opzioni di visualizzazione

Il pannello della libreria supporta diverse modalità di visualizzazione:

- **Vista elenco** - Elenco compatto con i nomi dei file
- **Vista icone** - Anteprime in miniatura dei tuoi progetti
- **Vista icone grandi** - Miniature più grandi per una consultazione più agevole

Puoi ordinare gli elementi per:

- **Nome** - Ordine alfabetico
- **Data di creazione** - Dal più recente o dal più vecchio
- **Data di modifica** - Prima quelli modificati più di recente

## Suggerimenti

- Usa la barra di ricerca in alto nella libreria per trovare rapidamente i progetti per nome
- Il browser della libreria mostra un'anteprima in miniatura per la maggior parte dei tipi di file
- I progetti salvati in formato MCX conservano tutti i parametri e l'albero del progetto per una completa rimodifica
