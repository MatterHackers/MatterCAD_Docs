# Libreria cloud

La Libreria cloud archivia i tuoi progetti online nel tuo account MatterHackers. In questo modo puoi accedere ai tuoi progetti da qualsiasi computer e mantenere un backup nel cloud.

![20260323 210141 paste 20260323 210141](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210141-paste-20260323-210141.jpg)

## Per iniziare

1. Accedi al tuo account MatterHackers dal menu dell'applicazione
2. La Libreria cloud compare nel browser della libreria
3. Carica i progetti trascinandoli nella cartella cloud, oppure salvali direttamente nel cloud

## Funzionalità

- **Accesso ovunque** - I tuoi progetti sono disponibili su qualsiasi computer in cui accedi
- **Backup nel cloud** - Il tuo lavoro è archiviato online in modo sicuro
- **Organizzazione in cartelle** - Crea cartelle per organizzare i progetti nel cloud esattamente come nella libreria locale
- **Condivisione** - Condividi i progetti con altri utenti MatterCAD. Vedi [Condivisione](sharing.md)

## Suggerimenti

- I progetti vengono sincronizzati automaticamente quando li salvi nella libreria cloud
- Per accedere ai contenuti della libreria cloud è necessaria una connessione a Internet
- I file di grandi dimensioni possono richiedere qualche istante per il caricamento o il download
- Conserva i progetti importanti sia nella libreria locale sia in quella cloud per maggiore sicurezza
