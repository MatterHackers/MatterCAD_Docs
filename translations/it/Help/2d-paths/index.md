# Percorsi 2D

I percorsi 2D sono forme piane che puoi usare come punto di partenza per gli oggetti 3D. Usa [Estrusione lineare](../operations/path/linear-extrude.md) per dare altezza a un percorso, oppure [Rivoluzione](../operations/path/revolve.md) per far ruotare un percorso attorno a un asse e creare una forma 3D.
