# Percorso Cerchio

Un percorso 2D circolare. Usalo con [Estrusione lineare](../operations/path/linear-extrude.md) per creare cilindri, oppure con [Rivoluzione](../operations/path/revolve.md) per creare forme simili a un toro.

## Parametri

- **Diametro** - Il diametro del cerchio (predefinito: 20mm)
- **Segmenti** - Numero di segmenti di linea che formano il cerchio. Maggiore = più liscio

## Suggerimenti

- Un Percorso Cerchio combinato con Estrusione lineare produce un cilindro, simile alla primitiva [Cilindro](../primitives/cylinder.md) ma con maggiore flessibilità nel modo in cui puoi costruirci sopra
- Usalo come base per Rivoluzione per creare forme ad anello

- [Percorso Anello](ring-path.md) - Un cerchio con un foro
