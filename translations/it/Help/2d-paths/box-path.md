# Percorso Riquadro

Un percorso 2D rettangolare. Usalo con [Estrusione lineare](../operations/path/linear-extrude.md) per creare forme a riquadro, oppure come base per altre operazioni sui percorsi.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parametri

- **Larghezza** - La larghezza del rettangolo (predefinito: 20mm)
- **Altezza** - L'altezza del rettangolo (predefinito: 20mm)

## Suggerimenti

- Un Percorso Riquadro combinato con Estrusione lineare crea una forma simile a un [Cubo](../primitives/cube.md), ma puoi applicare operazioni sui percorsi come [Gonfia](../operations/path/inflate-path.md) o [Leviga](../operations/path/smooth-path.md) prima di estrudere

- [Percorso Stella](star-path.md) - Un percorso 2D a forma di stella
