# Ingranaggio 2D

Un percorso di ingranaggio 2D che crea solo il profilo dei denti come percorso piano. Usalo con [Estrusione lineare](../operations/path/linear-extrude.md) o [Rivoluzione](../operations/path/revolve.md) per un maggiore controllo su come l'ingranaggio viene trasformato in una forma 3D.

<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->
![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)

## Come si usa

1. Aggiungi un **Ingranaggio 2D** dagli strumenti meccanici
2. Configura i parametri dei denti
3. Applica [Estrusione lineare](../operations/path/linear-extrude.md) per dargli altezza

## Suggerimenti

- Usa Ingranaggio 2D quando devi combinare un profilo di ingranaggio con altre operazioni sui percorsi prima di estrudere
- Per un ingranaggio 3D pronto all'uso, vedi invece [Ingranaggi](gears.md)
- Valgono le stesse regole di ingranamento: Passo circolare e Angolo di pressione corrispondenti per gli ingranaggi che devono lavorare insieme

## Correlati

- [Ingranaggi](gears.md) - Ingranaggi 3D pronti all'uso
- [Percorso stella](../2d-paths/star-path.md) - Una forma dentata più semplice
- [Estrusione lineare](../operations/path/linear-extrude.md) - Dai altezza al percorso dell'ingranaggio
