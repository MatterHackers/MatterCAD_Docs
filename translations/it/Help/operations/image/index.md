# Operazioni immagine
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

Le operazioni immagine convertono immagini 2D in oggetti o percorsi 3D, consentendoti di integrare fotografie, loghi e grafiche nei tuoi progetti.

## Operazioni

- [Convertitore immagini](image-converter.md) - Converte un'immagine in un rilievo 3D in base alla luminosità o al colore
- [Da immagine a percorso](image-to-path.md) - Traccia un'immagine per creare il contorno di un percorso 2D
- [Litofania](lithophane.md) - Crea una litofania che rivela un'immagine quando è retroilluminata
