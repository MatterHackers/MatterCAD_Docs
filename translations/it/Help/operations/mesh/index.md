# Operazioni sulla mesh
<!-- AUTO_IMAGE: type=toolbar_icons group=Mesh -->
![Mesh toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Mesh.png)

Le operazioni sulla mesh consentono di ripulire e ottimizzare la geometria della mesh triangolare dei modelli.

## Operazioni

- [Ripara](repair.md) - Corregge i problemi nella geometria della mesh, come fori, spigoli non-manifold e facce invertite
- [Riduci](decimate.md) - Riduce il numero di poligoni di una mesh per semplificarla preservandone la forma
