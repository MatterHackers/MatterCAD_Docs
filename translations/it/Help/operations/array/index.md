# Operazioni Serie
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Serie crea più copie di un oggetto disposte secondo uno schema. È utile per realizzare elementi ripetuti come fori per bulloni, pali di recinzione, denti di ingranaggi o elementi decorativi.

L'operazione Serie supporta quattro modalità — Lineare, Radiale, Curva e Trasforma — tutte in un unico strumento.
