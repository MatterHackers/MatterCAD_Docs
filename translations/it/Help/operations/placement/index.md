# Operazioni di posizionamento
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Le operazioni di posizionamento consentono di collocare con precisione gli oggetti l'uno rispetto all'altro o entro limiti specifici.

## Operazioni

- [Allinea](align.md) - Allinea gli oggetti tra loro lungo qualsiasi asse
- [Allineamento doppia estrusione](dual-extrusion-align.md) - Allinea gli oggetti alle rispettive posizioni di modellazione condivise
- [Adatta ai limiti](fit-to-bounds.md) - Scala un oggetto affinché rientri in un riquadro di delimitazione specificato
- [Adatta al cilindro](fit-to-cylinder.md) - Scala un oggetto affinché rientri in un cilindro specificato
