# Percorso contorno

Percorso contorno crea una versione contornata di un percorso pieno, convertendo una forma solida nel solo anello di confine con uno spessore specificato.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Come si usa

1. Seleziona un percorso 2D
2. Applica **Percorso contorno** dal menu delle operazioni Percorso
3. Regola lo spessore del contorno

## Suggerimenti

- Usalo per creare forme simili a telai a partire da percorsi pieni
- Combinalo con [Estrusione lineare](linear-extrude.md) per creare telai e bordi 3D
- Un [Percorso cerchio](../../2d-paths/circle-path.md) contornato equivale a un [Percorso anello](../../2d-paths/ring-path.md)

- [Percorso bordo](border-path.md) - Aggiungi un offset del bordo
