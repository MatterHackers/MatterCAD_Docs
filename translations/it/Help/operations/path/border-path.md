# Percorso bordo

Percorso bordo aggiunge un offset di bordo attorno a un percorso esistente, creando una versione più grande della forma che circonda l'originale.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Come si usa

1. Seleziona un percorso 2D
2. Applica **Percorso bordo** dal menu delle operazioni Percorso
3. Regola la larghezza del bordo

## Suggerimenti

- Usa questa operazione per creare un margine o una spaziatura attorno alle forme
- Combina il percorso originale con [Sottrai](../boolean/subtract.md) per creare forme a cornice
- Simile a [Gonfia percorso](inflate-path.md), ma pensato specificamente per la generazione di bordi

## Correlati

- [Gonfia percorso](inflate-path.md) - Espandi un percorso verso l'esterno
- [Percorso contorno](outline-path.md) - Crea un contorno da un percorso pieno
- [Estrusione lineare](linear-extrude.md) - Dai altezza al percorso con bordo
