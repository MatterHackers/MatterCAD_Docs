# Operazioni sui percorsi
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

Le operazioni sui percorsi lavorano con percorsi 2D per creare e modificare forme 3D. Utilizzale per estrudere, ruotare e perfezionare geometrie basate su percorsi.

## Operazioni

- [Estrusione lineare](linear-extrude.md) - Conferisce altezza a un percorso 2D per creare un oggetto 3D
- [Rivoluzione](revolve.md) - Fa ruotare un percorso 2D attorno a un asse per creare un solido di rivoluzione
- [Leviga percorso](smooth-path.md) - Leviga le curve di un percorso
- [Gonfia percorso](inflate-path.md) - Espande un percorso verso l'esterno
- [Percorso contorno](outline-path.md) - Crea un contorno a partire da un percorso pieno
- [Percorso bordo](border-path.md) - Aggiunge un offset di bordo attorno a un percorso
- [Seleziona percorsi](select-paths.md) - Seleziona percorsi specifici da oggetti complessi con più percorsi
