# Operazioni di Trasforma
<!-- AUTO_IMAGE: type=toolbar_icons group=Transform -->
![Transform toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Transform.png)

Le operazioni di Trasforma modificano la posizione, l'orientamento e le dimensioni degli oggetti senza alterarne la geometria.

## Operazioni

- [Trasla](translate.md) - Sposta un oggetto di uno scostamento specifico in X, Y o Z
- [Ruota](rotate.md) - Ruota un oggetto attorno a un asse di un angolo specificato
- [Scala](scale.md) - Ridimensiona un oggetto con opzioni di scalatura uniforme o per singolo asse
- [Specchia](mirror.md) - Crea una copia speculare di un oggetto rispetto a un asse
