# Controlli del mouse

Riferimento completo per i controlli del mouse nella vista 3D di MatterCAD.

## Navigazione

| Azione | Controllo del mouse |
|--------|--------------|
| **Ruota vista** | Clic destro + Trascinamento |
| **Panoramica vista** | Clic centrale + Trascinamento |
| **Zoom** | Rotellina di scorrimento |

## Navigazione alternativa

| Azione | Controllo del mouse |
|--------|--------------|
| **Ruota vista** | Ctrl + Clic sinistro + Trascinamento |
| **Panoramica vista** | Ctrl + Maiusc + Clic sinistro + Trascinamento |
| **Zoom** | Ctrl + Alt + Clic sinistro + Trascinamento |

## Interazione con gli oggetti

| Azione | Controllo del mouse |
|--------|--------------|
| **Seleziona oggetto** | Clic sinistro sull'oggetto |
| **Selezione multipla** | Maiusc + Clic sinistro su altri oggetti |
| **Selezione multipla** | Ctrl + Clic sinistro su altri oggetti |
| **Deseleziona tutto** | Clic sinistro su uno spazio vuoto |
| **Selezione con riquadro** | Clic sinistro + Trascinamento su uno spazio vuoto |
| **Sposta oggetto** | Clic sinistro + Trascinamento sull'oggetto selezionato |
| **Menu contestuale** | Clic destro sull'oggetto |

## Controlli dell'oggetto

Quando un oggetto è selezionato, compaiono controlli interattivi:

| Azione | Controllo |
|--------|---------|
| **Sposta sul piano** | Trascina l'oggetto |
| **Sposta su/giù** | Trascina la freccia verticale sopra l'oggetto |
| **Ruota** | Fai clic e trascina un controllo d'angolo di rotazione |
| **Scala** | Fai clic e trascina un controllo d'angolo di scala |

## Suggerimenti

- Lo zoom con la rotellina di scorrimento è centrato sulla posizione del cursore del mouse: punta all'area su cui vuoi ingrandire
- I controlli alternativi (Ctrl + Clic sinistro) sono utili se non disponi del pulsante centrale del mouse o se il clic destro è scomodo
- Quando ruoti con i controlli d'angolo, passa il puntatore sugli indicatori di angolo per agganciarti a incrementi di 45 gradi
