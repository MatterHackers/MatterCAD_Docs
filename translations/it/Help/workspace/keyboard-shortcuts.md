# Scorciatoie da tastiera

Guida rapida a tutte le scorciatoie da tastiera disponibili in MatterCAD.

## Modifica

| Scorciatoia | Azione |
|----------|--------|
| Ctrl + Z | Annulla |
| Ctrl + Y | Ripeti |
| Ctrl + Shift + Z | Ripeti (alternativa) |
| Ctrl + A | Seleziona tutti gli oggetti |
| Ctrl + C | Copia gli oggetti selezionati |
| Ctrl + X | Taglia gli oggetti selezionati |
| Ctrl + V | Incolla gli oggetti |
| Spazio | Cancella selezione |
| Escape | Annulla l'operazione di trascinamento in corso |
| Delete | Elimina gli oggetti selezionati |

## Vista

| Scorciatoia | Azione |
|----------|--------|
| W | Reimposta la vista (adatta tutti gli oggetti alla finestra) |
| Z | Ingrandisci sull'oggetto selezionato |
| Ctrl + Più (+) | Ingrandisci |
| Ctrl + Meno (-) | Riduci |
| Tasti freccia | Ruota la vista |
| Shift + Tasti freccia | Panoramica della vista |

## Controlli del mouse

| Azione | Controllo |
|--------|---------|
| Ruota la vista | Clic destro + Trascinamento |
| Panoramica della vista | Clic centrale + Trascinamento |
| Zoom | Ruota di scorrimento |
| Seleziona un oggetto | Clic sinistro sull'oggetto |
| Selezione multipla | Shift + Clic sinistro oppure Ctrl + Clic sinistro |
| Selezione a riquadro | Clic sinistro + Trascinamento su uno spazio vuoto |
| Menu contestuale | Clic destro sull'oggetto |

## Controlli del mouse alternativi

| Azione | Controllo |
|--------|---------|
| Ruota la vista | Ctrl + Clic sinistro + Trascinamento |
| Panoramica della vista | Ctrl + Shift + Clic sinistro + Trascinamento |
| Zoom | Ctrl + Alt + Clic sinistro + Trascinamento |

## Applicazione

| Scorciatoia | Azione |
|----------|--------|
| Ctrl + Shift + T | Riapri l'ultimo progetto chiuso |
| F1 | Apri Aiuto |
