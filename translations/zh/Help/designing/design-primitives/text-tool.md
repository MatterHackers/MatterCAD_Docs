 - **名称：** 输入您想要显示的任意文本
 - **点大小：** 设置字体的大小。当打印为与 2D 打印机相同的尺寸时，此数值是准确的。
 - **高度：** 设置您希望文本达到的高度
 - **字体：** 选择您想要使用的字体
