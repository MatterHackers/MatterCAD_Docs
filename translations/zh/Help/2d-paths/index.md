# 2D 路径

2D 路径是平面形状，可用作 3D 对象的起始基础。使用[线性拉伸](../operations/path/linear-extrude.md)为路径赋予高度，或使用[旋转成型](../operations/path/revolve.md)将路径绕轴旋转以生成 3D 形体。

## 可用路径

- [圆路径](circle-path.md) - 圆形的 2D 轮廓
- [方块路径](box-path.md) - 矩形的 2D 轮廓
- [圆环路径](ring-path.md) - 2D 圆环（带孔的圆）
- [星形路径](star-path.md) - 星形的 2D 轮廓，可配置角数
- [自定义路径](custom-path.md) - 使用控制点绘制您自己的 2D 路径
