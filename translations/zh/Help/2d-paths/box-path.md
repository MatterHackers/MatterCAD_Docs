# 方块路径

矩形二维路径。与[线性拉伸](../operations/path/linear-extrude.md)配合使用可创建方块形状，也可作为其他路径操作的基础。

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## 参数

- **宽度** - 矩形的宽度（默认值：20mm）
- **高度** - 矩形的高度（默认值：20mm）

## 提示

- 方块路径加上线性拉伸可创建类似[立方体](../primitives/cube.md)的形状，但在拉伸之前，你可以对其应用[膨胀](../operations/path/inflate-path.md)或[平滑](../operations/path/smooth-path.md)等路径操作
