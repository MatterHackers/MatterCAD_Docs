# 视口导航

3D 视口是您查看设计并与之交互的地方。MatterCAD 使用轨迹球相机模型，让您可以围绕对象自由地环绕、平移和缩放。

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## 鼠标控制

### 旋转视图

- **右键单击 + 拖动** - 围绕您的设计环绕相机
- **Ctrl + 左键单击 + 拖动** - 备选旋转方式

### 平移视图

- **中键单击 + 拖动** - 将视图向左、向右、向上或向下滑动
- **Ctrl + Shift + 左键单击 + 拖动** - 备选平移方式

### 放大和缩小

- **滚轮** - 向上滚动放大，向下滚动缩小
- **Ctrl + Alt + 左键单击 + 拖动** - 备选缩放方式

## 键盘控制

### 视图快捷键

- **W** - 重置视图，使所有对象适应视口
- **Z** - 缩放至当前选中的对象

### 方向键导航

- **方向键** - 旋转视图
- **Shift + 方向键** - 平移视图

### 缩放快捷键

- **Ctrl + 加号 (+)** - 放大
- **Ctrl + 减号 (-)** - 缩小

## 提示

- 如果找不到模型，按 **W** 重置视图，将所有内容重新纳入画面
- 选中对象后使用 **Z**，可快速聚焦到该对象
- 滚轮缩放以鼠标光标位置为中心，因此请将光标指向您想要放大的区域
- 您可以结合旋转和平移，从任意角度检查您的设计
