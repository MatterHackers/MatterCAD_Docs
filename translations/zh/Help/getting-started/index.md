# MatterCAD 入门

MatterCAD 是一款专业的 3D 设计应用程序，用于创建和修改 3D 模型。无论您是从零开始构建，还是编辑导入的文件，这些指南都能帮助您快速上手。

![20260324 081704 paste 20260324 081704](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081704-paste-20260324-081704.jpg)

## MatterCAD 工作区

打开 MatterCAD 时，您会看到几个关键区域：

- **3D 视口** - 查看 3D 模型并与之交互的主要区域
- **工具栏** - 位于顶部，包含撤销、重做、编组等常用操作按钮以及设计工具
- **库面板** - 位于左侧，可在此浏览基本体和您保存的设计
- **属性面板** - 位于右侧，显示所选对象的参数
- **设计树** - 显示场景中对象的层级结构

## 快速开始

1. **添加形状** - 打开基本体面板，点击立方体或圆柱体等形状，将其添加到工作区
2. **移动它** - 点击并拖动对象以重新定位，或使用上/下箭头调整高度
3. **修改它** - 选择该对象，并在右侧的属性面板中调整其参数
4. **添加更多形状** - 添加其他基本体，并使用[布尔运算](../operations/boolean/index.md)对它们进行合并或相减
5. **保存您的作品** - 使用品牌菜单将设计保存为 MCX 格式，或导出为 STL 以进行 3D 打印
