# 正在保存和正在导出

MatterCAD 支持多种文件格式来保存和导出您的设计。选择哪种格式取决于您打算如何使用该文件。

## 保存格式

### MCX（原生格式）

MCX 是 MatterCAD 的原生文件格式，也是您希望日后继续编辑的设计的最佳选择。它会保留：

- 完整的设计树，包含所有对象及其层级结构
- 每个对象的全部参数和设置
- 布尔运算、阵列以及其他可编辑形式的操作
- 组件之间的关系

**何时使用 MCX：** 当您想保存工作成果并在日后继续编辑时。

### STL

STL 是 3D 打印中使用最广泛的格式。它仅包含最终的三角网格几何体，不含任何设计历史或参数。

**何时使用 STL：** 当您想 3D 打印您的设计，或与不使用 MatterCAD 的人分享时。

### OBJ

OBJ（Wavefront）是大多数 3D 软件都支持的常见 3D 格式。与 STL 一样，它仅包含网格几何体。

**何时使用 OBJ：** 当您需要在 Blender 或游戏引擎等其他 3D 软件中打开您的设计时。

### SVG

SVG 导出会根据设计的俯视图生成 2D 矢量文件。这对于激光切割或 CNC 雕铣非常有用。

**何时使用 SVG：** 当您需要设计的 2D 轮廓以用于激光切割或雕刻时。

## 如何保存

![20260324 080726 paste 20260324 080726](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080726-paste-20260324-080726.jpg)

1. 打开**品牌菜单**（左上角的 MatterCAD 徽标）
2. 选择**另存为**以选择位置和格式
3. 从格式下拉菜单中选择文件格式
4. 选择文件的保存位置并点击**保存**

您的设计在工作过程中也会自动保存，因此即使关闭应用程序也不会丢失更改。

## 提示

- 在导出为 STL 或 OBJ 之前，请务必保存一份设计的 MCX 副本，以便日后进行修改
- 导出 STL 时，场景中的所有对象都会合并为单个网格
- 如果需要与使用 MatterCAD 的人分享设计，请发送 MCX 文件以保留完整的可编辑性
- 您还可以将设计保存到[云端库](../library/cloud-library.md)，以便从任意计算机访问
