# 库

库可用于整理、存储和共享您的 3D 设计。您可以浏览本地文件、访问云端存储，并与他人共享设计。

## 主题

- [本地库](local-library.md) - 管理存储在您计算机上的设计
- [云端库](cloud-library.md) - 在您的 MatterHackers 云账户中存储和访问设计
- [共享](sharing.md) - 与其他 MatterCAD 用户共享设计
