# 云端库

云端库将您的设计在线存储在您的 MatterHackers 账户中。这样您就可以从任何计算机访问自己的设计，并在云端保留备份。

![20260323 210141 paste 20260323 210141](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210141-paste-20260323-210141.jpg)

## 入门

1. 从应用程序菜单登录您的 MatterHackers 账户
2. 云端库将出现在库浏览器中
3. 将设计拖入云端文件夹以上传，或直接保存到云端

## 特征

- **随处访问** —— 在任何登录的计算机上都可以使用您的设计
- **云端备份** —— 您的作品安全地存储在线上
- **文件夹整理** —— 像本地库一样创建文件夹来整理云端设计
- **共享** —— 与其他 MatterCAD 用户共享设计。参见[共享](sharing.md)

## 提示

- 保存到云端库时，设计会自动同步
- 访问云端库内容需要联网
- 大文件的上传或下载可能需要稍等片刻
- 将重要设计同时保存在本地库和云端库中，以实现冗余备份
