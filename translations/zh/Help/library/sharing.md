# 共享

MatterCAD 允许您通过共享代码与其他用户共享您的设计。这让协作设计或分发您的作品变得非常简单。

![20260323 210309 paste 20260323 210309](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210309-paste-20260323-210309.jpg)


## 共享设计

1. 在[云端库](cloud-library.md)中右键单击某个设计
2. **选择****共享**
3. 系统会生成一个共享代码，您可以将其发送给他人

## 接收共享的设计

1. 从他人处获取共享代码
2. 在库中使用 **Redeem Share Code** 选项
3. 共享的设计将被添加到您的库中

## 提示

- 共享代码适用于存储在云端库中的设计
- 接收者获得的是设计的副本 —— 他们所做的更改不会影响您的原始设计
- 共享代码可以通过任何渠道分发：电子邮件、聊天工具、社交媒体等
