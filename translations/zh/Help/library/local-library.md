# 本地库

本地库将您的 3D 设计保存在您的计算机上。您可以将设计整理到文件夹中、搜索文件，并快速将它们添加到工作区。

![20260323 210208 paste 20260323 210208](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210208-paste-20260323-210208.jpg)


## 浏览库

1. 从侧边栏或库选项卡打开 **库** 面板
2. 浏览各个文件夹以找到您的设计
3. 双击某个设计将其打开，或将其拖入工作区以添加到当前场景

## 整理文件

- **新建文件夹** - 在库中右键单击并选择新建文件夹，以整理您的设计
- **重命名项目** - 右键单击任意项目并选择重命名
- **删除项目** - 右键单击并选择删除以移除项目
- **移动项目** - 在文件夹之间拖动项目以重新整理

## 视图选项

库面板支持多种视图模式：

- **列表视图** - 显示文件名称的紧凑列表
- **图标视图** - 设计的缩略图预览
- **大图标视图** - 更大的缩略图，便于浏览

您可以按以下方式排序：

- **名称** - 按字母顺序
- **创建日期** - 由新到旧或由旧到新
- **修改日期** - 最近修改的排在前面

## 提示

- 使用库顶部的搜索栏，可按名称快速查找设计
- 库浏览器为大多数文件类型显示预览缩略图
- 以 MCX 格式保存的设计会保留所有参数和设计树，可完整地重新编辑
