# 二维齿轮

一种二维齿轮路径，仅生成平面路径形式的轮齿轮廓。可将其与[线性拉伸](../operations/path/linear-extrude.md)或[旋转成型](../operations/path/revolve.md)配合使用，以便更好地控制齿轮如何构建成三维形状。

<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->
![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)

## 使用方法

1. 从机械工具中添加**二维齿轮**
2. 配置轮齿参数
3. 应用[线性拉伸](../operations/path/linear-extrude.md)为其赋予高度

## 提示

- 当你需要在拉伸之前将齿轮轮廓与其他路径操作组合时，请使用二维齿轮
- 如需可直接使用的三维齿轮，请改为参见[齿轮](gears.md)
- 同样适用啮合规则：相互配合的齿轮需具有相同的周节和压力角
