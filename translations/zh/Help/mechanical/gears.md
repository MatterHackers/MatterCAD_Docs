# 齿轮

创建齿形几何完全可配置的三维齿轮。MatterCAD 生成标准的渐开线齿廓，可与相同模数和压力角的其他齿轮正确啮合。

<!-- AUTO_IMAGE: type=from_thumbnail item=gear file=mechanical_gears -->
![mechanical_gears](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gears.png)

## 使用方法

1. 从机械工具或基本体面板中添加**齿轮**
2. 设置齿数及其他参数
3. 齿廓将自动生成

## 参数

### 特征

- **齿轮类型** - 外部齿轮或齿条（带齿的直条）
- **高度** - 齿轮的厚度（拉伸高度）
- **齿数** - 齿轮四周的齿的数量（默认值：30，范围：4-60）
- **周节** - 沿节圆测量的相邻齿之间的弧长距离（范围：3-30）。该值决定齿轮的整体尺寸。
- **中心孔直径** - 中心轴孔的直径（默认值：4mm，设为 0 则不生成孔）。仅适用于外部齿轮。
- **外边缘宽度** - 内齿之外的边缘宽度
- **内齿轮齿数** - 与之啮合的内齿轮的齿数

### 高级

- **压力角** - 齿面接触面的角度（常用值：14.5、20 或 25 度）。所有相互啮合的齿轮必须使用相同的压力角。
- **间隙** - 齿顶与配对齿的齿槽之间的最小间隙
- **背隙** - 啮合齿轮轮齿之间的最小间隙，用于防止卡死

### 齿轮数据（只读）

- **节圆半径** - 齿轮相互啮合处的半径
- **外径** - 到齿顶的总直径

## 提示

- 当两个齿轮具有相同的周节和压力角时，即可正确啮合
- 使用节圆半径的数值来正确布置啮合齿轮的间距——齿轮中心之间的距离应等于两者节圆半径之和
- 为 3D 打印的齿轮添加背隙，以补偿打印公差
- 如需二维齿廓（配合拉伸使用），请参阅[二维齿轮](gear-2d.md)
