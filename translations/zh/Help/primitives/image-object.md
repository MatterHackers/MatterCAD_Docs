# 图像对象

导入图像并将其转换为三维浮雕对象，图像的亮度值决定每个像素的高度。您可以借此将照片、徽标和艺术作品转换为可三维打印的对象。

## 使用方法

1. 从基本体面板中添加**图像转换器**，或将图像文件直接拖放到工作区中
2. 使用属性选择或更换图像
3. 调整高度以控制明亮区域的凸起程度

## 参数

- **高度** - 图像凸起部分的高度
- 图像预览显示在属性面板中

## 提示

- 形状清晰、对比度高的图像效果最佳
- 您可以将图像直接从桌面拖放到 MatterCAD 工作区中
- 对导入的图像使用溢出菜单中的工具，可获得更多转换选项
- 若要从图像生成基于路径的轮廓，请参阅[图像转路径](../operations/image/image-to-path.md)
- 若要制作背光图像展示效果，请参阅[浮雕灯片](../operations/image/lithophane.md)
- 将图像对象与[立方体](cube.md)组合可添加底座
