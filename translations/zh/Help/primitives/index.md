# 基本体

MatterCAD 提供了一个 3D 基本体形状库，可作为设计的构建模块。您可以从基本体面板将任意基本体添加到工作区，然后修改其参数，以获得所需的精确形状。

## 基础形状

- [立方体](cube.md) - 具有可调宽度、深度、高度以及可选圆角的盒状体
- [圆柱体](cylinder.md) - 可配置直径、高度和边数的圆形柱体
- [球体](sphere.md) - 具有可调直径和细节级别的圆球
- [圆锥体](cone.md) - 逐渐收拢至顶点的锥形圆柱
- [圆环体](torus.md) - 可控制内径和外径的甜甜圈形状
- [圆环](ring.md) - 具有内径和外径的管状形状（空心圆柱）
- [棱锥体](pyramid.md) - 底面和高度可调的四棱锥
- [楔形体](wedge.md) - 三角棱柱形状
- [半球](half-sphere.md) - 球体的上半部分
- [半圆柱](half-cylinder.md) - 沿长度方向剖成一半的圆柱体
- [半楔形](half-wedge.md) - 剖成一半的楔形体
- [孔](hole.md) - 用于布尔减运算的立方体形孔


## 文本与特殊形状

- [文本](text.md) - 创建可自定义字体和尺寸的 3D 拉伸文本
- [盲文](braille.md) - 生成可 3D 打印的盲文文本
- [盲文卡片](braille-card.md) - 创建带有浮凸文本的盲文卡片
- [二维码](qr-code.md) - 将二维码生成为 3D 对象
- [图像对象](image-object.md) - 导入图像并将其转换为 3D 浮雕
- [SVG 对象](svg-object.md) - 将 SVG 矢量图形导入为 3D 形状
