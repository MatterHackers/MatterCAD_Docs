# 盲文

从标准英文文本生成可3D打印的盲文。盲文工具同时支持一级（逐字母）和二级（缩写）盲文编码。

## 使用方法

1. 从基本体面板中添加一个**盲文**基本体
2. 在**待编码文本**字段中输入您的文本
3. 工具会自动将其转换为正确的盲文点阵图案

## 参数

- **待编码文本** - 要转换为盲文的英文文本
- **缩放** - 调整盲文输出的整体大小
- **高度** - 凸起盲文点的高度

## 提示

- 二级盲文对常用单词和字母组合使用缩写形式，因而更加紧凑
- 采用标准盲文方格尺寸，以确保输出内容可被读取
- 与扁平的[立方体](cube.md)底座合并，可制作完整的盲文标签或标牌
- 如需带一体式底座的盲文卡片，请参见[盲文卡片](braille-card.md)
