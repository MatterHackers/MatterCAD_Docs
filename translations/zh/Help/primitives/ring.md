# 圆环

一种空心圆柱体（管状），具有独立的内径和外径以及指定的高度。也称为管道或管状形状。

![20260318 183848 paste 20260318 183848](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183848-paste-20260318-183848.jpg)


## 参数

- **外径** - 圆环的外部宽度（默认值：20mm）
- **内径** - 空心中心的直径（默认值：15mm）
- **高度** - 圆环的高度（默认值：5mm）
- **侧面** - 周边的分段数量（默认值：40）

### 高级参数

启用**高级**模式可获得更多控制项：

- **起始角度** - 圆环开始处的角度（默认值：0）
- **终止角度** - 圆环结束处的角度（默认值：360）。设置为小于 360 可得到部分圆环
- **圆角** - 为边缘添加圆角（无、向上或向下）
- **方向** - 朝内侧或外侧边缘做圆角（启用圆角时可见）
- **圆角分段数** - 圆角的平滑程度（启用圆角时可见）

## 提示

- 壁厚等于（外径 - 内径）/ 2
- 可用于制作垫圈、垫片、衬套以及管状特征
- 高度设置得较高可制作管道，较低则可制作扁平垫圈
- 使用起始角度和终止角度可制作类似 C 形卡簧的部分圆环形状
