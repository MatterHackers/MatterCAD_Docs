# 楔形体

三角柱体形状——就像立方体沿着一条边到对边的对角线切开一样。适用于制作斜坡、支撑件和倾斜表面。

## 参数

- **宽度** - 沿 X 轴方向的尺寸（默认值：20mm）
- **深度** - 沿 Y 轴方向的尺寸（默认值：20mm）
- **高度** - 楔形体最高点处的高度（默认值：20mm）
- **圆角** - 为顶部边缘添加圆角（无、向上或向下）
- **圆角分段数** - 圆角的平滑程度（启用圆角时可见）

## 提示

- 楔形体非常适合创建斜坡、倾斜支架和支撑结构
- 使用圆角选项可让斜面边缘过渡更加平滑
