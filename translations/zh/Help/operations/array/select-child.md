# 选择子项

选择子项可根据索引编号或名称，从一组对象中挑选出其中一个子项。这在脚本化和参数化设计中尤为有用，因为你可以动态地选择要显示的对象。

![20260506 080526 paste 20260506 080526](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080526-paste-20260506-080526.jpg)


## 使用方法

1. 选择两个或更多对象
2. 从复制菜单中应用 **选择子项** 操作
3. 选择 **按索引** 或 **按名称** 来控制子项的选取方式
4. 设置要匹配的索引编号或名称

## 参数

- **选择方式** - 在 **按索引**（按位置选择）和 **按名称**（按对象名称选择）之间进行选择。以按钮形式显示。
- **子索引** - 要选择的子项的索引，从零开始计数（使用按索引时显示）。支持[表达式](../../workspace/expressions.md)。
- **子名称** - 要选择的子项的名称（使用按名称时显示）。支持[表达式](../../workspace/expressions.md)。

如果索引超出范围，或名称与任何子项都不匹配，则会返回第一个子项作为回退结果。如果没有任何子项，则不返回任何内容。

## 在脚本编写中的应用

选择子项旨在配合表达式和 `rand()` 函数使用，以创建动态的、由数据驱动的设计。例如，你可以搭建一个场景，将若干变体对象作为子项，并使用类似 `rand(42)` 的表达式作为索引种子来随机挑选其中一个。

**示例：舞台演出的随机书籍道具**

1. 导入 5 个不同的书籍网格，作为一个选择子项操作的子项
2. 将选择方式设置为 **按索引**
3. 为子索引使用表达式，例如 `floor(rand(seed) * 5)`，其中 `seed` 是一个表格变量
4. 将该选择子项操作复制多次，每次使用不同的种子值
5. 每个实例都会从集合中随机挑选出不同的书籍

这种方式适用于任何需要从一组变体中进行挑选的场景：家具、装饰、建筑元素，或任何可互换部件的集合。

## 提示

- 与[阵列](array.md) 结合使用，可创建富于变化的图案，让每个复制体都选择不同的子项
- 为索引或名称使用表格变量，即可通过电子表格来驱动选择
- 回退到第一个子项的行为意味着，即使索引或名称有误，你的设计也不会出错
