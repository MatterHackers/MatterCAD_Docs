# 阵列

阵列会创建对象的多个副本并按图案排列。从顶部的按钮中选择一种模式——**线性**、**径向**或**变换**——即可在图案类型之间切换。

## 使用方法

1. 选择一个对象
2. 从复制菜单中应用**阵列**操作
3. 选择一种模式（线性、径向或变换）
4. 调整所选模式的参数

## 模式：线性

线性模式会沿某一方向放置副本，并可选择叠加旋转和缩放的递进变化。

**数量** — 副本的数量（整数或表达式）。源对象即为第一个副本；其余副本相对于它进行偏移。

**偏移方式** — 间距的计算方式：
- **相对** — 偏移量会乘以对象包围盒的尺寸。相对偏移为 (1, 0, 0) 时，副本沿 X 轴之间正好相隔一个对象宽度。
- **偏移** — 每个副本之间固定的世界空间距离（mm）。
- **端点** — 设置最后一个副本的位置；间距在各副本之间平均分配。

**相对偏移** / **偏移** / **端点** — 间距向量，具体取决于所选的偏移方式。

**旋转模式** — 旋转在各副本之间的累积方式：
- **局部** — 每个副本围绕自身中心原地旋转；偏移方向保持在世界坐标轴上。
- **复合** — 旋转不断累积并带动偏移方向，可生成螺旋、扇形和螺旋线。

**旋转** — 每个副本在各轴上的旋转角度（度）。

**缩放** — 每个副本在各轴上的累积缩放。小于 1 的值会缩小副本；大于 1 的值会放大副本。

**缩放影响偏移** — 开启后，副本之间的间距也会随每一步一起缩放。可用于制作逐渐收紧的螺旋和几何级数排列（鹦鹉螺壳、层叠的螺壳曲线）。

## 模式：径向

径向模式会以固定半径围绕中心轴均匀分布副本。

![20260506 092618 paste 20260506 092618](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-092618-paste-20260506-092618.jpg)


**计数方式** — 副本数量的确定方式：
- **数量** — 明确指定副本的数量。
- **距离** — 副本之间的角度间隔（度）；数量会根据填满扫掠范围自动计算。

**数量** / **角距离** — 副本的数量（数量模式）或角度间距（距离模式，单位为度）。支持表达式。

**中心轴** — 用于旋转的轴（默认：Z）。

**圆弧段** — 副本是分布在完整的 360° 圆周上（**完整**）还是分布在部分圆弧上（**圆弧**）。

**半径** — 中心轴到每个副本的距离。

**扫掠角度** — 要填充的圆弧角度（当圆弧段为圆弧时显示）。支持表达式。

**对齐旋转** — 旋转每个副本，使其前向轴朝向远离中心的方向。

**前向轴** — 副本的哪个轴被视为对齐时的“前向”（当对齐旋转开启时显示）。

## 模式：变换

变换模式使用手动指定的变换，或跟随另一个对象的变换来逐步生成副本。

**数量** — 副本的数量（整数或表达式）。

**变换参考** — 每一步的变换来源：
- **输入** — 由你直接指定平移、旋转和缩放。
- **对象** — 从指定名称的同级对象中读取变换。

**平移** — 每一步在世界空间中的偏移量（mm）（当参考为输入时显示）。

**旋转** — 每一步各轴的旋转角度（度）（当参考为输入时显示）。

**缩放** / **缩放轴** — 每一步应用的统一缩放和各轴缩放（当参考为输入时显示）。

**变换名称** — 其变换用作每步增量的同级对象名称（当参考为对象时显示）。

**相对空间** — 开启时，每个副本的变换会在上一个副本的局部坐标系中复合累积；关闭时，每一步都在世界空间中应用（当参考为对象时显示）。

## 随机化

启用**随机化**可为所有副本添加变化。

- **随机偏移** — 各轴上最大的随机位置偏移量（mm）。
- **随机旋转** — 各轴上最大的随机旋转角度（度）。
- **随机缩放轴** — 各轴上最大的随机缩放变化。
- **排除第一个** — 使第一个副本保持在其精确的计算位置（默认：开启）。
- **排除最后一个** — 使最后一个副本保持在其精确的计算位置。
- **随机种子** — 更改此值可获得不同的随机排列。支持表达式。

## 合并

- **创建单一网格** — 将所有副本合并为一个网格对象。
- **合并顶点** — 焊接处于合并距离阈值内的顶点（当创建单一网格开启时显示）。
- **距离** — 合并阈值（mm）（当合并顶点开启时显示）。

## 提示

- 对数量、旋转或端点使用表达式，可创建参数化图案
- 制作圆形图案时请使用径向模式——设置半径以控制圆的大小，若希望副本朝外则启用对齐旋转
- 在线性模式中使用复合旋转，无需手动计算角度偏移即可生成螺旋和扇形
- 缩放影响偏移可自然地生成鹦鹉螺壳和几何级数式的布局
- 将阵列与[选择子项](select-child.md)结合使用，可创建每个副本显示不同变体的图案
