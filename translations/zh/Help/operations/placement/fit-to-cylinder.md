# 拟合圆柱

拟合圆柱可将对象缩放至由直径和高度所定义的指定圆柱边界之内。

## 使用方法

1. 选择一个对象
2. 从放置菜单中应用 **拟合圆柱** 操作
3. 设置目标直径和高度

## 参数

- **直径** - 目标圆柱体的直径
- **高度** - 目标圆柱体的高度
- **Z 向拉伸** - 启用后，将对象缩放至与圆柱体的高度相匹配
- **备用居中** - 启用后，根据零件的视觉重心而非其边界圆进行居中
