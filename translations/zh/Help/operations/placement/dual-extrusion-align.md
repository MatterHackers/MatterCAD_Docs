# 双挤出头对齐

![20260506 160531 paste 20260506 160531](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-160531-paste-20260506-160531.jpg)


双挤出头对齐会重新放置两个或更多选中的对象，使它们的中心对齐到共同的建模原点——即为双挤出打印而设计时，它们彼此之间应处的位置。

## 使用方法

1. 选择两个或更多对象
2. 从放置菜单中应用 **双挤出头对齐**

## 适用场景

当您的零件是为在双挤出打印机上一同打印而设计，但已被移出其相对位置时，请使用此操作。双挤出头对齐会将它们恢复到预期的共享坐标空间中。
