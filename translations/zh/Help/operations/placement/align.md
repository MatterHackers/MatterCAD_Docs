# 对齐

对齐可将多个对象相对于某个锚点对象精确定位。可用它对齐边缘、使零件彼此居中、将一个对象放在另一个对象之上，或创建间距均匀的堆叠。

![Two objects with the Align operation settings visible](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-154830-paste-20260506-154830.jpg)


## 使用方法

1. 选择两个或更多对象。
2. 从 **放置** 菜单中应用 **对齐** 操作。
3. 选择 **锚点** 对象。锚点保持不动，其他对象随之移动。
4. 分别为 X、Y 和 Z 轴设置对齐方式。
5. 若要将对齐后的位置固化到对象树中，请使用 **应用**。

## 参数

### 锚点

**锚点** 列表用于选择作为参考的子对象。锚点不会移动。对齐操作中的其他每个子对象都会相对于锚点重新定位，除非某个轴使用了 **堆叠** 模式。

### 轴控制

每个轴都有各自的控制。你可以在一个轴、两个轴或全部三个轴上进行对齐。最小和最大边缘按轴命名：

- **X 轴** - 最小为左侧，最大为右侧。
- **Y 轴** - 最小为前侧，最大为后侧。
- **Z 轴** - 最小为底部，最大为顶部。

对于每个轴：

- **对齐** - 选择该轴上的锚点参考点。使用 **无** 可保持该轴上的位置不变。
- **模式** - 控制所选对齐方式的应用方法：
  - **简单** - 将每个移动对象的相应边缘、中心或原点与锚点匹配。不使用偏移。
  - **偏移** - 选择移动对象的哪一部分落在锚点参考位置上，然后用 **偏移** 添加间距。
  - **堆叠** - 沿该轴依次排列对象，并以 **偏移** 作为它们之间的间隙。
- **子对齐** - 在 **偏移** 模式下可用。选择移动对象上要放置到锚点参考位置的部分。如果 **子对齐** 为 **无**，则对齐会使用 **对齐** 所选的同一边缘、中心或原点。
- **偏移** - 在 **偏移** 和 **堆叠** 模式下可用。沿该轴增加距离，并支持[表达式](../../workspace/expressions.md)。

## 对齐模式

### 简单

当需要匹配相同类型的位置时，请使用 **简单**。例如，**X 对齐：居中** 会移动每个非锚点对象，使其 X 中心与锚点的 X 中心一致。**Z 对齐：最小** 会移动每个非锚点对象，使其底部位于锚点底部的高度。

### 偏移

当移动对象上的参考部分应与锚点参考不同时，请使用 **偏移**。例如，要将一个对象放置在锚点顶部：

1. 将 **Z 对齐** 设为 **最大**（顶部）。
2. 将 **Z 模式** 设为 **偏移**。
3. 将 **Z 子对齐** 设为 **底部**。
4. 将 **Z 偏移** 设为所需的间隙，或保留为 `0` 以实现直接接触。

这样会将移动对象的底部放置在锚点的顶部，并可附加间距。

### 堆叠

使用 **堆叠** 可沿某个轴依次串联多个对象。对象先按名称处理，再按内部 ID 处理，因此为对象取清晰的名称可获得可预测的堆叠顺序。

在 **堆叠** 模式下，每个移动对象都会在该轴上贴靠到前一个参考位置：

- **最小** 对齐会朝正方向堆叠，例如在 X 上从左到右，或在 Z 上从下到上。
- **最大** 对齐会朝负方向堆叠，例如在 X 上从右到左，或在 Z 上从上到下。
- **居中** 和 **原点** 对齐使用每个对象的中心或原点之间的偏移。

在 **堆叠** 模式下使用 **偏移** 可设置对象之间的间隙。

## 示例

- **将对象在打印平台范围内居中** - 选择应保持固定的对象作为 **锚点**，然后将 **X 对齐** 和 **Y 对齐** 设为 **居中**。
- **将一个对象放在另一个对象之上** - 将 **Z 对齐** 设为 **最大**（顶部），**Z 模式** 设为 **偏移**，**Z 子对齐** 设为 **底部**。
- **与某条边缘保持精确间隙** - 使用 **偏移** 模式，用 **子对齐** 选择移动对象的边缘，然后将 **偏移** 设为所需间距。
- **将多个对象首尾相接排列** - 将 **X 对齐** 设为 **最小**（左侧），**X 模式** 设为 **堆叠**，并使用 **X 偏移** 设置间隙。
- **构建垂直堆叠** - 将 **Z 对齐** 设为 **最小**（底部），**Z 模式** 设为 **堆叠**，并使用 **Z 偏移** 设置对象之间的间距。

## 提示

- 锚点对象保持不动；其他对象会移动以与其对齐。
- 你可以在不同的轴上使用不同的模式，例如在 X 上使用 **堆叠**，同时在 Y 上使用 **居中** 和 **简单**。
- 当一次对齐多个对象时，可利用对象名称控制 **堆叠** 顺序。
- 在应用之前，对齐是非破坏性的。你可以随时更改设置以重新对齐子对象。
- 当需要对齐建模原点而非包围盒边缘时，请使用 **原点**。
