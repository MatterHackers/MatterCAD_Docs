# 放置操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

放置操作可帮助您精确地将对象相对于彼此定位，或定位在特定边界之内。

## 操作

- [对齐](align.md) - 沿任意轴将对象彼此对齐
- [双挤出头对齐](dual-extrusion-align.md) - 将对象对齐到其共享的建模位置
- [适配边界](fit-to-bounds.md) - 缩放对象以适配指定的边界框
- [拟合圆柱](fit-to-cylinder.md) - 缩放对象以适配指定的圆柱体
