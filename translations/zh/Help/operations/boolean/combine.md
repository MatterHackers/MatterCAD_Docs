# 合并

合并会将所有对象融合为单个实体。形状重叠处的内部面会被移除，因此结果是一个连续的网格，而不是相互重叠的壳体。

<!-- AUTO_IMAGE: type=from_mcx file=boolean_combine -->
![boolean_combine](https://matterhackers.github.io/MatterCAD_Docs/assets/boolean_combine.png)

合并、[减去](subtract.md)、[相交](intersect.md) 和 [减去并替换](subtract-and-replace.md) 都由同一个布尔对象执行——工具栏按钮创建该对象时已选中合并，你可以随时在属性面板顶部的 **操作** 图标行中切换到其他三种操作中的任意一种。

合并既适用于实体，也适用于二维路径。它会根据你提供的内容执行相应类型的操作，因此合并两条路径会生成一条路径，合并两个网格会生成一个实体。

## 使用方法

1. 选择两个或更多对象
2. 在工具栏中点击 **合并**
3. 随时可以在属性面板顶部的 **操作** 行中点击其他图标来改变主意——形状会按新的操作重新生成

## 参数

- **操作** - 要执行的布尔运算。显示为面板顶部的图标行
- **保留内外反转的几何体** - 将内外反转的壳体视为实体材料，而不是让它抵消掉周围的体积。当本应为实体的模型出现缺失部分时，请开启此选项。它会强制使用较慢但精确的布尔引擎
- **修复缠绕方向** - 在执行布尔运算之前，重新调整每个部件中内外反转壳体的缠绕方向。这种方式一次性修复几何体，而不是改变后续每次操作对实体的判定，通常是应对内外反转模型的两种方案中更好的一种

## 提示

- 合并同样会把不重叠的对象连接成一个网格，但它们在视觉上仍是分开的
- 合并会自动处理孔对象：任何标记为孔的对象都会从结果中减去，而不是加入其中
- 合并会保留原始对象的逐面颜色
- 如果结果看起来不正确，请检查源对象是否封闭水密。**修复缠绕方向** 可修复内外反转的壳体；[修复](../mesh/repair.md) 可修复导入模型中更广泛的损坏

## 相关

- [减去](subtract.md) - 从一个形状中切除另一个形状
- [相交](intersect.md) - 仅保留对象重叠的体积
- [减去并替换](subtract-and-replace.md) - 减去一个形状，并保留被切掉的部分
- [平面切割](../reshape/plane-cut.md) - 用一个平面而不是另一个形状进行切割
- [孔](../../primitives/hole.md) - 预先配置为执行减去的立方体
- [修复](../mesh/repair.md) - 在布尔运算之前修复损坏的导入网格

本页面同时涵盖在这些操作合并之前保存的设计中仍然存在的旧版合并对象。它们的工作方式完全不变；新设计使用共享的布尔对象，并选中合并操作。
