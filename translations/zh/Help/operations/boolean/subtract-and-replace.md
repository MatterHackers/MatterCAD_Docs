# 减去并替换

减去并替换会从未被选中的零件中减去你选择的零件，但会把切除掉的部分保留为独立零件，而不是将其丢弃。使用 **要减去的零件** 来选取用作切割的形状；其余的都是被切割的基础零件。

[合并](combine.md)、[减去](subtract.md)、[相交](intersect.md) 和减去并替换都由同一个布尔对象执行 —— 工具栏按钮创建该对象时已经选中了 减去并替换，你可以随时在 属性 面板顶部的 **操作** 图标行中切换到其他三种操作之一。

减去并替换不适用于二维路径 —— 区域没有可以交还的被移除体积。

## 使用方法

1. 选择两个或更多对象
2. 点击工具栏中的 **减去并替换**
3. 使用 **要减去的零件** 选择哪些子对象作为切割形状
4. 你可以随时在 属性 面板顶部的 **操作** 行中点击其他图标来改变主意 —— 形状会按新的操作重新生成

## 参数

- **操作** - 要执行的布尔运算。以图标行的形式显示在面板顶部
- **要减去的零件** - 哪些子对象作为切割形状
- **保留内外反转的几何体** - 将内外反转的壳体视为实体材料，而不是让它抵消掉周围的体积。当一个本应是实体的模型出现缺失部分时，请开启此项。它会强制使用较慢但精确的布尔引擎
- **修复缠绕方向** - 在执行布尔运算之前，重新调整每个零件中内外反转壳体的方向。这种方式一次性修复几何体，而不是改变后续每一步操作对实体的判定，通常是处理内外反转模型两种方案中更好的一种

## 提示

- 两个零件能够精确契合，因为它们来自同一次操作
- 可用于多色设计、互锁组件和镶嵌件
- 如果结果看起来不对，请检查源对象是否封闭无缝。**修复缠绕方向** 可修复内外反转的壳体；[修复](../mesh/repair.md) 可修复导入模型中更广泛的损坏

## 相关内容

- [合并](combine.md) - 将多个对象合并为单个实体形状
- [减去](subtract.md) - 从一个形状中切除另一个形状
- [相交](intersect.md) - 仅保留对象重叠处的体积
- [平面切割](../reshape/plane-cut.md) - 用一个平面进行切割，而不是用另一个形状
- [修复](../mesh/repair.md) - 在执行布尔运算前修复损坏的导入网格

本页也适用于在这些操作被合并之前保存的设计中仍然存在的旧版 减去 和 替换 对象。它们的工作方式完全不变；新设计使用共享的布尔对象并选中 减去并替换 操作。
