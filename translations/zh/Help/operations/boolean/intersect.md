# 相交

相交只保留所有对象共有的体积，并舍弃其余部分。

<!-- AUTO_IMAGE: type=from_mcx file=boolean_intersect -->
![boolean_intersect](https://matterhackers.github.io/MatterCAD_Docs/assets/boolean_intersect.png)

[合并](combine.md)、[减去](subtract.md)、相交和[减去并替换](subtract-and-replace.md) 都由同一个布尔对象执行——工具栏按钮创建该对象时已选中相交，你随时可以从属性面板顶部的 **操作** 图标行切换到其他三种中的任意一种。

相交可用于实体，也可用于二维路径。它会根据你提供的内容执行相应类型的运算，因此两条路径相交会得到一条路径，两个网格相交会得到一个实体。

## 使用方法

1. 选择两个或更多对象
2. 点击工具栏中的 **相交**
3. 随时可以在属性面板顶部的 **操作** 行中点击其他图标来改变主意——形状会按新的操作重新生成

## 参数

- **操作** - 要执行哪种布尔运算。以图标行的形式显示在面板顶部
- **保留内外反转的几何体** - 将内外反转的壳体视为实体材料，而不是让它抵消周围的体积。当本应为实体的模型出现缺失部分时，请开启此项。它会强制使用较慢但精确的布尔引擎
- **修复缠绕方向** - 在执行布尔运算之前，重新调整每个部件中内外反转壳体的缠绕方向。这种方式一次性修复几何体，而不是改变后续每次运算对实体的判定，通常是应对内外反转模型的两种方案中较好的一种

## 提示

- 对象之间必须重叠。如果它们实际上并不重叠，结果将为空
- 当对象超过两个时，会按列表顺序依次处理：先将前两个相交，然后将该结果与第三个相交，依此类推
- 如果结果看起来不正确，请检查源对象是否封闭水密。**修复缠绕方向** 可修复内外反转的壳体；[修复](../mesh/repair.md) 可修复导入模型中更广泛的损坏

## 相关内容

- [合并](combine.md) - 将多个对象合并为单个实体形状
- [减去](subtract.md) - 从一个形状中剪去另一个形状
- [减去并替换](subtract-and-replace.md) - 减去一个形状并保留被剪掉的部分
- [平面切割](../reshape/plane-cut.md) - 使用平面而非另一个形状进行切割

本页面同样适用于在这些操作合并之前保存的设计中仍然存在的旧版交集对象。它们的工作方式完全保持不变；新设计使用选中了相交操作的通用布尔对象。
