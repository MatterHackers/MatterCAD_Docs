# 减去

减去会将你选中的零件从未选中的零件中切除。使用 **要减去的零件** 来指定作为切割形状的部分；其余的一切都是被切割的基体。

<!-- AUTO_IMAGE: type=from_mcx file=boolean_subtract -->
![boolean_subtract](https://matterhackers.github.io/MatterCAD_Docs/assets/boolean_subtract.png)

[合并](combine.md)、减去、[相交](intersect.md) 和 [减去并替换](subtract-and-replace.md) 都由同一个布尔对象来执行 —— 工具栏按钮创建它时已默认选中减去，你随时可以在属性面板顶部的 **操作** 图标行中切换到其他三种操作中的任意一种。

减去既适用于实体，也适用于二维路径。它会根据你提供的内容执行相应类型的运算，因此从一条路径中减去另一条路径会得到路径，从一个网格中减去另一个网格则会得到实体。

## 使用方法

1. 选择两个或更多对象
2. 在工具栏中点击 **减去** —— 系统会为你预先选定一个用于切除的零件，因此它会立即产生效果
3. 使用 **要减去的零件** 来选择哪些子对象作为切割形状
4. 你随时可以在属性面板顶部的 **操作** 行中点击不同的图标来改变主意 —— 形状会按新的操作重新生成

## 参数

- **操作** - 要执行哪种布尔运算。以图标行的形式显示在面板顶部
- **要减去的零件** - 哪些子对象作为切割形状
- **保留被减部件** - 将被切除的部件保留在场景中，而不是将其丢弃
- **保留内外反转的几何体** - 将内外反转的壳体视为实体材料，而不是让它抵消其周围的体积。当本应为实体的模型出现缺失部分时，请启用此选项。它会强制使用较慢但精确的布尔运算引擎
- **修复缠绕方向** - 在布尔运算之前，重新缠绕每个零件中内外反转的壳体。这样做会一次性修复几何体，而不是改变后续每一步操作对实体的判定，通常是应对内外反转模型的两种方案中更好的那一种

## 提示

- 对象必须相互重叠，减去才会产生效果
- 若要切出通孔，请确保切割对象完全穿过基体
- 对于简单的孔洞，[孔](../../primitives/hole.md) 基本体已经预设为执行减去
- 切割对象仍保留在设计树中，因此你可以移动或调整它们的大小，切割结果会随之更新
- 如果结果看起来不对，请检查源对象是否封闭无缝。**修复缠绕方向** 可修复内外反转的壳体；[修复](../mesh/repair.md) 则可修复导入模型中更广泛的损坏

## 相关内容
