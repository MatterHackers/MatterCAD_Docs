# 缩减（Decimate）

**缩减**可在保持整体形状的前提下降低网格的多边形数量。它适用于简化高细节模型、减小文件体积，以及加快复杂几何体上的操作速度。

![20260324 080430 paste 20260324 080430](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080430-paste-20260324-080430.jpg)


## 使用方法

1. 选择一个对象
2. 从网格菜单中应用 **缩减** 操作
3. 选择目标（数量或百分比）并进行调整

## 参数

- **模式** - 选择目标的指定方式：
  - **百分比** - 保留原始多边形的一定百分比（默认：50%）
  - **数量** - 以特定的多边形数量为目标
- **源多边形数** - 原始多边形数量（只读）
- **目标百分比** - 要保留的多边形百分比（在百分比模式下显示）
- **目标数量** - 要保留的精确多边形数量（在数量模式下显示）
- **百分比缩减后的数量** - 按百分比缩减后的最终多边形数量（只读）
- **保持曲面** - 将顶点投影回原始曲面以获得更高精度（速度较慢，但更忠实于原始形状）

## 提示

- 缩减 50% 通常能较好地保持视觉质量
- 当精度比速度更重要时，请启用保持曲面
- 降低多边形数量可加快复杂导入模型上的布尔运算
- 多边形数量过低会明显破坏形状——在确认之前请先检查结果
