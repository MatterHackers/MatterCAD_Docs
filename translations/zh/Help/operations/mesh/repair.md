# 修复

修复可解决网格几何体中的常见问题，包括非流形边线、孔洞、面朝向不一致以及几乎重合的顶点。这对于可能存在错误的导入 STL 和 OBJ 文件尤其有用。

![20260324 080517 paste 20260324 080517](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080517-paste-20260324-080517.jpg)


## 使用方法

1. 选择存在网格问题的对象
2. 从网格菜单中应用 **修复** 操作
3. 查看修复前后的统计数据，了解修复了哪些内容

## 统计数据（只读）

- **初始顶点 / 最终顶点数** - 修复前后的顶点数量
- **初始面数 / 最终面数** - 修复前后的面数量
- **初始非流形边线 / 最终非流形边线** - 修复前后的问题边线数量

### 高级选项

启用 **高级** 模式可进行精细控制：

- **焊接顶点** - 合并几乎重合的顶点（默认：开启）
- **焊接容差** - 顶点之间需要多接近才会被合并
- **面朝向** - 将内外翻转的壳体调整为正确朝向，使每个实体都被识别为实心。每个壳体都会单独判断，因此中空模型会保留其空腔，而不会被填实。若某个壳体自身的各个面彼此矛盾，则会保持原样而不作猜测；对于不封闭的模型，则会回退到更为宽容的修复方式——如果仅调整朝向无法解决问题，请先运行 **填充孔**。
- **焊接边线** - 修复细小裂缝和不良接缝
- **填充孔** - 填补网格表面的缺口
- **移除模式** - 移除内部或被遮挡的几何体：
  - **无** - 保留所有几何体
  - **内部** - 移除隐藏在主体形状内部的实体
  - **被遮挡** - 移除从外部无法看到的面

## 提示

- 如果布尔运算（合并、减去）在导入的模型上产生意外结果，请先尝试修复
- 默认设置（开启焊接顶点，其余全部关闭）可解决最常见的问题
- 如果能透过模型的缺口看到内部，请启用填充孔
- 使用移除内部可清理内部含有隐藏几何体的模型
