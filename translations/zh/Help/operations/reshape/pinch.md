# 收缩

收缩会将物体的后部向内压缩，且效果向顶部逐渐增强。这会形成锥形或挤压的外观。

<!--  Before and after showing an object being pinched -->
![20260506 155449 paste 20260506 155449](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-155449-paste-20260506-155449.jpg)

## 使用方法

1. 选择一个物体
2. 从重塑菜单中应用 **收缩** 操作
3. 调整收缩百分比

## 参数

- **后比例** - 零件后部向内收缩的程度（0-300%，默认值：50%）。数值越高 = 压缩越强

## 提示

- 收缩从后向前起作用，压缩物体的后部
- 使用此操作可将矩形或圆柱形物体制作成锥形、逐渐变窄的形状
- 如需径向（全方位）压缩，请改用 [径向收缩](radial-pinch.md)
