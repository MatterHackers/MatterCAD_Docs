# 扭曲

扭曲会使物体的顶部相对于底部旋转，从而沿高度方向产生螺旋或扭转效果。默认情况下，旋转从下到上均匀推进；在**高级**中，你可以绘制旋转实际发生在高度上的哪些位置。

## 使用方法

1. 选择一个物体
2. 从重塑菜单中应用**扭曲**操作
3. 设置扭曲角度并调整切片以获得平滑效果
4. 如果你想绘制扭曲在零件上的分布方式，请打开**高级**

## 扭曲轮廓

在**高级**下，**扭曲轮廓**曲线决定扭曲发生的位置。扭曲的总量仍由**角度**（或**旋转距离**）控件设置——曲线只负责分配它：

- **曲线的纵向**是零件上的高度百分比——底部为 0，顶部为 100。编辑器中有一条横贯的参考线标记 100%，并以毫米标注零件的实际高度。
- **曲线的横向**是该高度处所达到的总扭曲百分比——0 表示完全未扭曲，100 表示全部扭曲。

新建的扭曲以一条从 0 到 100 的直斜线开始，这就是完全不使用**高级**时得到的普通均匀扭曲。

曲线中的水平段表示零件上不发生扭曲的一段区域。曲线未覆盖整个高度时，会沿用其最近端的值，因此一条只绘制在 40% 到 60% 之间的曲线，会使零件在其上下两端保持刚性不变——这正是让扭曲在中途开始和结束的方法。

向上推进时却回落的曲线段会反向解旋：零件的该段会朝相反方向转动，退回起始位置。将轮廓绘制到超过 100 再回落，就可以先过冲总量再回到该总量。

## 参数

- **旋转类型** - 可在以下选项中选择：
  - **角度** - 以度数指定总扭曲角度（3-360）
  - **距离** - 以沿圆周的距离指定扭曲量
- **切片** - 为实现平滑扭曲而添加的水平切割数量，沿零件高度均匀分布。切片越多 = 扭曲越平滑
- **最少边数** - 零件围绕扭曲轴应具有的最少边数。像立方体这样的粗糙形状在其周边没有可承载旋转的几何结构，因此其平面会呈现刻面而非弯曲；此设置会沿扭曲轴添加垂直切割，使这些面能够跟随扭曲。0（默认值）表示不改变零件
- **向右扭曲** - 扭曲方向：向右（顺时针）或向左（逆时针）
- **首选半径** - 只读：零件自身报告的半径，或由其形状推断出的半径，扭曲距离即以此为基准进行测量（仅限距离模式）
- **编辑半径** - 关闭报告的半径，以便你自行设置（仅限距离模式，且仅当零件报告了半径时）
- **覆盖半径** - 用于扭曲计算的自定义半径（仅限距离模式）

### 高级参数

- **扭曲轮廓** - 上文所述的曲线编辑器：在每个高度百分比处所达到的总扭曲百分比
- **旋转偏移** - 将零件旋转所围绕的中心从零件中间移开

## 提示

- 较高的切片值会产生更平滑的结果，但也会生成更多几何体
- 如果扭曲后的立方体或其他平面形状看起来呈刻面而非曲面，请提高最少边数
- 将轮廓底部绘制为水平段、之后再上升，可在扭曲柱体下方保留一段笔直的基座
- 在方柱上施加 90 度扭曲可营造优雅的建筑效果
- 绘制两段由短上升段连接的水平段，可扭转零件的中部并使两端保持刚性
