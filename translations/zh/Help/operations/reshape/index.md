# 重塑操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Reshape -->
![Reshape toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Reshape.png)

重塑操作可对物体的几何形状进行变形和修改，让你能够从简单形状创建出有机而复杂的造型。

## 操作

- [曲线](curve.md) - 沿曲线弯曲物体
- [扭曲](twist.md) - 沿物体高度方向逐渐旋转物体
- [收缩](pinch.md) - 朝物体的中心轴压缩物体
- [径向收缩](radial-pinch.md) - 围绕某一轴径向收缩物体
- [平面切割](plane-cut.md) - 在指定高度用一个平面切片物体
- [挖空](hollow-out.md) - 从实心物体创建中空壳体
