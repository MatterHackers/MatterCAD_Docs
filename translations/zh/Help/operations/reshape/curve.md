# 曲线

曲线可将直的物体弯曲成弧形或圆形。您可以通过指定角度或环绕直径来控制弯曲。

## 使用方法

1. 选择一个物体
2. 从重塑菜单中应用**曲线**操作
3. 在角度或直径弯曲类型之间进行选择
4. 调整参数以获得所需的曲率

## 参数

- **弯曲类型** - 可选择：
  - **角度** - 直接指定弯曲角度（1-360 度）
  - **直径** - 指定零件所环绕的圆的直径
- **弯曲方向** - 向上弯曲或向下弯曲
- **起始百分比** - 沿物体从何处开始弯曲（0-100%）
- **拆分网格** - 拆分网格以获得平滑的曲线（默认：开启）
- **每转最少边数** - 每整圈的最少网格分段数。数值越高 = 曲线越平滑

### 高级参数

- **起始弯曲百分比** - 从左侧起弯曲开始处的百分比
- **末端弯曲百分比** - 从左侧起弯曲结束处的百分比

## 提示

- 使用曲线可从平直的原始形状创建拱形、圆环和弯曲支架
- 将角度设置为 360 会将物体环绕成一个完整的圆环
- 对于急弯，增大每转最少边数可获得更平滑的效果
- 物体沿其长度方向（X 轴）弯曲
