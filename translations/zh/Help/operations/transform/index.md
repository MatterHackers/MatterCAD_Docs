# 变换操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Transform -->
![Transform toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Transform.png)

变换操作可在不改变对象几何形状的情况下更改其位置、方向和大小。

## 操作

- [平移](translate.md) - 按 X、Y 或 Z 方向的指定偏移量移动对象
- [旋转](rotate.md) - 使对象绕某一轴旋转指定角度
- [缩放](scale.md) - 调整对象大小，可选择等比缩放或按轴缩放
- [镜像](mirror.md) - 创建对象沿某一轴的镜像复制
