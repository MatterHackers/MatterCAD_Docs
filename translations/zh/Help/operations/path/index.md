# 路径操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

路径操作使用二维路径来创建和修改三维形状。可用于对基于路径的几何体进行拉伸、旋转成型和细化处理。

## 操作

- [线性拉伸](linear-extrude.md) - 为二维路径赋予高度以创建三维对象
- [旋转成型](revolve.md) - 让二维路径绕轴旋转以创建回转实体
- [平滑路径](smooth-path.md) - 平滑路径的曲线
- [膨胀路径](inflate-path.md) - 将路径向外扩展
- [轮廓路径](outline-path.md) - 从填充路径创建轮廓
- [边框路径](border-path.md) - 在路径周围添加边框偏移
- [选择路径](select-paths.md) - 从复杂的多路径对象中选择特定路径
