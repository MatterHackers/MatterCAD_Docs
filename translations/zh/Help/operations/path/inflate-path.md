# 膨胀路径

膨胀路径将二维路径向外扩展，在保持整体形态的同时使形状变大。这类似于对所有边缘应用统一的偏移量。

## 使用方法

1. 选择一条二维路径
2. 从路径操作菜单中应用**膨胀路径**
3. 调整膨胀量

## 膨胀开放线条

膨胀是将线条转换为形状的方法。在[自定义路径](../../2d-paths/custom-path.md)上取消勾选**已闭合**即可绘制开放线条，然后对其进行膨胀：结果是一条填充的带状形体，其在线条两侧的宽度均等于您设置的数值。此后它可以像任何其他路径一样进行挤出。

**样式**决定线条两端的端头形式，以及其转角的连接方式：

- **平面**在每个端点处以方形截断带状形体
- **圆角**在每个端点外侧添加一个半圆
- **尖锐**在每个端点外侧添加一个方形

开放线条没有可供收缩的内部区域，因此零值或负值将不会留下任何内容。当路径*完全*开放时，膨胀会将数值钳制为一个较小的正数，并将钳制后的数值写回输入框，以便您了解发生了什么。

混合了开放轮廓与闭合轮廓的路径不会被钳制：闭合轮廓会正常收缩，而开放轮廓则会直接消失。闭合路径在负值下的收缩行为与以往完全一致。

## 提示

- 使用负值可使路径向内收缩，而非向外扩展
- 膨胀非常适合在形状周围创建公差偏移
- 与[轮廓路径](outline-path.md)配合使用，可创建具有特定宽度的边框
