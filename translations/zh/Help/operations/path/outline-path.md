# 轮廓路径

轮廓路径可为已填充的路径创建轮廓版本，将实心形状转换为具有指定厚度的边界环。

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## 使用方法

1. 选择一个二维路径
2. 从路径操作菜单中应用 **轮廓路径**
3. 调整轮廓厚度

## 提示

- 使用此操作可将实心路径转换为框架状形状
- 与[线性拉伸](linear-extrude.md)结合使用，可创建三维框架和边框
- 对[圆路径](../../2d-paths/circle-path.md)执行轮廓操作，等效于[圆环路径](../../2d-paths/ring-path.md)
