# Lithophane

浮雕灯片是一种薄型 3D 面板，图像通过厚度的变化进行编码。背光照射时，较薄的区域透过更多光线，从而显现出图像。这为展示照片和艺术作品提供了一种精美的方式。

![20260324 080310 paste 20260324 080310](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080310-paste-20260324-080310.jpg)


## 使用方法

1. 导入图像或选择现有的图像对象
2. 应用 **浮雕灯片** 操作
3. 调整分辨率和尺寸
4. 使用浅色材料打印结果，并将其放置在光源前方

## 参数

- **每毫米像素** - 浮雕灯片的分辨率（默认值：1.5，范围：0.5-3）。数值越高捕捉的细节越多，但生成的文件也越大
- **高度** - 浮雕灯片面板的最大厚度（默认值：2.5mm，范围：0.5-3mm）
- **宽度** - 浮雕灯片的总宽度，以像素为单位（默认值：150）
- **反转** - 反转明暗映射关系（默认：开启）。通常保持开启，以便背光时正确显示

## 提示

- 使用白色或浅色材料打印可获得最佳效果
- 2-3mm 的高度适用于大多数浮雕灯片
- 更高的每毫米像素可捕捉更多细节，但会增加打印时间和文件大小
- 将成品装入带 LED 背光的相框中，可获得最佳观赏效果
- 对比度良好的人像照片效果尤为出色
