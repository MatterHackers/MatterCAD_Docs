# 图像操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

图像操作可将 2D 图像转换为 3D 对象或路径，使您能够将照片、徽标和艺术作品融入设计之中。

## 操作

- [图像转换器](image-converter.md) - 根据亮度或颜色将图像转换为 3D 浮雕
- [图像转路径](image-to-path.md) - 描摹图像以创建 2D 路径轮廓
- [浮雕灯片](lithophane.md) - 创建在背光照射下显现图像的浮雕灯片
