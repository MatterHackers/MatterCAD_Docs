# 图像转路径

图像转路径会描摹图像的轮廓以创建 2D 路径。这些路径随后可用于拉伸、旋转或任何其他路径操作。它非常适合将标志、剪影和简单图形转换为 3D 对象。

![20260324 075521 paste 20260324 075521](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-075521-paste-20260324-075521.jpg)


## 使用方法

1. 在工作区中选择一个图像对象
2. 从图像操作菜单中应用 **图像转路径**
3. 选择分析类型并调整选择范围

## 参数

- **分析类型** - 描摹时分析图像的方式：
  - **透明度** - 基于透明区域与不透明区域进行描摹（最适合带透明背景的 PNG）
  - **颜色** - 基于颜色区域进行描摹
  - **强度** - 基于亮度级别进行描摹（适合大多数图像）
- **选择范围** - 直方图控件，用于选择描摹中包含哪些亮度/颜色值
- **最小表面积** - 路径闭环被纳入所需的最小面积。增大该值可滤除细小的噪点杂物

## 提示

- 形状简单、干净且对比度高的图像效果最佳
- 对带透明背景的 PNG 图像使用透明度模式
- 对照片和不含透明度的图像使用强度模式
- 描摹完成后，应用[线性拉伸](../path/linear-extrude.md) 为路径赋予高度
- 增大最小表面积可从描摹结果中移除不需要的细小细节
