# 图像转换器

图像转换器可将位图图像转换为 3D 浮雕，其中像素亮度决定高度。明亮区域凸起，深色区域凹陷（反之亦然）。

![20260323 210414 paste 20260323 210414](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210414-paste-20260323-210414.jpg)


## 使用方法

1. 从**基本体**面板中添加一个图像转换器，或将图像文件拖放到工作区中
2. 图像将被转换为 3D 高度图
3. 调整高度及其他参数

## 提示

- 形状清晰、对比度高的图像效果最佳
- 若要将图像轮廓描摹为平面路径而非高度图，请使用[图像转路径](image-to-path.md)
- 若要制作背光图像展示效果，请使用[浮雕灯片](lithophane.md)
- 您可以直接将图像从桌面拖放到工作区中
- 将图像浮雕与[立方体](../../primitives/cube.md)组合即可添加底座
