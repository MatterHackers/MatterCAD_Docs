# 选择

选择对象是在 MatterCAD 中开展工作的基础。只有先选择对象，才能对其进行移动、修改或应用操作。

<!--  Screenshot showing multiple selected objects with selection highlights -->
![20260318 192323 paste 20260318 192323](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192323-paste-20260318-192323.jpg)


## 单个选择

- **在对象上单击左键**即可将其选中，之前选中的对象会被取消选择。
- **在空白处单击左键**可取消选择所有对象。

## 多重选择

- **Shift + 左键单击**其他对象，可将其添加到当前选择中
- **Ctrl + 左键单击**同样可将对象添加到当前选择中
- **Ctrl + A** 可选择场景中的全部对象

## 框选

在视口的空白区域点击并拖动，可绘制出一个选择矩形。矩形范围内的所有对象都会被选中。

## 清除选择

- **在空白处单击左键**可清除选择
- **空格键**可清除选择
- **Escape** 可取消拖动操作

## 使用选择的对象

选中对象后，您可以：

- 在视口中拖动以**移动**它们
- 从工具栏**应用操作**（布尔运算、变换、阵列等）
- 在**属性**面板中**编辑属性**（仅在选中单个对象时可用）
- **右键单击**打开上下文菜单，查看可用操作

## 提示

- 选中多个对象时，它们会被临时编组以便执行操作。**属性**面板会显示它们的共有属性。
- 对于在视口中难以点击的对象，可使用设计树进行选择 —— 在树中单击某个条目，即可在视图中选中它。
