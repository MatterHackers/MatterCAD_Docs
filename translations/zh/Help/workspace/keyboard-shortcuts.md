# 键盘快捷键

MatterCAD 中所有可用键盘快捷键的快速参考。

## 编辑

| 快捷键 | 操作 |
|----------|--------|
| Ctrl + Z | 撤销 |
| Ctrl + Y | 重做 |
| Ctrl + Shift + Z | 重做（备选） |
| Ctrl + A | 全选所有对象 |
| Ctrl + C | 复制所选对象 |
| Ctrl + X | 剪切所选对象 |
| Ctrl + V | 粘贴对象 |
| Space | 清除选择 |
| Escape | 取消当前拖动操作 |
| Delete | 删除所选对象 |

## 视图

| 快捷键 | 操作 |
|----------|--------|
| W | 重置视图（将所有对象适配到视口中） |
| Z | 缩放至所选对象 |
| Ctrl + 加号 (+) | 放大 |
| Ctrl + 减号 (-) | 缩小 |
| 方向键 | 旋转视图 |
| Shift + 方向键 | 平移视图 |

## 鼠标控制

| 操作 | 控制 |
|--------|---------|
| 旋转视图 | 右键单击 + 拖动 |
| 平移视图 | 中键单击 + 拖动 |
| 缩放 | 滚动滚轮 |
| 选择对象 | 在对象上左键单击 |
| 多选 | Shift + 左键单击 或 Ctrl + 左键单击 |
| 框选 | 在空白处左键单击 + 拖动 |
| 上下文菜单 | 在对象上右键单击 |

## 备选鼠标控制

| 操作 | 控制 |
|--------|---------|
| 旋转视图 | Ctrl + 左键单击 + 拖动 |
| 平移视图 | Ctrl + Shift + 左键单击 + 拖动 |
| 缩放 | Ctrl + Alt + 左键单击 + 拖动 |

## 应用程序

| 快捷键 | 操作 |
|----------|--------|
| Ctrl + Shift + T | 重新打开上次关闭的设计 |
| F1 | 打开帮助 |
