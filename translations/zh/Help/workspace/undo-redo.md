# 撤销与重做

MatterCAD 会保存完整的修改历史记录，因此您可以撤销错误操作，也可以重做已撤销的操作。

## 使用方法

- **Ctrl + Z** - 撤销上一步操作
- **Ctrl + Y** 或 **Ctrl + Shift + Z** - 重做上一步被撤销的操作
- 您还可以使用工具栏中的**撤销**和**重做**按钮

## 哪些操作可以撤销

所有设计操作都会记录在撤销历史中，包括：

- 添加或删除对象
- 移动、旋转和缩放对象
- 应用各类操作（布尔、变换、重塑等）
- 更改对象参数
- 编组和取消编组

## 提示

- 反复按 Ctrl + Z 可以连续撤销多个步骤
- 撤销历史仅在当前会话中保留。关闭并重新打开设计后，将开始全新的历史记录。
- 如果您撤销了若干步骤后又进行了新的修改，该点之后的重做历史将被清除
