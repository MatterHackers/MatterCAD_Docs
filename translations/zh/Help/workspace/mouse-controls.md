# 鼠标控制

MatterCAD 3D 视口中鼠标控制的完整参考。

## 导航

| 操作 | 鼠标控制 |
|--------|--------------|
| **旋转视图** | 右键单击 + 拖动 |
| **平移视图** | 中键单击 + 拖动 |
| **缩放** | 滚轮 |

## 备选导航方式

| 操作 | 鼠标控制 |
|--------|--------------|
| **旋转视图** | Ctrl + 左键单击 + 拖动 |
| **平移视图** | Ctrl + Shift + 左键单击 + 拖动 |
| **缩放** | Ctrl + Alt + 左键单击 + 拖动 |

## 对象交互

| 操作 | 鼠标控制 |
|--------|--------------|
| **选择对象** | 在对象上左键单击 |
| **多选** | Shift + 在其他对象上左键单击 |
| **多选** | Ctrl + 在其他对象上左键单击 |
| **取消全部选择** | 在空白处左键单击 |
| **框选** | 在空白处左键单击 + 拖动 |
| **移动对象** | 在选中的对象上左键单击 + 拖动 |
| **右键菜单** | 在对象上右键单击 |

## 对象控制

选中对象后，会出现交互式控制手柄：

| 操作 | 控制 |
|--------|---------|
| **在打印床上移动** | 拖动该对象 |
| **上下移动** | 拖动对象上方的垂直箭头 |
| **旋转** | 点击并拖动某个旋转角控制手柄 |
| **缩放** | 点击并拖动某个缩放角控制手柄 |

## 提示

- 使用滚轮缩放时以鼠标光标位置为中心 —— 将光标指向想要放大的区域
- 如果你没有鼠标中键，或者右键单击不方便，备选控制方式（Ctrl + 左键单击）会很有用
- 使用角控制手柄旋转时，将鼠标悬停在角度指示器上可按 45 度增量吸附
