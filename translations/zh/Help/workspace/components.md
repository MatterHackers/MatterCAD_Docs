# 组件

组件是可重复使用的参数化对象组。创建组件后,它将成为一个独立的单元,你可以在设计中多次插入该组件,而编辑该组件会同步更新所有实例。

## 使用方法

### 创建组件

1. 选择一个或多个对象
2. 右键单击并选择 **创建组件**(或使用菜单)
3. 所选对象将被包装到一个组件容器中

### 编辑组件

1. 选择该组件
2. 该组件公开的参数会显示在属性面板中
3. 修改参数即可更改组件的形状

## 提示

- 组件非常适合在复杂设计中创建可重复使用的构建模块
- 参数更改是非破坏性的,可以随时调整
- 组件通过将相关对象编组,帮助组织复杂的设计
- 对于需要多次放置且略有差异的零件,请使用组件
