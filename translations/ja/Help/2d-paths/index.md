# 2Dパス

2Dパスは、3Dオブジェクトの出発点として使用できる平面形状です。[直線押し出し](../operations/path/linear-extrude.md) を使ってパスに高さを与えるか、[回転体](../operations/path/revolve.md) を使ってパスを軸まわりに回転させ、3D形状を作成します。

## 利用できるパス

- [円パス](circle-path.md) - 円形の2D輪郭
- [ボックスパス](box-path.md) - 矩形の2D輪郭
- [リングパス](ring-path.md) - 2Dのリング（穴の開いた円）
- [星パス](star-path.md) - 頂点の数を設定できる星型の2D輪郭
- [カスタムパス](custom-path.md) - 制御点を使って独自の2Dパスを描画
