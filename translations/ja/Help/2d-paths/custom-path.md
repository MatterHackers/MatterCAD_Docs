# カスタムパス

制御点を使って独自の2Dパスを描きます。これにより、任意の2D形状を自由に作成でき、その形状を押し出したり回転体にしたりして3Dオブジェクトにできます。

## 使い方

1. 2Dパスライブラリから**カスタムパス**を追加します
2. 制御点を編集して形状を定義します
3. [直線押し出し](../operations/path/linear-extrude.md)などのパス操作を適用して3Dオブジェクトを作成します

## 開いたパスと閉じたパス

**閉じている**チェックボックスは、パスの最後の点を最初の点に接続するかどうかを制御します。

- **閉じている**（既定）にすると、パスは領域を囲む輪郭になります。[直線押し出し](../operations/path/linear-extrude.md)や[回転体](../operations/path/revolve.md)が塗りつぶすのはこの領域です。
- **開く**にすると、パスは線になります。線は何も囲まないため、シーン上では塗りつぶされた形状ではなく、長さに沿った細いリボンとして表示されます。[パスを膨張](../operations/path/inflate-path.md)を使って幅を与え、再びソリッドな形状に戻してください。

**閉じている**のチェックを外す前に、知っておくべきことが2つあります。

- **閉じ直しても元には戻りません。** パスを開くと、閉じるためのセグメントは破棄されます。そのセグメントが曲線だった場合、再び**閉じている**をチェックしても、曲線ではなく直線が戻ってきます。代わりにCtrl+Zを使ってください。元に戻す操作なら、元のパスが正確に復元されます。
- **開けない輪郭もあります。** 点が2つ未満になってしまう輪郭 — たとえば1つの点と、そこへ戻ってループする曲線で描かれた涙型 — は、見ることもクリックすることもできない状態に潰れてしまうため、閉じたままになります。二次曲線を含む輪郭も同様で、これはインポートしたSVGに含まれることがあります。開くと曲線が角に平坦化されてしまうためです。この拒否は輪郭ごとに行われるため、パスの残りの部分は開きます。

パスに複数の輪郭があり、それらの状態が一致していない場合、チェックボックスは開いた状態として表示されます。チェックを入れると、すべての輪郭が揃います。

領域を必要とする操作は、開いたパスを拒否するのではなく、自動的に閉じて処理します。直線押し出し、回転体、減算、その他のブーリアン操作はすべてこの動作をするため、開いたパスを押し出しても、閉じた状態と同じソリッドが得られます。

## ヒント

- 組み込みのパス形状のどれも必要な形に合わない場合は、カスタムパスを使用してください
- 外部のベクター編集ソフトから形状をインポートするには、[SVGオブジェクト](../primitives/svg-object.md)を参照してください
- 線を描いて部品にするには、**閉じている**のチェックを外し、[パスを膨張](../operations/path/inflate-path.md)を適用して厚みを与え、次に[直線押し出し](../operations/path/linear-extrude.md)で高さを与えます
