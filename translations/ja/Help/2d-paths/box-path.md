# ボックス パス

矩形の2Dパスです。[直線押し出し](../operations/path/linear-extrude.md)と組み合わせてボックス形状を作成したり、他のパス操作のベースとして使用したりします。

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## パラメータ

- **幅** - 矩形の幅（デフォルト: 20mm）
- **高さ** - 矩形の高さ（デフォルト: 20mm）

## ヒント

- ボックス パスに直線押し出しを適用すると[立方体](../primitives/cube.md)に似た形状になりますが、押し出す前に[膨張](../operations/path/inflate-path.md)や[スムーズ](../operations/path/smooth-path.md)などのパス操作を適用できます

## 関連項目

- [円 パス](circle-path.md) - 円形の2Dパス
- [星 パス](star-path.md) - 星形の2Dパス
- [直線押し出し](../operations/path/linear-extrude.md) - パスに高さを与えます
