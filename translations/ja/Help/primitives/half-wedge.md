# 半ウェッジ

ウェッジ形状を半分にカットし、直角三角形の断面を作成した形状です。コーナーのサポートや小さな傾斜フィーチャーに便利です。

![20260318 183405 paste 20260318 183405](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183405-paste-20260318-183405.jpg)


## パラメータ

- **幅** - X 軸方向のサイズ（デフォルト: 20mm）
- **深さ** - Y 軸方向のサイズ（デフォルト: 20mm）
- **高さ** - 半ウェッジの最も高い位置での高さ（デフォルト: 10mm）

## ヒント

- コーナーのフィレットやサポートブラケットとして使用します
- 他の形状と結合して、傾斜のある移行部を作成します
