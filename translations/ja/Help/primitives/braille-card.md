# 点字カード

一体型のベースに点字テキストを浮き出させた点字カードを作成します。これは、点字テキストオブジェクトと裏面のカードを1ステップで組み合わせる便利なツールです。

<!--  Screenshot of a Braille Card object showing dots on a rectangular card base -->
![20260318 182929 paste 20260318 182929](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-182929-paste-20260318-182929.jpg)


## 使い方

1. プリミティブパネルから**点字カード**を追加します
2. エンコードしたいテキストを入力します
3. ツールが点字のドットとカードのベースの両方を生成します

## ヒント

- 印刷してすぐに使える完成した点字ラベルが欲しい場合に使用してください
- ベースなしの点字ドット（独自の面に配置する場合）が必要なときは、代わりに[点字](braille.md)を使用してください
