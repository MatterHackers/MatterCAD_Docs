# リング

内径と外径を個別に指定できる中空の円柱（チューブ）で、高さも指定できます。パイプ形状やチューブ形状とも呼ばれます。

![20260318 183848 paste 20260318 183848](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183848-paste-20260318-183848.jpg)


## パラメータ

- **外径** - リングの外側の幅（初期値: 20mm）
- **内径** - 中空部分の直径（初期値: 15mm）
- **高さ** - リングの高さ（初期値: 5mm）
- **側面** - 外周のセグメント数（初期値: 40）

### 詳細設定パラメータ

**詳細設定** モードを有効にすると、次の設定を利用できます:

- **開始角度** - リングが始まる角度（初期値: 0）
- **終了角度** - リングが終わる角度（初期値: 360）。360 未満にすると部分的なリングになります
- **丸め** - エッジに丸めを追加します（なし、上、下）
- **方向** - 内側または外側のエッジに向けて丸めます（丸めが有効なときに表示されます）
- **丸めセグメント** - 丸めの滑らかさ（丸めが有効なときに表示されます）

## ヒント

- 肉厚は（外径 - 内径）/ 2 になります
- ワッシャー、スペーサー、ブッシング、チューブ状の形状に使用します
- パイプにする場合は高さを大きく、平らなワッシャーにする場合は小さく設定します
- C クリップのような部分的なリング形状には、開始角度と終了角度を使用します
