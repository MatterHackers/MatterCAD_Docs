# プリミティブ

MatterCADには、デザインの構成要素となる3Dプリミティブシェイプのライブラリが含まれています。プリミティブパネルから任意のプリミティブをワークスペースに追加し、パラメータを変更して必要な形状に正確に仕上げることができます。

## 基本シェイプ

- [立方体](cube.md) - 幅、奥行き、高さを調整でき、任意で角を丸められるボックス形状
- [円柱](cylinder.md) - 直径、高さ、側面数を設定できる円形の柱
- [球](sphere.md) - 直径と詳細度を調整できる丸いボール
- [円錐](cone.md) - 先端が一点に向かって細くなる円柱
- [トーラス](torus.md) - 内径と外径を制御できるドーナツ形状
- [リング](ring.md) - 内径と外径を持つチューブ形状（中空の円柱）
- [ピラミッド](pyramid.md) - 底面と高さを調整できる四角錐
- [ウェッジ](wedge.md) - 三角柱の形状
- [半球](half-sphere.md) - 球の上半分
- [半円柱](half-cylinder.md) - 長手方向に半分に切った円柱
- [半ウェッジ](half-wedge.md) - 半分に切ったウェッジ
- [穴](hole.md) - ブール減算演算で使用する立方体形状の穴


## テキストと特殊シェイプ

- [テキスト](text.md) - フォントやサイズをカスタマイズできる3D押し出しテキストを作成
- [点字](braille.md) - 3Dプリント可能な点字テキストを生成
- [点字カード](braille-card.md) - 浮き出し文字付きの点字カードを作成
- [QRコード](qr-code.md) - QRコードを3Dオブジェクトとして生成
- [画像オブジェクト](image-object.md) - 画像をインポートして3Dレリーフに変換
- [SVGオブジェクト](svg-object.md) - SVGベクターグラフィックスを3Dシェイプとしてインポート
