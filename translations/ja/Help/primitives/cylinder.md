# 円柱

直径、高さ、側面の数を設定できる丸い柱形状です。円柱は、ピン、ロッド、穴、丸みのある形状を作成するために欠かせません。

![20260318 183248 paste 20260318 183248](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183248-paste-20260318-183248.jpg)


## パラメータ

- **直径** - 円柱の幅（既定値: 20mm）
- **高さ** - 円柱の高さ（既定値: 20mm）
- **側面** - 外周を構成するセグメントの数（既定値: 40）。値を小さくすると多角形の形状になります（例: 6 で六角形）

### 詳細設定パラメータ

**詳細設定** モードを有効にすると、追加のコントロールを使用できます。

- **上部直径** - 円柱の上部に異なる直径を設定し、テーパー形状や円錐台形状を作成します（既定値: 直径 と同じ）
- **開始角度** - 円柱が始まる角度（既定値: 0）。終了角度 と組み合わせて部分的な円柱を作成します
- **終了角度** - 円柱が終わる角度（既定値: 360）。360 未満に設定すると扇形の形状になります

## ヒント

- 側面 に小さい数値を設定すると正多角形を作成できます -- 六角形なら 6、八角形なら 8 など
- 直径 と 上部直径 に異なる値を設定すると、円錐台やテーパー形状を作成できます
- 開始角度 と 終了角度 を設定すると、扇形や円弧状の形状を作成できます
- 円柱は [減算](../operations/boolean/subtract.md) で丸い穴を作成する際の切り抜きツールとして最適です
