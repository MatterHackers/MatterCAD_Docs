# テキスト

内容、フォント、サイズ、高さをカスタマイズできる3D押し出しテキストを作成します。テキストオブジェクトは、ラベル、看板、ネームプレート、装飾文字に最適です。

## 使い方

1. プリミティブパネルから**テキスト**プリミティブを追加します
2. プロパティパネルの**名前**フィールドにテキストを入力します
3. 必要に応じてフォント、サイズ、押し出し高さを調整します

## パラメータ

- **名前** - 表示するテキストの内容
- **点のサイズ** - フォントサイズ。標準の印刷サイズに対応しており、MatterCADの12ポイントは2Dプリンターでの12ポイント活字と一致します
- **高さ** - 押し出し高さ（テキストが面からどれだけ突き出るか）
- **フォント** - 利用可能なシステムフォントから選択します

## ヒント

- テキストを盛り上げる代わりに面へ彫り込むには、[減算](../operations/boolean/subtract.md) を使用します
- 非常に小さいテキストの場合は、点のサイズを大きくしてから、オブジェクト全体を[スケール](../operations/transform/scale.md) で縮小すると、ディテールがきれいに出ます
- テキスト内の各文字はそれぞれ別のパスであり、まとめて押し出されます
