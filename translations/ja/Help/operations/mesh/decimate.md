# 縮小（デシメート）

縮小は、全体的な形状を保ちながらメッシュのポリゴン数を減らします。ディテールの多いモデルを簡略化したり、ファイルサイズを小さくしたり、複雑なジオメトリでの操作を高速化したりするのに便利です。

![20260324 080430 paste 20260324 080430](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080430-paste-20260324-080430.jpg)


## 使い方

1. オブジェクトを選択します
2. メッシュメニューから **縮小** 操作を適用します
3. 目標（数量またはパーセンテージ）を選択して調整します

## パラメータ

- **モード** - 目標の指定方法を選択します:
  - **パーセント** - 元のポリゴンのうち一定の割合を保持します（デフォルト: 50%）
  - **数量** - 特定のポリゴン数を目標にします
- **ソースポリゴン数** - 元のポリゴン数（読み取り専用）
- **目標パーセント** - 保持するポリゴンのパーセンテージ（パーセントモードで表示）
- **目標数** - 保持するポリゴンの厳密な数（数量モードで表示）
- **パーセント縮小後の数量** - パーセンテージ縮小後の最終的なポリゴン数（読み取り専用）
- **サーフェスを維持** - 頂点を元のサーフェスに投影し直して精度を高めます（処理は遅くなりますが、元の形状により忠実になります）

## ヒント

- 50% の縮小であれば、通常は見た目の品質が十分に保たれます
- 速度よりも精度が重要な場合は、サーフェスを維持を有効にしてください
- ポリゴン数を減らすと、複雑なインポートモデルでのブーリアン演算が高速になります
- ポリゴン数が極端に少ないと形状が目に見えて劣化します。確定する前に結果を確認してください
