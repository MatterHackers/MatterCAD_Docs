# メッシュ操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Mesh -->
![Mesh toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Mesh.png)

メッシュ操作を使うと、モデルの三角形メッシュジオメトリをクリーンアップして最適化できます。

## 操作

- [修復](repair.md) - 穴、非多様体エッジ、反転した面など、メッシュジオメトリの問題を修正します
- [縮小](decimate.md) - 形状を保ちながらメッシュのポリゴン数を減らして簡略化します
