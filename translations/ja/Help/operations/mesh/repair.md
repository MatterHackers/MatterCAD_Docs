# 修復

**修復**は、非多様体エッジ、穴、一貫性のない面の向き、ほぼ重複した頂点など、メッシュジオメトリによくある問題を修正します。これは、エラーを含む可能性のあるインポートされたSTLファイルやOBJファイルに特に有効です。

![20260324 080517 paste 20260324 080517](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080517-paste-20260324-080517.jpg)


## 使い方

1. メッシュに問題のあるオブジェクトを選択します
2. メッシュメニューから**修復**操作を適用します
3. 実行前後の統計を確認して、何が修正されたかを把握します

## 統計（読み取り専用）

- **初期頂点 / 最終頂点数** - 修復前後の頂点数
- **初期フェイス / 最終面数** - 修復前後の面数
- **初期非多様体エッジ / 最終非多様体エッジ** - 修復前後の問題エッジ数

### 詳細設定オプション

**詳細設定**モードを有効にすると、細かな制御が可能になります。

- **頂点を溶接** - ほぼ重複した頂点を結合します（デフォルト: オン）
- **溶接許容差** - 頂点を結合するために必要な近さ
- **面の向き** - 裏返しになったシェルを正しい向きに直し、すべてのボディがソリッドとして認識されるようにします。各シェルは個別に判定されるため、中空モデルは空洞が埋められることなく保持されます。シェル内の面同士が矛盾している場合は、推測せずにそのまま残されます。また、水密でないモデルにはより寛容な修復が適用されます。向きの修正だけでは解決しない場合は、先に**穴を埋める**を実行してください。
- **エッジを溶接** - 小さな亀裂や不良な継ぎ目を修復します
- **穴を埋める** - メッシュ表面の隙間を埋めます
- **削除モード** - 内部ジオメトリまたは遮蔽ジオメトリを削除します:
  - **なし** - すべてのジオメトリを保持します
  - **内部** - メイン形状の内部に隠れているボディを削除します
  - **遮蔽** - 外側から見えない面を削除します

## ヒント

- インポートしたモデルでブーリアン演算（結合、減算）が予期しない結果になる場合は、まず修復を試してください
- デフォルト設定（頂点を溶接がオン、それ以外はオフ）で、最もよくある問題は解決します
- モデルの隙間から向こう側が見える場合は、穴を埋めるを有効にしてください
- 内部に隠れたジオメトリがあるモデルを整理するには、削除モードの内部を使用してください
