# ミラー

ミラーは、3 つの主要な軸のいずれかを基準にしてオブジェクトの反転したコピーを作成します。結果として、元の形状のミラー版が得られます。

<!--  Before and after showing an object mirrored across the X axis -->
![20260506 160651 paste 20260506 160651](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-160651-paste-20260506-160651.jpg)


## 使い方

1. オブジェクトを選択します
2. 変換メニューから **ミラー** 操作を適用します
3. どの軸を基準にミラーするかを選びます

## パラメータ

- **ミラー オン** - 基準にする軸:
  - **X 軸** - オブジェクトを左右に反転します
  - **Y 軸** - オブジェクトを前後に反転します
  - **Z 軸** - オブジェクトを上下に反転します

## ヒント

- ミラーはオブジェクトのバウンディング ボックスを中心に行われるため、ミラーした結果は元のオブジェクトと同じ空間を占めます
- 適切なレンダリングを維持するため、ミラー後は面法線が自動的に補正されます
- 左右対称のデザインを作るにはミラーを使います。半分をモデリングしてからミラーし、元のオブジェクトと [結合](../boolean/combine.md) します
- ミラーは非破壊的です: ミラーの軸はいつでも変更できます

## 関連項目

- [回転](rotate.md) - ミラーの代わりにオブジェクトを回転します
- [スケール](scale.md) - オブジェクトのサイズを変更します
- [結合](../boolean/combine.md) - 元のオブジェクトとミラーしたコピーを 1 つのオブジェクトに結合します
