# 変換操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Transform -->
![Transform toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Transform.png)

変換操作は、ジオメトリを変えることなく、オブジェクトの位置、向き、サイズを変更します。

## 操作

- [移動](translate.md) - オブジェクトを X、Y、Z 方向に指定したオフセットだけ移動します
- [回転](rotate.md) - オブジェクトを軸まわりに指定した角度で回転します
- [スケール](scale.md) - 均一または軸ごとのスケーリングのオプションでオブジェクトのサイズを変更します
- [ミラー](mirror.md) - オブジェクトを軸に対して反転したコピーを作成します
