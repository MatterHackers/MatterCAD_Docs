# 放射状ピンチ

放射状ピンチは、カスタマイズ可能なプロファイルカーブを使って、中心点に向かってオブジェクトを内側に圧縮します。後ろから前へ圧縮する通常の [ピンチ](pinch.md) とは異なり、放射状ピンチは中心軸を基準に対称的に圧縮します。

## 使い方

1. オブジェクトを選択します
2. 形状変更メニューから **放射状ピンチ** 操作を適用します
3. パスのプロファイルを編集し、各高さでどの程度ピンチをかけるかを定義します
4. なめらかさを調整するためにスライス数を調節します

## パラメータ

- **パス** - 各高さレベルでのピンチ量を定義するプロファイルカーブエディターです。カーブを編集して独自のピンチプロファイルを作成できます
- **スライス** - なめらかにピンチさせるための水平方向のカット数で、パーツの高さ方向に均等に配置されます。スライスが多いほど結果はなめらかになります

### 詳細設定パラメータ

- **ピンチタイプ** - 圧縮する方向:
  - **放射状** - 全方向から中心に向かって均等に圧縮します
  - **X 軸** - X 軸方向にのみ圧縮します
  - **Y 軸** - Y 軸方向にのみ圧縮します
- **回転オフセット** - ピンチ効果の中心をずらします

## ヒント

- パスエディターを使って、砂時計・ボトル・花瓶のような形状を作成できます
- 放射状ピンチは、円筒形のオブジェクトから有機的で丸みのある形状を作るのに最適です
- 特に急峻なピンチプロファイルでは、スライスを増やすとカーブがよりなめらかになります
