# カーブ

カーブは、まっすぐなオブジェクトを円弧状または円形に曲げます。曲げ具合は、角度を指定するか、巻き付ける直径を指定して制御できます。

![20260506 155243 paste 20260506 155243](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-155243-paste-20260506-155243.jpg)

## 使い方

1. オブジェクトを選択します
2. 形状変更メニューから **カーブ** 操作を適用します
3. 曲げタイプとして角度または直径を選びます
4. 目的の曲率になるようにパラメーターを調整します

## パラメーター

- **曲げタイプ** - 次のいずれかを選択します:
  - **角度** - 曲げ角度を直接指定します（1〜360度）
  - **直径** - パーツが巻き付く円の直径を指定します
- **曲げ方向** - 上に曲げる、または下に曲げる
- **開始パーセント** - オブジェクトのどの位置から曲げを開始するか（0〜100%）
- **メッシュを分割** - 滑らかなカーブにするためにメッシュを分割します（デフォルト: オン）
- **1回転あたりの最小辺数** - 1回転あたりのメッシュ分割数の最小値。値を大きくするほどカーブが滑らかになります

### 詳細設定のパラメーター

- **曲げ開始率** - 左端から見て曲げが始まる位置のパーセンテージ
- **終端ベンド率** - 左端から見て曲げが終わる位置のパーセンテージ

## ヒント

- カーブを使うと、まっすぐな素材形状からアーチ、リング、曲げブラケットを作成できます
- 角度を360に設定すると、オブジェクトが完全なリング状に巻き付きます
- 急な曲げで滑らかな結果を得るには、1回転あたりの最小辺数を大きくします
- オブジェクトは長さ方向（X軸）に沿って曲げられます
