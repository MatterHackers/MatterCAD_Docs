# 形状変更操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Reshape -->
![Reshape toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Reshape.png)

形状変更操作はオブジェクトのジオメトリを変形・修正し、単純な形状から有機的で複雑な形状を作成できるようにします。

## 操作

- [カーブ](curve.md) - オブジェクトを曲線に沿って曲げます
- [ツイスト](twist.md) - オブジェクトを高さ方向に沿って徐々に回転させます
- [ピンチ](pinch.md) - オブジェクトを中心軸に向かって圧縮します
- [放射状ピンチ](radial-pinch.md) - オブジェクトを軸のまわりに放射状にピンチします
- [平面カット](plane-cut.md) - 指定した高さの平らな平面でオブジェクトをスライスします
- [中空化](hollow-out.md) - ソリッドオブジェクトから中空のシェルを作成します
