# 画像操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

画像操作は2D画像を3Dオブジェクトやパスに変換し、写真、ロゴ、アートワークをデザインに取り込むことができます。

## 操作

- [画像コンバーター](image-converter.md) - 明るさまたは色に基づいて画像を3Dレリーフに変換します
- [画像をパスに変換](image-to-path.md) - 画像をトレースして2Dパスの輪郭を作成します
- [リトフェイン](lithophane.md) - 背後から光を当てると画像が浮かび上がるリトフェインを作成します
