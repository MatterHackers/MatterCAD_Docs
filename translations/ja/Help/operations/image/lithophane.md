# リトフェイン

リトフェインは、画像を厚みの変化として表現した薄い3Dパネルです。背面から光を当てると、薄い部分ほど多くの光を通し、画像が浮かび上がります。写真やアートワークを美しく展示する方法として利用できます。

![20260324 080310 paste 20260324 080310](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080310-paste-20260324-080310.jpg)


## 使い方

1. 画像をインポートするか、既存の画像オブジェクトを選択します
2. **リトフェイン** 操作を適用します
3. 解像度と寸法を調整します
4. 明るい色の材料でプリントし、光源の前に設置します

## パラメーター

- **mmあたりのピクセル数** - リトフェインの解像度（デフォルト: 1.5、範囲: 0.5〜3）。値を大きくするとディテールがより細かく再現されますが、ファイルサイズが大きくなります
- **高さ** - リトフェインパネルの最大厚さ（デフォルト: 2.5mm、範囲: 0.5〜3mm）
- **幅** - リトフェイン全体の幅（ピクセル単位、デフォルト: 150）
- **反転** - 明暗のマッピングを反転します（デフォルト: オン）。背面から光を当てたときに正しく表示されるよう、通常はオンのままにします

## ヒント

- 白または明るい色の材料でプリントすると最良の結果が得られます
- ほとんどのリトフェインでは高さ2〜3mmが適しています
- mmあたりのピクセル数を大きくするとディテールが細かくなりますが、プリント時間とファイルサイズが増加します
- 完成したプリントはLEDバックライト付きのフレームに取り付けると最もよく見えます
- コントラストの高いポートレート写真は特に適しています
