# 画像をパスに変換

画像をパスに変換は、画像の輪郭をトレースして2Dパスを作成します。作成したパスは、押し出し、回転、その他のあらゆるパス操作に使用できます。ロゴ、シルエット、シンプルなグラフィックを3Dオブジェクトに変換するのに最適です。

![20260324 075521 paste 20260324 075521](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-075521-paste-20260324-075521.jpg)


## 使い方

1. ワークスペースで画像オブジェクトを選択します
2. 画像操作メニューから **画像をパスに変換** を適用します
3. 解析タイプを選び、範囲を選択を調整します

## パラメーター

- **解析タイプ** - トレースのために画像をどのように解析するか:
  - **透明度** - 透明部分と不透明部分に基づいてトレースします（透明な背景を持つPNGに最適）
  - **カラー** - 色の領域に基づいてトレースします
  - **強度** - 明るさのレベルに基づいてトレースします（ほとんどの画像に最適）
- **範囲を選択** - トレースに含める明るさ／色の値を選択するヒストグラムコントロール
- **最小表面積** - パスループを含めるための最小面積。小さなノイズを除外するには値を大きくします

## ヒント

- シンプルな形状で、くっきりとコントラストの高い画像が最も適しています
- 透明な背景を持つPNG画像には透明度モードを使用してください
- 写真や透明部分のない画像には強度モードを使用してください
- トレース後は、[直線押し出し](../path/linear-extrude.md) を適用してパスに高さを与えます
- トレースから不要な細部を削除するには、最小表面積の値を大きくします
