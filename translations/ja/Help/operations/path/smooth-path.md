# パスをスムーズ

パスをスムーズは、2D パスの角やカーブを丸め、角張った入力からより滑らかで有機的な形状を作成します。

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## 使い方

1. 2D パスを選択します
2. パス操作メニューから **パスをスムーズ** を適用します
3. パスの角がカーブに滑らかになります

## ヒント

- [直線押し出し](linear-extrude.md) の前に適用すると、エッジの柔らかい押し出し形状を作成できます
- [星パス](../../2d-paths/star-path.md) に使用すると、角の丸い星を作成できます
- パスをスムーズを複数回適用すると、スムージング効果が強くなります

## 関連項目

- [パスを膨張](inflate-path.md) - パスを外側に展開します
- [アウトラインパス](outline-path.md) - パスからアウトラインを作成します
- [直線押し出し](linear-extrude.md) - スムーズにしたパスに高さを与えます
