# アウトラインパス

アウトラインパスは、塗りつぶされたパスのアウトライン版を作成し、ソリッド形状を指定した太さの境界リングのみに変換します。

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## 使い方

1. 2Dパスを選択します
2. パス操作メニューから **アウトラインパス** を適用します
3. アウトラインの太さを調整します

## ヒント

- ソリッドなパスからフレーム状の形状を作成するのに使用します
- [直線押し出し](linear-extrude.md) と組み合わせて、3Dのフレームや縁取りを作成できます
- アウトライン化した [円パス](../../2d-paths/circle-path.md) は [リングパス](../../2d-paths/ring-path.md) と同等です

- [境界パス](border-path.md) - 境界オフセットを追加します
