# パスを膨張

パスを膨張は2Dパスを外側に拡張し、全体の形状を保ったまま図形を大きくします。これは、すべてのエッジに均一なオフセットを適用することに似ています。

## 使い方

1. 2Dパスを選択します
2. パス操作メニューから**パスを膨張**を適用します
3. 膨張量を調整します

## 開いた線を膨張させる

膨張は、線を図形に変える方法です。[カスタムパス](../../2d-paths/custom-path.md) で**閉じている**のチェックを外して開いた線を描き、それを膨張させます。結果として、線の両側に設定した量だけの幅を持つ、塗りつぶされたリボンが得られます。そこから先は、他のパスと同じように押し出すことができます。

**スタイル**は、線の両端をどのように閉じるか、また角をどのように接合するかを設定します:

- **フラット**は各端点でリボンを四角く止めます
- **丸め**は各端点の先に半円を追加します
- **シャープ**は各端点の先に四角形を追加します

開いた線には縮小する内側がないため、値がゼロまたは負の場合は何も残りません。パスが*完全に*開いている場合、膨張は値を小さな正の数まで引き上げ、その制限された数値をボックスに書き戻すので、何が起きたかを確認できます。

開いた輪郭と閉じた輪郭が混在するパスは制限されません。閉じた輪郭は通常どおり縮小し、開いた輪郭は単に消えます。閉じたパスは、これまでどおり負の値で縮小します。

## ヒント

- 拡張する代わりにパスを内側に縮小するには、負の値を使用します
- 膨張は、図形の周囲に公差オフセットを作成するのに便利です
- 特定の幅の境界を作成するには、[アウトラインパス](outline-path.md) と組み合わせます
