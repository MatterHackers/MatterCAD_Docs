# パスを選択

パスを選択は、複雑なパスオブジェクトのうちどのサブパスを残すかをフィルタリングします。装飾的なフォントや複数パーツで構成されたフォントを扱うとき、外側の文字形状と内側の切り抜き形状を別々のパーツとして取り出したい場合に特に便利です。たとえば、2色に分けて3Dプリントするような場合です。

## パスの深さの仕組み

パスオブジェクトに囲まれた領域を持つ形状（たとえば文字「O」の内側や、装飾的な渦巻きの中空部分）が含まれる場合、それらの囲まれた領域は深さ1の**穴**になります。各文字や形状の外側の輪郭は**深さ0**です。

```
Depth 0 — outer contour of each letter or shape
Depth 1 — first level of enclosed holes (inside an "O", "A", etc.)
Depth 2 — shapes nested inside a hole (rarely used)
```

## フィルタープリセット

### すべて
すべてのパスをそのまま含めます。これが既定値で、パスを選択をまったく適用しない場合と同じです。

### 外側のパスのみ
各形状の外側の輪郭（深さ == 0）だけを残します。装飾的なフォントから、内側の切り抜き領域を除いた文字の輪郭だけを取り出したいときに使用します。

### 穴のみ
囲まれた穴（深さ > 0）だけを残します。文字や形状の内側の切り抜き領域だけを取り出したいときに使用します。

### グループインデックス指定
1つの独立した形状に属するパスだけを残します。グループ0が最初の形状、グループ1が2番目の形状、というように続きます。単語から1文字だけを分離したいときに使用します。

### カスタム
各パスに対して評価される式を記述します。式の結果が0以外のときそのパスは**含まれ**、0のときは**除外**されます。

式は変数の置換を有効にするために `=` で始める必要があります。`=` がない場合、値は単なる数値として扱われます（例: `1` は常に含める、`0` は常に除外する）。

## カスタム式の例

| 式 | 効果 |
|------------|--------|
| `=PathDepth==0` | 外側の輪郭のみ（外側のパスのみと同じ） |
| `=PathDepth>0` | 穴のみ（穴のみと同じ） |
| `=GroupIndex==0` | 最初の独立した形状のみ |
| `=PathArea>100` | 面積が100 mm²より大きい形状 |
| `=PathLength>50` | 周長が50 mmより長い形状 |

## カスタム式の変数

| 変数 | 意味 |
|----------|---------|
| `PathDepth` | 0 = 外側の輪郭、1以上 = 穴または入れ子になった形状 |
| `GroupIndex` | 独立した形状のインデックス（0、1、2…） |
| `GroupOuterArea` | このグループの外側パスの面積 |
| `GroupOuterLength` | このグループの外側パスの周長 |
| `ChildCount` | このグループの外側パス内にある穴の数 |
| `PathIndex` | グループ内におけるこのパスの連番インデックス |
| `PathArea` | このパス単体の面積 |
| `PathLength` | このパス単体の周長 |

## 例: 多色クリスマスフォントのプリント

パスを選択のよくある用途は、文字の内側に切り抜き形状を持つ装飾的なテキストをプリントすることです。外側の文字を1色目で、内側の切り抜きを2色目でプリントするには次のようにします。

1. **テキスト**オブジェクトを追加し、**2D出力**に設定します
2. **パスを選択**を適用 → プリセットを**外側のパスのみ**に設定します
3. **直線押し出し**を適用して高さを与えます → 1色目のフィラメント色を割り当てます
4. 元のテキストオブジェクトに戻ります
5. 2つ目の**パスを選択**を適用 → プリセットを**穴のみ**に設定します
6. 同じ高さで**直線押し出し**を適用します → 2色目のフィラメント色を割り当てます
7. 一方の押し出したオブジェクトをもう一方の上に配置します。2色はぴったり揃います
