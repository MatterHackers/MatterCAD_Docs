# パス操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

パス操作は 2D パスを扱い、3D 形状を作成・変更します。これらを使用して、パスベースのジオメトリを押し出し、回転、調整できます。

## 操作

- [直線押し出し](linear-extrude.md) - 2D パスに高さを与えて 3D オブジェクトを作成します
- [回転体](revolve.md) - 2D パスを軸まわりに回転させて回転体を作成します
- [パスをスムーズ](smooth-path.md) - パスの曲線をスムーズにします
- [パスを膨張](inflate-path.md) - パスを外側に展開します
- [アウトラインパス](outline-path.md) - 塗りつぶされたパスからアウトラインを作成します
- [境界パス](border-path.md) - パスの周囲に境界オフセットを追加します
- [パスを選択](select-paths.md) - 複雑なマルチパスオブジェクトから特定のパスを選択します
