# 配置の操作
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

配置の操作を使うと、オブジェクトを互いに対して、または特定の境界内に正確に位置決めできます。

## 操作

- [整列](align.md) - 任意の軸に沿ってオブジェクト同士を整列します
- [デュアル押し出しの位置合わせ](dual-extrusion-align.md) - オブジェクトを共有のモデリング位置に整列します
- [境界にフィット](fit-to-bounds.md) - 指定したバウンディングボックス内に収まるようにオブジェクトをスケールします
- [円柱にフィット](fit-to-cylinder.md) - 指定した円柱内に収まるようにオブジェクトをスケールします
