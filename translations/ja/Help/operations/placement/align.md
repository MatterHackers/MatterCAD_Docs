# 整列

**整列**は、アンカーオブジェクトを基準にして複数のオブジェクトを正確に配置します。エッジをそろえる、パーツどうしを中心に合わせる、あるオブジェクトを別のオブジェクトの上に置く、等間隔のスタックを作成するといった用途に使用します。

## 使い方

1. 2つ以上のオブジェクトを選択します。
2. **配置**メニューから**整列**操作を適用します。
3. **アンカー**オブジェクトを選択します。アンカーはその場に留まり、他のオブジェクトが移動します。
4. X、Y、Z の各軸について個別に整列を設定します。
5. 整列後の位置をオブジェクトツリーに確定させたい場合は**適用**を使用します。

## パラメーター

### アンカー

**アンカー**リストでは、基準として使用する子オブジェクトを選択します。アンカーは移動しません。整列操作に含まれる他のすべての子オブジェクトは、アンカーを基準に再配置されます。ただし、その軸が**積み重ね**モードを使用している場合を除きます。

### 軸コントロール

各軸にはそれぞれ独自のコントロールがあります。1つの軸、2つの軸、または3つすべての軸で整列できます。最小・最大のエッジは軸ごとに次の意味になります。

- **X 軸** - 最小は左、最大は右です。
- **Y 軸** - 最小は手前、最大は奥です。
- **Z 軸** - 最小は下、最大は上です。

各軸について:

- **整列** - その軸のアンカー基準点を選択します。その軸で位置を変更しない場合は**なし**を使用します。
- **モード** - 選択した整列をどのように適用するかを制御します:
  - **シンプル** - 移動する各オブジェクトの対応するエッジ、中心、または原点をアンカーに合わせます。オフセットは使用しません。
  - **オフセット** - 移動するオブジェクトのどの部分をアンカー基準に合わせるかを選択し、**オフセット**で間隔を追加します。
  - **積み重ね** - **オフセット**を間隔として使用しながら、その軸に沿ってオブジェクトを次々に配置します。
- **サブ整列** - **オフセット**モードで使用できます。アンカー基準に合わせる移動オブジェクト側の部分を選択します。**サブ整列**が**なし**の場合、整列は**整列**で選択したものと同じエッジ、中心、または原点を使用します。
- **オフセット** - **オフセット**モードと**積み重ね**モードで使用できます。その軸に沿って距離を追加し、[数式](../../workspace/expressions.md)に対応しています。

## 整列モード

### シンプル

同種どうしの位置を合わせる場合は**シンプル**を使用します。たとえば、**X 方向の整列: 中心**では、アンカー以外のすべてのオブジェクトの X 中心がアンカーの X 中心に一致するように移動します。**Zアライメント: 最小**では、アンカー以外のすべてのオブジェクトの底面がアンカーの底面の高さに来るように移動します。

### オフセット

移動するオブジェクト側の基準部分をアンカー基準と異なるものにしたい場合は**オフセット**を使用します。たとえば、アンカーの上にオブジェクトを配置するには:

1. **Zアライメント**を**最大**（上）に設定します。
2. **Z モード**を**オフセット**に設定します。
3. **Z サブ整列**を**下**に設定します。
4. **Zオフセット**に必要な間隔を設定します。密着させる場合は `0` のままにします。

これにより、移動するオブジェクトの底面がアンカーの上面に配置され、必要に応じて間隔が追加されます。

### 積み重ね

複数のオブジェクトを1つの軸に沿って連結するには**積み重ね**を使用します。オブジェクトは名前順、次に内部 ID 順に処理されるため、オブジェクトに分かりやすい名前を付けると積み重ね順序を予測できます。

**積み重ね**モードでは、移動する各オブジェクトはその軸上で直前の基準に接するように配置されます:

- **最小**の整列では正方向に積み重ねられます（X なら左から右、Z なら下から上）。
- **最大**の整列では負方向に積み重ねられます（X なら右から左、Z なら上から下）。
- **中心**および**原点**の整列では、各オブジェクトの中心または原点の間のオフセットが使用されます。

**積み重ね**モードでオブジェクト間の間隔を設定するには**オフセット**を使用します。

## 例

- **ベッドの設置面にオブジェクトを中心合わせする** - 固定しておきたいオブジェクトを**アンカー**として選択し、**X 方向の整列**と**Y 方向の整列**を**中心**に設定します。
- **あるオブジェクトを別のオブジェクトの上に配置する** - **Zアライメント**を**最大**（上）、**Z モード**を**オフセット**、**Z サブ整列**を**下**に設定します。
- **エッジから正確な間隔を空ける** - **オフセット**モードを使用し、**サブ整列**で移動するオブジェクトのエッジを選択してから、**オフセット**に必要な間隔を設定します。
- **複数のオブジェクトを端から端まで並べる** - **X 方向の整列**を**最小**（左）、**X モード**を**積み重ね**に設定し、間隔には **X オフセット**を使用します。
- **垂直方向のスタックを作成する** - **Zアライメント**を**最小**（下）、**Z モード**を**積み重ね**に設定し、オブジェクト間の間隔には **Zオフセット**を使用します。

## ヒント

- アンカーオブジェクトはその場に留まり、他のオブジェクトがそれに合わせて移動します。
- 軸ごとに異なるモードを使用できます。たとえば、X では**積み重ね**を使い、Y では**中心**と**シンプル**を使うことができます。
- 複数のオブジェクトを一度に整列させる場合は、オブジェクトの名前で**積み重ね**の順序を制御します。
- 整列は適用するまで非破壊です。設定はいつでも変更して子オブジェクトを再整列できます。
- バウンディングボックスのエッジではなくモデリング原点をそろえたい場合は**原点**を使用します。
