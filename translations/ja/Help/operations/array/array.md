# 配列

配列は、オブジェクトの複数のコピーをパターン状に配置して作成します。上部のボタン — **線形**、**放射状**、**変換** — からモードを選択して、パターンの種類を切り替えます。

![20260506 080647 paste 20260506 080647](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080647-paste-20260506-080647.jpg)


## 使い方

1. オブジェクトを選択します
2. 複製メニューから **配列** 操作を適用します
3. モード（線形、放射状、変換）を選択します
4. 選択したモードのパラメータを調整します

## モード: 線形

線形モードは、指定した方向に沿ってコピーを配置し、必要に応じて回転とスケールを段階的に変化させます。

**数量** — コピーの数（整数または式）。元のオブジェクトが最初のコピーとなり、追加のコピーはそこからオフセットされます。

**オフセット方式** — 間隔の計算方法：
- **相対** — オフセットにオブジェクトのバウンディングボックスサイズが乗算されます。相対オフセットが (1, 0, 0) の場合、コピーは X 方向にちょうどオブジェクト 1 個分の幅で配置されます。
- **オフセット** — コピーごとの固定のワールド空間距離（mm）。
- **終点** — 最後のコピーの位置を設定します。間隔はコピー間で均等に分割されます。

**相対オフセット** / **オフセット** / **終点** — 選択したオフセット方式に応じた間隔ベクトル。

**回転モード** — コピー間で回転がどのように累積するか：
- **ローカル** — 各コピーはそれぞれの中心でその場で回転し、オフセット方向はワールド軸のまま保たれます。
- **複合** — 回転が累積してオフセット方向を導き、スパイラル、ファン、ヘリックスを生成します。

**回転** — 各軸におけるコピーごとの回転角度（度）。

**スケール** — 各軸におけるコピーごとの累積スケール。1 未満の値はコピーを縮小し、1 より大きい値は拡大します。

**スケールがオフセットに影響** — オンにすると、コピー間の間隔もステップごとにスケールされます。次第に締まっていくスパイラルや等比数列的な配置（オウムガイの殻、積み重なった巻貝状のカーブ）に使用します。

## モード: 放射状

放射状モードは、中心軸のまわりに一定の半径でコピーを均等に配置します。

![20260506 092618 paste 20260506 092618](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-092618-paste-20260506-092618.jpg)


**カウント方法** — コピー数の決定方法：
- **数量** — コピー数を明示的に指定します。
- **距離** — コピー間の角度間隔（度）。スイープを満たすように数量が計算されます。

**数量** / **角距離** — コピー数（数量モード）または角度間隔（度、距離モード）。式に対応しています。

**中心軸** — 回転の基準となる軸（既定値: Z）。

**円セグメント** — コピーを 360° の完全な円（**フル**）に配置するか、部分的な円弧（**円弧**）に配置するか。

**半径** — 中心軸から各コピーまでの距離。

**スイープ角度** — 満たす円弧の角度（円セグメントが円弧のときに表示）。式に対応しています。

**回転を整列** — 各コピーの前方軸が中心から外向きになるように回転させます。

**前方軸** — 整列時にコピーのどの軸を「前方」として扱うか（回転を整列がオンのときに表示）。

## モード: 変換

変換モードは、手動で指定した変換、または別のオブジェクトの変換に従って、コピーを段階的に配置します。

**数量** — コピーの数（整数または式）。

**変換リファレンス** — ステップごとの変換の取得元：
- **入力** — 移動、回転、スケールを直接指定します。
- **オブジェクト** — 指定した名前の同階層オブジェクトから変換を読み取ります。

**移動** — ステップごとのワールド空間オフセット（mm）（リファレンスが入力のときに表示）。

**回転** — ステップごとの各軸の回転角度（度）（リファレンスが入力のときに表示）。

**スケール** / **スケール軸** — 各ステップで適用される均一スケールおよび軸ごとのスケール（リファレンスが入力のときに表示）。

**変換名** — ステップごとの増分として変換が使用される同階層オブジェクトの名前（リファレンスがオブジェクトのときに表示）。

**相対空間** — オンにすると、各コピーの変換は直前のコピーのローカルフレーム上で累積されます。オフの場合、各ステップはワールド空間で適用されます（リファレンスがオブジェクトのときに表示）。

## ランダム化

**ランダム化** を有効にすると、すべてのコピーにばらつきを加えられます。

- **ランダムオフセット** — 軸ごとの最大ランダム位置オフセット（mm）。
- **ランダム回転** — 軸ごとの最大ランダム回転角度（度）。
- **ランダムスケール軸** — 軸ごとの最大ランダムスケール変動。
- **最初を除外** — 最初のコピーを計算どおりの正確な位置に保ちます（既定値: オン）。
- **最後を除外** — 最後のコピーを計算どおりの正確な位置に保ちます。
- **ランダムシード** — この値を変更すると、異なるランダム配置が得られます。式に対応しています。

## 結合

- **単一メッシュを作成** — すべてのコピーを 1 つの結合されたメッシュオブジェクトに結合します。
- **頂点を結合** — 結合距離のしきい値内にある頂点を溶接します（単一メッシュを作成がオンのときに表示）。
- **距離** — 結合のしきい値（mm）（頂点を結合がオンのときに表示）。

## ヒント

- 数量、回転、終点に式を使用すると、パラメトリックなパターンを作成できます
- 円形のパターンには放射状モードを使用します。半径で円の大きさを制御し、コピーを外向きにしたい場合は回転を整列を有効にします
- 線形モードでの複合回転を使えば、角度オフセットを手計算せずにスパイラルやファンを作成できます
- スケールがオフセットに影響を使うと、オウムガイの殻のような配置や等比数列的なレイアウトを自然に作成できます
- 配列を [子を選択](select-child.md) と組み合わせると、コピーごとに異なるバリエーションを表示するパターンを作成できます
