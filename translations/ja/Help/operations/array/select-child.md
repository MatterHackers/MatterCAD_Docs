# 子を選択

子を選択は、インデックス番号または名前に基づいて、オブジェクトのグループから 1 つの子を選び出します。これは、表示するオブジェクトを動的に選択したいスクリプト設計やパラメトリック設計で特に便利です。

![20260506 080526 paste 20260506 080526](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080526-paste-20260506-080526.jpg)


## 使い方

1. 2 つ以上のオブジェクトを選択します
2. 複製メニューから **子を選択** 操作を適用します
3. 子の選択方法を制御するために **インデックス順** または **名前順** を選びます
4. 一致させるインデックス番号または名前を設定します

## パラメーター

- **選択方法** - **インデックス順**（位置で選択）または **名前順**（オブジェクト名で選択）から選びます。ボタンとして表示されます。
- **子インデックス** - 選択する子のゼロ始まりのインデックス（インデックス順を使用しているときに表示）。[式](../../workspace/expressions.md) に対応しています。
- **子の名前** - 選択する子の名前（名前順を使用しているときに表示）。[式](../../workspace/expressions.md) に対応しています。

インデックスが範囲外の場合や、名前がどの子とも一致しない場合は、フォールバックとして最初の子が返されます。子が存在しない場合は、何も返されません。

## スクリプトでの使用

子を選択は、式や `rand()` 関数と組み合わせて、動的でデータ駆動型の設計を作成できるように設計されています。たとえば、複数のバリエーションオブジェクトを子としてシーンを構築し、`rand(42)` のような式をインデックスのシードとして使用すれば、ランダムに 1 つを選び出せます。

**例: 舞台公演用のランダムな本の小道具**

1. 5 種類の異なる本のメッシュを、子を選択操作の子としてインポートします
2. 選択方法を **インデックス順** に設定します
3. 子インデックスに `floor(rand(seed) * 5)` のような式を使用します（`seed` はシート変数です）
4. 子を選択操作を複数回複製し、それぞれに異なるシード値を設定します
5. 各インスタンスがセットの中から異なる本をランダムに選び出します

このパターンは、バリエーションのセットから 1 つを選ぶ必要があるあらゆる場面で機能します。家具、装飾、建築要素、または交換可能なパーツのコレクションなどです。

## ヒント

- [配列](array.md) と結合すると、各コピーが異なる子を選択する多様なパターンを作成できます
- インデックスや名前にシート変数を使用すると、スプレッドシートから選択を制御できます
- 最初の子にフォールバックする動作により、インデックスや名前が間違っていても設計が壊れることはありません
