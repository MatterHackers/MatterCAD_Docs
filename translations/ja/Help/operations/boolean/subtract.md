# 減算

減算は、選択したパーツを選択しなかったパーツから切り取ります。**減算するパーツ** で切り取り用の形状を指定します。それ以外のすべてが、切り取られるベースになります。

<!-- AUTO_IMAGE: type=from_mcx file=boolean_subtract -->
![boolean_subtract](https://matterhackers.github.io/MatterCAD_Docs/assets/boolean_subtract.png)

[結合](combine.md)、減算、[交差](intersect.md)、[減算と置換](subtract-and-replace.md) はいずれも 1 つのブーリアンオブジェクトによって実行されます。ツールバーのボタンでは減算が選択された状態で作成され、プロパティパネル上部の **操作** アイコン列からいつでも他の 3 つのいずれかに切り替えられます。

減算はソリッドにも 2D パスにも使用できます。与えられたものを判別して適切な種類の演算を行うため、パスからパスを減算するとパスが生成され、メッシュからメッシュを減算するとソリッドが生成されます。

## 使い方

1. 2 つ以上のオブジェクトを選択します
2. ツールバーの **減算** をクリックします。切り取るパーツが既定で 1 つ選ばれるため、すぐに結果が得られます
3. **減算するパーツ** で、どの子オブジェクトを切り取り用の形状にするかを選びます
4. プロパティパネル上部の **操作** 列で別のアイコンをクリックすれば、いつでも変更できます。新しい操作で形状が再構築されます

## パラメーター

- **操作** - 実行するブーリアン演算。パネル上部にアイコン列として表示されます
- **減算するパーツ** - どの子オブジェクトを切り取り用の形状にするか
- **減算したパーツを保持** - 切り取られたパーツを破棄せず、シーン内に残します
- **裏返ったジオメトリを保持** - 裏返ったシェルを、周囲の体積を打ち消すものとしてではなく、ソリッドの材料として扱います。ソリッドになるはずのモデルの一部が欠けて返ってくる場合にオンにしてください。低速ですが厳密なブーリアンエンジンが強制的に使用されます
- **ワインディング順序を修復** - ブーリアン演算の実行前に、各パーツの裏返ったシェルの向きを直します。以降のすべての操作がソリッドとみなす対象を変えるのではなく、ジオメトリそのものを一度で修正するため、裏返ったモデルへの 2 つの対処法のうち通常はこちらが適しています

## ヒント

- 減算が機能するには、オブジェクト同士が重なっている必要があります
- 貫通穴を作るには、切り取り用オブジェクトがベースを完全に貫通していることを確認してください
- 単純な穴には、あらかじめ減算するように設定された [穴](../../primitives/hole.md) プリミティブが便利です
- 切り取り用オブジェクトはデザインツリーに残るため、移動やサイズ変更を行うと切り取り結果も更新されます
- 結果がおかしい場合は、元のオブジェクトが水密かどうかを確認してください。**ワインディング順序を修復** は裏返ったシェルを直します。インポートしたモデルのより大きな破損には [修復](../mesh/repair.md) を使用します

## 関連項目

- [結合](combine.md) - 複数のオブジェクトを 1 つのソリッド形状にまとめます
- [交差](intersect.md) - オブジェクトが重なっている体積だけを残します
- [減算と置換](subtract-and-replace.md) - 一方の形状を減算し、切り取られた部分を残します
- [平面カット](../reshape/plane-cut.md) - 別の形状ではなく平面で切断します
- [穴](../../primitives/hole.md) - 減算するようにあらかじめ設定された立方体です
- [修復](../mesh/repair.md) - ブーリアン演算の前に、破損したインポートメッシュを修正します
