# グループ化

グループ化は、複数のオブジェクトを1つの単位にまとめ、1つのオブジェクトとして移動、コピー、操作できるようにする機能です。[結合](../operations/boolean/combine.md) とは異なり、グループ化ではジオメトリは統合されません。各オブジェクトはグループ内で個別のまま保持されます。

## 使い方

### オブジェクトをグループ化する

1. 2つ以上のオブジェクトを選択します（Shift+クリックまたはCtrl+クリックで複数選択）
2. ツールバーの **グループ化** ボタンをクリックします
3. これでオブジェクトがグループ化され、1つの単位として一緒に移動します

### オブジェクトのグループ解除

1. グループを選択します
2. ツールバーの **グループ解除** ボタンをクリックします
3. ![20260318 193354 paste 20260318 193354](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-193354-paste-20260318-193354.jpg)
4. 個々のオブジェクトが別々のアイテムとして復元されます

グループ解除では、インポートした1つのSTLファイル内に複数のボディが含まれている場合、それらの分離も試みます。

## グループ化と結合の比較

| 機能 | グループ化 | 結合 |
|---------|-------|---------|
| オブジェクトが個別のまま保持される | はい | いいえ |
| 後からグループ解除できる | はい | いいえ（破壊的） |
| 重なったジオメトリを統合する | いいえ | はい |
| オブジェクトごとに異なる色を設定できる | はい | カラーは面ごとに保持されます |
| 用途 | 整理と移動 | 単一のソリッド形状の作成 |

## ヒント

- グループは入れ子にできます。すでにグループになっているオブジェクトをさらにグループ化できます
- グループを選択してデザインツリーを見ると、その中の個々のオブジェクトを確認したり選択したりできます
- グループ化は非破壊的で、いつでも グループ解除 で元に戻せます
