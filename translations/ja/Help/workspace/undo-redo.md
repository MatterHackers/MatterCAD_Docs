# 元に戻すとやり直し

MatterCAD は変更履歴をすべて保持しているため、操作ミスを元に戻したり、取り消した操作をやり直したりできます。

## 使い方

- **Ctrl + Z** - 直前の操作を元に戻します
- **Ctrl + Y** または **Ctrl + Shift + Z** - 直前に元に戻した操作をやり直します
- 次のこともできます: ツールバーの **元に戻す** および **やり直し** ボタンを使用する

## 元に戻せる操作

すべての設計操作が元に戻す履歴に記録されます。次のような操作が含まれます:

- オブジェクトの追加または削除
- オブジェクトの移動、回転、拡大縮小
- 操作の適用(ブーリアン、変換、形状変更など)
- オブジェクトのパラメーターの変更
- グループ化とグループ解除

## ヒント

- Ctrl + Z を繰り返し押すと、複数のステップを元に戻せます
- 元に戻す履歴は現在のセッションでのみ保持されます。設計を閉じて開き直すと、履歴は新しく始まります。
- 数ステップ元に戻してから新しい変更を加えると、その時点より先のやり直し履歴は消去されます
