# 測定ツール

測定ツールを使うと、デザイン内の点と点の間の距離を測定できます。3D ビューポート内の任意の位置に測定点を配置して、寸法を確認できます。

<!--  Screenshot showing the Measure Tool with a distance measurement displayed between two points -->
![20260318 192711 paste 20260318 192711](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192711-paste-20260318-192711.jpg)


## 使い方

1. ツールメニューから **測定ツール** を追加します
2. 測定したい位置まで測定点をドラッグします
3. 距離がビューポートに表示されます

## ヒント

- 3D プリント用にエクスポートする前の寸法確認に使用してください
- 測定ツールは 2 つのコントロールポイント間の直線距離を表示します
- 作業中は測定ツールをデザイン内に残しておき、エクスポート前に削除できます
