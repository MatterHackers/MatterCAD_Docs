# 変数シート

変数シートは、デザインで共有する値を保存します。複数のオブジェクトが同じ寸法、数量、ラベル、数式を参照する必要がある場合に使用します。シート内の値を変更すると、依存するオブジェクトが再計算されるため、オブジェクトを1つずつ編集しなくてもパラメトリックなデザインの整合性が保たれます。

## 変数シートを追加する方法

1. ライブラリを開き、**変数シート**をシーンに追加します。
2. 変数シートオブジェクトを選択してシートエディタを表示します。
3. セルを選択し、**名前**と値または数式を入力します。
4. デザイン内の式に対応した他のフィールドから、そのセル名を使用します。

## セルの編集

各セルには編集可能な部分が2つあります。

- **名前** - セルに付ける任意の変数名です。名前は大文字と小文字を区別せず、スペースはアンダースコアに変換され、重複する名前は自動的に調整されます。
- **式** - セルの値です。プレーンテキストや数値はそのまま保存されます。数式は`=`で始めます。

セルは`A1`や`B2`のようにアドレスで参照することもできます。デザインパラメータには、`wall_thickness`、`outer_diameter`、`hole_count`のように意図を表す名前付きセルの方が通常は分かりやすくなります。

## 数式

シート内で評価させるには、数式を`=`で始めます。

- `=20 + 5` は `25` を返します
- `=pi * 10` は `31.41592653589793` を返します
- `=A1 * 2` はアドレスで別のセルを参照します
- `=wall_thickness + 4` は名前付きセルを参照します

シートは算術演算、括弧、比較演算子、`sin`、`cos`、`sqrt`、`round` などの一般的な `Math` 関数、および `pi`、`tau`、`e` を含む定数をサポートしています。

## オブジェクトでシートの値を使用する

MatterCAD のほとんどの数値フィールドは式をサポートしています。オブジェクトのパラメータでシートの値を使用するには、参照の先頭に `=` を付けます。

- 立方体の**幅**に `=case_width` を設定します。
- 配列の**数量**に `=hole_count` を設定します。
- 移動の**オフセット**値に `=wall_thickness * 2` を設定します。

シートが変更されると、MatterCAD はそれに依存するオブジェクトを再計算します。

## テキストとヘルパー関数

変数シートのセルには、数値だけでなくテキストも保持できます。テキスト値は、生成されるラベル、部品番号、インポートしたデータ、カスタムデザインアプリで役立ちます。

便利なヘルパー関数には次のものがあります。

- `concat()` または `strcat()` - テキストや値を連結します。
- `substring()` - テキスト値の一部を抽出します。
- `split()` - テキストを分割して1つの項目を返します。
- `count()` - テキスト内の区切られた項目数を数えます。
- `substitute()` - テキストを置換します。
- `rand(seed)` - シードを指定すると決定論的な乱数値を生成します。
- `importdata()` - URL またはローカルファイルパスから値を読み込みます。

## ヒント

- 他のオブジェクトから使用する値には、セルアドレスではなく分かりやすい名前を使いましょう。
- 主要な寸法はシートの左上付近にまとめておくと見つけやすくなります。
- `inner_diameter = outer_diameter - wall_thickness * 2` のような派生値には数式を使用します。
- `pi`、`e`、`true`、`false` などの予約語や関数名をセル名に使用しないでください。
- 数式を解析できない場合、MatterCAD は入力された内容をテキストとしてそのまま保持します。
