# マウスコントロール

MatterCAD の 3D ビューポートにおけるマウスコントロールの完全リファレンスです。

## ナビゲーション

| 操作 | マウスコントロール |
|--------|--------------|
| **表示を回転** | 右クリック + ドラッグ |
| **表示をパン** | 中クリック + ドラッグ |
| **ズーム** | スクロールホイール |

## 代替ナビゲーション

| 操作 | マウスコントロール |
|--------|--------------|
| **表示を回転** | Ctrl + 左クリック + ドラッグ |
| **表示をパン** | Ctrl + Shift + 左クリック + ドラッグ |
| **ズーム** | Ctrl + Alt + 左クリック + ドラッグ |

## オブジェクトの操作

| 操作 | マウスコントロール |
|--------|--------------|
| **オブジェクトを選択** | オブジェクトを左クリック |
| **複数選択** | Shift + 追加のオブジェクトを左クリック |
| **複数選択** | Ctrl + 追加のオブジェクトを左クリック |
| **すべて選択解除** | 何もない場所を左クリック |
| **ラバーバンド選択** | 何もない場所で左クリック + ドラッグ |
| **オブジェクトを移動** | 選択したオブジェクトを左クリック + ドラッグ |
| **コンテキストメニュー** | オブジェクトを右クリック |

## オブジェクトコントロール

オブジェクトを選択すると、インタラクティブなコントロールが表示されます。

| 操作 | コントロール |
|--------|---------|
| **ベッド上で移動** | オブジェクトをドラッグ |
| **上下に移動** | オブジェクトの上にある垂直の矢印をドラッグ |
| **回転** | 回転コーナーコントロールをクリックしてドラッグ |
| **スケール** | スケールコーナーコントロールをクリックしてドラッグ |

## ヒント

- スクロールホイールによるズームはマウスカーソルの位置を中心に行われます。ズームしたい領域にカーソルを合わせてください
- 代替コントロール（Ctrl + 左クリック）は、中ボタンのないマウスを使用している場合や、右クリックが使いにくい場合に便利です
- コーナーコントロールで回転する際は、角度インジケーターにカーソルを合わせると 45 度刻みでスナップします
