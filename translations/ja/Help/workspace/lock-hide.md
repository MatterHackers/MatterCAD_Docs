# ロックと非表示

ロックと非表示を使うと、デザイン内のどのオブジェクトを選択でき、どのオブジェクトを表示するかを制御できます。これらの機能により、意図しない変更を防ぎ、画面の煩雑さを減らして、複雑なデザインでも効率よく作業できます。

## ロック
![20260318 193003 paste 20260318 193003](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-193003-paste-20260318-193003.jpg)


オブジェクトをロックすると、ビューポート内でそのオブジェクトを選択したり移動したりできなくなります。オブジェクトは表示されたままですが、誤って変更されることはありません。

- デザインツリーでオブジェクトの横にある**ロックアイコン**をクリックすると、ロック状態を切り替えられます
- ロックされたオブジェクトも、ブーリアン演算やその他の計算には引き続き使用されます

## 非表示

![20260318 192834 paste 20260318 192834](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192834-paste-20260318-192834.jpg)

オブジェクトを非表示にすると、デザイン内に残したままビューポートで見えなくなります。オブジェクトは引き続き存在し、各種の操作にも使用されます。

- デザインツリーでオブジェクトの横にある**目のアイコン**をクリックすると、表示/非表示を切り替えられます
- 非表示のオブジェクトも、削除しない限りエクスポートに含まれます

## ヒント

- 細部の作業中は、ベースとなるオブジェクトや参照用のオブジェクトをロックしておくと、誤って動かすのを防げます
- 作業中の領域を隠しているオブジェクトは非表示にしましょう
- ロック状態と非表示状態は、どちらもデザインと一緒に保存されます
- グループやコンポーネントの内部にあるオブジェクトでも、デザインツリーでロックや非表示にできます
