# コンポーネント

コンポーネントは、再利用可能でパラメータ化されたオブジェクトのグループです。コンポーネントを作成すると、それ自体で完結する単位となり、デザイン内に何度でも挿入できます。また、コンポーネントを編集すると、すべてのインスタンスが更新されます。

## 使い方

### コンポーネントの作成

1. 1つ以上のオブジェクトを選択します
2. 右クリックして **コンポーネント化** を選択します（またはメニューから実行します）
3. 選択したオブジェクトがコンポーネントコンテナにまとめられます

### コンポーネントの編集

1. コンポーネントを選択します
2. コンポーネントの公開パラメータが プロパティ パネルに表示されます
3. パラメータを変更してコンポーネントの形状を変えます

## ヒント

- コンポーネントは、複雑なデザインで再利用可能なビルディングブロックを作成するのに便利です
- パラメータの変更は非破壊的で、いつでも調整できます
- コンポーネントは関連するオブジェクトをまとめることで、複雑なデザインの整理に役立ちます
- わずかな違いを付けて何度も配置する必要があるパーツには、コンポーネントを使いましょう
