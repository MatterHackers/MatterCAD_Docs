# キーボードショートカット

MatterCAD で使用できるすべてのキーボードショートカットのクイックリファレンスです。

## 編集

| ショートカット | 操作 |
|----------|--------|
| Ctrl + Z | 元に戻す |
| Ctrl + Y | やり直し |
| Ctrl + Shift + Z | やり直し（代替） |
| Ctrl + A | すべてのオブジェクトを選択 |
| Ctrl + C | 選択したオブジェクトをコピー |
| Ctrl + X | 選択したオブジェクトを切り取り |
| Ctrl + V | オブジェクトを貼り付け |
| Space | 選択をクリア |
| Escape | 現在のドラッグ操作をキャンセル |
| Delete | 選択したオブジェクトを削除 |

## 表示

| ショートカット | 操作 |
|----------|--------|
| W | 表示をリセット（すべてのオブジェクトをビューポートに収める） |
| Z | 選択したオブジェクトにズーム |
| Ctrl + Plus (+) | ズームイン |
| Ctrl + Minus (-) | ズームアウト |
| 矢印キー | 表示を回転 |
| Shift + 矢印キー | 表示をパン |

## マウスコントロール

| 操作 | コントロール |
|--------|---------|
| 表示を回転 | 右クリック + ドラッグ |
| 表示をパン | 中クリック + ドラッグ |
| ズーム | スクロールホイール |
| オブジェクトを選択 | オブジェクトを左クリック |
| 複数選択 | Shift + 左クリック または Ctrl + 左クリック |
| ラバーバンド選択 | 空白部分で左クリック + ドラッグ |
| コンテキストメニュー | オブジェクトを右クリック |

## 代替マウスコントロール

| 操作 | コントロール |
|--------|---------|
| 表示を回転 | Ctrl + 左クリック + ドラッグ |
| 表示をパン | Ctrl + Shift + 左クリック + ドラッグ |
| ズーム | Ctrl + Alt + 左クリック + ドラッグ |

## アプリケーション

| ショートカット | 操作 |
|----------|--------|
| Ctrl + Shift + T | 最後に閉じたデザインを再度開く |
| F1 | ヘルプを開く |
