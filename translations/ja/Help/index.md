# ようこそ

![paste 20260317 175249](https://matterhackers.github.io/MatterCAD_Docs/assets/paste-20260317-175249.jpg)

3Dモデルの作成と編集を支援するプロフェッショナル3D設計ソフトウェア、MatterCADへようこそ。以下のリンクから、各トピックのヘルプをご覧いただけます。

## はじめに

- [はじめに](getting-started/index.md) - MatterCADのワークスペースの基本を学ぶ
- [ビューポートの操作](getting-started/viewport-navigation.md) - 3D表示の回転、パン、ズームの方法
- [新規オブジェクトの作成](getting-started/creating-new-objects.md) - プリミティブを追加して設計を始める
- [既存オブジェクトの追加](getting-started/adding-existing-objects.md) - ファイルやライブラリのコンテンツをインポートする
- [オブジェクトの編集](getting-started/editing-objects.md) - 3D表示でパーツを移動、回転、スケールする
- [保存とエクスポート](getting-started/saving-and-exporting.md) - 作業内容を保存し、さまざまな形式でエクスポートする

## 設計の構成要素

- [プリミティブ](primitives/index.md) - 立方体、円柱、球、テキストなどの3D形状
- [2Dパス](2d-paths/index.md) - 押し出しや回転で3Dオブジェクトにできるフラットな形状
- [メカニカルパーツ](mechanical/index.md) - ギア、ねじ、その他の機械部品

## 操作

- [ブーリアン](operations/boolean/index.md) - オブジェクトの結合、減算、交差
- [変換](operations/transform/index.md) - 移動、回転、スケール、ミラー
- [配置](operations/placement/index.md) - オブジェクトの整列と境界へのフィット
- [形状変更](operations/reshape/index.md) - カーブ、ツイスト、ピンチ、ベベルなど
- [配列](operations/array/index.md) - オブジェクトの直線状・放射状パターンを作成
- [パス](operations/path/index.md) - 2Dパスの押し出し、回転、編集
- [メッシュ](operations/mesh/index.md) - メッシュジオメトリの修復と簡略化
- [画像](operations/image/index.md) - 画像を3Dオブジェクトに変換

## ワークスペースとワークフロー
