# メカニカルパーツ

MatterCAD には、ギアやねじ部品などのメカニカルコンポーネントを作成するための専用ツールが用意されています。

## ツール

|ギア 2D                          .|ギア|ねじ|
| :--- | :--- | :--- |
|<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)|<!-- AUTO_IMAGE: type=from_thumbnail item=gear file=mechanical_gears -->![mechanical_gears](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gears.png)|<!-- AUTO_IMAGE: type=from_thumbnail item=threads file=mechanical_threads -->![mechanical_threads](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_threads.png)|

- [ギア](gears.md) - 歯数、モジュールサイズ、圧力角を設定できる 3D ギアを作成します
- [ギア 2D](gear-2d.md) - 押し出しやその他のパス操作で使用する 2D ギアパスを作成します
- [ねじ](threads.md) - 円柱状のオブジェクトにねじ山を追加します
