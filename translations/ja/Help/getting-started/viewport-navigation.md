# ビューポートナビゲーション

3D ビューポートは、デザインを表示し、操作するための場所です。MatterCAD はトラックボール型のカメラモデルを採用しており、オブジェクトの周囲を自由にオービット、パン、ズームできます。

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## マウスコントロール

### 表示を回転する

- **右クリック + ドラッグ** - デザインの周囲でカメラをオービットします
- **Ctrl + 左クリック + ドラッグ** - 別の回転方法です

### 表示をパンする

- **中クリック + ドラッグ** - 表示を左右または上下にスライドします
- **Ctrl + Shift + 左クリック + ドラッグ** - 別のパン方法です

### ズームインとズームアウト

- **スクロールホイール** - 上にスクロールでズームイン、下にスクロールでズームアウトします
- **Ctrl + Alt + 左クリック + ドラッグ** - 別のズーム方法です

## キーボードコントロール

### 表示のショートカット

- **W** - すべてのオブジェクトがビューポートに収まるように表示をリセットします
- **Z** - 現在選択しているオブジェクトにズームします

### 矢印キーによる操作

- **矢印キー** - 表示を回転します
- **Shift + 矢印キー** - 表示をパンします

### ズームのショートカット

- **Ctrl + プラス (+)** - ズームイン
- **Ctrl + マイナス (-)** - ズームアウト

## ヒント

- モデルを見失った場合は、**W** を押して表示をリセットし、すべてを画面内に戻します
- オブジェクトを選択したあとに **Z** を使うと、すばやくそのオブジェクトに焦点を合わせられます
- スクロールホイールのズームはマウスカーソルの位置を中心に行われるため、ズームしたい領域にカーソルを合わせてください
- 回転とパンを組み合わせることで、デザインをあらゆる角度から確認できます
