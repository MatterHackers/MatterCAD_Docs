# オブジェクトの編集

MatterCAD には、オブジェクトの移動、回転、スケールを行うための直感的なコントロールが 3D ビューに直接組み込まれています。プロパティパネルでオブジェクトのパラメーターを編集することもできます。

## パーツの移動


- **ベッド上でドラッグする** - 任意のオブジェクトをクリックしてドラッグすると、作業領域の面上でスライドさせられます
- **上下に移動する** - 選択したオブジェクトの上部にある垂直方向の矢印コントロールを使って、高さ（Z 位置）を調整します
- 正確に配置するには、[移動](../operations/transform/translate.md) 操作を使うか、プロパティパネルに正確な値を入力します

## パーツの回転

![20260324 080843 paste 20260324 080843](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080843-paste-20260324-080843.jpg)

オブジェクトを選択したときに表示される **回転コーナーコントロール** のいずれかをクリックします。これらを使うと、そのコントロールの平面上でオブジェクトを回転できます。

- 角度インジケーターのいずれかにマウスを合わせると、回転が **45 度刻み** にスナップします
- 正確に回転させるには、[回転](../operations/transform/rotate.md) 操作を使って正確な角度を入力します

## パーツのスケール

![20260324 080819 paste 20260324 080819](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080819-paste-20260324-080819.jpg)


**スケールコーナーコントロール** のいずれかをクリックすると、作業領域上でパーツのサイズを変更できます。

- コーナーをドラッグすると、比率を保ったままスケールされます
- 正確なサイズ指定や不均一なスケールを行うには、[スケール](../operations/transform/scale.md) 操作を使います。正確な寸法を設定したり、各軸を個別にスケールしたりできます

## パラメーターの編集

オブジェクトを選択すると、そのパラメーターが画面右側のプロパティパネルに表示されます。例えば次のとおりです。

- **立方体** では、幅、深さ、高さ、およびオプションの丸めコントロールが表示されます
- **円柱** では、直径、高さ、側面が表示されます
- **テキスト** オブジェクトでは、テキストの内容、フォント、サイズ、高さが表示されます

値を直接入力したり、スライダーを使ったり、パラメトリックな関係を表す [数式](../workspace/expressions.md) を入力したりできます。

## コンテキストメニュー

任意のオブジェクトを右クリックすると、次のような追加オプションにアクセスできます。

- コピー、切り取り、削除
- グループ化 / グループ解除
- 選択したオブジェクトで利用できる操作
- その特定のオブジェクトタイプに関するヘルプ（利用可能な場合）

## ヒント

- **Shift** を押しながらクリックすると複数のオブジェクトを選択でき、まとめて移動したり操作したりできます
- **Ctrl+Z** を押すと、加えた変更を元に戻せます
- [整列](../operations/placement/align.md) を使うと、複数のオブジェクトを互いに正確な位置に配置できます
- **Space** を押すと選択が解除されます
