# 保存とエクスポート

MatterCAD は、デザインの保存とエクスポートにいくつかのファイル形式をサポートしています。どの形式を選ぶかは、そのファイルをどのように使う予定かによって決まります。

## 保存形式

### MCX（ネイティブ形式）

MCX は MatterCAD のネイティブファイル形式で、後から編集を続けたいデザインに最適です。次の情報が保持されます。

- すべてのオブジェクトとその階層を含む完全なデザインツリー
- 各オブジェクトのすべてのパラメータと設定
- ブーリアン演算、配列、その他の操作（編集可能な形式のまま）
- コンポーネントの関係

**MCX を使う場面：** 作業内容を保存して、後から編集を続けたいとき。

### STL

STL は 3D プリントで最も広く使われている形式です。デザイン履歴やパラメータは含まれず、最終的な三角形メッシュのジオメトリのみが含まれます。

**STL を使う場面：** デザインを 3D プリントしたいとき、または MatterCAD を使っていない相手と共有したいとき。

### OBJ

OBJ（Wavefront）は、ほとんどの 3D ソフトウェアでサポートされている一般的な 3D 形式です。STL と同様に、メッシュのジオメトリのみが含まれます。

**OBJ を使う場面：** Blender やゲームエンジンなど、他の 3D ソフトウェアでデザインを開く必要があるとき。

### SVG

SVG エクスポートは、デザインを上面から見た状態から 2D のベクターファイルを作成します。レーザーカットや CNC ルーター加工に便利です。

**SVG を使う場面：** レーザーカットや彫刻のために、デザインの 2D 輪郭が必要なとき。

## 保存の方法

![20260324 080726 paste 20260324 080726](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080726-paste-20260324-080726.jpg)

1. **ブランドメニュー**（左上隅の MatterCAD ロゴ）を開きます
2. **名前を付けて保存** を選択して、保存場所と形式を選びます
3. 形式のドロップダウンからファイル形式を選択します
4. ファイルの保存先を選び、**保存** をクリックします

デザインは作業中にも自動的に保存されるため、アプリケーションを閉じても変更が失われることはありません。

## ヒント

- STL や OBJ にエクスポートする前に、必ずデザインの MCX コピーを保存しておくと、後から変更できます
- STL にエクスポートすると、シーン内のすべてのオブジェクトが 1 つのメッシュに統合されます
- MatterCAD を使っている相手とデザインを共有する場合は、完全な編集可能性を保つために MCX ファイルを送ってください
- デザインを [クラウドライブラリ](../library/cloud-library.md) に保存して、どのコンピュータからでもアクセスすることもできます
