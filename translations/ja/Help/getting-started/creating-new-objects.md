# 新しいオブジェクトの作成

MatterCAD には、3D オブジェクトを作成するための豊富なツールが用意されています。プリミティブシェイプから始めることも、テキストや QRコード などの専用ツールを使うことも、ブーリアン操作や配列で複雑な形状を組み立てることもできます。

![20260324 081122 paste 20260324 081122](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081122-paste-20260324-081122.jpg)

## プリミティブの追加

デザインを始める最も手軽な方法は、プリミティブシェイプを追加することです。ライブラリの プリミティブ パネルを開き、任意のシェイプをクリックするとワークスペースに追加されます。利用できるプリミティブは次のとおりです。

- **基本シェイプ** - 立方体、円柱、球、円錐、トーラス、リング、ピラミッド、ウェッジ、およびそれぞれの半分バリエーション
- **テキストと特殊シェイプ** - テキスト、点字、QRコード、画像オブジェクト、SVGオブジェクト

各プリミティブには、選択後に プロパティ パネルで調整できるパラメーターがあります。たとえば、立方体には 幅、深さ、高さ のコントロールがあります。各シェイプの詳細は [プリミティブ](../primitives/index.md) を参照してください。

## 操作ツールバー

![20260324 081005 paste 20260324 081005](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081005-paste-20260324-081005.jpg)

ビューポート上部のツールバーから、よく使う操作にすばやくアクセスできます。

- **元に戻す / やり直し** - 変更を取り消したり、やり直したりします。**Ctrl+Z** で元に戻し、**Ctrl+Y** でやり直すこともできます
- **グループ化 / グループ解除** - 選択したオブジェクトを 1 つの単位として移動・操作できるグループにまとめたり、グループを分解したりします
- **コピー / 削除** - 選択したオブジェクトを複製または削除します。標準の **Ctrl+C**、**Ctrl+X**、**Ctrl+V** のショートカットも使用できます
- **整列** - 複数のオブジェクトを互いの位置関係に基づいて配置します
- **ブーリアン操作** - [結合](../operations/boolean/combine.md)、[減算](../operations/boolean/subtract.md)、[交差](../operations/boolean/intersect.md)、[減算して置換](../operations/boolean/subtract-and-replace.md)
- **配列** - 複製したオブジェクトの [直線、放射、カーブ、変換のパターン](../operations/array/array.md) を作成します
- **変換** - [回転](../operations/transform/rotate.md)、[スケール](../operations/transform/scale.md)、[ミラー](../operations/transform/mirror.md) などの変更を適用します

## 複雑な形状の作成

MatterCAD のほとんどのデザインは、シンプルなシェイプを組み合わせて作られます。

1. **プリミティブから始める** - 必要な基本シェイプを追加します
2. **配置する** - オブジェクトを移動・回転させ、思いどおりの位置で重なるようにします
3. **ブーリアン操作を適用する** - [結合](../operations/boolean/combine.md) でシェイプ同士をまとめたり、[減算](../operations/boolean/subtract.md) で一方のシェイプを他方から切り取ったりします
4. **仕上げる** - 面取り、カーブ、ツイスト などの [形状変更](../operations/reshape/index.md) 操作でディテールを加えます
