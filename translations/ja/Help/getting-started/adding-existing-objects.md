# 既存オブジェクトの追加

コンピューターからファイルをインポートしたり、内蔵のライブラリからコンテンツを追加したりすることで、既存の3DモデルをMatterCADに取り込めます。

## コンピューターから

![20260324 081143 paste 20260324 081143](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081143-paste-20260324-081143.jpg)

![20260324 081240 paste 20260324 081240](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081240-paste-20260324-081240.jpg)


ツールバーの**開く**ボタンをクリックすると、コンピューター内のファイルを参照して追加できます。MatterCADは次のインポート形式に対応しています。

- **STL** (.stl) - 業界標準の3Dモデル形式。3Dプリントで広く使用されています
- **AMF** (.amf) - 色やマルチマテリアルオブジェクトに対応した高度な形式
- **OBJ** (.obj) - Wavefrontの3Dグラフィックス形式(メッシュ形状のみ)
- **3MF** (.3mf) - 豊富なメタデータに対応した3D Manufacturing Format
- **MCX** (.mcx) - MatterCAD独自の形式。すべての設計データとパラメーターを保持します
- **SVG** (.svg) - Scalable Vector Graphics。2Dパスとしてインポートされます
- **TTF / OTF** (.ttf, .otf) - テキストツールで使用するフォントファイル

## ドラッグ＆ドロップ

デスクトップやファイルエクスプローラーから直接、MatterCADのワークスペースにファイルをドラッグ＆ドロップすることもできます。対応するファイル形式は自動的にインポートされます。

![20260324 081416 paste 20260324 081416](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081416-paste-20260324-081416.jpg)

## ライブラリから

### ライブラリサイドバー

ツールバーの**コンテンツを追加**ボタンをクリックすると、ライブラリブラウザーパネルが開きます。ここでは次のこともできます。

- 保存した設計を参照する
- プリミティブライブラリに移動して内蔵の形状を使用する
- サインインしている場合はクラウドライブラリにアクセスする
- ライブラリ内の任意のアイテムをワークスペースに直接ドラッグ＆ドロップする

![20260324 081446 paste 20260324 081446](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081446-paste-20260324-081446.jpg)

### ライブラリタブ

ライブラリタブを使ってコレクションを参照することもできます。ライブラリ内の任意のオブジェクトを右クリックし、**シーンに追加**を選択すると、現在の設計ワークスペースにインポートされます。

![20260324 081536 paste 20260324 081536](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081536-paste-20260324-081536.jpg)

## ヒント

- MCXはすべてのパラメーターと設計ツリーを保持するため、後から設計を再編集するのに最適な形式です
- STLファイルにはメッシュ形状のみが含まれます。STLをインポートした場合も操作を適用できますが、元のパラメーターを編集することはできません
- 複数のファイルをインポートすると、それぞれがシーン内の個別のオブジェクトになります。[グループ化](../workspace/grouping.md)を使って整理しましょう
