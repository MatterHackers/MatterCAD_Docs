# MatterCAD をはじめる

MatterCAD は、3D モデルの作成と編集を行うためのプロフェッショナル向け 3D デザインアプリケーションです。ゼロから何かを作り上げる場合でも、インポートしたファイルを編集する場合でも、これらのガイドが作業を始める手助けとなります。

![20260324 081704 paste 20260324 081704](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081704-paste-20260324-081704.jpg)

## MatterCAD のワークスペース

MatterCAD を開くと、いくつかの主要な領域が表示されます。

- **3D ビューポート** - 3D モデルを表示し、操作するためのメイン領域です
- **ツールバー** - 上部にあり、元に戻す、やり直し、グループ化、デザインツールなど、よく使う操作のボタンが並んでいます
- **ライブラリパネル** - 左側にあり、プリミティブや保存したデザインを参照できます
- **プロパティパネル** - 右側にあり、選択したオブジェクトのパラメーターを表示します
- **デザインツリー** - シーン内のオブジェクトの階層を表示します

## クイックスタート

1. **形状を追加する** - プリミティブパネルを開き、立方体や円柱などの形状をクリックしてワークスペースに追加します
2. **移動する** - オブジェクトをクリックしてドラッグして位置を変更するか、上下の矢印で高さを調整します
3. **変更する** - オブジェクトを選択し、右側のプロパティパネルでパラメーターを調整します
4. **さらに形状を追加する** - プリミティブを追加し、[ブール演算](../operations/boolean/index.md) を使用して結合または減算します
5. **作業内容を保存する** - ブランドメニューからデザインを MCX 形式で保存するか、3D プリント用に STL へエクスポートします
