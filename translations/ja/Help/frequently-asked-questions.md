# オブジェクトのスケールが正しくないのはなぜですか？
- STL ファイルには単位情報が保存されません。MatterCAD は STL の寸法をミリメートル単位として扱いますが、多くの CAD ソフトウェアはそれぞれのネイティブ単位（通常はインチ）で書き出します。このため、デザインをインポートするときにスケールの不一致が発生します。

- 最善の解決策は、お使いのデザインソフトウェアで STL ファイルをミリメートル単位で書き出すように設定することです。たとえば SolidWorks では、**名前を付けて保存**ダイアログの**オプション**ボタンから STL の書き出しパラメータを設定します。

- あるいは、MatterCAD 内でパーツのスケールを変更することもできます。3D 表示で**編集**モードに入り、右側のツールバーから SCALE を選択します。ドロップダウンメニューから一般的な換算係数を選ぶか、各軸のフィールドに具体的な寸法を入力してください。

# アプリケーションデータを消去するにはどうすればよいですか？

- 再インストールしても問題が解決しない場合は、MatterCAD が保存しているデータを削除する必要があるかもしれません。このデータはアンインストール後も残ります。既定の設定へ完全にリセットするには、アプリケーションフォルダを**削除**してください。次のこともできます。SQLite データベースファイル（MatterCAD.db）の**名前**を一時的に変更し、設定が問題の原因かどうかを確認できます。
