# ライブラリ

ライブラリでは、3D デザインの整理、保存、共有ができます。ローカルファイルの閲覧、クラウドストレージへのアクセス、他のユーザーとのデザイン共有が可能です。

## トピック

- [ローカルライブラリ](local-library.md) - コンピューターに保存されているデザインを管理します
- [クラウドライブラリ](cloud-library.md) - MatterHackers クラウドアカウントにデザインを保存し、アクセスします
- [共有](sharing.md) - 他の MatterCAD ユーザーとデザインを共有します
