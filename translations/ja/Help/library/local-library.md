# ローカルライブラリ

ローカルライブラリは、3Dデザインをお使いのコンピューターに保存します。デザインをフォルダーで整理したり、ファイルを検索したり、素早くワークスペースに追加したりできます。

![20260323 210208 paste 20260323 210208](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210208-paste-20260323-210208.jpg)


## ライブラリを閲覧する

1. サイドバーまたはライブラリタブから **ライブラリ** パネルを開きます
2. フォルダーをたどってデザインを探します
3. デザインをダブルクリックして開くか、ワークスペースにドラッグして現在のシーンに追加します

## ファイルを整理する

- **フォルダーを作成する** - ライブラリ内で右クリックし、フォルダーを作成を選択してデザインを整理します
- **項目の名前を変更する** - 任意の項目を右クリックし、名前の変更を選択します
- **項目を削除する** - 右クリックして削除を選択し、項目を削除します
- **項目を移動する** - 項目をフォルダー間でドラッグして整理し直します

## 表示オプション

ライブラリパネルは複数の表示モードに対応しています:

- **リスト表示** - ファイル名を表示するコンパクトなリスト
- **アイコン表示** - デザインのサムネイルプレビュー
- **大アイコン表示** - 閲覧しやすい大きなサムネイル

次の項目で並べ替えできます:

- **名前** - アルファベット順
- **作成日** - 新しい順または古い順
- **更新日** - 最近変更したものが先頭

## ヒント

- ライブラリ上部の検索バーを使うと、名前でデザインを素早く見つけられます
- ライブラリブラウザーは、ほとんどのファイル形式でプレビューサムネイルを表示します
- MCX形式で保存したデザインは、すべてのパラメーターとデザインツリーが保持され、完全に再編集できます
