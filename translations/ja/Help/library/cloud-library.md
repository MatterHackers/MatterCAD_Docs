# クラウドライブラリ

クラウドライブラリは、デザインを MatterHackers アカウント内のオンライン上に保存します。これにより、どのコンピューターからでもデザインにアクセスでき、クラウドにバックアップを保持できます。

![20260323 210141 paste 20260323 210141](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210141-paste-20260323-210141.jpg)

## はじめに

1. アプリケーションメニューから MatterHackers アカウントにサインインします
2. ライブラリブラウザーにクラウドライブラリが表示されます
3. デザインをクラウドフォルダーにドラッグしてアップロードするか、直接クラウドに保存します

## フィーチャー

- **どこからでもアクセス** - サインインしたどのコンピューターからでもデザインを利用できます
- **クラウドバックアップ** - 作業内容がオンラインに安全に保存されます
- **フォルダーでの整理** - ローカルライブラリと同じように、フォルダーを作成してクラウド上のデザインを整理できます
- **共有** - 他の MatterCAD ユーザーとデザインを共有できます。[共有](sharing.md) を参照してください

## ヒント

- クラウドライブラリに保存すると、デザインは自動的に同期されます
- クラウドライブラリの内容にアクセスするにはインターネット接続が必要です
- 大きなファイルはアップロードやダウンロードに時間がかかる場合があります
- 重要なデザインは冗長性のためにローカルライブラリとクラウドライブラリの両方に保管してください
