# 共有

MatterCAD では、共有コードを使って他のユーザーとデザインを共有できます。これにより、デザインでの共同作業や作品の配布が簡単になります。

![20260323 210309 paste 20260323 210309](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210309-paste-20260323-210309.jpg)


## デザインを共有する

1. [クラウドライブラリ](cloud-library.md) 内のデザインを右クリックします
2. **共有** を選択します
3. 共有コードが生成されるので、他の人に送信できます

## 共有されたデザインを受け取る

1. 誰かから共有コードを受け取ります
2. ライブラリの **共有コードを利用する** オプションを使用します
3. 共有されたデザインがライブラリに追加されます

## ヒント

- 共有コードは、クラウドライブラリに保存されているデザインで使用できます
- 受け取った人にはデザインのコピーが渡ります。相手が加えた変更は、あなたの元のデザインには影響しません
- 共有コードは、メール、チャット、ソーシャルメディアなど、どのような手段でも配布できます
