# Отверстие

Объект в форме куба, заранее настроенный как инструмент булева вычитания. При использовании операции [Объединить](../operations/boolean/combine.md) объекты Отверстие автоматически вычитаются из других фигур, а не добавляются к ним.

## Как это работает

Примитив Отверстие работает так же, как [Куб](cube.md), но его тип вывода задан как «Отверстие». При объединении объектов, среди которых есть Отверстие, объём Отверстия удаляется из результата.

## Параметры

Те же, что и у [Куба](cube.md):

- **Ширина** — размер вдоль оси X
- **Глубина** — размер вдоль оси Y
- **Высота** — размер вдоль оси Z

## Советы

- Расположите Отверстие так, чтобы оно пересекалось с объектом, который нужно вырезать
- Сделайте так, чтобы Отверстие проходило сквозь целевой объект насквозь, если вам нужно сквозное отверстие
- Для того же эффекта можно использовать обычные фигуры с операцией [Вычитание](../operations/boolean/subtract.md), но Отверстия удобны тем, что работают автоматически с операцией [Объединить](../operations/boolean/combine.md)
- Для круглых отверстий используйте [Цилиндр](cylinder.md) с операцией Вычитание

## Связанные темы

- [Куб](cube.md) — та же фигура без поведения отверстия
- [Объединить](../operations/boolean/combine.md) — объединяет фигуры и автоматически вычитает Отверстия
- [Вычитание](../operations/boolean/subtract.md) — вручную вычесть любую фигуру из другой
