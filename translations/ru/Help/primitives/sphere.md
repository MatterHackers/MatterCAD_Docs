# Сфера

Круглая шарообразная форма с настраиваемым диаметром и уровнем детализации.

## Параметры

- **Диаметр** - Ширина сферы (по умолчанию: 20mm)
- **Стороны** - Число сегментов по периметру (по умолчанию: 40). Больше сторон = более гладкая поверхность

### Дополнительные параметры

Включите режим **Дополнительно** для доступа к дополнительным настройкам:

- **Начальный угол** - Угол, с которого начинается поверхность сферы (по умолчанию: 0)
- **Конечный угол** - Угол, на котором заканчивается поверхность сферы (по умолчанию: 360). Задайте значение меньше 360, чтобы получить неполную сферу
- **Сегменты по широте** - Число сегментов от верха до низа (по умолчанию: 30). Больше = более гладкие полюса

## Советы

- Для 3D-печати обычно достаточно 40 сторон. Более высокие значения дают более гладкие поверхности, но увеличивают размер файлов
- Используйте Начальный угол и Конечный угол, чтобы создавать неполные сферы, например чаши или купола
- Сочетайте с операцией [Вычитание](../operations/boolean/subtract.md) для создания сферических полостей
