# Текст

Создавайте объёмный выдавленный текст с настраиваемым содержимым, шрифтом, размером и высотой. Текстовые объекты отлично подходят для надписей, табличек, шильдиков и декоративных букв.

## Как использовать

1. Добавьте примитив **Текст** из панели Примитивы
2. Введите свой текст в поле **Имя** на панели Свойства
3. При необходимости настройте шрифт, размер и высоту выдавливания

## Параметры

- **Имя** — отображаемое текстовое содержимое
- **Размер точки** — размер шрифта. Он точно соответствует стандартной типографской системе: размер 12 пунктов в MatterCAD совпадает с 12-пунктовым шрифтом на 2D-принтере
- **Высота** — высота выдавливания (насколько текст выступает над поверхностью)
- **Шрифт** — выбор из доступных системных шрифтов

## Советы

- Используйте [Вычитание](../operations/boolean/subtract.md), чтобы выгравировать текст в поверхности, а не поднимать его над ней
- Для очень мелкого текста увеличьте Размер точки, а затем уменьшите весь объект с помощью [Масштаб](../operations/transform/scale.md) — так детализация будет лучше
- Каждая буква текста представляет собой отдельный контур, который выдавливается вместе с остальными
