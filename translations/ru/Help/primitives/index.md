# Примитивы

MatterCAD включает библиотеку трёхмерных примитивов, которые служат строительными блоками для ваших моделей. Любой примитив можно добавить в рабочую область из панели «Примитивы», а затем изменить его параметры, чтобы получить нужную форму.

## Базовые формы

- [Куб](cube.md) — параллелепипед с настраиваемыми шириной, глубиной, высотой и необязательным скруглением
- [Цилиндр](cylinder.md) — круглая колонна с настраиваемыми диаметром, высотой и числом граней
- [Сфера](sphere.md) — шар с настраиваемыми диаметром и уровнем детализации
- [Конус](cone.md) — сужающийся цилиндр, сходящийся в точку
- [Тор](torus.md) — форма бублика с управлением внутренним и внешним диаметром
- [Кольцо](ring.md) — трубчатая форма (полый цилиндр) с внутренним и внешним диаметрами
- [Пирамида](pyramid.md) — четырёхгранная пирамида с настраиваемыми основанием и высотой
- [Клин](wedge.md) — треугольная призма
- [Полусфера](half-sphere.md) — верхняя половина сферы
- [Полуцилиндр](half-cylinder.md) — цилиндр, разрезанный вдоль пополам
- [Половина клина](half-wedge.md) — клин, разрезанный пополам
- [Отверстие](hole.md) — отверстие в форме куба, используемое в булевых операциях вычитания
