# SVG Объект

Импортируйте файлы SVG (Scalable Vector Graphics) и используйте их как 2D-пути в своём проекте. Затем SVG можно преобразовать в 3D-формы с помощью операций [Линейное выдавливание](../operations/path/linear-extrude.md) или [Вращение](../operations/path/revolve.md).

## Как использовать

1. Импортируйте файл SVG, перетащив его в рабочую область или воспользовавшись кнопкой Открыть
2. SVG импортируется как 2D-путь
3. Примените [Линейное выдавливание](../operations/path/linear-extrude.md), чтобы задать высоту, или используйте другие [Операции с путями](../operations/path/index.md)

## Советы

- Для наилучшего результата файлы SVG должны содержать залитые фигуры или замкнутые контуры
- Обработка сложных SVG с большим количеством контуров может занять больше времени
- Используйте [Выбрать пути](../operations/path/select-paths.md) для работы с отдельными частями SVG, состоящего из нескольких контуров
- В интернете доступно множество бесплатных файлов SVG с логотипами, значками и декоративными узорами
