# Объект Изображение

Импортируйте изображение и преобразуйте его в трёхмерный рельефный объект, в котором значения яркости определяют высоту каждого пикселя. Это позволяет превращать фотографии, логотипы и рисунки в объекты, пригодные для 3D-печати.

## Как использовать

1. Добавьте **Конвертер изображений** из панели Примитивы или перетащите файл изображения прямо в рабочую область
2. Выберите или замените изображение с помощью свойств
3. Отрегулируйте высоту, чтобы задать, насколько сильно приподняты светлые области

## Параметры

- **Высота** — насколько высокими будут выступающие части изображения
- Предварительный просмотр изображения отображается в панели Свойства

## Советы

- Лучше всего подходят контрастные изображения с чёткими формами
- Изображения можно перетаскивать прямо с рабочего стола в рабочую область MatterCAD
- Используйте инструменты дополнительного меню импортированного изображения, чтобы получить больше вариантов преобразования
- Для получения контуров на основе путей из изображений см. [Изображение в контур](../operations/image/image-to-path.md)
- Для изображений с подсветкой см. [Литофания](../operations/image/lithophane.md)
- Добавьте основание, объединив объект изображения с объектом [Куб](cube.md)
