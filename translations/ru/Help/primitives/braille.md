# Шрифт Брайля

Создайте пригодный для 3D-печати текст шрифтом Брайля из обычного английского текста. Инструмент Шрифт Брайля поддерживает кодирование как первой ступени (побуквенное), так и второй ступени (сокращённое).

## Как использовать

1. Добавьте примитив **Шрифт Брайля** из панели Примитивы
2. Введите текст в поле **Текст для кодирования**
3. Инструмент автоматически преобразует его в правильный точечный узор Брайля

## Параметры

- **Текст для кодирования** — английский текст для преобразования в шрифт Брайля
- **Масштаб** — регулирует общий размер результата в шрифте Брайля
- **Высота** — высота выступающих точек Брайля

## Советы

- Шрифт Брайля второй ступени использует сокращения и аббревиатуры для распространённых слов и буквосочетаний, что делает запись более компактной
- Используются стандартные размеры ячейки Брайля, чтобы результат был читаемым
- Объедините с плоским основанием [Куб](cube.md), чтобы создать полноценную табличку или указатель со шрифтом Брайля
- Для карточек со шрифтом Брайля со встроенным основанием см. [Карточка со шрифтом Брайля](braille-card.md)
