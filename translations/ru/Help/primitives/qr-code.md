# QR-код

Создавайте QR-коды в виде 3D-объектов. Вы можете закодировать текст, URL-адрес или данные для подключения к WiFi в сканируемый трёхмерный QR-код.

## Как использовать

1. **Добавить** **QR-код** из панели **Примитивы**
2. Выберите тип содержимого (**Текст** или WiFi)
3. Введите своё содержимое
4. QR-код создаётся как 3D-объект, который можно разместить в вашей модели

## Параметры

### Режим Текст

- **Текст** — текст или URL-адрес для кодирования (по умолчанию: «https://matterhackers.com»)

### Режим WiFi

- **SSID** — имя сети WiFi
- **Пароль** — пароль сети WiFi
- **Безопасность** — тип защиты (WEP, WPA или Нет)

## Советы

- Используйте [Вычитание](../operations/boolean/subtract.md), чтобы выгравировать QR-код на поверхности, или разместите его поверх основания [Куб](cube.md)
- Перед печатью проверьте телефоном, что ваш QR-код корректно сканируется
- QR-коды WiFi позволяют людям подключаться к вашей сети простым сканированием кода
- Убедитесь, что QR-код достаточно велик, чтобы его можно было отсканировать после печати, — не менее 20–25 мм в поперечнике
