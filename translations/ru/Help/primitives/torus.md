# Тор

Кольцо в форме бублика с независимым управлением общим размером и толщиной сечения кольца.

## Параметры

- **Внешний диаметр** - Общая ширина тора (по умолчанию: 20mm)
- **Внутренний диаметр** - Диаметр отверстия в центре (по умолчанию: 10mm)
- **Стороны** - Число сегментов по основному кольцу (по умолчанию: 40)

### Дополнительные параметры

Включите режим **Дополнительно** для доступа к дополнительным элементам управления:

- **Начальный угол** - Угол, с которого начинается тор (по умолчанию: 0)
- **Конечный угол** - Угол, на котором тор заканчивается (по умолчанию: 360). Задайте значение меньше 360, чтобы получить незамкнутое кольцо или дугу
- **Стороны кольца** - Число сегментов по сечению кольца (по умолчанию: 15). Больше = более гладкий профиль трубки
- **Фазовый угол кольца** - Поворачивает профиль сечения (по умолчанию: 0)

## Советы

- Толщина трубки кольца определяется разностью между Внешним диаметром и Внутренним диаметром
- Используйте Начальный угол и Конечный угол для создания незамкнутых сегментов кольца, дуг или C-образных форм
- Полезно для создания уплотнительных колец, ручек, декоративных колец и изгибов труб
