# Куб

Прямоугольная коробчатая форма с настраиваемыми шириной, глубиной, высотой и необязательными скруглёнными рёбрами. Куб — один из самых часто используемых примитивов при построении моделей.

## Параметры

- **Ширина** — размер вдоль оси X (по умолчанию: 20mm)
- **Глубина** — размер вдоль оси Y (по умолчанию: 20mm)
- **Высота** — размер вдоль оси Z (по умолчанию: 20mm)
- **Скругление** — включает скругление рёбер
- **Радиус** — величина скругления (отображается при включённом параметре Скругление)
- **Сегменты скругления** — гладкость скругления, больше сегментов = более плавные кривые (отображается при включённом параметре Скругление)

## Советы

- Используйте Куб как отправную точку для коробок, пластин, кронштейнов и корпусов
- Включите Скругление, чтобы получить гладкие, профессионально выглядящие рёбра
- Радиус не может превышать половину наименьшего размера
- Сочетайте Куб с операцией [Вычитание](../operations/boolean/subtract.md) для создания прямоугольных вырезов и пазов
