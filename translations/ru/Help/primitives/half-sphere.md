# Полусфера

Верхняя половина сферы — форма купола. Полезна для создания куполообразных вершин, форм линз и скруглённых крышек.

## Параметры

- **Диаметр** — ширина основания купола (по умолчанию: 20 мм)
- **Сегменты по долготе** — число сегментов по периметру (по умолчанию: 40)
- **Сегменты по широте** — число сегментов от основания к вершине (по умолчанию: 10). Больше — глаже купол

## Советы

- Объедините две полусферы с цилиндром, чтобы получить форму капсулы
- Разместите полусферу поверх цилиндра, чтобы создать куполообразную крышку или кнопку
- Используйте вместе с операцией [Вычитание](../operations/boolean/subtract.md) для создания куполообразных полостей
