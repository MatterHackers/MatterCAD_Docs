# Цилиндр

Круглая колонна с настраиваемым диаметром, высотой и числом сторон. **Цилиндр** незаменим при создании штифтов, стержней, отверстий и круглых элементов.

## Параметры

- **Диаметр** — ширина цилиндра (по умолчанию: 20 мм)
- **Высота** — высота цилиндра (по умолчанию: 20 мм)
- **Стороны** — число сегментов по периметру (по умолчанию: 40). Меньшие значения дают многоугольные формы (например, 6 — шестиугольник)

### Дополнительные параметры

Включите режим **Дополнительно**, чтобы получить доступ к дополнительным элементам управления:

- **Верхний диаметр** — задайте другой диаметр для верха цилиндра, чтобы получить конусообразные или усечённые формы (по умолчанию: совпадает с параметром **Диаметр**)
- **Начальный угол** — угол, с которого начинается цилиндр (по умолчанию: 0). Используйте вместе с параметром **Конечный угол** для создания частичных цилиндров
- **Конечный угол** — угол, на котором цилиндр заканчивается (по умолчанию: 360). Задайте значение меньше 360 для форм в виде сектора

## Советы

- Задайте малое значение параметра **Стороны**, чтобы получить правильные многоугольники: 6 — шестиугольник, 8 — восьмиугольник и т. д.
- Используйте разные значения параметров **Диаметр** и **Верхний диаметр**, чтобы создавать усечённые конусы и конусообразные формы
- Задайте **Начальный угол** и **Конечный угол**, чтобы получить форму сектора или дуги
- Цилиндры отлично подходят в качестве режущих инструментов для создания круглых отверстий с помощью операции [Вычитание](../operations/boolean/subtract.md)
