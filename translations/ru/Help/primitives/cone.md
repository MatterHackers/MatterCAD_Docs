# Конус

Сужающийся цилиндр, сходящийся в точку сверху. Удобен для создания заострённых элементов, воронок и фасок.

<!--  Screenshot of a Cone primitive on the workspace -->
![20260318 183159 paste 20260318 183159](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183159-paste-20260318-183159.jpg)


## Параметры

- **Диаметр** - Ширина основания (по умолчанию: 20mm)
- **Высота** - Высота конуса (по умолчанию: 20mm)
- **Стороны** - Число сегментов по периметру (по умолчанию: 40)

## Советы

- Для усечённого конуса (с плоским верхом вместо точки) используйте [Цилиндр](cylinder.md) в режиме Дополнительно и задайте разные значения Диаметр и Верхний диаметр
- Конусы удобны для создания фасок на рёбрах в сочетании с [Вычитание](../operations/boolean/subtract.md)
