# Навигация в области просмотра

3D-область просмотра — это место, где вы просматриваете свои модели и работаете с ними. MatterCAD использует камеру типа «трекбол», которая позволяет свободно вращать, панорамировать и масштабировать вид вокруг ваших объектов.

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## Управление мышью

### Повернуть вид

- **Правая кнопка мыши + перетаскивание** — вращение камеры вокруг модели
- **Ctrl + левая кнопка мыши + перетаскивание** — альтернативный способ вращения

### Панорама вида

- **Средняя кнопка мыши + перетаскивание** — сдвиг вида влево, вправо, вверх или вниз
- **Ctrl + Shift + левая кнопка мыши + перетаскивание** — альтернативный способ панорамы

### Приблизить и отдалить

- **Колесо прокрутки** — прокрутка вверх приближает, прокрутка вниз отдаляет
- **Ctrl + Alt + левая кнопка мыши + перетаскивание** — альтернативный способ масштабирования

## Управление с клавиатуры

### Горячие клавиши вида

- **W** — сброс вида так, чтобы все объекты поместились в области просмотра
- **Z** — масштабирование по текущему выбранному объекту

### Навигация клавишами со стрелками

- **Клавиши со стрелками** — поворот вида
- **Shift + клавиши со стрелками** — панорама вида

### Горячие клавиши масштабирования

- **Ctrl + плюс (+)** — приблизить
- **Ctrl + минус (-)** — отдалить

## Советы

- Если вы потеряли модель из виду, нажмите **W**, чтобы сбросить вид и вернуть всё в кадр
- Нажмите **Z** после выбора объекта, чтобы быстро сфокусироваться на нём
- Масштабирование колесом прокрутки центрируется по положению курсора мыши, поэтому наводите его на ту область, которую хотите приблизить
- Вы можете сочетать вращение и панораму, чтобы осмотреть модель под любым углом
