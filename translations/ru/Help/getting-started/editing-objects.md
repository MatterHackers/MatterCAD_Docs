# Изменение объектов

MatterCAD предоставляет интуитивно понятные элементы управления, встроенные прямо в 3D-вид, для перемещения, поворота и масштабирования объектов. Вы также можете изменять параметры объекта на панели **Свойства**.

## Перемещение деталей


- **Перетаскивание по столу** — нажмите и перетащите любой объект, чтобы переместить его по поверхности рабочей области
- **Перемещение вверх и вниз** — используйте вертикальный элемент управления со стрелкой в верхней части выделенного объекта, чтобы изменить его высоту (положение по Z)
- Для точного позиционирования используйте операцию [Переместить](../operations/transform/translate.md) или введите точные значения на панели **Свойства**

## Поворот деталей

![20260324 080843 paste 20260324 080843](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080843-paste-20260324-080843.jpg)

Нажмите на любой из **угловых элементов управления поворотом**, которые появляются при выделении объекта. Они позволяют поворачивать объект в плоскости соответствующего элемента управления.

- Наведите указатель мыши на один из индикаторов угла, чтобы привязать поворот к шагу в **45 градусов**
- Для точного поворота используйте операцию [Повернуть](../operations/transform/rotate.md) и введите точный угол

## Масштабирование деталей

![20260324 080819 paste 20260324 080819](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080819-paste-20260324-080819.jpg)


Нажмите на любой из **угловых элементов управления масштабом**, чтобы изменить размер детали в рабочей области.

- Перетащите угол, чтобы масштабировать пропорционально
- Для точного задания размеров или неравномерного масштабирования используйте операцию [Масштаб](../operations/transform/scale.md), где можно задать точные размеры или масштабировать каждую ось независимо

## Изменение параметров

При выделении объекта его параметры отображаются на панели **Свойства** в правой части экрана. Например:

- Для **Куба** отображаются **Ширина**, **Глубина**, **Высота** и дополнительные элементы управления скруглением
- Для **Цилиндра** отображаются **Диаметр**, **Высота** и **Стороны**
- Для объекта **Текст** отображаются содержимое текста, шрифт, размер и высота

Вы можете вводить значения напрямую, использовать ползунки или задавать [выражения](../workspace/expressions.md) для параметрических зависимостей.

## Контекстное меню

Нажмите правой кнопкой мыши на любом объекте, чтобы получить доступ к дополнительным возможностям, включая:

- **Копировать**, **Вырезать**, **Удалить**
- **Группировать** / **Разгруппировать**
- Доступные операции для выделенного объекта
- **Справка** по конкретному типу объекта (если доступна)

## Советы

- Удерживайте **Shift** при нажатии, чтобы выделить несколько объектов, а затем перемещать их или выполнять над ними операции вместе
- Нажмите **Ctrl+Z**, чтобы отменить любое сделанное изменение
- Используйте [Выровнять](../operations/placement/align.md) для точного позиционирования нескольких объектов относительно друг друга
- Нажмите **Space**, чтобы снять выделение
