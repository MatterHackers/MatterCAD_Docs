# Добавление существующих объектов

Вы можете загрузить существующие 3D-модели в MatterCAD, импортировав файлы с компьютера или добавив содержимое из встроенной библиотеки.

## С вашего компьютера

![20260324 081143 paste 20260324 081143](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081143-paste-20260324-081143.jpg)

![20260324 081240 paste 20260324 081240](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081240-paste-20260324-081240.jpg)


Нажмите кнопку **Открыть** на панели инструментов, чтобы выбрать и добавить файлы с вашего компьютера. MatterCAD поддерживает следующие форматы импорта:

- **STL** (.stl) — отраслевой стандарт формата 3D-моделей, широко используемый для 3D-печати
- **AMF** (.amf) — расширенный формат с поддержкой цветов и многоматериальных объектов
- **OBJ** (.obj) — формат 3D-графики Wavefront (только геометрия сетки)
- **3MF** (.3mf) — 3D Manufacturing Format с широкой поддержкой метаданных
- **MCX** (.mcx) — собственный формат MatterCAD, сохраняющий все данные и параметры проекта
- **SVG** (.svg) — Scalable Vector Graphics, импортируется как 2D-контуры
- **TTF / OTF** (.ttf, .otf) — файлы шрифтов для использования с инструментом **Текст**

## Перетаскивание

Вы также можете перетаскивать файлы напрямую с рабочего стола или из проводника в рабочую область MatterCAD. Поддерживаемые типы файлов будут импортированы автоматически.

## Из Библиотеки

### Боковая панель Библиотеки

Нажмите кнопку **Добавить контент** на панели инструментов, чтобы открыть панель обзора библиотеки. Отсюда вы можете:

- Просматривать сохранённые проекты
- Переходить в библиотеку Примитивы для встроенных фигур
- Обращаться к Облачной библиотеке, если вы вошли в учётную запись
- Перетаскивать любой элемент из библиотеки прямо в рабочую область

![20260324 081446 paste 20260324 081446](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081446-paste-20260324-081446.jpg)

### Вкладка Библиотека

Вы также можете использовать вкладку Библиотека для просмотра ваших коллекций. Щёлкните правой кнопкой мыши по любому объекту в библиотеке и выберите **Добавить на сцену**, чтобы импортировать его в текущую рабочую область проекта.

![20260324 081536 paste 20260324 081536](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081536-paste-20260324-081536.jpg)

## Советы

- MCX — лучший формат для последующего редактирования проектов, поскольку он сохраняет все параметры и дерево построения
- Файлы STL содержат только геометрию сетки. Если вы импортируете STL, вы всё равно можете применять к нему операции, но не сможете изменить исходные параметры
- При импорте нескольких файлов каждый из них становится отдельным объектом в сцене. Используйте [Группировать](../workspace/grouping.md), чтобы упорядочить их
