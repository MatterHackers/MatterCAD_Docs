# Уменьшить (децимация)

Операция **Уменьшить** снижает количество полигонов сетки, сохраняя общую форму. Это полезно для упрощения моделей с высокой детализацией, уменьшения размера файла и ускорения операций над сложной геометрией.

![20260324 080430 paste 20260324 080430](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080430-paste-20260324-080430.jpg)


## Как использовать

1. Выберите объект
2. Примените операцию **Уменьшить** из меню Сетка
3. Задайте цель (количество или проценты) и отрегулируйте её

## Параметры

- **Режим** - выберите способ задания цели:
  - **Процент** - сохранить процент от исходных полигонов (по умолчанию: 50%)
  - **Количество** - задать конкретное количество полигонов
- **Число полигонов источника** - исходное количество полигонов (только для чтения)
- **Целевой процент** - процент сохраняемых полигонов (отображается в режиме Процент)
- **Целевое количество** - точное количество сохраняемых полигонов (отображается в режиме Количество)
- **Количество после процентного уменьшения** - итоговое количество полигонов после уменьшения в процентах (только для чтения)
- **Сохранять поверхность** - проецирует вершины обратно на исходную поверхность для большей точности (работает медленнее, но точнее передаёт исходную форму)

## Советы

- Уменьшение на 50% обычно хорошо сохраняет визуальное качество
- Включайте **Сохранять поверхность**, когда точность важнее скорости
- Уменьшение количества полигонов ускоряет булевы операции над сложными импортированными моделями
- При очень малом количестве полигонов форма заметно ухудшается -- проверяйте результат перед применением
