# Операции с сеткой
<!-- AUTO_IMAGE: type=toolbar_icons group=Mesh -->
![Mesh toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Mesh.png)

Операции с сеткой помогают очистить и оптимизировать геометрию треугольной сетки ваших моделей.

## Операции

- [Восстановить](repair.md) — исправление проблем геометрии сетки, таких как отверстия, неманифольдные рёбра и вывернутые грани
- [Уменьшить](decimate.md) — уменьшение количества полигонов сетки для её упрощения с сохранением формы
