# Операции с изображениями
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

Операции с изображениями преобразуют 2D-изображения в 3D-объекты или пути, позволяя включать фотографии, логотипы и графику в ваши модели.

## Операции

- [Конвертер изображений](image-converter.md) — преобразование изображения в 3D-рельеф на основе яркости или цвета
- [Изображение в контур](image-to-path.md) — трассировка изображения для создания 2D-контура пути
- [Литофания](lithophane.md) — создание литофании, которая проявляет изображение при подсветке сзади
