# Конвертер изображений

Конвертер изображений преобразует растровое изображение в трёхмерный рельеф, где высота определяется яркостью пикселей. Светлые области становятся выпуклыми, а тёмные — низкими (или наоборот).

![20260323 210414 paste 20260323 210414](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210414-paste-20260323-210414.jpg)


## Как использовать

1. Добавьте Конвертер изображений из панели Примитивы или перетащите файл изображения в рабочую область
2. Изображение преобразуется в трёхмерную карту высот
3. Настройте высоту и другие параметры

## Советы

- Лучший результат дают контрастные изображения с чёткими формами
- Чтобы обвести контуры изображения плоскими путями вместо карты высот, используйте [Изображение в контур](image-to-path.md)
- Для создания изображений с подсветкой используйте [Литофания](lithophane.md)
- Изображения можно перетаскивать в рабочую область прямо с рабочего стола
- Добавьте основание, объединив рельеф изображения с объектом [Куб](../../primitives/cube.md)
