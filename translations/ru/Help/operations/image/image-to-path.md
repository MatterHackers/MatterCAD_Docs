# Изображение в контур

Операция «Изображение в контур» трассирует очертания изображения и создаёт 2D-контуры. Полученные контуры можно выдавить, повернуть или использовать с любой другой операцией над путями. Это идеальный способ преобразовать логотипы, силуэты и простую графику в 3D-объекты.

![20260324 075521 paste 20260324 075521](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-075521-paste-20260324-075521.jpg)


## Как использовать

1. Выберите объект-изображение в рабочей области
2. Примените **Изображение в контур** из меню операций с изображением
3. Выберите тип анализа и настройте диапазон выбора

## Параметры

- **Тип анализа** - способ анализа изображения при трассировке:
  - **Прозрачность** - трассировка по прозрачным и непрозрачным областям (лучше всего для PNG с прозрачным фоном)
  - **Цвета** - трассировка по цветовым областям
  - **Интенсивность** - трассировка по уровням яркости (лучше всего для большинства изображений)
- **Выбрать диапазон** - элемент управления в виде гистограммы для выбора значений яркости/цвета, включаемых в трассировку
- **Мин. площадь поверхности** - минимальная площадь замкнутого контура для его включения. Увеличьте значение, чтобы отфильтровать мелкие шумовые артефакты

## Советы

- Лучше всего подходят чистые контрастные изображения с простыми формами
- Используйте режим **Прозрачность** для PNG-изображений с прозрачным фоном
- Используйте режим **Интенсивность** для фотографий и изображений без прозрачности
- После трассировки примените [Линейное выдавливание](../path/linear-extrude.md), чтобы придать контуру высоту
- Увеличьте значение **Мин. площадь поверхности**, чтобы удалить мелкие нежелательные детали из результата трассировки
