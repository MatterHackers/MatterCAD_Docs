# Булевы операции
<!-- AUTO_IMAGE: type=toolbar_icons group=Merge -->
![Merge toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Merge.png)

Булевы операции позволяют создавать сложные формы, комбинируя более простые. Выберите два или более объекта и примените булеву операцию, чтобы объединить их, вырезать одну форму из другой или найти область их перекрытия.

Все четыре операции выполняются одним булевым объектом. Кнопки на панели инструментов, приведённые ниже, лишь заранее задают, с какой операции он начинается, и вы можете изменить её позже в ряду значков **Операция** в верхней части панели Свойства.

## Операции

- [Объединить](combine.md) - Слияние нескольких объектов в одну сплошную форму
- [Вычитание](subtract.md) - Вырезание одной формы из другой
- [Пересечение](intersect.md) - Сохранение только того объёма, где объекты перекрываются
- [Вычесть и заменить](subtract-and-replace.md) - Вычитание одной формы из другой с заменой вырезанной области
