# Вычесть и заменить

Операция «Вычесть и заменить» вычитает выбранные вами детали из тех, которые вы не выбрали, но при этом отсечённая часть не удаляется, а сохраняется как отдельная деталь. С помощью параметра **Деталь(и) для вычитания** укажите режущие形 формы; всё остальное считается основой, которая будет разрезана.

[Объединить](combine.md), [Вычитание](subtract.md), [Пересечение](intersect.md) и «Вычесть и заменить» выполняются одним и тем же булевым объектом: кнопка на панели инструментов создаёт его с уже выбранной операцией **Вычесть и заменить**, и вы в любой момент можете переключиться на любую из трёх других в строке значков **Операция** в верхней части панели «Свойства».

Операция «Вычесть и заменить» недоступна для 2D-контуров: у области нет удаляемого объёма, который можно было бы вернуть.

## Как использовать

1. Выберите два или более объектов
2. Нажмите **Вычесть и заменить** на панели инструментов
3. С помощью параметра **Деталь(и) для вычитания** укажите, какие дочерние объекты являются режущими формами
4. В любой момент передумайте и нажмите другой значок в строке **Операция** в верхней части панели «Свойства» — форма перестроится с новой операцией

## Параметры

- **Операция** — какую булеву операцию выполнять. Отображается в виде строки значков в верхней части панели
- **Деталь(и) для вычитания** — какие дочерние объекты являются режущими формами
- **Сохранять вывернутую геометрию** — считать вывернутую наизнанку оболочку сплошным материалом, а не позволять ей взаимно уничтожать окружающий объём. Включите этот параметр, если модель, которая должна быть сплошной, получается с отсутствующими частями. Он принудительно использует более медленный точный булев движок
- **Исправить порядок обхода** — перестроить вывернутые оболочки каждой детали до выполнения булевой операции. Это исправляет геометрию один раз, вместо того чтобы менять представление о сплошном теле для всех последующих операций, и обычно является лучшим из двух решений для вывернутой модели

## Советы

- Две детали точно подходят друг к другу, поскольку получены в одной и той же операции
- Используйте эту операцию для многоцветных моделей, взаимно стыкующихся сборок и вставок
- Если результат выглядит неправильно, проверьте, являются ли исходные объекты герметичными. **Исправить порядок обхода** исправляет вывернутые оболочки; [Восстановить](../mesh/repair.md) устраняет более серьёзные повреждения импортированных моделей
