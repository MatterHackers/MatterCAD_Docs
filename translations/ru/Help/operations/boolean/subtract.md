# Вычитание

Вычитание вырезает выбранные вами детали из тех деталей, которые вы не выбрали. С помощью параметра **Деталь(и) для вычитания** укажите режущие формы; всё остальное считается основой, из которой вырезают.

![boolean_subtract](https://matterhackers.github.io/MatterCAD_Docs/assets/boolean_subtract.png)

[Объединить](combine.md), Вычитание, [Пересечение](intersect.md) и [Вычитание и замена](subtract-and-replace.md) выполняются одним булевым объектом: кнопка на панели инструментов создаёт его с уже выбранной операцией Вычитание, и вы в любой момент можете переключиться на любую из трёх других в строке значков **Операция** в верхней части панели Свойства.

Вычитание работает как с телами, так и с 2D-контурами. Оно определяет, что вы ему передали, и выполняет операцию соответствующего типа: при вычитании одного контура из другого получается контур, а при вычитании одной сетки из другой — тело.

## Как использовать

1. Выберите два или более объектов
2. Нажмите **Вычитание** на панели инструментов — деталь для вырезания подбирается по умолчанию, поэтому результат появляется сразу
3. С помощью параметра **Деталь(и) для вычитания** выберите, какие дочерние объекты являются режущими формами
4. Вы можете передумать в любой момент, щёлкнув другой значок в строке **Операция** в верхней части панели Свойства — форма перестроится с новой операцией

## Параметры

- **Операция** — какую булеву операцию выполнять. Отображается в виде строки значков в верхней части панели
- **Деталь(и) для вычитания** — какие дочерние объекты являются режущими формами
- **Сохранять вычитаемые детали** — оставлять вырезанные детали в сцене, а не удалять их
- **Сохранять вывернутую геометрию** — считать вывернутую оболочку сплошным материалом, вместо того чтобы позволять ей «гасить» окружающий объём. Включите этот параметр, если у модели, которая должна быть сплошной, пропадают части. Это принудительно задействует более медленное точное булево ядро
- **Исправить порядок обхода** — перестроить обход вывернутых оболочек каждой детали перед выполнением булевой операции. Так геометрия исправляется один раз, а не меняется трактовка сплошного материала во всех последующих операциях, и обычно это лучшее из двух решений проблемы вывернутой модели

## Советы

- Чтобы Вычитание что-то сделало, объекты должны пересекаться
- Чтобы получить сквозное отверстие, убедитесь, что режущий объект проходит основу насквозь
- Для простого отверстия примитив [Отверстие](../../primitives/hole.md) уже настроен на вычитание
- Режущие объекты остаются в дереве проекта, поэтому вы можете перемещать или изменять их размер, и вырез обновится
- Если результат выглядит неправильно, проверьте, являются ли исходные объекты герметичными. **Исправить порядок обхода** устраняет вывернутые оболочки; [Восстановить](../mesh/repair.md) исправляет более серьёзные повреждения импортированных моделей
