# Вращение

Вращение прокручивает 2D-путь вокруг оси, создавая трёхмерное тело вращения. Так создаются вазы, чаши, колёса и другие объекты с вращательной симметрией.

## Как использовать

1. Выберите 2D-путь
2. Примените **Вращение** из меню операций с путями
3. Настройте диапазон поворота, положение оси и число сторон

## Параметры

- **Поворот** — общий угол поворота при вращении (по умолчанию: 0, диапазон: 0–360). Установите 360 для полного оборота.
- **Положение оси** — смещение оси вращения относительно центра пути (по умолчанию: 0, диапазон: от -30 до 30). Положительные значения отодвигают ось от пути, создавая более широкое отверстие.
- **Начальный угол** — где начинается вращение (по умолчанию: 0)
- **Конечный угол** — где заканчивается вращение (по умолчанию: 45). Установите 360 для полного оборота.
- **Стороны** — число сегментов по окружности вращения (по умолчанию: 30). Больше — глаже поверхность.

## Советы

- Используйте **Положение оси**, чтобы задать внутренний диаметр формы вращения
- Задайте **Начальный угол** и **Конечный угол** меньше 360, чтобы получить неполные обороты (арки, желоба)
- Нарисуйте профиль вазы или чаши, а затем поверните его вращением для идеальной симметрии
- [Путь-окружность](../../2d-paths/circle-path.md) при вращении даёт тор
