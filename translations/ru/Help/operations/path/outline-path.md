# Контурный путь

Контурный путь создаёт контурную версию заполненного пути, превращая сплошную фигуру в её граничное кольцо заданной толщины.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Как использовать

1. Выберите 2D-путь
2. Примените **Контурный путь** из меню операций с путями
3. Настройте толщину контура

## Советы

- Используйте эту операцию для создания рамочных фигур из сплошных путей
- Объедините с [Линейное выдавливание](linear-extrude.md) для создания трёхмерных рамок и каёмок
- Контур из [Окружность (путь)](../../2d-paths/circle-path.md) эквивалентен [Кольцо (путь)](../../2d-paths/ring-path.md)
