# Контур каймы

Контур каймы добавляет смещение каймы вокруг существующего пути, создавая увеличенную версию фигуры, которая окружает исходную.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Как использовать

1. Выберите 2D-путь
2. Примените **Контур каймы** из меню операций Путь
3. Настройте ширину каймы

## Советы

- Используйте это для создания поля или отступа вокруг фигур
- Объедините с исходным путём и операцией [Вычитание](../boolean/subtract.md), чтобы создать рамки
- Похоже на [Расширить контур](inflate-path.md), но специально предназначено для создания каймы
