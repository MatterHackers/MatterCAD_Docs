# Сгладить контур

Сгладить контур скругляет углы и изгибы 2D-пути, создавая из угловатых исходных форм более мягкие, органичные очертания.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Как использовать

1. Выберите 2D-путь
2. Примените **Сгладить контур** из меню операций Путь
3. Углы пути сглаживаются в плавные кривые

## Советы

- Применяйте перед [Линейное выдавливание](linear-extrude.md), чтобы создать выдавленные формы с мягкими краями
- Используйте на [Звезда Путь](../../2d-paths/star-path.md), чтобы получить скруглённую звезду
- Многократное применение операции Сгладить контур усиливает эффект сглаживания
