# Операции с путями
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

Операции с путями работают с 2D-путями для создания и изменения 3D-форм. Используйте их, чтобы выдавливать, вращать и уточнять геометрию на основе путей.

## Операции

- [Линейное выдавливание](linear-extrude.md) — придаёт 2D-пути высоту для создания 3D-объекта
- [Вращение](revolve.md) — вращает 2D-путь вокруг оси для создания тела вращения
- [Сгладить контур](smooth-path.md) — сглаживает кривые пути
- [Расширить контур](inflate-path.md) — расширяет путь наружу
- [Контурный путь](outline-path.md) — создаёт контур из залитого пути
- [Контур каймы](border-path.md) — добавляет смещение каймы вокруг пути
- [Выбрать пути](select-paths.md) — выбирает отдельные пути в сложных объектах с несколькими путями
