# Линейное выдавливание

Линейное выдавливание придаёт 2D-пути высоту, превращая плоскую форму в 3D-тело. Это основной способ преобразования путей в 3D-объекты.

## Как использовать

1. Выберите 2D-путь или объект на основе пути
2. Примените **Линейное выдавливание** из меню операций с путями
3. Задайте нужную высоту

## Параметры

- **Высота** — высота выдавливания (по умолчанию: 5 мм, диапазон: 0,1–50 мм)
- **Фаска сверху** — добавляет скошенную (скруглённую) кромку сверху выдавливания (по умолчанию: выкл.)

### Параметры фаски (отображаются при включённой опции Фаска сверху)

- **Стиль** — профиль фаски (Острый или скруглённый)
- **Радиус** — ширина фаски (по умолчанию: 3 мм)
- **Сегменты** — гладкость кривой фаски (по умолчанию: 9)

## Советы

- Работает с любым 2D-путём: [Окружность](../../2d-paths/circle-path.md), [Куб](../../2d-paths/box-path.md), [Звезда](../../2d-paths/star-path.md), [SVG](../../primitives/svg-object.md) и [Пользовательский](../../2d-paths/custom-path.md) путь
- Включите Фаска сверху для более аккуратного, профессионального вида
- Чтобы вращать путь вокруг оси вместо прямого выдавливания, см. [Вращение](revolve.md)
