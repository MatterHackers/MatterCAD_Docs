# Выбрать пути

Операция Выбрать пути отфильтровывает, какие подпути сложного объекта-пути будут сохранены. Она особенно полезна при работе с декоративными или составными шрифтами, когда внешние контуры букв и внутренние вырезы нужны как отдельные детали — например, чтобы напечатать их на 3D-принтере двумя разными цветами.

## Как работает глубина пути

Если объект-путь содержит фигуры с замкнутыми областями (например, внутренняя часть буквы «O» или полость декоративного завитка), такие замкнутые области являются **отверстиями** на глубине 1. Внешний контур каждой буквы или фигуры находится на **глубине 0**.

```
Depth 0 — outer contour of each letter or shape
Depth 1 — first level of enclosed holes (inside an "O", "A", etc.)
Depth 2 — shapes nested inside a hole (rarely used)
```

## Предустановки фильтра

### Все
Включает все пути без изменений. Это значение по умолчанию, равносильное тому, чтобы вовсе не применять операцию Выбрать пути.

### Только внешние пути
Сохраняет только внешний контур каждой фигуры (глубина == 0). Используйте этот вариант, чтобы получить только очертания букв декоративного шрифта, без внутренних вырезов.

### Только отверстия
Сохраняет только замкнутые отверстия (глубина > 0). Используйте этот вариант, чтобы получить только внутренние вырезы букв и фигур.

### По индексу группы
Сохраняет только пути, принадлежащие одной несвязной фигуре. Группа 0 — первая фигура, группа 1 — вторая и так далее. Используйте этот вариант, чтобы выделить один символ из слова.

### Пользовательский
Задайте выражение, которое вычисляется для каждого пути. Путь **включается**, когда выражение отлично от нуля, и **исключается**, когда оно равно нулю.

Выражения должны начинаться с `=`, чтобы включить подстановку переменных. Без `=` значение считается обычным числом (например, `1` включает всегда, `0` всегда исключает).

## Примеры пользовательских выражений

| Выражение | Действие |
|------------|--------|
| `=PathDepth==0` | Только внешние контуры (то же, что Только внешние пути) |
| `=PathDepth>0` | Только отверстия (то же, что Только отверстия) |
| `=GroupIndex==0` | Только первая несвязная фигура |
| `=PathArea>100` | Фигуры с площадью больше 100 мм² |
| `=PathLength>50` | Фигуры с периметром больше 50 мм |

## Переменные пользовательских выражений

| Переменная | Значение |
|----------|---------|
| `PathDepth` | 0 = внешний контур; 1 и больше = отверстие или вложенная фигура |
| `GroupIndex` | Индекс несвязной фигуры (0, 1, 2…) |
| `GroupOuterArea` | Площадь внешнего пути этой группы |
| `GroupOuterLength` | Периметр внешнего пути этой группы |
| `ChildCount` | Количество отверстий внутри внешнего пути этой группы |
| `PathIndex` | Порядковый индекс этого пути внутри его группы |
| `PathArea` | Площадь этого отдельного пути |
| `PathLength` | Периметр этого отдельного пути |

## Пример: многоцветная печать рождественским шрифтом

Часто операцию Выбрать пути применяют для печати декоративного текста, у которого буквы содержат внутренние вырезы. Чтобы напечатать внешние буквы одним цветом, а внутренние вырезы — другим:

1. Добавьте объект **Текст** и задайте для него **2D-вывод**
2. Примените **Выбрать пути** → установите предустановку **Только внешние пути**
3. Примените **Линейное выдавливание**, чтобы задать высоту → назначьте цвет первого филамента
4. Вернитесь к исходному текстовому объекту
5. Примените второй раз **Выбрать пути** → установите предустановку **Только отверстия**
6. Примените **Линейное выдавливание** с той же высотой → назначьте цвет второго филамента
7. Разместите один выдавленный объект поверх другого — два цвета совместятся идеально
