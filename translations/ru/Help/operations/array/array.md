# Массив

**Массив** создаёт несколько копий объекта, расположенных по шаблону. Выберите режим с помощью кнопок вверху — **Линейный**, **Радиальный** или **Преобразование**, — чтобы переключаться между типами шаблонов.

## Как использовать

1. Выберите объект
2. Примените операцию **Массив** из меню Дублирование
3. Выберите режим (Линейный, Радиальный или Преобразование)
4. Настройте параметры выбранного режима

## Режим: Линейный

В линейном режиме копии размещаются вдоль направления с необязательным нарастанием поворота и масштаба.

**Количество** — число копий (целое число или выражение). Исходный объект является первой копией; остальные копии смещаются относительно него.

**Метод смещения** — как вычисляется шаг:
- **Относительный** — смещение умножается на размер габаритного параллелепипеда объекта. Относительное смещение (1, 0, 0) располагает копии ровно через одну ширину объекта вдоль оси X.
- **Смещение** — фиксированное расстояние в мировых координатах в мм на каждую копию.
- **Конечная точка** — задаёт положение последней копии; шаг распределяется равномерно между копиями.

**Относительное смещение** / **Смещение** / **Конечная точка** — вектор шага в зависимости от выбранного метода смещения.

**Режим поворота** — как поворот накапливается от копии к копии:
- **Локальный** — каждая копия поворачивается на месте вокруг собственного центра; направление смещения остаётся в мировых осях.
- **Объединение** — поворот накапливается и задаёт направление смещения, создавая спирали, веера и винтовые линии.

**Поворот** — поворот в градусах по каждой оси для каждой копии.

**Масштаб** — накопительный масштаб по каждой оси для каждой копии. Значения меньше 1 уменьшают копии, значения больше 1 — увеличивают.

**Масштаб влияет на смещение** — если включено, расстояние между копиями также масштабируется на каждом шаге. Используйте это для сужающихся спиралей и геометрических прогрессий (раковины наутилуса, сложенные кривые «раковины улитки»).

## Режим: Радиальный

В радиальном режиме копии равномерно распределяются вокруг центральной оси на заданном радиусе.

![20260506 092618 paste 20260506 092618](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-092618-paste-20260506-092618.jpg)


**Метод подсчёта** — как определяется число копий:
- **Количество** — явное число копий.
- **Расстояние** — угловой промежуток между копиями в градусах; количество вычисляется так, чтобы заполнить сектор.

**Количество** / **Угловое расстояние** — число копий (режим Количество) или угловой шаг в градусах (режим Расстояние). Поддерживает выражения.

**Центральная ось** — ось, вокруг которой выполняется поворот (по умолчанию: Z).

**Сегмент окружности** — занимают ли копии полную окружность 360° (**Полный**) или частичную дугу (**Дуга**).

**Радиус** — расстояние от центральной оси до каждой копии.

**Угол протяжки** — количество градусов дуги для заполнения (отображается, когда Сегмент окружности установлен в Дуга). Поддерживает выражения.

**Выровнять поворот** — поворачивает каждую копию так, чтобы её ось вперёд была направлена наружу от центра.

**Ось вперёд** — какая ось копии считается «вперёд» при выравнивании (отображается, когда включено Выровнять поворот).

## Режим: Преобразование

В режиме Преобразование копии смещаются с помощью заданного вручную преобразования или по преобразованию другого объекта.

**Количество** — число копий (целое число или выражение).

**Опорный элемент преобразования** — откуда берётся преобразование для каждого шага:
- **Вход** — вы задаёте перемещение, поворот и масштаб напрямую.
- **Объект** — преобразование считывается из соседнего объекта, указанного по имени.

**Перемещение** — смещение в мировых координатах в мм на каждый шаг (отображается, когда опорный элемент — Вход).

**Поворот** — поворот в градусах по каждой оси на каждый шаг (отображается, когда опорный элемент — Вход).

**Масштаб** / **Оси масштабирования** — равномерный и поосевой масштаб, применяемый на каждом шаге (отображается, когда опорный элемент — Вход).

**Имя преобразования** — имя соседнего объекта, преобразование которого используется как приращение на каждом шаге (отображается, когда опорный элемент — Объект).

**Относительное пространство** — если включено, преобразование каждой копии накапливается в локальной системе координат предыдущей копии; если выключено, каждый шаг применяется в мировом пространстве (отображается, когда опорный элемент — Объект).

## Перемешать

Включите **Перемешать**, чтобы добавить разброс всем копиям.

- **Случайное смещение** — максимальное случайное смещение положения по каждой оси в мм.
- **Случайный поворот** — максимальный случайный поворот по каждой оси в градусах.
- **Оси случайного масштаба** — максимальный случайный разброс масштаба по каждой оси.
- **Исключить первый** — оставляет первую копию точно в вычисленном положении (по умолчанию: включено).
- **Исключить последний** — оставляет последнюю копию точно в вычисленном положении.
- **Начальное число** — измените его, чтобы получить другое случайное расположение. Поддерживает выражения.

## Объединить

- **Создать единую сетку** — объединяет все копии в один объединённый объект-сетку.
- **Объединить вершины** — сваривает вершины в пределах порогового расстояния объединения (отображается, когда включено Создать единую сетку).
- **Расстояние** — порог объединения в мм (отображается, когда включено Объединить вершины).

## Советы

- Используйте выражения для параметров Количество, Поворот или Конечная точка, чтобы создавать параметрические шаблоны
- Для круговых шаблонов используйте Радиальный режим — задайте Радиус для управления размером окружности и включите Выровнять поворот, если копии должны смотреть наружу
- Режим поворота Объединение в Линейном режиме создаёт спирали и веера без ручного расчёта угловых смещений
- Масштаб влияет на смещение естественным образом создаёт компоновки в виде раковины наутилуса и геометрических прогрессий
- Сочетайте Массив с [Выбрать дочерний](select-child.md), чтобы создавать шаблоны, в которых каждая копия показывает свой вариант
