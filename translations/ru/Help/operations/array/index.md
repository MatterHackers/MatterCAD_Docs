# Операции массива
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

**Массив** создаёт несколько копий объекта, расположенных по определённому шаблону. Это удобно для создания повторяющихся элементов, таких как отверстия под болты, столбы ограждения, зубья шестерён или декоративные детали.

Операция **Массив** поддерживает четыре режима — **Линейный**, **Радиальный**, **Кривая** и **Преобразование** — и все они собраны в одном инструменте.
