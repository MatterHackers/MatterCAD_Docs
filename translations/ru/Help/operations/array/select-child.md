# Выбрать дочерний

Операция «Выбрать дочерний» выбирает один дочерний объект из группы объектов по номеру индекса или по имени. Это особенно полезно в скриптовых и параметрических моделях, где нужно динамически определять, какой объект отображать.

## Как использовать

1. Выделите два или более объектов
2. Примените операцию **Выбрать дочерний** из меню **Дублирование**
3. Выберите **По индексу** или **По имени**, чтобы задать способ выбора дочернего объекта
4. Укажите номер индекса или имя для сопоставления

## Параметры

- **Способ выделения** — выбор между **По индексу** (выбор по позиции) и **По имени** (выбор по имени объекта). Отображается в виде кнопок.
- **Индекс потомка** — индекс выбираемого дочернего объекта, начиная с нуля (отображается при использовании варианта «По индексу»). Поддерживает [выражения](../../workspace/expressions.md).
- **Имя потомка** — имя выбираемого дочернего объекта (отображается при использовании варианта «По имени»). Поддерживает [выражения](../../workspace/expressions.md).

Если индекс выходит за пределы диапазона или имя не совпадает ни с одним дочерним объектом, в качестве запасного варианта возвращается первый дочерний объект. Если дочерних объектов нет, не возвращается ничего.

## Использование в скриптах

Операция «Выбрать дочерний» рассчитана на работу с выражениями и функцией `rand()` для создания динамических моделей, управляемых данными. Например, можно построить сцену с несколькими вариантами объектов в качестве дочерних и использовать выражение вида `rand(42)` как начальное значение индекса, чтобы выбирать один из них случайным образом.

**Пример: случайные книги-реквизит для театральной сцены**

1. Импортируйте 5 различных сеток книг как дочерние объекты операции «Выбрать дочерний»
2. Задайте для параметра **Способ выделения** значение **По индексу**
3. Используйте выражение для параметра **Индекс потомка**, например `floor(rand(seed) * 5)`, где `seed` — переменная таблицы
4. Продублируйте операцию «Выбрать дочерний» несколько раз, задав каждой копии своё начальное значение
5. Каждый экземпляр случайным образом выберет свою книгу из набора

Этот приём подходит для любой ситуации, когда нужно выбрать один вариант из набора: мебель, декор, архитектурные элементы или любая коллекция взаимозаменяемых деталей.

## Советы

- Сочетайте с операцией [Массив](array.md), чтобы создавать разнообразные узоры, где каждая копия выбирает свой дочерний объект
- Используйте переменные таблицы для индекса или имени, чтобы управлять выбором из электронной таблицы
- Благодаря возврату первого дочернего объекта в качестве запасного варианта модель не сломается, даже если индекс или имя указаны неверно
