# Операции преобразования
<!-- AUTO_IMAGE: type=toolbar_icons group=Transform -->
![Transform toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Transform.png)

Операции преобразования изменяют положение, ориентацию и размер объектов, не затрагивая их геометрию.

## Операции

- [Переместить](translate.md) — Перемещение объекта на заданное смещение по X, Y или Z
- [Повернуть](rotate.md) — Поворот объекта вокруг оси на заданный угол
- [Масштаб](scale.md) — Изменение размера объекта с возможностью равномерного или пооосного масштабирования
- [Отразить](mirror.md) — Создать зеркальную копию объекта относительно оси
