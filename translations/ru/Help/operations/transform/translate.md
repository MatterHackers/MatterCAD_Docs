# Переместить

Операция Переместить смещает объект на заданное расстояние вдоль осей X, Y и/или Z. В отличие от перетаскивания объекта мышью, операция Переместить позволяет вводить точные значения смещения.

## Как использовать

1. Выберите объект
2. Примените операцию **Переместить** из меню Преобразование
3. Введите нужные значения смещения по X, Y и Z на панели Свойства

## Параметры

- **X, Y, Z** (Перемещение) — расстояние, на которое объект смещается вдоль каждой оси, в миллиметрах. Поддерживает [выражения](../../workspace/expressions.md) для вычисляемых значений.

## Советы

- Используйте операцию Переместить, когда нужно точное, воспроизводимое позиционирование, которое можно скорректировать позже
- Значения перемещения задаются относительно текущего положения объекта — ввод 10 для X сместит его на 10 мм вправо от текущего места
- Для быстрого изменения положения объекты также можно перетаскивать прямо в области просмотра. См. [Изменение объектов](../../getting-started/editing-objects.md)
