# Отразить

Операция «Отразить» создаёт зеркальную копию объекта относительно одной из трёх основных осей. В результате получается зеркальная версия исходной формы.

## Как использовать

1. Выберите объект
2. Примените операцию **Отразить** из меню **Преобразование**
3. Выберите ось, относительно которой выполняется отражение

## Параметры

- **Зеркало вкл.** — ось, относительно которой выполняется отражение:
  - **Ось X** — переворачивает объект слева направо
  - **Ось Y** — переворачивает объект спереди назад
  - **Ось Z** — переворачивает объект сверху вниз

## Советы

- Отражение выполняется относительно центра габаритного контейнера объекта, поэтому зеркальный результат занимает то же пространство, что и оригинал
- Нормали граней автоматически корректируются после отражения для сохранения правильного отображения
- Используйте операцию «Отразить» для создания симметричных моделей: постройте одну половину, затем отразите её и выполните [Объединить](../boolean/combine.md) с оригиналом
- Отражение неразрушающее: вы можете изменить ось отражения в любой момент
