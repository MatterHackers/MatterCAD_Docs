# Сжатие

Сжатие сдавливает заднюю часть объекта внутрь, причём эффект усиливается к верху. Это создаёт сужающийся или сжатый вид.

![20260506 155449 paste 20260506 155449](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-155449-paste-20260506-155449.jpg)

## Как использовать

1. Выберите объект
2. Примените операцию **Сжатие** из меню Изменить форму
3. Настройте процент сжатия

## Параметры

- **Задний коэффициент** — насколько сильно задняя часть детали сжимается внутрь (0–300%, по умолчанию: 50%). Более высокие значения = более сильное сжатие

## Советы

- Сжатие действует сзади вперёд, сдавливая заднюю часть объекта
- Используйте его для создания сужающихся, конусообразных форм из прямоугольных или цилиндрических объектов
- Для радиального (кругового) сжатия используйте вместо этого [Радиальное сжатие](radial-pinch.md)
