# Операции «Изменить форму»
<!-- AUTO_IMAGE: type=toolbar_icons group=Reshape -->
![Reshape toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Reshape.png)

Операции «Изменить форму» деформируют и изменяют геометрию объектов, позволяя создавать органичные и сложные формы из простых фигур.

## Операции

- [Кривая](curve.md) — изгиб объекта вдоль кривой
- [Скручивание](twist.md) — постепенный поворот объекта по его высоте
- [Сжатие](pinch.md) — сжатие объекта к его центральной оси
- [Радиальное сжатие](radial-pinch.md) — радиальное сжатие объекта вокруг оси
- [Разрез плоскостью](plane-cut.md) — разрезание объекта плоскостью на заданной высоте
- [Сделать полым](hollow-out.md) — создание полой оболочки из сплошного объекта
