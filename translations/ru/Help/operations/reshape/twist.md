# Скручивание

Скручивание поворачивает верх объекта относительно низа, создавая спиральный или закрученный эффект по высоте. По умолчанию поворот нарастает равномерно снизу вверх; в разделе **Дополнительно** можно нарисовать, на каких участках высоты поворот происходит на самом деле.

## Как использовать

1. Выберите объект
2. Примените операцию **Скручивание** из меню **Изменить форму**
3. Задайте угол скручивания и настройте нарезку для плавности
4. Включите **Дополнительно**, если хотите нарисовать, как скручивание распределяется по высоте детали

## Профиль скручивания

В разделе **Дополнительно** кривая **Профиль скручивания** определяет, где происходит скручивание. Общая величина скручивания по-прежнему задаётся элементом **Угол** (или **Расстояние поворота**) — кривая только распределяет её:

- **По вертикали кривой** отложена высота детали в процентах — 0 внизу, 100 вверху. Направляющая линия поперёк редактора отмечает 100 процентов и подписана реальной высотой детали в мм.
- **По горизонтали кривой** отложен процент от общего скручивания, достигнутый на этой высоте, — 0, если его нет вовсе, и 100, если достигнуто всё.

Новое **Скручивание** начинается с прямой диагонали от 0 до 100 — это то самое равномерное скручивание, которое получается вообще без раздела **Дополнительно**.

Горизонтальный участок кривой — это полоса детали, которая не скручивается. Там, где кривая не покрывает всю высоту, удерживается её ближайший конец, поэтому кривая, нарисованная только между 40 и 60 процентами, оставляет деталь неподвижной ниже и выше этого диапазона — именно так скручивание начинают и заканчивают на середине высоты.

Участок, который при подъёме идёт назад, раскручивает: эта полоса детали поворачивается в другую сторону, обратно к исходному положению. Если провести профиль выше 100 и затем вернуть его вниз, получится перебег общего значения с возвратом к нему.

## Параметры

- **Тип поворота** — выберите между:
  - **Угол** — задайте общий угол скручивания в градусах (3–360)
  - **Расстояние** — задайте скручивание как расстояние вдоль окружности
- **Срезы** — количество горизонтальных разрезов, добавляемых для плавного скручивания, равномерно распределённых по высоте детали. Больше срезов = более плавное скручивание
- **Минимум сторон** — наименьшее число сторон, которое должно быть у детали вокруг оси скручивания. У грубой формы, например у куба, нет геометрии по периметру, способной передать поворот, поэтому его плоские грани получаются гранёными, а не изогнутыми; этот параметр добавляет вертикальные разрезы через ось скручивания, чтобы такие грани могли следовать за скручиванием. Значение 0 (по умолчанию) оставляет деталь без изменений
- **Скрутить вправо** — направление скручивания: вправо (по часовой стрелке) или влево (против часовой стрелки)
- **Предпочтительный радиус** — только для чтения: радиус, который сообщает сама деталь, либо радиус, подразумеваемый её формой; именно вокруг него измеряется расстояние скручивания (только в режиме **Расстояние**)
- **Изменить радиус** — отключить сообщённый радиус, чтобы задать собственный (только в режиме **Расстояние** и только если деталь сообщает радиус)
- **Переопределить радиус** — пользовательский радиус для расчёта скручивания (только в режиме **Расстояние**)

### Дополнительные параметры

- **Профиль скручивания** — описанный выше редактор кривой: процент от общего скручивания, достигнутый на каждой высоте в процентах
- **Смещение поворота** — сдвиг центра, вокруг которого поворачивается деталь, относительно её середины

## Советы

- Большие значения параметра **Срезы** дают более гладкий результат, но создают больше геометрии
- Если скрученный куб или другая форма с плоскими гранями выглядит гранёной, а не изогнутой, увеличьте значение **Минимум сторон**
- Нарисуйте профиль горизонтальным внизу и поднимающимся дальше, чтобы оставить прямое основание под скрученной колонной
- Скручивание на 90 градусов на квадратной колонне создаёт изящный архитектурный эффект
- Нарисуйте два горизонтальных участка, соединённых коротким подъёмом, чтобы закрутить середину детали и оставить оба конца неподвижными
