# Радиальное сжатие

Операция **Радиальное сжатие** сжимает объект внутрь от центральной точки по настраиваемой профильной кривой. В отличие от обычного [Сжатие](pinch.md), которое действует сзади вперёд, **Радиальное сжатие** сжимает объект симметрично вокруг центральной оси.

## Как использовать

1. Выберите объект
2. Примените операцию **Радиальное сжатие** из меню **Изменить форму**
3. Отредактируйте профиль пути, чтобы задать степень сжатия на каждой высоте
4. Настройте число срезов для получения плавности

## Параметры

- **Путь** — редактор профильной кривой, задающий величину сжатия на каждом уровне высоты. Изменяйте кривую, чтобы создавать собственные профили сжатия
- **Срезы** — число горизонтальных разрезов для плавного сжатия, равномерно распределённых по высоте детали. Больше срезов — более плавный результат

### Дополнительные параметры

- **Тип сжатия** — направление сжатия:
  - **Радиальный** — равномерное сжатие со всех сторон к центру
  - **Ось X** — сжатие только вдоль оси X
  - **Ось Y** — сжатие только вдоль оси Y
- **Смещение поворота** — сдвигает центр эффекта сжатия

## Советы

- Используйте редактор пути для создания форм в виде песочных часов, бутылки или вазы
- Радиальное сжатие идеально подходит для создания органических округлых форм из цилиндрических объектов
- Увеличивайте значение параметра **Срезы** для более гладких кривых, особенно при резких профилях сжатия
