# Сделать полым

Операция «Сделать полым» создаёт из сплошного объекта полую оболочку, смещая поверхность внутрь. В результате получается тонкостенный вариант исходной формы.

![20260506 155412 paste 20260506 155412](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-155412-paste-20260506-155412.jpg)

## Как использовать

1. Выберите сплошной объект
2. Примените операцию **Сделать полым** из меню **Изменить форму**
3. Задайте нужную толщину стенки

## Параметры

- **Расстояние** — толщина стенки в миллиметрах (по умолчанию: 2 мм). Именно такой толщины будет получившаяся оболочка.
- **Кол-во ячеек** — разрешение алгоритма создания полости (по умолчанию: 64). Большие значения дают более гладкие внутренние поверхности, но требуют больше времени на расчёт.

## Советы

- Операция «Сделать полым» удобна для создания корпусов, ёмкостей, ваз и облегчённых деталей
- Для большинства деталей, печатаемых на 3D-принтере, типична толщина стенки 1–2 мм
- Увеличьте значение параметра **Кол-во ячеек**, если внутренняя поверхность выглядит грубой или ступенчатой
- При создании полости низ остаётся открытым — объедините результат с объектом [Куб](../../primitives/cube.md), если нужно закрытое основание
- Для сложных форм расчёт может занять несколько секунд
