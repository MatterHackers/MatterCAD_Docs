# Кривая

Кривая изгибает прямой объект в дугу или круговую форму. Изгибом можно управлять, задавая либо угол, либо диаметр, вокруг которого происходит обёртывание.

## Как использовать

1. Выберите объект
2. Примените операцию **Кривая** из меню Изменить форму
3. Выберите тип изгиба: Угол или Диаметр
4. Настройте параметры, чтобы получить нужную кривизну

## Параметры

- **Тип изгиба** - Выберите один из вариантов:
  - **Угол** - Задать угол изгиба напрямую (1-360 градусов)
  - **Диаметр** - Задать диаметр окружности, вокруг которой оборачивается деталь
- **Направление изгиба** - Изгиб вверх или Согнуть вниз
- **Начальный процент** - Место вдоль объекта, где начинается изгиб (0-100%)
- **Разделить сетку** - Разделяет сетку для получения плавных кривых (по умолчанию: включено)
- **Мин. сторон на оборот** - Минимальное количество сегментов сетки на полный оборот. Чем больше значение, тем более плавные кривые

### Дополнительно

- **Процент начала изгиба** - Процент от левого края, где начинается изгиб
- **Процент изгиба в конце** - Процент от левого края, где заканчивается изгиб

## Советы

- Используйте Кривую для создания арок, колец и гнутых кронштейнов из прямых заготовок
- Значение угла 360 сворачивает объект в замкнутое кольцо
- Увеличивайте значение Мин. сторон на оборот для более плавного результата на крутых изгибах
- Объект изгибается вдоль своей длины (ось X)
