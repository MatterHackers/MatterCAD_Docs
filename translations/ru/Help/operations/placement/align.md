# Выровнять

Операция **Выровнять** точно позиционирует несколько объектов относительно объекта-привязки. Используйте её, чтобы выстроить края по одной линии, отцентрировать детали друг относительно друга, разместить один объект поверх другого или создать стопки с равными промежутками.

## Как использовать

1. Выберите два или более объектов.
2. Примените операцию **Выровнять** из меню **Размещение**.
3. Выберите объект-**Привязку**. Привязка остаётся на месте, а остальные объекты перемещаются.
4. Задайте выравнивание для осей X, Y и Z независимо друг от друга.
5. Нажмите **Применить**, когда захотите зафиксировать выровненные положения в дереве объектов.

## Параметры

### Привязка

Список **Привязка** выбирает дочерний объект, используемый как эталон. Привязка не перемещается. Все остальные дочерние объекты операции **Выровнять** переставляются относительно привязки, если только для оси не используется режим **С накоплением**.

### Управление осями

У каждой оси свои элементы управления. Можно выравнивать по одной оси, по двум или по всем трём. Минимальный и максимальный края именуются по оси:

- **Ось X** - Мин слева, Макс справа.
- **Ось Y** - Мин спереди, Макс сзади.
- **Ось Z** - Мин снизу, Макс сверху.

Для каждой оси:

- **Выровнять** - Выбирает опорную точку привязки для этой оси. Используйте **Нет**, чтобы оставить положения по этой оси без изменений.
- **Режим** - Определяет, как применяется выбранное выравнивание:
  - **Простой** - Совместить соответствующий край, центр или начало координат каждого перемещаемого объекта с привязкой. Смещение не используется.
  - **Смещение** - Выберите, какая часть перемещаемого объекта должна попасть на опорную точку привязки, затем задайте промежуток параметром **Смещение**.
  - **С накоплением** - Размещает объекты один за другим вдоль этой оси, используя **Смещение** как зазор между ними.
- **Подвыравнивание** - Доступно в режиме **Смещение**. Выбирает часть перемещаемого объекта, которая размещается на опорной точке привязки. Если **Подвыравнивание** установлено в **Нет**, операция **Выровнять** использует тот же край, центр или начало координат, что выбраны в параметре **Выровнять**.
- **Смещение** - Доступно в режимах **Смещение** и **С накоплением**. Добавляет расстояние вдоль этой оси и поддерживает [выражения](../../workspace/expressions.md).

## Режимы выравнивания

### Простой

Используйте режим **Простой**, когда сопоставляются одинаковые положения. Например, **Выравнивание по X: По центру** перемещает каждый объект, кроме привязки, так, чтобы его центр по X совпал с центром привязки по X. **Выравнивание по Z: Мин** перемещает каждый объект, кроме привязки, так, чтобы его низ находился на высоте низа привязки.

### Смещение

Используйте режим **Смещение**, когда часть перемещаемого объекта должна отличаться от опорной точки привязки. Например, чтобы разместить объект поверх привязки:

1. Задайте для **Выравнивание по Z** значение **Макс** (верх).
2. Задайте для **Режим Z** значение **Смещение**.
3. Задайте для **Подвыравнивание Z** значение **Снизу**.
4. Задайте **Смещение Z** равным нужному зазору или оставьте `0` для прямого контакта.

Это разместит низ перемещаемого объекта на верхней грани привязки, с необязательным промежутком.

### С накоплением

Используйте режим **С накоплением**, чтобы выстроить несколько объектов цепочкой вдоль оси. Объекты обрабатываются по имени, затем по внутреннему идентификатору, поэтому понятные имена объектов дают предсказуемый порядок стопки.

В режиме **С накоплением** каждый перемещаемый объект размещается вплотную к предыдущему эталону по этой оси:

- Выравнивание **Мин** складывает объекты в положительном направлении, например слева направо по X или снизу вверх по Z.
- Выравнивание **Макс** складывает объекты в отрицательном направлении, например справа налево по X или сверху вниз по Z.
- Выравнивание **По центру** и **Начало координат** использует смещение между центрами или началами координат объектов.

Используйте **Смещение** в режиме **С накоплением**, чтобы задать зазор между объектами.

## Примеры

- **Отцентрировать объекты по площадке стола** - Выберите объект, который должен остаться неподвижным, в качестве **Привязки**, затем задайте для **Выравнивание по X** и **Выравнивание по Y** значение **По центру**.
- **Разместить один объект поверх другого** - Задайте для **Выравнивание по Z** значение **Макс** (верх), для **Режим Z** - **Смещение**, а для **Подвыравнивание Z** - **Снизу**.
- **Добавить точный зазор от края** - Используйте режим **Смещение**, выберите край перемещаемого объекта с помощью **Подвыравнивание**, затем задайте **Смещение** равным нужному промежутку.
- **Выстроить несколько объектов встык** - Задайте для **Выравнивание по X** значение **Мин** (слева), для **Режим X** - **С накоплением**, а зазор задайте параметром **Смещение по X**.
- **Построить вертикальную стопку** - Задайте для **Выравнивание по Z** значение **Мин** (низ), для **Режим Z** - **С накоплением**, а расстояние между объектами задайте параметром **Смещение Z**.

## Советы

- Объект-привязка остаётся на месте; остальные объекты перемещаются, выравниваясь по нему.
- Для разных осей можно использовать разные режимы, например **С накоплением** по X и **По центру** с режимом **Простой** по Y.
- Используйте имена объектов, чтобы управлять порядком в режиме **С накоплением**, когда выравнивается сразу несколько объектов.
- Операция **Выровнять** неразрушающая до её применения. Вы можете в любой момент изменить настройки и заново выровнять дочерние объекты.
- Используйте **Начало координат**, когда нужно выстроить начала координат моделей, а не края габаритных прямоугольников.
