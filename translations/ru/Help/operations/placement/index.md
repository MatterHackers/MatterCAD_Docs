# Операции размещения
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Операции размещения помогают точно позиционировать объекты относительно друг друга или в пределах заданных границ.

## Операции

- [Выровнять](align.md) — выравнивание объектов относительно друг друга по любой оси
- [Выравнивание двойной экструзии](dual-extrusion-align.md) — выравнивание объектов по их общим позициям моделирования
- [Вписать в границы](fit-to-bounds.md) — масштабирование объекта для размещения внутри заданного ограничивающего параллелепипеда
- [Вписать в цилиндр](fit-to-cylinder.md) — масштабирование объекта для размещения внутри заданного цилиндра
