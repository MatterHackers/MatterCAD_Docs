# Вписать в границы

Операция «Вписать в границы» масштабирует объект так, чтобы он поместился в заданные ширину, глубину и высоту. Вы можете управлять тем, как объект растягивается и выравнивается внутри целевых границ.

## Как использовать

1. Выберите объект
2. Примените операцию **Вписать в границы** из меню **Размещение**
3. Введите целевые размеры
4. Выберите режим сохранения пропорций и способ растяжения

## Параметры

- **Сохранять пропорции** — как ограничивать пропорции:
  - **Нет** — каждая ось задаётся независимо
  - **X и Y** — ширина и глубина связаны между собой
  - **X, Y и Z** — равномерное масштабирование по всем осям
- **Ширина** — целевая ширина (размер по X)
- **Глубина** — целевая глубина (размер по Y)
- **Высота** — целевая высота (размер по Z)

### Когда для параметра **Сохранять пропорции** выбрано X и Y или X, Y и Z

- **Растянуть** — как объект вписывается:
  - **Внутри** — уменьшить масштаб так, чтобы объект полностью поместился в границы (могут остаться зазоры)
  - **Развернуть** — увеличить масштаб так, чтобы объект заполнил границы (по некоторым измерениям он может выходить за них)

### Когда для параметра **Сохранять пропорции** выбрано **Нет**

У каждой оси есть свои:

- **Растянуть** — **Внутри** или **Развернуть** для каждой оси
- **Выровнять** — где расположить объект внутри границ (**Мин**, **По центру**, **Макс**)

## Советы

- Используйте эту операцию, чтобы изменить размер импортированных моделей до точных целевых значений
- Заблокируйте все пропорции для равномерного масштабирования с сохранением исходной формы
- Используйте управление по каждой оси, когда нужно подогнать определённую ширину, а остальные размеры не важны
