# Выравнивание двойной экструзии

![20260506 160531 paste 20260506 160531](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-160531-paste-20260506-160531.jpg)


Выравнивание двойной экструзии перемещает два или более выбранных объекта так, чтобы их центры совпали с общим началом координат модели — положением, которое они должны занимать относительно друг друга при печати двойной экструзией.

## Как использовать

1. Выберите два или более объекта
2. Примените **Выравнивание двойной экструзии** из меню Размещение

## Когда использовать

Используйте эту операцию, когда у вас есть детали, предназначенные для совместной печати на принтере с двойной экструзией, но смещённые из своих взаимных положений. Выравнивание двойной экструзии возвращает их в предусмотренное общее координатное пространство.
