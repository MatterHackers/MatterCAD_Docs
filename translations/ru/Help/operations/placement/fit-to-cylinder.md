# Вписать в цилиндр

Операция Вписать в цилиндр масштабирует объект так, чтобы он поместился в заданную цилиндрическую границу, определяемую диаметром и высотой.

## Как использовать

1. Выберите объект
2. Примените операцию **Вписать в цилиндр** из меню Размещение
3. Задайте требуемые Диаметр и Высоту

## Параметры

- **Диаметр** — диаметр целевого цилиндра
- **Высота** — высота целевого цилиндра
- **Растянуть по Z** — если включено, объект масштабируется по высоте цилиндра
- **Альтернативное центрирование** — если включено, центрирование выполняется по визуальному весу детали, а не по её описанной окружности
