# Облачная библиотека

Облачная библиотека хранит ваши модели в интернете, в вашей учётной записи MatterHackers. Это позволяет обращаться к моделям с любого компьютера и хранить резервную копию в облаке.

![20260323 210141 paste 20260323 210141](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210141-paste-20260323-210141.jpg)

## Начало работы

1. Войдите в свою учётную запись MatterHackers из меню приложения
2. Облачная библиотека появится в браузере библиотеки
3. Загружайте модели, перетаскивая их в облачную папку, или сохраняйте сразу в облако

## Элементы

- **Доступ откуда угодно** — ваши модели доступны на любом компьютере, где вы вошли в учётную запись
- **Резервная копия в облаке** — ваша работа надёжно хранится в интернете
- **Организация по папкам** — создавайте папки для упорядочивания облачных моделей так же, как в локальной библиотеке
- **Совместный доступ** — делитесь моделями с другими пользователями MatterCAD. См. [Поделиться](sharing.md)

## Советы

- Модели синхронизируются автоматически при сохранении в облачную библиотеку
- Для доступа к содержимому облачной библиотеки необходимо подключение к интернету
- Загрузка или скачивание больших файлов может занять некоторое время
- Храните важные модели одновременно в локальной и облачной библиотеках для надёжности
