# Локальная библиотека

Локальная библиотека хранит ваши 3D-модели на компьютере. Вы можете распределять модели по папкам, искать файлы и быстро добавлять их в рабочую область.

![20260323 210208 paste 20260323 210208](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210208-paste-20260323-210208.jpg)


## Просмотр библиотеки

1. Откройте панель **Библиотека** на боковой панели или вкладку Библиотека
2. Перемещайтесь по папкам, чтобы найти нужные модели
3. Дважды щёлкните по модели, чтобы открыть её, или перетащите её в рабочую область, чтобы добавить в текущую сцену

## Организация файлов

- **Создание папок** — щёлкните правой кнопкой мыши в библиотеке и выберите Создать папку, чтобы упорядочить свои модели
- **Переименование элементов** — щёлкните правой кнопкой мыши по любому элементу и выберите Переименовать
- **Удаление элементов** — щёлкните правой кнопкой мыши и выберите Удалить, чтобы удалить элементы
- **Перемещение элементов** — перетаскивайте элементы между папками для изменения структуры

## Параметры отображения

Панель библиотеки поддерживает несколько режимов просмотра:

- **Список** — компактный список с именами файлов
- **Значки** — миниатюры предварительного просмотра ваших моделей
- **Крупные значки** — увеличенные миниатюры для удобного просмотра

Элементы можно сортировать по следующим критериям:

- **Имя** — в алфавитном порядке
- **Дата создания** — сначала новые или сначала старые
- **Дата изменения** — сначала недавно изменённые

## Советы

- Используйте строку поиска в верхней части библиотеки, чтобы быстро находить модели по имени
- Обозреватель библиотеки показывает миниатюру предварительного просмотра для большинства типов файлов
- Модели, сохранённые в формате MCX, сохраняют все параметры и дерево построения для полноценного повторного редактирования
