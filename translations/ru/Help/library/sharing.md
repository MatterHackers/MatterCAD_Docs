# Поделиться

MatterCAD позволяет делиться своими моделями с другими пользователями с помощью кодов доступа. Это упрощает совместную работу над моделями и распространение ваших работ.

![20260323 210309 paste 20260323 210309](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210309-paste-20260323-210309.jpg)


## Как поделиться моделью

1. Щёлкните правой кнопкой мыши по модели в разделе [Облачная библиотека](cloud-library.md)
2. Выберите **Поделиться**
3. Будет создан код доступа, который можно отправить другим пользователям

## Получение модели, которой с вами поделились

1. Получите код доступа от другого пользователя
2. Используйте пункт **Активировать код доступа** в библиотеке
3. Модель будет добавлена в вашу библиотеку

## Советы

- Коды доступа работают с моделями, которые хранятся в Облачной библиотеке
- Получатель получает копию модели — вносимые им изменения не затрагивают ваш оригинал
- Коды доступа можно передавать по любому каналу: по электронной почте, в чате, в социальных сетях и т. д.
