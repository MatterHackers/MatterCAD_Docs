# Библиотека

Библиотека позволяет упорядочивать, хранить и публиковать ваши 3D-модели. Вы можете просматривать локальные файлы, получать доступ к облачному хранилищу и делиться моделями с другими пользователями.

## Разделы

- [Локальная библиотека](local-library.md) — управление моделями, сохранёнными на вашем компьютере
- [Облачная библиотека](cloud-library.md) — хранение моделей в вашей облачной учётной записи MatterHackers и доступ к ним
- [Поделиться](sharing.md) — публикация моделей для других пользователей MatterCAD
