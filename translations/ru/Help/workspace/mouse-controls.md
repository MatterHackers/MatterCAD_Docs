# Управление мышью

Полный справочник по управлению мышью в 3D-области просмотра MatterCAD.

## Навигация

| Действие | Управление мышью |
|--------|--------------|
| **Повернуть вид** | Правая кнопка + перетаскивание |
| **Панорама вида** | Средняя кнопка + перетаскивание |
| **Масштаб** | Колесо прокрутки |

## Альтернативная навигация

| Действие | Управление мышью |
|--------|--------------|
| **Повернуть вид** | Ctrl + левая кнопка + перетаскивание |
| **Панорама вида** | Ctrl + Shift + левая кнопка + перетаскивание |
| **Масштаб** | Ctrl + Alt + левая кнопка + перетаскивание |

## Взаимодействие с объектом

| Действие | Управление мышью |
|--------|--------------|
| **Выбрать объект** | Левый щелчок по объекту |
| **Множественное выделение** | Shift + левый щелчок по дополнительным объектам |
| **Множественное выделение** | Ctrl + левый щелчок по дополнительным объектам |
| **Снять всё выделение** | Левый щелчок по пустому месту |
| **Выделение рамкой** | Левая кнопка + перетаскивание по пустому месту |
| **Переместить объект** | Левая кнопка + перетаскивание выбранного объекта |
| **Контекстное меню** | Правый щелчок по объекту |

## Управление объектом

При выборе объекта появляются интерактивные элементы управления:

| Действие | Управление |
|--------|---------|
| **Перемещение по столу** | Перетащите объект |
| **Перемещение вверх/вниз** | Перетащите вертикальную стрелку над объектом |
| **Повернуть** | Нажмите и перетащите угловой элемент поворота |
| **Масштаб** | Нажмите и перетащите угловой элемент масштабирования |

## Советы

- Масштабирование колесом прокрутки выполняется относительно позиции курсора мыши — наведите указатель на ту область, которую хотите приблизить
- Альтернативное управление (Ctrl + левая кнопка) удобно, если у вас нет средней кнопки мыши или щелчок правой кнопкой неудобен
- При повороте с помощью угловых элементов наведите указатель на индикаторы угла, чтобы привязаться к шагу в 45 градусов
