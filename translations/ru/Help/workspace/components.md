# Компоненты

Компоненты — это переиспользуемые параметризованные группы объектов. При создании компонента он становится самостоятельным элементом, который можно многократно вставлять в проект, и изменение компонента обновляет все его экземпляры.

## Как использовать

### Создание компонента

1. Выберите один или несколько объектов
2. Щёлкните правой кнопкой мыши и выберите **Создать компонент** (или воспользуйтесь меню)
3. Выбранные объекты будут помещены в контейнер компонента

### Изменение компонента

1. Выберите компонент
2. Открытые параметры компонента появятся на панели **Свойства**
3. Измените параметры, чтобы изменить форму компонента

## Советы

- Компоненты удобны для создания переиспользуемых строительных блоков в сложных проектах
- Изменения параметров неразрушающие и могут быть скорректированы в любой момент
- Компоненты помогают упорядочить сложные проекты, объединяя связанные объекты
- Используйте компоненты для деталей, которые нужно размещать многократно с небольшими различиями
