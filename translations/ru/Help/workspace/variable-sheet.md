# Лист переменных

Лист переменных хранит общие значения для проекта. Используйте его, когда несколько объектов должны ссылаться на одни и те же размеры, количества, подписи или формулы. Изменение значения на листе пересчитывает зависимые объекты, поэтому параметрические проекты остаются согласованными без необходимости править каждый объект по отдельности.

## Как добавить Лист переменных

1. Откройте библиотеку и добавьте **Лист переменных** в сцену.
2. Выберите объект Лист переменных, чтобы открыть редактор листа.
3. Выберите ячейку, затем введите **Имя** и значение или формулу.
4. Используйте имя ячейки в других полях проекта, поддерживающих выражения.

## Изменение ячеек

У каждой ячейки есть две изменяемые части:

- **Имя** — необязательное имя переменной для ячейки. Имена не чувствительны к регистру, пробелы преобразуются в подчёркивания, а повторяющиеся имена корректируются автоматически.
- **Выражение** — значение ячейки. Обычный текст или числа сохраняются напрямую. Формулы начинаются с `=`.

На ячейки также можно ссылаться по адресу, например `A1` или `B2`. Именованные ячейки обычно понятнее для параметров проекта, потому что они описывают назначение, например `wall_thickness`, `outer_diameter` или `hole_count`.

## Формулы

Начните формулу с `=`, чтобы она вычислялась на листе:

- `=20 + 5` возвращает `25`
- `=pi * 10` возвращает `31.41592653589793`
- `=A1 * 2` ссылается на другую ячейку по адресу
- `=wall_thickness + 4` ссылается на именованную ячейку

Лист поддерживает арифметические операции, скобки, операторы сравнения, распространённые функции `Math`, такие как `sin`, `cos`, `sqrt` и `round`, а также константы, включая `pi`, `tau` и `e`.

## Использование значений листа в объектах

Большинство числовых полей в MatterCAD поддерживают выражения. Чтобы использовать значение листа в параметре объекта, добавьте перед ссылкой префикс `=`:

- Задайте для Куба **Ширина** значение `=case_width`.
- Задайте для Массива **Количество** значение `=hole_count`.
- Задайте для операции Переместить значение **Смещение** равным `=wall_thickness * 2`.

При изменении листа MatterCAD пересчитывает зависящие от него объекты.

## Текст и вспомогательные функции

Ячейки Листа переменных могут содержать как числа, так и текст. Текстовые значения полезны для генерируемых подписей, номеров деталей, импортированных данных и пользовательских приложений для проектирования.

Полезные вспомогательные функции:

- `concat()` или `strcat()` — объединение текста или значений.
- `substring()` — извлечение части текстового значения.
- `split()` — разделение текста и возврат одного элемента.
- `count()` — подсчёт элементов, разделённых разделителем, в тексте.
- `substitute()` — замена текста.
- `rand(seed)` — получение детерминированного случайного значения при указании начального числа.
- `importdata()` — чтение значения по URL или из локального файла.

## Советы

- Для значений, используемых другими объектами, предпочитайте описательные имена, а не адреса ячеек.
- Держите основные размеры в левом верхнем углу листа, чтобы их было легко найти.
- Используйте формулы для производных значений, например `inner_diameter = outer_diameter - wall_thickness * 2`.
- Избегайте использования зарезервированных слов, таких как `pi`, `e`, `true`, `false`, или имён функций в качестве имён ячеек.
- Если формулу не удаётся разобрать, MatterCAD сохраняет исходный ввод как текст.
