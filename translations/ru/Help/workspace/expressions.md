# Выражения

Многие параметры в MatterCAD принимают математические выражения вместо обычных чисел. Это позволяет создавать параметрические модели, в которых изменение одного значения автоматически обновляет связанные размеры.

## Как использовать

Вместо обычного числа в поле параметра можно ввести математическое выражение. Например:

- `20 + 5` вычисляется как 25
- `pi * 10` вычисляется как 31.416
- `width * 2` ссылается на другой параметр с именем «width»

## Доступные константы

- **pi** — 3.14159... (отношение длины окружности к диаметру)
- **tau** — 6.28318... (2 * pi, полный оборот в радианах)

## Поддерживаемые операции

- Сложение: `+`
- Вычитание: `-`
- Умножение: `*`
- Деление: `/`
- Скобки: `(` и `)` для группировки

## Советы

- Выражения поддерживаются в любом поле, для которого в коде указано `DoubleOrExpression`, `IntOrExpression` или `StringOrExpression` — на практике их принимает большинство числовых полей в инструментах проектирования
- Используйте выражения для создания связей между параметрами — например, задайте диаметр отверстия как `outer_diameter - 4`, чтобы стенки всегда были толщиной 2 мм
- Выражения обновляются автоматически при изменении значений, на которые они ссылаются
- Используйте [Лист переменных](variable-sheet.md), когда несколько объектов должны использовать одни и те же именованные значения или формулы
- Выражения можно применять в операциях [Массив](../operations/array/index.md) для создания параметрических узоров
