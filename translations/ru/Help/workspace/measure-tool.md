# Инструмент измерения

Инструмент измерения позволяет измерять расстояния между точками в вашей модели. Размещайте точки измерения в любом месте 3D-области просмотра, чтобы проверить размеры.

<!--  Screenshot showing the Measure Tool with a distance measurement displayed between two points -->
![20260318 192711 paste 20260318 192711](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192711-paste-20260318-192711.jpg)


## Как использовать

1. Добавьте **Инструмент измерения** из меню инструментов
2. Перетащите точки измерения в места, между которыми нужно измерить расстояние
3. Расстояние отображается в области просмотра

## Советы

- Используйте это, чтобы проверить размеры перед экспортом для 3D-печати
- Инструмент измерения показывает расстояние по прямой между двумя контрольными точками
- Вы можете оставить Инструмент измерения в модели во время работы и удалить его перед экспортом
