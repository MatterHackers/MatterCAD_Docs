# Выделение

Выделение объектов — основа работы в MatterCAD. Прежде чем перемещать, изменять объекты или применять к ним операции, их нужно выделить.

<!--  Screenshot showing multiple selected objects with selection highlights -->
![20260318 192323 paste 20260318 192323](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192323-paste-20260318-192323.jpg)


## Одиночное выделение

- **Щелчок левой кнопкой мыши по объекту** выделяет его. Ранее выделенный объект снимается с выделения.
- **Щелчок левой кнопкой мыши по пустому месту** снимает всё выделение.

## Множественное выделение

- **Shift + щелчок левой кнопкой мыши** по дополнительным объектам добавляет их к выделению
- **Ctrl + щелчок левой кнопкой мыши** также добавляет объекты к выделению
- **Ctrl + A** выделяет все объекты в сцене

## Выделение рамкой

Нажмите и перетащите указатель по пустой области области просмотра, чтобы нарисовать прямоугольник выделения. Все объекты внутри прямоугольника будут выделены.

## Очистка выделения

- **Щелчок левой кнопкой мыши по пустому месту** очищает выделение
- **Пробел** очищает выделение
- **Escape** отменяет операцию перетаскивания

## Работа с выделением

Когда объекты выделены, вы можете:

- **Переместить** их перетаскиванием в области просмотра
- **Применить операции** с панели инструментов (булевы, преобразование, массив и т. д.)
- **Изменить свойства** на панели **Свойства** (если выделен один объект)
- **Щелчок правой кнопкой мыши** открывает контекстное меню с доступными действиями

## Советы

- При выделении нескольких объектов они временно группируются для выполнения операций. Панель **Свойства** показывает общие свойства.
- Используйте дерево построения, чтобы выделять объекты, по которым сложно щёлкнуть в области просмотра: щелчок по элементу в дереве выделяет его в виде.
