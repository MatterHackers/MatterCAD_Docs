# Сочетания клавиш

Краткий справочник по всем сочетаниям клавиш, доступным в MatterCAD.

## Изменить

| Сочетание | Действие |
|----------|--------|
| Ctrl + Z | Отменить |
| Ctrl + Y | Повторить |
| Ctrl + Shift + Z | Повторить (альтернативный вариант) |
| Ctrl + A | Выделить всё объекты |
| Ctrl + C | Копировать выделенные объекты |
| Ctrl + X | Вырезать выделенные объекты |
| Ctrl + V | Вставить объекты |
| Space | Снять выделение |
| Escape | Отмена текущей операции перетаскивания |
| Delete | Удалить выделенные объекты |

## Вид

| Сочетание | Действие |
|----------|--------|
| W | Сброс вида (вписать все объекты в область просмотра) |
| Z | Масштаб по выделенному объекту |
| Ctrl + Plus (+) | Приблизить |
| Ctrl + Minus (-) | Отдалить |
| Стрелки | Повернуть вид |
| Shift + Стрелки | Панорама вида |

## Управление мышью

| Действие | Управление |
|--------|---------|
| Повернуть вид | Правая кнопка + перетаскивание |
| Панорама вида | Средняя кнопка + перетаскивание |
| Масштаб | Колесо прокрутки |
| Выбрать объект | Левая кнопка по объекту |
| Множественное выделение | Shift + левая кнопка или Ctrl + левая кнопка |
| Выделение рамкой | Левая кнопка + перетаскивание по пустому месту |
| Контекстное меню | Правая кнопка по объекту |

## Альтернативное управление мышью

| Действие | Управление |
|--------|---------|
| Повернуть вид | Ctrl + левая кнопка + перетаскивание |
| Панорама вида | Ctrl + Shift + левая кнопка + перетаскивание |
| Масштаб | Ctrl + Alt + левая кнопка + перетаскивание |

## Приложение

| Сочетание | Действие |
|----------|--------|
| Ctrl + Shift + T | Открыть заново последний закрытый проект |
| F1 | Открыть Справку |
