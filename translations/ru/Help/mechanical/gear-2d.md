# Шестерня 2D

Двумерный путь шестерни, создающий только профиль зубьев в виде плоского пути. Используйте его вместе с [Линейное выдавливание](../operations/path/linear-extrude.md) или [Вращение](../operations/path/revolve.md), чтобы точнее управлять тем, как шестерня превращается в объёмную форму.

<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->
![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)

## Как использовать

1. Добавьте **Шестерня 2D** из механических инструментов
2. Настройте параметры зубьев
3. Примените [Линейное выдавливание](../operations/path/linear-extrude.md), чтобы задать высоту

## Советы

- Используйте Шестерня 2D, когда нужно объединить профиль шестерни с другими операциями над путями перед выдавливанием
- Если нужна готовая объёмная шестерня, обратитесь к статье [Шестерни](gears.md)
- Действуют те же правила зацепления: для совместно работающих шестерён должны совпадать Окружной шаг и Угол зацепления
