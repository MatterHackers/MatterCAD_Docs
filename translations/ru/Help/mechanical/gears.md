# Шестерни

Создавайте трёхмерные шестерни с полностью настраиваемой геометрией зубьев. MatterCAD строит корректные эвольвентные профили зубьев, которые правильно зацепляются с другими шестернями того же модуля и угла зацепления.

![mechanical_gears](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gears.png)

## Как использовать

1. Добавьте **Шестерню** из инструментов Механические или панели Примитивы
2. Задайте число зубьев и другие параметры
3. Профиль шестерни строится автоматически

## Параметры

### Элементы

- **Тип шестерни** — Внешний зубчатый венец или Рейка (прямая планка с зубьями)
- **Высота** — Толщина шестерни (высота выдавливания)
- **Число зубьев** — Количество зубьев по окружности шестерни (по умолчанию: 30, диапазон: 4–60)
- **Окружной шаг** — Расстояние по дуге между зубьями вдоль делительной окружности (диапазон: 3–30). Определяет общий размер.
- **Диаметр центрального отверстия** — Диаметр центрального отверстия под вал (по умолчанию: 4 мм, значение 0 — без отверстия). Только для внешних шестерён.
- **Ширина внешней кромки** — Ширина кромки за пределами внутренних зубьев
- **Число зубьев внутренней шестерни** — Число зубьев сопрягаемой внутренней шестерни

### Дополнительно

- **Угол зацепления** — Угол контактной поверхности зуба (обычные значения: 14,5, 20 или 25 градусов). Все зацепляющиеся шестерни должны иметь одинаковый угол зацепления.
- **Зазор** — Минимальный зазор между вершиной зуба и впадиной сопрягаемого зуба
- **Люфт** — Минимальный зазор между зубьями зацепляющихся шестерён для предотвращения заклинивания

### Данные шестерни (только для чтения)

- **Делительный радиус** — Радиус, по которому шестерни зацепляются друг с другом
- **Внешний диаметр** — Полный диаметр по вершинам зубьев

## Советы

- Две шестерни правильно зацепятся, если у них одинаковые Окружной шаг и Угол зацепления
- Используйте значения Делительного радиуса для правильного размещения зацепляющихся шестерён — расстояние между центрами шестерён должно быть равно сумме их делительных радиусов
- Для шестерён, печатаемых на 3D-принтере, добавляйте Люфт с учётом допусков печати
- Для двумерных профилей шестерён (для использования с Выдавливанием) см. [Шестерня 2D](gear-2d.md)
