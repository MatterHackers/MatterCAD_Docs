# Механические детали

MatterCAD включает специализированные инструменты для создания механических компонентов, таких как шестерни и резьбовые крепёжные элементы.

- [Шестерня 2D](gear-2d.md) — создание 2D-контура шестерни для использования с выдавливанием или другими операциями по контуру
- [Резьба](threads.md) — добавление винтовой резьбы на цилиндрические объекты
