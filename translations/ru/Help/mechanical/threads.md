# Резьба

Создавайте винтовую резьбу с настраиваемыми диаметром, шагом и профилем резьбы. Резьбу можно использовать как самостоятельные болты/винты либо вычитать из других объектов для создания резьбовых отверстий.

![mechanical_threads](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_threads.png)

## Как использовать

1. Добавьте **Резьба** из инструментов **Механические** или панели **Примитивы**
2. Задайте диаметр, шаг и число оборотов
3. При необходимости включите «Использовать как отверстие» для создания резьбовых отверстий

## Параметры

### Использование

- **Использовать как отверстие** — когда включено, резьба строится с дополнительным допуском для использования в качестве вычитаемого отверстия (по умолчанию: выкл.)
- **Допуск** — дополнительный зазор для посадки при использовании в качестве отверстия (по умолчанию: 0.2mm, отображается, когда включено «Использовать как отверстие»)

### Атрибуты

- **Диаметр** — наружный диаметр резьбового участка (по умолчанию: 10mm)
- **Шаг** — расстояние между витками резьбы (по умолчанию: 2mm). Меньший шаг = более мелкая резьба
- **Масштаб резьбы** — ширина резьбы как отношение к шагу (по умолчанию: 1.0, диапазон: 0.1–1.0)
- **Повороты** — число полных витков резьбы (по умолчанию: 10)

### Геометрия

- **Стороны** — число сегментов по периметру (по умолчанию: 40). Больше = более гладкая поверхность

### Концы (окончания резьбы)

- **Масштаб конца** — насколько сужаются концы резьбы (по умолчанию: 0, диапазон: 0–1). Задайте значение больше 0, чтобы создать конический заход на концах
- **Угол конца** — угол, на котором выполняется сужение концов (по умолчанию: 90 градусов)

## Советы

- Чтобы создать резьбовое отверстие: включите «Использовать как отверстие», разместите резьбу и выполните [Вычитание](../operations/boolean/subtract.md) из вашего объекта
- Добавляйте **Допуск** при использовании в качестве отверстия, чтобы напечатанные детали подходили друг к другу
- Стандартные шаги метрической резьбы: M3=0.5mm, M4=0.7mm, M5=0.8mm, M6=1.0mm, M8=1.25mm, M10=1.5mm
- Используйте **Масштаб конца**, чтобы создать заход, облегчающий начало закручивания
