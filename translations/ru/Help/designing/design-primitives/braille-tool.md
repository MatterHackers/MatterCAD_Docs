Приложение для проектирования Шрифт Брайля позволяет создавать пригодные для 3D-печати таблички со шрифтом Брайля для людей с нарушениями зрения, выступая одновременно практическим инструментом и учебным пособием для изучения шрифта Брайля. Приложение поддерживает английский шрифт Брайля 1-й и 2-й степени.

Доступ к нему осуществляется через раздел Приложения для проектирования.
