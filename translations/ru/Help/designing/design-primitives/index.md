MatterCAD включает всё необходимое для воплощения ваших идей — прямо «из коробки»!

![2018-07-02 10_46_48-start](https://user-images.githubusercontent.com/1158332/42188916-c7102220-7e0a-11e8-8d7b-dc1921e304c6.png)

С помощью этих простых примитивов и встроенных инструментов вы можете создать всё, что только можете себе представить.

- Куб  
  ![](https://lh3.googleusercontent.com/aGY-iwwo77dHM61NXPzSkB2IAF9mVyiRtwQqzJ7MB2kHKFbGh-O1mqxTYGr_PBub63jvVcZNFCT_FM7MKf4_RH8b07A)
  - **Ширина:** задаёт размер по X
  - **Глубина:** задаёт размер по Y
  - **Высота:** задаёт размер по Z
- Пирамида  
  ![](https://lh3.googleusercontent.com/U3AI6kAX3FMp1MEVn1HTHXzrH1-mKGN6hxQx0p_WRP0ETbj2ckSffbsFX_C1H8jct5pw0P5TFPbYGPbF2hzh1ulv4Q)
  - **Ширина:** задаёт размер по X
  - **Глубина:** задаёт размер по Y
  - **Высота:** задаёт размер по Z
- Половина клина  
  ![](https://lh3.googleusercontent.com/r6-jVvMdeFiG3mH04WTBNRvY5ibWze0WejDxdla43PCkC1aj1NR6oQBrlncOWmOn-xlgZDzUkTgvSFfSpdEA9NST-w)
  - **Ширина:** задаёт размер по X
  - **Глубина:** задаёт размер по Y
  - **Высота:** задаёт размер по Z
- Текст  
  ![](https://lh3.googleusercontent.com/XLlyBUeloa3Q1FQF8-fCD0zx036yFCLsvyUKrE9zaV-p1k4Jt4m5QK3W59c8CnwPurZ_RW2xBazi9E3AmMmhkuL_OA)
  - **Имя:** введите любой текст, который хотите отобразить
  - **Размер точки:** задаёт размер шрифта. Он точен при печати в том же размере, что и на 2D-принтере.
  - **Высота:** задаёт высоту, до которой будет подниматься текст
  - **Шрифт:** выберите шрифт, который хотите использовать
- Цилиндр  
  ![](https://lh3.googleusercontent.com/Gy_YL8RYVbXwPDHVgkixUC17HN8qOLLOdaVzsNfGD1uFCjlWFD8nWPB56GcCh_Wj7fXQBqCWtuxidMi26dDfxycWnvw)
  - **Диаметр:** задаёт размер поперёк детали
  - **Высота:** задаёт размер по Z
  - **Стороны:** задаёт количество граней (или сторон) вокруг детали
  - **Дополнительно:** открывает дополнительные настройки для управления другими параметрами
    - **Начальный угол:** угол, с которого начинается вращение цилиндра
    - **Конечный угол:** угол, на котором заканчивается вращение цилиндра
    - **Верхний диаметр:** размер верхней части цилиндра

  - **Диаметр:** задаёт размер поперёк детали
