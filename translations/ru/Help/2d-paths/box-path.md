# Путь Куб

Прямоугольный 2D-путь. Используйте его вместе с [Линейное выдавливание](../operations/path/linear-extrude.md) для создания коробчатых форм или как основу для других операций с путями.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Параметры

- **Ширина** - Ширина прямоугольника (по умолчанию: 20mm)
- **Высота** - Высота прямоугольника (по умолчанию: 20mm)

## Советы

- Путь Куб вместе с операцией Линейное выдавливание создаёт форму, похожую на [Куб](../primitives/cube.md), но до выдавливания вы можете применить операции с путями, такие как [Расширить](../operations/path/inflate-path.md) или [Сгладить](../operations/path/smooth-path.md)
