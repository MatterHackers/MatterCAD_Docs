# Путь «Окружность»

Круговой 2D-путь. Используйте его с [Линейным выдавливанием](../operations/path/linear-extrude.md) для создания цилиндров или с [Вращением](../operations/path/revolve.md) для создания форм, похожих на тор.

![20260506 080110 paste 20260506 080110](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080110-paste-20260506-080110.jpg)


## Параметры

- **Диаметр** - Диаметр окружности (по умолчанию: 20mm)
- **Сегменты** - Число отрезков, образующих окружность. Больше — плавнее

## Советы

- Путь «Окружность» в сочетании с Линейным выдавливанием даёт цилиндр, похожий на примитив [Цилиндр](../primitives/cylinder.md), но с большей свободой в том, как строить модель дальше
- Используйте его как основу для Вращения, чтобы создавать кольцевые формы
