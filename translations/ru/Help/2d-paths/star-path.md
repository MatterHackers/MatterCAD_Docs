# Контур «Звезда»

Двумерный контур в форме звезды с настраиваемым числом лучей и внутренним/внешним радиусом. Используйте вместе с [Линейное выдавливание](../operations/path/linear-extrude.md) для создания трёхмерных звёзд.

## Параметры

- **Точки** - Число лучей звезды
- **Внешний радиус** - Расстояние от центра до вершины каждого луча
- **Внутренний радиус** - Расстояние от центра до впадин между лучами

## Советы

- Соотношение между внутренним и внешним радиусом определяет, насколько «острой» будет звезда. Малый внутренний радиус создаёт резкие, ярко выраженные лучи.
- Задайте параметру **Точки** значение 5 для классической звезды, 6 для звезды Давида или больше — для форм, похожих на шестерню
- Примените [Сгладить контур](../operations/path/smooth-path.md) к контуру «Звезда», чтобы получить звезду со скруглёнными очертаниями
