# Путь «Кольцо»

Плоская (2D) фигура кольца — окружность с круговым отверстием в центре. Используйте вместе с [Линейным выдавливанием](../operations/path/linear-extrude.md) для создания труб или шайб.

<!-- Screenshot of a Ring Path on the workspace -->
![20260506 080211 paste 20260506 080211](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080211-paste-20260506-080211.jpg)

## Параметры

- **Внешний диаметр** — внешний диаметр кольца
- **Внутренний диаметр** — диаметр отверстия в центре

## Советы

- Толщина стенки кольца равна (Внешний диаметр − Внутренний диаметр) / 2
- Выдавливание пути «Кольцо» создаёт трубу, аналогичную примитиву [Кольцо](../primitives/ring.md)
