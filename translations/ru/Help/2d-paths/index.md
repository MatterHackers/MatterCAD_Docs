# 2D пути

2D пути — это плоские фигуры, которые можно использовать как основу для 3D объектов. Используйте [Линейное выдавливание](../operations/path/linear-extrude.md), чтобы придать пути высоту, или [Вращение](../operations/path/revolve.md), чтобы повернуть путь вокруг оси и создать 3D форму.

## Доступные пути

- [Путь Окружность](circle-path.md) — круговой 2D контур
- [Путь Куб](box-path.md) — прямоугольный 2D контур
- [Путь Кольцо](ring-path.md) — 2D кольцо (окружность с отверстием)
- [Путь Звезда](star-path.md) — 2D контур в форме звезды с настраиваемым числом лучей
- [Пользовательский путь](custom-path.md) — начертите собственный 2D путь с помощью контрольных точек
