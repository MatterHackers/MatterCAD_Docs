# MatterCAD 2.2026.8 (13 Αυγούστου 2026)
[Λήψη για Windows](https://mattercontrol.appspot.com/downloads/mattercad-windows/release)

## Νέα χαρακτηριστικά

* **Επεξεργασία Θυγατρικών**
  * Κάντε διπλό κλικ σε ένα αντικείμενο στην επιφάνεια εκτύπωσης ή στο Δέντρο Σκηνής για να μπείτε μέσα σε αυτό και να επεξεργαστείτε τα μέρη από τα οποία έχει δημιουργηθεί — χωρίς ξεχωριστό παράθυρο ή καρτέλα
  * Για λειτουργίες όπως η Αφαίρεση, επεξεργάζεστε τα αρχικά μέρη και το αποτέλεσμα αναδημιουργείται όταν βγείτε ξανά έξω
  * Μια διαδρομή πλοήγησης στο επάνω μέρος του Δέντρου Σκηνής δείχνει την πλήρη διαδρομή· κάνοντας κλικ σε ένα επίπεδο, οι αλλαγές σας ενσωματώνονται ως ένα βήμα με δυνατότητα αναίρεσης, ενώ κάθε επίπεδο διατηρεί το δικό του ιστορικό αναιρέσεων
  <!-- Double-click into a nested group, move a part, then click back out through the breadcrumb. ~700x450px -->
  * ![Drill In](https://www.matterhackers.com/r/qgG4VA)

* **Ένα εργαλείο Boolean**
  * Ο Συνδυασμός, η Αφαίρεση, η Τομή και η Αφαίρεση και Αντικατάσταση αποτελούν πλέον μία ενιαία λειτουργία με μια σειρά εικονιδίων στο επάνω μέρος του πίνακά της — αλλάξτε λειτουργία με ένα κλικ, αντί να διαγράφετε και να εφαρμόζετε εκ νέου
  * Η ίδια λειτουργία χειρίζεται τόσο πλέγματα 3D όσο και διαδρομές 2D, και εμφανίζει την πρόοδο όσο εκτελείται μια βαριά πράξη boolean
  * Σχέδια που αποθηκεύτηκαν με τα παλαιότερα ξεχωριστά αντικείμενα boolean συνεχίζουν να ανοίγουν κανονικά
  <!-- Boolean property panel with the four-icon operation row, Subtract selected. ~500x400px -->
  * ![20260810 181041 paste 20260810 181041](https://matterhackers.github.io/MatterCAD_Docs/assets/20260810-181041-paste-20260810-181041.jpg)


* **Πράξεις Boolean που απλώς δουλεύουν**
  * Οι πράξεις boolean εκτελούνται σε μια νέα εγγενή μηχανή που είναι ταχύτερη και πετυχαίνει σε πλέγματα που προηγουμένως αποτύγχαναν
  * Ο Συνδυασμός επιδιορθώνει αυτόματα μέρη με οπές: οι καθαρές επιδιορθώσεις ενώνονται στην ένωση, τα μέρη που δεν μπορούν να συγχωνευτούν με ασφάλεια διατηρούνται δίπλα της και ονομάζονται για εσάς, ενώ ένα μέρος που δεν μπόρεσε να επιδιορθωθεί διατηρεί την αρχική σας γεωμετρία
  * Η Τομή Επιπέδου είναι πλέον μια πραγματική στερεή τομή, οπότε το αποτέλεσμα είναι υδατοστεγές και εκτυπώσιμο αντί για ανοιχτό κέλυφος
  * Νέες επιλογές Διατήρηση Ανεστραμμένης Γεωμετρίας και Επιδιόρθωση φοράς περιέλιξης για προβληματικά εισαγόμενα πλέγματα


## Βελτιώσεις

* **Επεξεργαστής Διαδρομής 2D**
  * Τέσσερις λειτουργίες σημείων — Αιχμηρό, Συμμετρικό, Στοιχισμένο και Ελεύθερο — που εφαρμόζονται με ένα κλικ, τόσο στον επεξεργαστή 2D όσο και στην προβολή 3D
  * Ο Καθρεπτισμός είναι πλέον μια ζωντανή λειτουργία συμμετρίας: οι αλλαγές καθρεπτίζονται γύρω από το κέντρο καθώς τις κάνετε, και σύροντας ένα καθρεπτισμένο ζεύγος πάνω στον άξονα συγχωνεύεται σε ένα σημείο
  * Επιλέξτε σημεία με πλαίσιο επιλογής, μετακινήστε τα ως ομάδα, κουμπώστε τα στο πλέγμα και πατήστε Esc για ακύρωση της μετακίνησης
  * Η Εξομάλυνση προσαρμόζει μια καμπύλη μέσα από τα σημεία που ορίσατε με ένα βήμα
  <!-- gif — Rubber-band select several points, drag them as a group, Esc to cancel. ~700x450px -->
  * ![Path Edit](https://www.matterhackers.com/r/yQwWXB)

* **Προβολή και πλοήγηση**
  * Πατήστε Z με επιλεγμένη μια επίπεδη διαδρομή για να μεταβείτε με κίνηση σε κατακόρυφη προβολή επεξεργασίας προσαρμοσμένη στη διαδρομή
  * Η απόδοση κειμένου με υποεικονοστοιχεία ενεργοποιείται πλέον αυτόματα όταν η οθόνη σας την υποστηρίζει, και μπορεί ακόμη να ενεργοποιηθεί ή να απενεργοποιηθεί στις ρυθμίσεις Για προχωρημένους

* **Μοντελοποίηση**
  * Η Γραμμική Εξώθηση μπορεί να λοξοτομήσει την κάτω ακμή με δικό της στυλ, ακτίνα και πλήθος τμημάτων
  * Τα αντικείμενα μόνο για τον επεξεργαστή (Καμπύλη 3D, Εργαλείο Μέτρησης, Περιγραφή, Φύλλο) εξακολουθούν να εμφανίζονται αλλά εξαιρούνται από την εξαγωγή

## Κυριότερες διορθώσεις σφαλμάτων

  * Μια αποθήκευση που αποτύγχανε στη μέση μπορούσε να περικόψει το αρχείο που αντικαθιστούσε, αναφέροντας παράλληλα επιτυχία. Οι αποθηκεύσεις πλέον ολοκληρώνονται πλήρως και έπειτα αντικαθιστούν τον προορισμό ατομικά — η ίδια προστασία καλύπτει τις αποθηκεύσεις στη βιβλιοθήκη και τις εξαγωγές
  * Μια αποθήκευση που αποτυγχάνει αφήνει το σχέδιο σημειωμένο ως μη αποθηκευμένο, ώστε το κλείσιμο της εφαρμογής να μην μπορεί να απορρίψει σιωπηλά τη δουλειά σας
  * Η αποθήκευση ενός στοιχείου cloud στον δίσκο διατηρούσε το παλιό όνομα καρτέλας και έχανε την καρτέλα κατά την επανεκκίνηση
  * Διορθώθηκε η σιωπηλή απόρριψη υπο-μοντέλων 3MF κατά τη φόρτωση, καθώς και η αλληλοεπιμόλυνση αρχείων 3MF που φορτώνονταν ταυτόχρονα
  * Διορθώθηκαν καταρρεύσεις, ένα χαλασμένο φίλτρο ιστογράμματος και αντίγραφα ενός μέρους εικόνας που δεν παρέμεναν συγχρονισμένα με το πρωτότυπο
  * Διορθώθηκε μια κατάρρευση κατά τη διαγραφή σημείου καμπύλης, καθώς και σημεία στη ραφή μιας κλειστής διαδρομής που επανέφεραν τη λειτουργία που επιλέξατε
  * Το κουμπί Διακοπή σε μια εργασία που εκτελείται είναι πλέον διαθέσιμο για κλικ και όντως ακυρώνει
