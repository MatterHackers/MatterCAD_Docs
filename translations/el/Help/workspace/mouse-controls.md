# Χειριστήρια Ποντικιού

Πλήρης αναφορά για τα χειριστήρια του ποντικιού στο τρισδιάστατο παράθυρο προβολής του MatterCAD.

## Πλοήγηση

| Ενέργεια | Χειριστήριο Ποντικιού |
|--------|--------------|
| **Περιστροφή προβολής** | Δεξί κλικ + Σύρσιμο |
| **Μετατόπιση προβολής** | Μεσαίο κλικ + Σύρσιμο |
| **Ζουμ** | Τροχός κύλισης |

## Εναλλακτική Πλοήγηση

| Ενέργεια | Χειριστήριο Ποντικιού |
|--------|--------------|
| **Περιστροφή προβολής** | Ctrl + Αριστερό κλικ + Σύρσιμο |
| **Μετατόπιση προβολής** | Ctrl + Shift + Αριστερό κλικ + Σύρσιμο |
| **Ζουμ** | Ctrl + Alt + Αριστερό κλικ + Σύρσιμο |

## Αλληλεπίδραση με Αντικείμενα

| Ενέργεια | Χειριστήριο Ποντικιού |
|--------|--------------|
| **Επιλογή αντικειμένου** | Αριστερό κλικ στο αντικείμενο |
| **Πολλαπλή επιλογή** | Shift + Αριστερό κλικ σε επιπλέον αντικείμενα |
| **Πολλαπλή επιλογή** | Ctrl + Αριστερό κλικ σε επιπλέον αντικείμενα |
| **Αποεπιλογή όλων** | Αριστερό κλικ σε κενό χώρο |
| **Επιλογή με πλαίσιο** | Αριστερό κλικ + Σύρσιμο σε κενό χώρο |
| **Μετακίνηση αντικειμένου** | Αριστερό κλικ + Σύρσιμο στο επιλεγμένο αντικείμενο |
| **Μενού περιβάλλοντος** | Δεξί κλικ στο αντικείμενο |

## Χειριστήρια Αντικειμένου

Όταν ένα αντικείμενο είναι επιλεγμένο, εμφανίζονται διαδραστικά χειριστήρια:

| Ενέργεια | Χειριστήριο |
|--------|---------|
| **Μετακίνηση στην επιφάνεια εκτύπωσης** | Σύρετε το αντικείμενο |
| **Μετακίνηση πάνω/κάτω** | Σύρετε το κατακόρυφο βέλος πάνω από το αντικείμενο |
| **Περιστροφή** | Κάντε κλικ και σύρετε ένα γωνιακό χειριστήριο περιστροφής |
| **Κλίμακα** | Κάντε κλικ και σύρετε ένα γωνιακό χειριστήριο κλίμακας |

## Συμβουλές

- Το ζουμ με τον τροχό κύλισης εστιάζει στη θέση του δείκτη του ποντικιού -- στοχεύστε στην περιοχή στην οποία θέλετε να κάνετε ζουμ
- Τα εναλλακτικά χειριστήρια (Ctrl + Αριστερό κλικ) είναι χρήσιμα αν δεν διαθέτετε μεσαίο πλήκτρο ποντικιού ή αν το δεξί κλικ είναι δύσχρηστο
- Κατά την περιστροφή με τα γωνιακά χειριστήρια, τοποθετήστε τον δείκτη πάνω στις ενδείξεις γωνίας για κούμπωμα σε βήματα 45 μοιρών
