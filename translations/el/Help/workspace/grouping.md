# Ομαδοποίηση

Η ομαδοποίηση συνδυάζει πολλαπλά αντικείμενα σε μία ενιαία μονάδα που μπορεί να μετακινηθεί, να αντιγραφεί και να υποστεί επεξεργασία ως ένα αντικείμενο. Σε αντίθεση με τη λειτουργία [Συνδυασμός](../operations/boolean/combine.md), η ομαδοποίηση δεν συγχωνεύει τη γεωμετρία -- κάθε αντικείμενο παραμένει ξεχωριστό μέσα στην ομάδα.

## Τρόπος χρήσης

### Ομαδοποίηση αντικειμένων

1. Επιλέξτε δύο ή περισσότερα αντικείμενα (Shift-κλικ ή Ctrl-κλικ για πολλαπλή επιλογή)
2. Κάντε κλικ στο κουμπί **Ομαδοποίηση** στη γραμμή εργαλείων
3. Τα αντικείμενα είναι πλέον ομαδοποιημένα -- μετακινούνται μαζί ως μία ενιαία μονάδα

### Κατάργηση ομαδοποίησης αντικειμένων

1. Επιλέξτε μια ομάδα
2. Κάντε κλικ στο κουμπί **Κατάργηση ομαδοποίησης** στη γραμμή εργαλείων
3. ![20260318 193354 paste 20260318 193354](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-193354-paste-20260318-193354.jpg)
4. Τα μεμονωμένα αντικείμενα αποκαθίστανται ως ξεχωριστά στοιχεία

Η κατάργηση ομαδοποίησης επιχειρεί επίσης να διαχωρίσει πολλαπλά σώματα μέσα σε ένα μεμονωμένο εισαγόμενο αρχείο STL, εφόσον υπάρχουν.

## Ομαδοποίηση έναντι Συνδυασμού

| Χαρακτηριστικό | Ομαδοποίηση | Συνδυασμός |
|---------|-------|---------|
| Τα αντικείμενα παραμένουν ξεχωριστά | Ναι | Όχι |
| Δυνατότητα κατάργησης ομαδοποίησης αργότερα | Ναι | Όχι (καταστροφική) |
| Συγχωνεύει την επικαλυπτόμενη γεωμετρία | Όχι | Ναι |
| Τα αντικείμενα μπορούν να έχουν διαφορετικά χρώματα | Ναι | Τα Χρώματα διατηρούνται ανά έδρα |
| Περίπτωση χρήσης | Οργάνωση και μετακίνηση | Δημιουργία ενιαίων συμπαγών σχημάτων |

## Συμβουλές

- Οι ομάδες μπορούν να είναι ένθετες -- μπορείτε να ομαδοποιήσετε αντικείμενα που βρίσκονται ήδη σε ομάδες
- Επιλέξτε μια ομάδα και δείτε το Δέντρο Σχεδίασης για να εντοπίσετε και να επιλέξετε μεμονωμένα αντικείμενα μέσα σε αυτήν
- Η ομαδοποίηση δεν είναι καταστροφική και μπορεί πάντα να αναιρεθεί με την Κατάργηση ομαδοποίησης
