# Επιλογή

Η επιλογή αντικειμένων είναι θεμελιώδης για την εργασία στο MatterCAD. Πρέπει να επιλέξετε αντικείμενα προτού μπορέσετε να τα μετακινήσετε, να τα τροποποιήσετε ή να εφαρμόσετε λειτουργίες σε αυτά.

## Μεμονωμένη επιλογή

- **Αριστερό κλικ σε ένα αντικείμενο** για να το επιλέξετε. Το προηγουμένως επιλεγμένο αντικείμενο αποεπιλέγεται.
- **Αριστερό κλικ σε κενό χώρο** για να αποεπιλέξετε τα πάντα.

## Πολλαπλή επιλογή

- **Shift + Αριστερό κλικ** σε επιπλέον αντικείμενα για να τα προσθέσετε στην επιλογή σας
- **Ctrl + Αριστερό κλικ** προσθέτει επίσης αντικείμενα στην επιλογή σας
- **Ctrl + A** επιλέγει όλα τα αντικείμενα της σκηνής

## Επιλογή με Πλαίσιο

Κάντε κλικ και σύρετε σε μια κενή περιοχή του παραθύρου προβολής για να σχεδιάσετε ένα ορθογώνιο επιλογής. Επιλέγονται όλα τα αντικείμενα που βρίσκονται μέσα στο ορθογώνιο.

## Εκκαθάριση της επιλογής

- **Αριστερό κλικ σε κενό χώρο** εκκαθαρίζει την επιλογή
- **Space** εκκαθαρίζει την επιλογή
- **Escape** ακυρώνει μια ενέργεια συρσίματος

## Εργασία με τις επιλογές

Αφού έχετε επιλέξει αντικείμενα:

- **Μετακίνηση** των αντικειμένων σύροντάς τα μέσα στο παράθυρο προβολής
- **Εφαρμογή λειτουργιών** από τη γραμμή εργαλείων (boolean, μετασχηματισμός, συστοιχία κ.λπ.)
- **Επεξεργασία ιδιοτήτων** στον πίνακα Ιδιότητες (όταν είναι επιλεγμένο ένα μόνο αντικείμενο)
- **Δεξί κλικ** για πρόσβαση στο μενού περιβάλλοντος με τις διαθέσιμες ενέργειες

## Συμβουλές

- Όταν είναι επιλεγμένα πολλά αντικείμενα, ομαδοποιούνται προσωρινά για τις λειτουργίες. Ο πίνακας Ιδιότητες εμφανίζει τις κοινές ιδιότητες.
- Χρησιμοποιήστε το Δέντρο Σχεδίασης για να επιλέξετε αντικείμενα στα οποία είναι δύσκολο να κάνετε κλικ μέσα στο παράθυρο προβολής -- κάνοντας κλικ σε ένα στοιχείο του δέντρου, αυτό επιλέγεται και στην προβολή.
