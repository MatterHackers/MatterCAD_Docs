# Χώρος εργασίας

Μάθετε πώς να πλοηγείστε στον χώρο εργασίας του MatterCAD, να χρησιμοποιείτε συντομεύσεις πληκτρολογίου και να διαχειρίζεστε τη ροή εργασίας του σχεδιασμού σας.

## Θέματα

- [Συντομεύσεις πληκτρολογίου](keyboard-shortcuts.md) - Γρήγορη αναφορά για όλες τις συντομεύσεις πληκτρολογίου
- [Χειριστήρια Ποντικιού](mouse-controls.md) - Πώς να πλοηγείστε στο τρισδιάστατο παράθυρο προβολής με το ποντίκι σας
- [Επιλογή](selection.md) - Πώς να επιλέγετε, να κάνετε πολλαπλή επιλογή και να διαχειρίζεστε την επιλογή αντικειμένων
- [Αναίρεση και Επανάληψη](undo-redo.md) - Αναιρέστε και επαναλάβετε αλλαγές στο σχέδιό σας
- [Ομαδοποίηση](grouping.md) - Ομαδοποιήστε και καταργήστε την ομαδοποίηση αντικειμένων για ευκολότερη διαχείριση
- [Εξαρτήματα](components.md) - Δημιουργήστε επαναχρησιμοποιήσιμα εξαρτήματα και συναρμολογήσεις
- [Εκφράσεις](expressions.md) - Χρησιμοποιήστε μαθηματικές εκφράσεις για παραμετρικό σχεδιασμό
- [Φύλλο μεταβλητών](variable-sheet.md) - Αποθηκεύστε κοινόχρηστες τιμές και τύπους για παραμετρικά σχέδια
- [Εργαλείο Μέτρησης](measure-tool.md) - Μετρήστε αποστάσεις μεταξύ σημείων στο σχέδιό σας
- [Κλείδωμα και Απόκρυψη](lock-hide.md) - Κλειδώστε αντικείμενα για να αποτρέψετε αλλαγές και αποκρύψτε αντικείμενα για λιγότερη ακαταστασία
