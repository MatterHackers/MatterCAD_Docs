# Αναίρεση και Επανάληψη

Το MatterCAD διατηρεί πλήρες ιστορικό των αλλαγών σας, ώστε να μπορείτε να αναιρείτε λάθη και να επαναλαμβάνετε ενέργειες που ακυρώσατε.

## Τρόπος χρήσης

- **Ctrl + Z** - Αναίρεση της τελευταίας ενέργειας
- **Ctrl + Y** ή **Ctrl + Shift + Z** - Επανάληψη της τελευταίας ενέργειας που αναιρέθηκε
- Μπορείτε επίσης να χρησιμοποιήσετε τα κουμπιά **Αναίρεση** και **Επανάληψη** στη γραμμή εργαλείων

## Τι μπορεί να αναιρεθεί

Όλες οι λειτουργίες σχεδίασης καταγράφονται στο ιστορικό αναίρεσης, όπως:

- Προσθήκη ή διαγραφή αντικειμένων
- Μετακίνηση, περιστροφή και κλιμάκωση αντικειμένων
- Εφαρμογή λειτουργιών (boolean, μετασχηματισμός, αναμόρφωση κ.λπ.)
- Αλλαγή παραμέτρων αντικειμένου
- Ομαδοποίηση και κατάργηση ομαδοποίησης

## Συμβουλές

- Μπορείτε να αναιρέσετε πολλαπλά βήματα πατώντας επανειλημμένα Ctrl + Z
- Το ιστορικό αναίρεσης διατηρείται για την τρέχουσα συνεδρία. Το κλείσιμο και το εκ νέου άνοιγμα ενός σχεδίου ξεκινά νέο ιστορικό.
- Αν αναιρέσετε αρκετά βήματα και στη συνέχεια κάνετε μια νέα αλλαγή, το ιστορικό επανάληψης πέρα από εκείνο το σημείο διαγράφεται
