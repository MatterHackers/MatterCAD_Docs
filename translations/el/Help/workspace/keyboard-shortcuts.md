# Συντομεύσεις πληκτρολογίου

Γρήγορη αναφορά για όλες τις συντομεύσεις πληκτρολογίου που είναι διαθέσιμες στο MatterCAD.

## Επεξεργασία

| Συντόμευση | Ενέργεια |
|----------|--------|
| Ctrl + Z | Αναίρεση |
| Ctrl + Y | Επανάληψη |
| Ctrl + Shift + Z | Επανάληψη (εναλλακτικά) |
| Ctrl + A | Επιλογή όλων των αντικειμένων |
| Ctrl + C | Αντιγραφή επιλεγμένων αντικειμένων |
| Ctrl + X | Αποκοπή επιλεγμένων αντικειμένων |
| Ctrl + V | Επικόλληση αντικειμένων |
| Space | Εκκαθάριση επιλογής |
| Escape | Ακύρωση της τρέχουσας ενέργειας μεταφοράς |
| Delete | Διαγραφή επιλεγμένων αντικειμένων |

## Προβολή

| Συντόμευση | Ενέργεια |
|----------|--------|
| W | Επαναφορά προβολής (προσαρμογή όλων των αντικειμένων στο παράθυρο προβολής) |
| Z | Ζουμ στο επιλεγμένο αντικείμενο |
| Ctrl + Συν (+) | Μεγέθυνση |
| Ctrl + Πλην (-) | Σμίκρυνση |
| Πλήκτρα βελών | Περιστροφή της προβολής |
| Shift + Πλήκτρα βελών | Μετατόπιση της προβολής |

## Χειριστήρια ποντικιού

| Ενέργεια | Χειριστήριο |
|--------|---------|
| Περιστροφή προβολής | Δεξί κλικ + Σύρσιμο |
| Μετατόπιση προβολής | Μεσαίο κλικ + Σύρσιμο |
| Ζουμ | Τροχός κύλισης |
| Επιλογή αντικειμένου | Αριστερό κλικ στο αντικείμενο |
| Πολλαπλή επιλογή | Shift + Αριστερό κλικ ή Ctrl + Αριστερό κλικ |
| Επιλογή με πλαίσιο | Αριστερό κλικ + Σύρσιμο σε κενό χώρο |
| Μενού περιβάλλοντος | Δεξί κλικ στο αντικείμενο |

## Εναλλακτικά χειριστήρια ποντικιού

| Ενέργεια | Χειριστήριο |
|--------|---------|
| Περιστροφή προβολής | Ctrl + Αριστερό κλικ + Σύρσιμο |
| Μετατόπιση προβολής | Ctrl + Shift + Αριστερό κλικ + Σύρσιμο |
| Ζουμ | Ctrl + Alt + Αριστερό κλικ + Σύρσιμο |

## Εφαρμογή

| Συντόμευση | Ενέργεια |
|----------|--------|
| Ctrl + Shift + T | Εκ νέου άνοιγμα του τελευταίου σχεδίου που έκλεισε |
| F1 | Άνοιγμα της Βοήθειας |
