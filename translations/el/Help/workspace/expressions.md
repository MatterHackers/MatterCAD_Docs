# Εκφράσεις

Πολλές παράμετροι στο MatterCAD δέχονται μαθηματικές εκφράσεις αντί για απλούς αριθμούς. Αυτό επιτρέπει τον παραμετρικό σχεδιασμό, όπου η αλλαγή μιας τιμής ενημερώνει αυτόματα τις σχετιζόμενες διαστάσεις.

## Τρόπος χρήσης

Αντί να πληκτρολογήσετε έναν απλό αριθμό σε ένα πεδίο παραμέτρου, μπορείτε να πληκτρολογήσετε μια μαθηματική έκφραση. Για παράδειγμα:

- Το `20 + 5` υπολογίζεται σε 25
- Το `pi * 10` υπολογίζεται σε 31,416
- Το `width * 2` αναφέρεται σε μια άλλη παράμετρο με το όνομα "width"

## Διαθέσιμες σταθερές

- **pi** - 3,14159... (ο λόγος της περιφέρειας προς τη διάμετρο)
- **tau** - 6,28318... (2 * pi, μια πλήρης περιστροφή σε ακτίνια)

## Υποστηριζόμενες πράξεις

- Πρόσθεση: `+`
- Αφαίρεση: `-`
- Πολλαπλασιασμός: `*`
- Διαίρεση: `/`
- Παρενθέσεις: `(` και `)` για ομαδοποίηση

## Συμβουλές

- Οι εκφράσεις υποστηρίζονται σε κάθε πεδίο που εμφανίζει `DoubleOrExpression`, `IntOrExpression` ή `StringOrExpression` στον κώδικα -- στην πράξη, τα περισσότερα αριθμητικά πεδία στα εργαλεία σχεδίασης τις δέχονται
- Χρησιμοποιήστε εκφράσεις για να δημιουργήσετε σχέσεις μεταξύ παραμέτρων -- για παράδειγμα, ορίστε τη διάμετρο μιας οπής σε `outer_diameter - 4` ώστε να έχει πάντα τοιχώματα 2mm
- Οι εκφράσεις ενημερώνονται αυτόματα όταν αλλάζουν οι τιμές στις οποίες αναφέρονται
- Χρησιμοποιήστε ένα [Φύλλο μεταβλητών](variable-sheet.md) όταν αρκετά αντικείμενα πρέπει να μοιράζονται τις ίδιες επώνυμες τιμές ή τύπους
- Μπορείτε να χρησιμοποιήσετε εκφράσεις σε λειτουργίες [Συστοιχία](../operations/array/index.md) για να δημιουργήσετε παραμετρικά μοτίβα
