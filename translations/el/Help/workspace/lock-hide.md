# Κλείδωμα και Απόκρυψη

Το Κλείδωμα και η Απόκρυψη σάς επιτρέπουν να ελέγχετε ποια αντικείμενα του σχεδίου σας μπορούν να επιλεγούν και ποια είναι ορατά. Αυτές οι λειτουργίες σάς βοηθούν να εργάζεστε πιο αποδοτικά σε σύνθετα σχέδια, αποτρέποντας τυχαίες αλλαγές και μειώνοντας την οπτική πολυπλοκότητα.

## Κλείδωμα
![20260318 193003 paste 20260318 193003](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-193003-paste-20260318-193003.jpg)


Το κλείδωμα ενός αντικειμένου εμποδίζει την επιλογή ή τη μετακίνησή του στο παράθυρο προβολής. Το αντικείμενο παραμένει ορατό, αλλά δεν μπορεί να τροποποιηθεί κατά λάθος.

- Κάντε κλικ στο **εικονίδιο κλειδώματος** δίπλα σε ένα αντικείμενο στο Δέντρο Σχεδίασης για εναλλαγή της κατάστασης κλειδώματος
- Τα κλειδωμένα αντικείμενα εξακολουθούν να συμμετέχουν σε λογικές (boolean) πράξεις και άλλους υπολογισμούς

## Απόκρυψη

![20260318 192834 paste 20260318 192834](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192834-paste-20260318-192834.jpg)

Η απόκρυψη ενός αντικειμένου το καθιστά αόρατο στο παράθυρο προβολής, διατηρώντας το ωστόσο στο σχέδιο. Το αντικείμενο εξακολουθεί να υπάρχει και να συμμετέχει σε πράξεις.

- Κάντε κλικ στο **εικονίδιο ματιού** δίπλα σε ένα αντικείμενο στο Δέντρο Σχεδίασης για εναλλαγή της ορατότητας
- Τα κρυμμένα αντικείμενα εξακολουθούν να συμπεριλαμβάνονται στις εξαγωγές, εκτός αν τα αφαιρέσετε

## Συμβουλές

- Κλειδώστε τα βασικά αντικείμενα ή τα αντικείμενα αναφοράς όσο εργάζεστε σε λεπτομέρειες, για να αποφύγετε την κατά λάθος μετακίνησή τους
- Αποκρύψτε αντικείμενα που εμποδίζουν την περιοχή στην οποία εργάζεστε
- Οι καταστάσεις κλειδώματος και απόκρυψης αποθηκεύονται μαζί με το σχέδιο
- Μπορείτε να κλειδώσετε και να αποκρύψετε αντικείμενα στο Δέντρο Σχεδίασης ακόμη κι αν βρίσκονται μέσα σε ομάδες ή εξαρτήματα
