# Εξαρτήματα

Τα εξαρτήματα είναι επαναχρησιμοποιήσιμες, παραμετροποιημένες ομάδες αντικειμένων. Όταν δημιουργείτε ένα εξάρτημα, γίνεται μια αυτοτελής μονάδα που μπορείτε να εισαγάγετε πολλές φορές στο σχέδιό σας, ενώ η επεξεργασία του εξαρτήματος ενημερώνει όλα τα στιγμιότυπα.

## Τρόπος χρήσης

### Δημιουργία εξαρτήματος

1. Επιλέξτε ένα ή περισσότερα αντικείμενα
2. Κάντε δεξί κλικ και επιλέξτε **Δημιουργία Εξαρτήματος** (ή χρησιμοποιήστε το μενού)
3. Τα επιλεγμένα αντικείμενα τυλίγονται σε έναν περιέκτη εξαρτήματος

### Επεξεργασία εξαρτήματος

1. Επιλέξτε το εξάρτημα
2. Οι εκτεθειμένες παράμετροι του εξαρτήματος εμφανίζονται στον πίνακα Ιδιότητες
3. Τροποποιήστε τις παραμέτρους για να αλλάξετε το σχήμα του εξαρτήματος

## Συμβουλές

- Τα εξαρτήματα είναι χρήσιμα για τη δημιουργία επαναχρησιμοποιήσιμων δομικών στοιχείων σε σύνθετα σχέδια
- Οι αλλαγές παραμέτρων δεν είναι καταστροφικές και μπορούν να προσαρμοστούν ανά πάσα στιγμή
- Τα εξαρτήματα βοηθούν στην οργάνωση σύνθετων σχεδίων ομαδοποιώντας σχετιζόμενα αντικείμενα
- Χρησιμοποιήστε εξαρτήματα για μέρη που χρειάζεται να τοποθετήσετε πολλές φορές με μικρές παραλλαγές
