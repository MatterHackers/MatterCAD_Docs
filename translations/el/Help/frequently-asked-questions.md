# Γιατί τα αντικείμενά μου έχουν λάθος κλίμακα;
- Τα αρχεία STL δεν αποθηκεύουν πληροφορίες μονάδων μέτρησης. Το MatterCAD αναμένει διαστάσεις STL σε χιλιοστά, ενώ τα περισσότερα προγράμματα CAD κάνουν εξαγωγή στις δικές τους εγγενείς μονάδες (συνήθως ίντσες). Αυτό προκαλεί αποκλίσεις κλίμακας κατά την εισαγωγή σχεδίων.

- Η καλύτερη λύση είναι να ρυθμίσετε το λογισμικό σχεδίασής σας ώστε να εξάγει αρχεία STL σε χιλιοστά. Για παράδειγμα, στο SolidWorks, χρησιμοποιήστε το κουμπί Επιλογές στο παράθυρο διαλόγου Αποθήκευση Ως για να ορίσετε τις παραμέτρους εξαγωγής STL.

- Εναλλακτικά, μπορείτε να αλλάξετε την κλίμακα του εξαρτήματος μέσα στο MatterCAD. Στην 3D Προβολή, μεταβείτε στη λειτουργία Επεξεργασία και επιλέξτε ΚΛΙΜΑΚΑ από τη δεξιά γραμμή εργαλείων. Χρησιμοποιήστε το αναπτυσσόμενο μενού για τους συνήθεις συντελεστές μετατροπής ή εισαγάγετε συγκεκριμένες διαστάσεις στα πεδία των αξόνων.

# Πώς μπορώ να διαγράψω τα δεδομένα της εφαρμογής;

- Αν η επανεγκατάσταση δεν λύνει κάποιο πρόβλημα, ίσως χρειαστεί να διαγράψετε τα αποθηκευμένα δεδομένα του MatterCAD. Αυτά τα δεδομένα παραμένουν και μετά την απεγκατάσταση. Για πλήρη επαναφορά στις προεπιλεγμένες ρυθμίσεις, κάντε αφαίρεση του φακέλου της εφαρμογής. Μπορείτε επίσης να μετονομάσετε προσωρινά το αρχείο βάσης δεδομένων SQLite (MatterCAD.db) για να ελέγξετε αν οι ρυθμίσεις προκαλούν προβλήματα.
