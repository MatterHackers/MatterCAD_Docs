Ο Μετατροπέας Εικόνας μπορεί να σας βοηθήσει να δημιουργήσετε εύκολα εξαρτήματα από εικόνες

### Προσθήκη Μετατροπέα Εικόνας
- Σύρετε τον Μετατροπέα Εικόνας από την πλαϊνή μπάρα στην επιφάνεια εκτύπωσης
- Αλλάξτε την εικόνα που χρησιμοποιεί κάνοντας κλικ στο 'Αλλαγή'  
![Image Converter](https://www.matterhackers.com/r/zrXG9u)
### Αλλαγή του ύψους
- Μόλις έχετε μια εικόνα στην επιφάνεια εκτύπωσης, μπορείτε να αλλάξετε το ύψος της  
![Change Height](https://www.matterhackers.com/r/MOtISv)
### Αναζήτηση για νέες εικόνες
- Ο Μετατροπέας Εικόνας μπορεί επίσης να σας βοηθήσει να αναζητήσετε στο Google εικόνες που ίσως θέλετε να χρησιμοποιήσετε (βεβαιωθείτε ότι έχετε άδεια για οποιαδήποτε εικόνα χρησιμοποιείτε).  
![Search Image](https://www.matterhackers.com/r/p3lA0F)
### Προσθήκη Βάσης
- Μόλις έχετε την εικόνα που θέλετε, μπορείτε εύκολα να προσθέσετε μια βάση στη δημιουργία σας.  
![Add Base](https://www.matterhackers.com/r/LBiZnR)
### Οι εικόνες μπορούν επίσης να χρησιμοποιηθούν απευθείας
- Μπορείτε επίσης να σύρετε απευθείας εικόνες στην επιφάνεια εκτύπωσης και να χρησιμοποιήσετε τα εργαλεία που βρίσκετε στο μενού δεξιού κλικ για να δημιουργήσετε όλες τις δυνατότητες (και περισσότερες) του Μετατροπέα Εικόνας.

Εξερευνήστε και διασκεδάστε, τα μόνα όρια είναι η φαντασία σας
