 - **Όνομα:** Πληκτρολογήστε το κείμενο που θέλετε να εμφανίζεται
 - **Μέγεθος σημείου:** Ορίστε το μέγεθος της γραμματοσειράς. Αυτό είναι ακριβές όταν εκτυπώνεται στο ίδιο μέγεθος με έναν 2D εκτυπωτή.
 - **Ύψος:** Ορίστε το ύψος στο οποίο θέλετε να φτάνει το κείμενο
 - **Γραμματοσειρά:** Επιλέξτε τη γραμματοσειρά που θέλετε να χρησιμοποιήσετε
