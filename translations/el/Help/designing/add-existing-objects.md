Από τον Υπολογιστή σας
======================

![](https://lh3.googleusercontent.com/32sfdux7Fo64mrzY9hHBcWLoc8SKwTKuof6tEntzDbhKG27Y5Ow3NPEuwYGUJ9GR64tVk6h7MRY5T_UUIbi4a1NEeA)  
Κάντε κλικ στο κουμπί Άνοιγμα στη γραμμή εργαλείων για να προσθέσετε αρχεία από τον υπολογιστή σας. Το MatterCAD υποστηρίζει τις ακόλουθες μορφές αρχείων:

* STL - Πρότυπη μορφή τρισδιάστατων μοντέλων του κλάδου
* AMF - Προηγμένη μορφή που υποστηρίζει χρώματα και αντικείμενα πολλαπλών υλικών
* OBJ - Μορφή τρισδιάστατων γραφικών Wavefront (μόνο πλέγματα, χωρίς υφές ή δεδομένα χρώματος)
* MCX - Εγγενής μορφή του MatterCAD

Μεταφορά και απόθεση
--------------------

Μπορείτε να σύρετε και να αποθέσετε αρχεία απευθείας από την επιφάνεια εργασίας ή την εξερεύνηση αρχείων στο MatterCAD.

Από τη Βιβλιοθήκη
=================

Η Πλαϊνή γραμμή της Βιβλιοθήκης
-------------------------------

![](https://lh3.googleusercontent.com/crGYrE83PyWb-hntQ8d-RhEeoiN_S8OI7uUnCS1oOm-8eMT5ExkDRSYZCr3IiT7Bx42HzrmFcg4yHhrv_GgzmbyfRA)  
Κάντε κλικ στο κουμπί Προσθήκη περιεχομένου στη γραμμή εργαλείων για να ανοίξετε την περιήγηση της βιβλιοθήκης. Από εδώ μπορείτε να σύρετε και να αποθέσετε οποιοδήποτε περιεχόμενο από τη βιβλιοθήκη στον χώρο εργασίας σας.

![](https://lh3.googleusercontent.com/926cpzNy9wQBIxRHCBUCaUJhIpWdHVp8FRXpr5sC07rIBiIOO_Ryh2PGX6_mW9Ooe4i8TBR5XlejcqL6B0cJupT4)

Η καρτέλα Βιβλιοθήκη
--------------------

Στην καρτέλα Βιβλιοθήκη, μπορείτε να κάνετε δεξί κλικ σε οποιοδήποτε αντικείμενο και να επιλέξετε Προσθήκη στη σκηνή για να το εισαγάγετε στον τρέχοντα χώρο εργασίας σχεδίασης.
