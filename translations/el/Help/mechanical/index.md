# Μηχανικά Εξαρτήματα

Το MatterCAD περιλαμβάνει εξειδικευμένα εργαλεία για τη δημιουργία μηχανικών εξαρτημάτων, όπως γρανάζια και κοχλιωτοί σύνδεσμοι.
