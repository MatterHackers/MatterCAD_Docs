# Σπειρώματα

Δημιουργήστε σπειρώματα βίδας με ρυθμιζόμενη διάμετρο, βήμα και προφίλ σπειρώματος. Τα σπειρώματα μπορούν να χρησιμοποιηθούν ως αυτόνομα μπουλόνια/βίδες ή να αφαιρεθούν από άλλα αντικείμενα για τη δημιουργία σπειρωτών οπών.

## Πώς να το χρησιμοποιήσετε

1. Προσθέστε **Σπειρώματα** από τα εργαλεία Μηχανικό ή από τον πίνακα Βασικά Σχήματα
2. Ορίστε τη διάμετρο, το βήμα και τον αριθμό των περιστροφών
3. Προαιρετικά ενεργοποιήστε την επιλογή "Χρήση ως Οπή" για τη δημιουργία σπειρωτών οπών

## Παράμετροι

### Χρήση

- **Χρήση ως Οπή** - Όταν είναι ενεργοποιημένη, τα σπειρώματα διαστασιολογούνται με επιπλέον ανοχή ώστε να χρησιμοποιηθούν ως αφαιρούμενη οπή (προεπιλογή: ανενεργό)
- **Ανοχή** - Επιπλέον διάκενο για την εφαρμογή όταν χρησιμοποιείται ως οπή (προεπιλογή: 0.2mm, εμφανίζεται όταν η Χρήση ως Οπή είναι ενεργή)

### Χαρακτηριστικά

- **Διάμετρος** - Η εξωτερική διάμετρος του σπειρωτού τμήματος (προεπιλογή: 10mm)
- **Βήμα** - Απόσταση μεταξύ κάθε στροφής του σπειρώματος (προεπιλογή: 2mm). Μικρότερο βήμα = λεπτότερα σπειρώματα
- **Κλίμακα σπειρώματος** - Πλάτος των σπειρωμάτων ως αναλογία του βήματος (προεπιλογή: 1.0, εύρος: 0.1-1.0)
- **Περιστροφές** - Αριθμός πλήρων στροφών του σπειρώματος (προεπιλογή: 10)

### Γεωμετρία

- **Πλευρές** - Αριθμός τμημάτων γύρω από την περίμετρο (προεπιλογή: 40). Περισσότερα = πιο ομαλό

### Μύτες (Άκρα σπειρώματος)

- **Κλίμακα μύτης** - Πόσο θα λεπτύνουν τα άκρα του σπειρώματος (προεπιλογή: 0, εύρος: 0-1). Ορίστε τιμή μεγαλύτερη του 0 για να δημιουργήσετε κωνική είσοδο στα άκρα
- **Γωνία μύτης** - Η γωνία στην οποία λεπταίνουν οι μύτες (προεπιλογή: 90 μοίρες)

## Συμβουλές

- Για να δημιουργήσετε μια σπειρωτή οπή: ενεργοποιήστε τη "Χρήση ως Οπή", τοποθετήστε τα σπειρώματα και κάντε [Αφαίρεση](../operations/boolean/subtract.md) από το αντικείμενό σας
- Προσθέστε Ανοχή όταν χρησιμοποιείτε το σχήμα ως οπή, ώστε να εφαρμόζουν σωστά τα εκτυπωμένα εξαρτήματα
- Τυπικά μετρικά βήματα σπειρώματος: M3=0.5mm, M4=0.7mm, M5=0.8mm, M6=1.0mm, M8=1.25mm, M10=1.5mm
- Χρησιμοποιήστε την Κλίμακα μύτης για να δημιουργήσετε μια είσοδο που διευκολύνει το ξεκίνημα του βιδώματος
