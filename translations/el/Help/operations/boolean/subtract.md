# Αφαίρεση

Η Αφαίρεση κόβει τα εξαρτήματα που επιλέγετε από τα εξαρτήματα που δεν επιλέξατε. Χρησιμοποιήστε το **Εξάρτημα(τα) προς Αφαίρεση** για να επιλέξετε τα σχήματα κοπής· όλα τα υπόλοιπα αποτελούν τη βάση που κόβεται.

Ο [Συνδυασμός](combine.md), η Αφαίρεση, η [Τομή](intersect.md) και η [Αφαίρεση και Αντικατάσταση](subtract-and-replace.md) εκτελούνται όλες από ένα αντικείμενο Boolean -- το κουμπί της γραμμής εργαλείων το δημιουργεί με την Αφαίρεση ήδη επιλεγμένη, και μπορείτε να μεταβείτε σε οποιαδήποτε από τις άλλες τρεις ανά πάσα στιγμή από τη σειρά εικονιδίων **Λειτουργία** στο επάνω μέρος του πίνακα Ιδιότητες.

Η Αφαίρεση λειτουργεί σε στερεά και σε δισδιάστατες διαδρομές. Εξετάζει αυτό που της δώσατε και εκτελεί το σωστό είδος λειτουργίας, έτσι η αφαίρεση μιας διαδρομής από μια άλλη παράγει διαδρομή και η αφαίρεση ενός πλέγματος από ένα άλλο παράγει στερεό.

## Πώς Χρησιμοποιείται

1. Επιλέξτε δύο ή περισσότερα αντικείμενα
2. Κάντε κλικ στο **Αφαίρεση** στη γραμμή εργαλείων -- επιλέγεται αυτόματα ένα προεπιλεγμένο εξάρτημα προς κοπή, ώστε να έχει άμεσο αποτέλεσμα
3. Χρησιμοποιήστε το **Εξάρτημα(τα) προς Αφαίρεση** για να επιλέξετε ποια θυγατρικά αντικείμενα είναι τα σχήματα κοπής
4. Αλλάξτε γνώμη ανά πάσα στιγμή κάνοντας κλικ σε διαφορετικό εικονίδιο στη σειρά **Λειτουργία** στο επάνω μέρος του πίνακα Ιδιότητες -- το σχήμα αναδημιουργείται με τη νέα λειτουργία

## Παράμετροι

- **Λειτουργία** - Ποια λογική πράξη θα εκτελεστεί. Εμφανίζεται ως σειρά εικονιδίων στο επάνω μέρος του πίνακα
- **Εξάρτημα(τα) προς Αφαίρεση** - Ποια θυγατρικά αντικείμενα είναι τα σχήματα κοπής
- **Διατήρηση Αφαιρεμένων Τμημάτων** - Αφήνει στη σκηνή τα τμήματα που αφαιρέθηκαν αντί να τα απορρίπτει
- **Διατήρηση Ανεστραμμένης Γεωμετρίας** - Αντιμετωπίζει ένα ανεστραμμένο κέλυφος ως συμπαγές υλικό, αντί να το αφήνει να ακυρώνει τον όγκο γύρω του. Ενεργοποιήστε το όταν ένα μοντέλο που θα έπρεπε να είναι συμπαγές επιστρέφει με τμήματα να λείπουν. Επιβάλλει τη χρήση της πιο αργής, ακριβούς μηχανής λογικών πράξεων
- **Επιδιόρθωση φοράς περιέλιξης** - Αντιστρέφει τη φορά περιέλιξης στα ανεστραμμένα κελύφη κάθε εξαρτήματος πριν εκτελεστεί η λογική πράξη. Αυτό διορθώνει τη γεωμετρία μία φορά αντί να αλλάζει το τι θεωρείται συμπαγές σε κάθε επόμενη λειτουργία, και συνήθως είναι η καλύτερη από τις δύο λύσεις για ένα ανεστραμμένο μοντέλο

## Συμβουλές

- Τα αντικείμενα πρέπει να επικαλύπτονται για να έχει αποτέλεσμα η Αφαίρεση
- Για να κόψετε μια διαμπερή οπή, βεβαιωθείτε ότι το αντικείμενο κοπής διαπερνά πλήρως τη βάση
- Για μια απλή οπή, το βασικό σχήμα [Οπή](../../primitives/hole.md) είναι ήδη ρυθμισμένο ώστε να αφαιρείται
- Τα αντικείμενα κοπής παραμένουν στο δέντρο σχεδίασης, οπότε μπορείτε να τα μετακινήσετε ή να αλλάξετε το μέγεθός τους και η κοπή ενημερώνεται
- Αν ένα αποτέλεσμα φαίνεται λάθος, ελέγξτε ότι τα αρχικά αντικείμενα είναι στεγανά. Η **Επιδιόρθωση φοράς περιέλιξης** διορθώνει τα ανεστραμμένα κελύφη· η [Επιδιόρθωση](../mesh/repair.md) διορθώνει εκτενέστερες βλάβες σε εισαγόμενα μοντέλα

## Σχετικά

- [Συνδυασμός](combine.md) - Συγχώνευση πολλών αντικειμένων σε ένα ενιαίο στερεό σχήμα
- [Τομή](intersect.md) - Διατήρηση μόνο του όγκου όπου τα αντικείμενα επικαλύπτονται
- [Αφαίρεση και Αντικατάσταση](subtract-and-replace.md) - Αφαίρεση ενός σχήματος και διατήρηση του κομματιού που αφαιρέθηκε
- [Τομή Επιπέδου](../reshape/plane-cut.md) - Κοπή με επίπεδη επιφάνεια αντί για άλλο σχήμα
- [Οπή](../../primitives/hole.md) - Ένας κύβος προρυθμισμένος ώστε να αφαιρείται
- [Επιδιόρθωση](../mesh/repair.md) - Διόρθωση κατεστραμμένων εισαγόμενων πλεγμάτων πριν από μια λογική πράξη

Αυτή η σελίδα καλύπτει επίσης τα παλαιότερα αντικείμενα Αφαίρεσης που εξακολουθούν να υπάρχουν σε σχέδια αποθηκευμένα πριν από τη συγχώνευση των λειτουργιών. Συνεχίζουν να λειτουργούν ακριβώς όπως πριν· τα νέα σχέδια χρησιμοποιούν το κοινό αντικείμενο Boolean με επιλεγμένη τη λειτουργία Αφαίρεση.
