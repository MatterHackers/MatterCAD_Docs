# Λειτουργίες Boolean
<!-- AUTO_IMAGE: type=toolbar_icons group=Merge -->
![Merge toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Merge.png)

Οι λειτουργίες Boolean σάς επιτρέπουν να δημιουργείτε σύνθετα σχήματα συνδυάζοντας απλούστερα. Επιλέξτε δύο ή περισσότερα αντικείμενα και εφαρμόστε μια λειτουργία Boolean για να τα συγχωνεύσετε, να τα κόψετε ή να βρείτε την επικάλυψη μεταξύ τους.

Και οι τέσσερις λειτουργίες εκτελούνται από ένα αντικείμενο Boolean. Τα κουμπιά της γραμμής εργαλείων παρακάτω απλώς προεπιλέγουν με ποια λειτουργία θα ξεκινήσει, και μπορείτε να την αλλάξετε στη συνέχεια από τη σειρά εικονιδίων **Λειτουργία** στο επάνω μέρος του πίνακα Ιδιότητες.
