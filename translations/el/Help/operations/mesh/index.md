# Λειτουργίες Πλέγματος
<!-- AUTO_IMAGE: type=toolbar_icons group=Mesh -->
![Mesh toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Mesh.png)

Οι λειτουργίες πλέγματος σάς βοηθούν να καθαρίσετε και να βελτιστοποιήσετε τη γεωμετρία τριγωνικού πλέγματος των μοντέλων σας.

## Λειτουργίες

- [Επιδιόρθωση](repair.md) - Διορθώστε προβλήματα στη γεωμετρία του πλέγματος, όπως οπές, μη πολλαπλότητες ακμές και ανεστραμμένες έδρες
- [Αραίωση](decimate.md) - Μειώστε τον αριθμό πολυγώνων ενός πλέγματος για να το απλοποιήσετε διατηρώντας το σχήμα του
