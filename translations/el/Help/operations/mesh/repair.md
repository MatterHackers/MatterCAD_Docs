# Επιδιόρθωση

Η Επιδιόρθωση διορθώνει συνήθη προβλήματα στη γεωμετρία του πλέγματος, όπως μη πολλαπλές ακμές, οπές, ασυνεπή προσανατολισμό εδρών και σχεδόν συμπίπτουσες κορυφές. Είναι ιδιαίτερα χρήσιμη για εισαγόμενα αρχεία STL και OBJ που ενδέχεται να περιέχουν σφάλματα.

![20260324 080517 paste 20260324 080517](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080517-paste-20260324-080517.jpg)


## Τρόπος χρήσης

1. Επιλέξτε ένα αντικείμενο με προβλήματα πλέγματος
2. Εφαρμόστε τη λειτουργία **Επιδιόρθωση** από το μενού Πλέγμα
3. Ελέγξτε τα στατιστικά πριν/μετά για να δείτε τι διορθώθηκε

## Στατιστικά (Μόνο για ανάγνωση)

- **Αρχικές κορυφές / Τελικές κορυφές** - Πλήθος κορυφών πριν και μετά την επιδιόρθωση
- **Αρχικές έδρες / Τελικές έδρες** - Πλήθος εδρών πριν και μετά την επιδιόρθωση
- **Αρχικές μη πολλαπλές ακμές / Τελικές μη πολλαπλές ακμές** - Πλήθος προβληματικών ακμών πριν και μετά

### Επιλογές για προχωρημένους

Ενεργοποιήστε τη λειτουργία **Για προχωρημένους** για λεπτομερή έλεγχο:

- **Συγκόλληση κορυφών** - Συγχώνευση σχεδόν συμπιπτουσών κορυφών (προεπιλογή: ενεργό)
- **Ανοχή συγκόλλησης** - Πόσο κοντά πρέπει να βρίσκονται οι κορυφές για να συγχωνευθούν
- **Προσανατολισμός Έδρας** - Αναστρέφει τα κελύφη που είναι γυρισμένα το μέσα έξω, ώστε κάθε σώμα να ερμηνεύεται ως συμπαγές. Κάθε κέλυφος αξιολογείται ξεχωριστά, έτσι ένα κοίλο μοντέλο διατηρεί τις κοιλότητές του αντί να γεμίζουν. Τα κελύφη των οποίων οι έδρες διαφωνούν μεταξύ τους αφήνονται ως έχουν αντί να γίνει εικασία, ενώ τα μοντέλα που δεν είναι στεγανά επιστρέφουν σε μια πιο ανεκτική επιδιόρθωση - εκτελέστε πρώτα **Πλήρωση Οπών** αν ο προσανατολισμός από μόνος του δεν τα διορθώνει.
- **Συγκόλληση ακμών** - Επιδιορθώνει μικρές ρωγμές και προβληματικές ενώσεις
- **Πλήρωση Οπών** - Γεμίζει τα κενά στην επιφάνεια του πλέγματος
- **Λειτουργία αφαίρεσης** - Αφαιρεί εσωτερική ή αποκρυμμένη γεωμετρία:
  - **Καμία** - Διατήρηση όλης της γεωμετρίας
  - **Εσωτερικό** - Αφαίρεση εσωτερικών σωμάτων που κρύβονται μέσα στο κύριο σχήμα
  - **Αποκρυμμένο** - Αφαίρεση εδρών που δεν είναι ορατές από έξω

## Συμβουλές

- Δοκιμάστε πρώτα την Επιδιόρθωση αν οι λογικές πράξεις (Συνδυασμός, Αφαίρεση) δίνουν απροσδόκητα αποτελέσματα σε εισαγόμενα μοντέλα
- Οι προεπιλεγμένες ρυθμίσεις (Συγκόλληση κορυφών ενεργή, όλα τα υπόλοιπα ανενεργά) διορθώνουν τα πιο συνηθισμένα προβλήματα
- Ενεργοποιήστε την Πλήρωση Οπών αν βλέπετε μέσα από κενά στο μοντέλο
- Χρησιμοποιήστε την Αφαίρεση Εσωτερικού για να καθαρίσετε μοντέλα που έχουν κρυμμένη γεωμετρία στο εσωτερικό τους
