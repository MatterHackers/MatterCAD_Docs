# Διόγκωση διαδρομής

Η Διόγκωση διαδρομής επεκτείνει μια 2D διαδρομή προς τα έξω, μεγαλώνοντας το σχήμα διατηρώντας τη συνολική του μορφή. Αυτό είναι παρόμοιο με την εφαρμογή μιας ομοιόμορφης μετατόπισης σε όλες τις ακμές.

## Πώς χρησιμοποιείται

1. Επιλέξτε μια 2D διαδρομή
2. Εφαρμόστε τη **Διόγκωση διαδρομής** από το μενού λειτουργιών Διαδρομής
3. Ρυθμίστε το ποσό διόγκωσης

## Διόγκωση ανοιχτής γραμμής

Η Διόγκωση είναι ο τρόπος με τον οποίο μετατρέπετε μια γραμμή σε σχήμα. Καταργήστε την επιλογή **Κλειστό** σε μια [Προσαρμοσμένη διαδρομή](../../2d-paths/custom-path.md) για να σχεδιάσετε μια ανοιχτή γραμμή και έπειτα διογκώστε την: το αποτέλεσμα είναι μια γεμάτη κορδέλα, τόσο πλατιά εκατέρωθεν της γραμμής όσο και το ποσό που ορίσατε. Από εκεί και πέρα εξωθείται όπως κάθε άλλη διαδρομή.

Το **Στυλ** καθορίζει πώς τερματίζονται τα δύο άκρα της γραμμής, καθώς και πώς ενώνονται οι γωνίες της:

- Το **Επίπεδο** σταματά την κορδέλα τετράγωνα σε κάθε ακραίο σημείο
- Το **Στρογγυλό** προσθέτει ένα ημικύκλιο πέρα από κάθε ακραίο σημείο
- Το **Αιχμηρό** προσθέτει ένα τετράγωνο πέρα από κάθε ακραίο σημείο

Μια ανοιχτή γραμμή δεν έχει εσωτερικό μέσα στο οποίο να συρρικνωθεί, οπότε ένα μηδενικό ή αρνητικό ποσό δεν θα άφηνε απολύτως τίποτα. Όταν η διαδρομή είναι *εξ ολοκλήρου* ανοιχτή, η Διόγκωση περιορίζει την τιμή προς τα πάνω σε έναν μικρό θετικό αριθμό και γράφει τον περιορισμένο αριθμό πίσω στο πλαίσιο, ώστε να βλέπετε τι συνέβη.

Μια διαδρομή που συνδυάζει ανοιχτά και κλειστά περιγράμματα δεν περιορίζεται: τα κλειστά περιγράμματα συρρικνώνονται κανονικά και τα ανοιχτά απλώς παραλείπονται. Οι κλειστές διαδρομές εξακολουθούν να συρρικνώνονται σε αρνητικές τιμές ακριβώς όπως πάντα.

## Συμβουλές

- Χρησιμοποιήστε αρνητικές τιμές για να συρρικνώσετε τη διαδρομή προς τα μέσα αντί να την επεκτείνετε
- Η Διόγκωση είναι χρήσιμη για τη δημιουργία μετατοπίσεων ανοχής γύρω από σχήματα
- Συνδυάστε την με τη [Διαδρομή περιγράμματος](outline-path.md) για τη δημιουργία περιγραμμάτων με συγκεκριμένα πλάτη
