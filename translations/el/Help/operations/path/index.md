# Λειτουργίες Διαδρομής
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

Οι λειτουργίες διαδρομής δουλεύουν με 2D διαδρομές για τη δημιουργία και την τροποποίηση 3D σχημάτων. Χρησιμοποιήστε τες για να κάνετε εξώθηση, περιστροφή και βελτίωση γεωμετρίας βασισμένης σε διαδρομές.

## Λειτουργίες

- [Γραμμική Εξώθηση](linear-extrude.md) - Δώστε ύψος σε μια 2D διαδρομή για να δημιουργήσετε ένα 3D αντικείμενο
- [Περιστροφή](revolve.md) - Περιστρέψτε μια 2D διαδρομή γύρω από έναν άξονα για να δημιουργήσετε ένα στερεό εκ περιστροφής
- [Εξομάλυνση Διαδρομής](smooth-path.md) - Εξομαλύνετε τις καμπύλες μιας διαδρομής
- [Διόγκωση διαδρομής](inflate-path.md) - Αναπτύξτε μια διαδρομή προς τα έξω
- [Διαδρομή περιγράμματος](outline-path.md) - Δημιουργήστε ένα περίγραμμα από μια γεμισμένη διαδρομή
- [Διαδρομή περιγράμματος](border-path.md) - Προσθέστε μια μετατόπιση περιγράμματος γύρω από μια διαδρομή
- [Επιλογή διαδρομών](select-paths.md) - Επιλέξτε συγκεκριμένες διαδρομές από σύνθετα αντικείμενα πολλαπλών διαδρομών
