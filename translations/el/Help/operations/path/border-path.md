# Διαδρομή περιγράμματος

Η Διαδρομή περιγράμματος προσθέτει μια μετατόπιση περιγράμματος γύρω από μια υπάρχουσα διαδρομή, δημιουργώντας μια μεγαλύτερη εκδοχή του σχήματος που περιβάλλει το αρχικό.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Τρόπος χρήσης

1. Επιλέξτε μια δισδιάστατη διαδρομή
2. Εφαρμόστε τη λειτουργία **Διαδρομή περιγράμματος** από το μενού λειτουργιών Διαδρομή
3. Προσαρμόστε το πλάτος του περιγράμματος

## Συμβουλές

- Χρησιμοποιήστε το για να δημιουργήσετε περιθώριο ή γέμισμα γύρω από σχήματα
- Συνδυάστε το με την αρχική διαδρομή και την [Αφαίρεση](../boolean/subtract.md) για να δημιουργήσετε σχήματα πλαισίου
- Παρόμοιο με τη [Διόγκωση διαδρομής](inflate-path.md), αλλά σχεδιασμένο ειδικά για τη δημιουργία περιγραμμάτων
