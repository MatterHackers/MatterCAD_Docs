# Επιλογή διαδρομών

Η Επιλογή διαδρομών φιλτράρει ποιες υπο-διαδρομές ενός σύνθετου αντικειμένου διαδρομής διατηρούνται. Είναι ιδιαίτερα χρήσιμη όταν εργάζεστε με διακοσμητικές ή πολυμερείς γραμματοσειρές, όπου χρειάζεστε τα εξωτερικά περιγράμματα των γραμμάτων και τα εσωτερικά κομμένα σχήματα ως ξεχωριστά κομμάτια — για παράδειγμα, για να τα εκτυπώσετε σε 3D με δύο διαφορετικά χρώματα.

## Πώς λειτουργεί το βάθος διαδρομής

Όταν ένα αντικείμενο διαδρομής περιέχει σχήματα με κλειστές περιοχές (όπως το εσωτερικό του γράμματος «O» ή το κενό μιας διακοσμητικής σπείρας), αυτές οι κλειστές περιοχές είναι **οπές** στο βάθος 1. Το εξωτερικό περίγραμμα κάθε γράμματος ή σχήματος βρίσκεται στο **βάθος 0**.

```
Depth 0 — outer contour of each letter or shape
Depth 1 — first level of enclosed holes (inside an "O", "A", etc.)
Depth 2 — shapes nested inside a hole (rarely used)
```

## Προρυθμίσεις φίλτρου

### Όλα
Περιλαμβάνει κάθε διαδρομή αμετάβλητη. Αυτή είναι η προεπιλογή και ισοδυναμεί με το να μην εφαρμοστεί καθόλου η Επιλογή διαδρομών.

### Μόνο εξωτερικές διαδρομές
Διατηρεί μόνο το εξωτερικό περίγραμμα κάθε σχήματος (βάθος == 0). Χρησιμοποιήστε το για να πάρετε μόνο τα περιγράμματα των γραμμάτων μιας διακοσμητικής γραμματοσειράς, χωρίς τις εσωτερικές κομμένες περιοχές.

### Μόνο οπές
Διατηρεί μόνο τις κλειστές οπές (βάθος > 0). Χρησιμοποιήστε το για να πάρετε μόνο τις εσωτερικές κομμένες περιοχές γραμμάτων και σχημάτων.

### Κατά δείκτη ομάδας
Διατηρεί μόνο τις διαδρομές που ανήκουν σε ένα ασύνδετο σχήμα. Η ομάδα 0 είναι το πρώτο σχήμα, η ομάδα 1 το δεύτερο, και ούτω καθεξής. Χρησιμοποιήστε το για να απομονώσετε έναν μεμονωμένο χαρακτήρα από μια λέξη.

### Προσαρμοσμένο
Γράψτε μια έκφραση που αξιολογείται για κάθε διαδρομή. Η διαδρομή **περιλαμβάνεται** όταν η έκφραση είναι μη μηδενική και **εξαιρείται** όταν είναι μηδέν.

Οι εκφράσεις πρέπει να ξεκινούν με `=` ώστε να ενεργοποιηθεί η αντικατάσταση μεταβλητών. Χωρίς το `=`, η τιμή αντιμετωπίζεται ως απλός αριθμός (π.χ. το `1` περιλαμβάνει πάντα, το `0` εξαιρεί πάντα).

## Παραδείγματα προσαρμοσμένων εκφράσεων

| Έκφραση | Αποτέλεσμα |
|------------|--------|
| `=PathDepth==0` | Μόνο εξωτερικά περιγράμματα (ίδιο με Μόνο εξωτερικές διαδρομές) |
| `=PathDepth>0` | Μόνο οπές (ίδιο με Μόνο οπές) |
| `=GroupIndex==0` | Μόνο το πρώτο ασύνδετο σχήμα |
| `=PathArea>100` | Σχήματα με εμβαδόν μεγαλύτερο από 100 mm² |
| `=PathLength>50` | Σχήματα με περίμετρο μεγαλύτερη από 50 mm |

## Μεταβλητές προσαρμοσμένων εκφράσεων

| Μεταβλητή | Σημασία |
|----------|---------|
| `PathDepth` | 0 = εξωτερικό περίγραμμα· 1+ = οπή ή ένθετο σχήμα |
| `GroupIndex` | Δείκτης του ασύνδετου σχήματος (0, 1, 2…) |
| `GroupOuterArea` | Εμβαδόν της εξωτερικής διαδρομής αυτής της ομάδας |
| `GroupOuterLength` | Περίμετρος της εξωτερικής διαδρομής αυτής της ομάδας |
| `ChildCount` | Αριθμός οπών μέσα στην εξωτερική διαδρομή αυτής της ομάδας |
| `PathIndex` | Διαδοχικός δείκτης αυτής της διαδρομής μέσα στην ομάδα της |
| `PathArea` | Εμβαδόν αυτής της μεμονωμένης διαδρομής |
| `PathLength` | Περίμετρος αυτής της μεμονωμένης διαδρομής |

## Παράδειγμα: Πολύχρωμη εκτύπωση χριστουγεννιάτικης γραμματοσειράς

Μια συνηθισμένη χρήση της Επιλογής διαδρομών είναι η εκτύπωση διακοσμητικού κειμένου όπου τα γράμματα έχουν εσωτερικά κομμένα σχήματα. Για να εκτυπώσετε τα εξωτερικά γράμματα σε ένα χρώμα και τις εσωτερικές κοπές σε δεύτερο χρώμα:

1. Προσθέστε ένα αντικείμενο **Κείμενο** και ορίστε το σε **έξοδο 2D**
2. Εφαρμόστε **Επιλογή διαδρομών** → ορίστε την προρύθμιση σε **Μόνο εξωτερικές διαδρομές**
3. Εφαρμόστε **Γραμμική Εξώθηση** για να του δώσετε ύψος → αναθέστε το πρώτο σας χρώμα νήματος
4. Επιστρέψτε στο αρχικό αντικείμενο κειμένου
5. Εφαρμόστε μια δεύτερη **Επιλογή διαδρομών** → ορίστε την προρύθμιση σε **Μόνο οπές**
6. Εφαρμόστε **Γραμμική Εξώθηση** με το ίδιο ύψος → αναθέστε το δεύτερο σας χρώμα νήματος
7. Τοποθετήστε το ένα εξωθημένο αντικείμενο πάνω στο άλλο — τα δύο χρώματα ευθυγραμμίζονται τέλεια
