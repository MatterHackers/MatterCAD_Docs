# Διαδρομή περιγράμματος

Η Διαδρομή περιγράμματος δημιουργεί μια εκδοχή περιγράμματος από μια γεμάτη διαδρομή, μετατρέποντας ένα συμπαγές σχήμα μόνο στον οριακό του δακτύλιο με καθορισμένο πάχος.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Τρόπος χρήσης

1. Επιλέξτε μια δισδιάστατη διαδρομή
2. Εφαρμόστε τη **Διαδρομή περιγράμματος** από το μενού λειτουργιών Διαδρομή
3. Ρυθμίστε το πάχος του περιγράμματος

## Συμβουλές

- Χρησιμοποιήστε τη για να δημιουργήσετε σχήματα τύπου πλαισίου από συμπαγείς διαδρομές
- Συνδυάστε τη με τη [Γραμμική Εξώθηση](linear-extrude.md) για να δημιουργήσετε τρισδιάστατα πλαίσια και περιγράμματα
- Μια διαδρομή [Κύκλος](../../2d-paths/circle-path.md) με περίγραμμα ισοδυναμεί με μια διαδρομή [Δακτύλιος](../../2d-paths/ring-path.md)
