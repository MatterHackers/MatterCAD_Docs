# Γραμμική Εξώθηση

Η Γραμμική Εξώθηση δίνει ύψος σε μια 2D διαδρομή, μετατρέποντας ένα επίπεδο σχήμα σε 3D στερεό. Αυτός είναι ο βασικός τρόπος για να μετατρέψετε διαδρομές σε 3D αντικείμενα.

## Πώς χρησιμοποιείται

1. Επιλέξτε μια 2D διαδρομή ή ένα αντικείμενο βασισμένο σε διαδρομή
2. Εφαρμόστε τη **Γραμμική Εξώθηση** από το μενού λειτουργιών Διαδρομής
3. Ορίστε το επιθυμητό ύψος

## Παράμετροι

- **Ύψος** - Πόσο ψηλή είναι η εξώθηση (προεπιλογή: 5mm, εύρος: 0.1-50mm)
- **Λοξοτόμηση πάνω** - Προσθέτει μια λοξοτομημένη (στρογγυλεμένη) ακμή στο επάνω μέρος της εξώθησης (προεπιλογή: ανενεργό)

### Παράμετροι Λοξοτόμησης (εμφανίζονται όταν είναι ενεργή η Λοξοτόμηση πάνω)

- **Στυλ** - Το στυλ του προφίλ λοξοτόμησης (Αιχμηρό ή στρογγυλεμένο)
- **Ακτίνα** - Πόσο πλατιά εκτείνεται η λοξοτόμηση (προεπιλογή: 3mm)
- **Τμήματα** - Ομαλότητα της καμπύλης λοξοτόμησης (προεπιλογή: 9)

## Συμβουλές

- Λειτουργεί με οποιαδήποτε 2D διαδρομή: [Κύκλος](../../2d-paths/circle-path.md), [Κουτί](../../2d-paths/box-path.md), [Αστέρι](../../2d-paths/star-path.md), [SVG](../../primitives/svg-object.md) και [Προσαρμοσμένο](../../2d-paths/custom-path.md) διαδρομές
- Ενεργοποιήστε τη Λοξοτόμηση πάνω για πιο περιποιημένη, επαγγελματική εμφάνιση
- Για περιστροφή μιας διαδρομής γύρω από έναν άξονα αντί για ευθεία εξώθηση προς τα πάνω, δείτε την [Περιστροφή](revolve.md)
