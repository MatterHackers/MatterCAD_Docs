# Εξομάλυνση Διαδρομής

Η Εξομάλυνση Διαδρομής στρογγυλεύει τις γωνίες και τις καμπύλες μιας 2D διαδρομής, δημιουργώντας πιο απαλά, πιο οργανικά σχήματα από γωνιώδεις εισόδους.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Τρόπος χρήσης

1. Επιλέξτε μια 2D διαδρομή
2. Εφαρμόστε την **Εξομάλυνση Διαδρομής** από το μενού λειτουργιών Διαδρομής
3. Οι γωνίες της διαδρομής εξομαλύνονται σε καμπύλες

## Συμβουλές

- Εφαρμόστε την πριν από τη [Γραμμική Εξώθηση](linear-extrude.md) για να δημιουργήσετε εξωθημένα σχήματα με απαλές ακμές
- Χρησιμοποιήστε την σε μια [Διαδρομή Αστεριού](../../2d-paths/star-path.md) για να δημιουργήσετε ένα στρογγυλεμένο αστέρι
- Πολλαπλές εφαρμογές της Εξομάλυνσης Διαδρομής αυξάνουν το αποτέλεσμα της εξομάλυνσης
