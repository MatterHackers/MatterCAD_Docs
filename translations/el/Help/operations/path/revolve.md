# Περιστροφή

Η Περιστροφή περιστρέφει μια διαδρομή 2D γύρω από έναν άξονα για τη δημιουργία ενός τρισδιάστατου στερεού εκ περιστροφής. Έτσι δημιουργείτε βάζα, μπολ, τροχούς και άλλα αντικείμενα με συμμετρία περιστροφής.

## Τρόπος χρήσης

1. Επιλέξτε μια διαδρομή 2D
2. Εφαρμόστε την **Περιστροφή** από το μενού λειτουργιών Διαδρομής
3. Προσαρμόστε το εύρος περιστροφής, τη θέση του άξονα και τον αριθμό των πλευρών

## Παράμετροι

- **Περιστροφή** - Συνολική γωνία περιστροφής για την περιστροφή (προεπιλογή: 0, εύρος: 0-360). Ορίστε την σε 360 για πλήρη περιστροφή.
- **Θέση άξονα** - Μετατόπιση του άξονα περιστροφής από το κέντρο της διαδρομής (προεπιλογή: 0, εύρος: -30 έως 30). Οι θετικές τιμές απομακρύνουν τον άξονα από τη διαδρομή, δημιουργώντας μεγαλύτερο άνοιγμα.
- **Αρχική Γωνία** - Πού ξεκινά η περιστροφή (προεπιλογή: 0)
- **Γωνία Τέλους** - Πού τελειώνει η περιστροφή (προεπιλογή: 45). Ορίστε την σε 360 για πλήρη περιστροφή.
- **Πλευρές** - Αριθμός τμημάτων γύρω από την περιστροφή (προεπιλογή: 30). Περισσότερα = πιο ομαλή επιφάνεια.

## Συμβουλές

- Χρησιμοποιήστε τη Θέση άξονα για να ελέγξετε την εσωτερική διάμετρο του σχήματος εκ περιστροφής
- Ορίστε την Αρχική Γωνία και τη Γωνία Τέλους σε τιμές μικρότερες από 360 για να δημιουργήσετε μερικές περιστροφές (αψίδες, υδρορροές)
- Σχεδιάστε μια διαδρομή προφίλ του βάζου ή του μπολ σας και έπειτα εφαρμόστε περιστροφή για τέλεια συμμετρία
- Μια [Διαδρομή Κύκλου](../../2d-paths/circle-path.md) σε περιστροφή δημιουργεί έναν δακτύλιο
