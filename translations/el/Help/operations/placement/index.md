# Λειτουργίες Τοποθέτησης
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

Οι λειτουργίες τοποθέτησης σας βοηθούν να τοποθετείτε με ακρίβεια αντικείμενα το ένα σε σχέση με το άλλο ή μέσα σε συγκεκριμένα όρια.

## Λειτουργίες

- [Στοίχιση](align.md) - Στοιχίστε αντικείμενα μεταξύ τους κατά μήκος οποιουδήποτε άξονα
- [Ευθυγράμμιση Διπλής Εξώθησης](dual-extrusion-align.md) - Ευθυγραμμίστε αντικείμενα στις κοινές τους θέσεις μοντελοποίησης
- [Προσαρμογή στα όρια](fit-to-bounds.md) - Κλιμακώστε ένα αντικείμενο ώστε να χωρά μέσα σε ένα καθορισμένο πλαίσιο ορίων
- [Προσαρμογή σε κύλινδρο](fit-to-cylinder.md) - Κλιμακώστε ένα αντικείμενο ώστε να χωρά μέσα σε έναν καθορισμένο κύλινδρο
