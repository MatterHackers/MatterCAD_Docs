# Επιλογή θυγατρικού

Η Επιλογή θυγατρικού επιλέγει ένα θυγατρικό αντικείμενο από μια ομάδα αντικειμένων, με βάση είτε έναν αριθμό δείκτη είτε ένα όνομα. Αυτό είναι ιδιαίτερα χρήσιμο σε σχεδιάσεις με σενάρια και παραμετρικές σχεδιάσεις, όπου θέλετε να επιλέγετε δυναμικά ποιο αντικείμενο θα εμφανίζεται.

## Τρόπος χρήσης

1. Επιλέξτε δύο ή περισσότερα αντικείμενα
2. Εφαρμόστε την λειτουργία **Επιλογή θυγατρικού** από το μενού Δημιουργία Διπλότυπου
3. Επιλέξτε **Κατά Δείκτη** ή **Κατά Όνομα** για να καθορίσετε τον τρόπο επιλογής του θυγατρικού
4. Ορίστε τον αριθμό δείκτη ή το όνομα που θα αντιστοιχιστεί

## Παράμετροι

- **Μέθοδος επιλογής** - Επιλέξτε ανάμεσα σε **Κατά Δείκτη** (επιλογή κατά θέση) ή **Κατά Όνομα** (επιλογή κατά όνομα αντικειμένου). Εμφανίζεται ως κουμπιά.
- **Θυγατρικός Δείκτης** - Ο δείκτης του θυγατρικού που θα επιλεγεί, με αρίθμηση από το μηδέν (εμφανίζεται όταν χρησιμοποιείται η μέθοδος Κατά Δείκτη). Υποστηρίζει [εκφράσεις](../../workspace/expressions.md).
- **Όνομα Θυγατρικού** - Το όνομα του θυγατρικού που θα επιλεγεί (εμφανίζεται όταν χρησιμοποιείται η μέθοδος Κατά Όνομα). Υποστηρίζει [εκφράσεις](../../workspace/expressions.md).

Αν ο δείκτης βρίσκεται εκτός εύρους ή το όνομα δεν αντιστοιχεί σε κανένα θυγατρικό, επιστρέφεται το πρώτο θυγατρικό ως εναλλακτική λύση. Αν δεν υπάρχουν θυγατρικά, δεν επιστρέφεται τίποτα.

## Χρήση σε Σενάρια

Η Επιλογή θυγατρικού έχει σχεδιαστεί για να συνεργάζεται με εκφράσεις και τη συνάρτηση `rand()`, ώστε να δημιουργείτε δυναμικές σχεδιάσεις καθοδηγούμενες από δεδομένα. Για παράδειγμα, μπορείτε να δημιουργήσετε μια σκηνή με πολλές παραλλαγές αντικειμένων ως θυγατρικά και να χρησιμοποιήσετε μια έκφραση όπως `rand(42)` ως σπόρο δείκτη για να επιλέγεται τυχαία ένα από αυτά.

**Παράδειγμα: Τυχαία σκηνικά βιβλία για μια θεατρική παράσταση**

1. Εισαγάγετε 5 διαφορετικά πλέγματα βιβλίων ως θυγατρικά μιας λειτουργίας Επιλογή θυγατρικού
2. Ορίστε τη Μέθοδο επιλογής σε **Κατά Δείκτη**
3. Χρησιμοποιήστε μια έκφραση για τον Θυγατρικό Δείκτη, όπως `floor(rand(seed) * 5)`, όπου το `seed` είναι μεταβλητή φύλλου
4. Δημιουργήστε πολλαπλά διπλότυπα της λειτουργίας Επιλογή θυγατρικού, το καθένα με διαφορετική τιμή σπόρου
5. Κάθε στιγμιότυπο επιλέγει τυχαία ένα διαφορετικό βιβλίο από το σύνολο

Το μοτίβο αυτό λειτουργεί σε κάθε περίπτωση όπου χρειάζεται να επιλέξετε από ένα σύνολο παραλλαγών: έπιπλα, διακοσμητικά, αρχιτεκτονικά στοιχεία ή οποιαδήποτε συλλογή εναλλάξιμων εξαρτημάτων.

## Συμβουλές

- Συνδυάστε την με τη [Συστοιχία](array.md) για να δημιουργήσετε ποικίλα μοτίβα, όπου κάθε αντιγραφή επιλέγει διαφορετικό θυγατρικό
- Χρησιμοποιήστε μεταβλητές φύλλου για τον δείκτη ή το όνομα, ώστε η επιλογή να καθοδηγείται από ένα υπολογιστικό φύλλο
- Η συμπεριφορά επιστροφής στο πρώτο θυγατρικό σημαίνει ότι η σχεδίασή σας δεν χαλάει ποτέ, ακόμη κι αν ο δείκτης ή το όνομα είναι λανθασμένα
