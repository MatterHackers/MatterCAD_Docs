# Λειτουργίες Συστοιχίας
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

Η Συστοιχία δημιουργεί πολλαπλά αντίγραφα ενός αντικειμένου διατεταγμένα σε ένα μοτίβο. Αυτό είναι χρήσιμο για τη δημιουργία επαναλαμβανόμενων χαρακτηριστικών όπως οπές βιδών, πάσσαλοι φράχτη, δόντια γραναζιών ή διακοσμητικά στοιχεία.

Η λειτουργία Συστοιχία υποστηρίζει τέσσερις τρόπους — Γραμμικό, Ακτινικό, Καμπύλη και Μετασχηματισμός — όλους σε ένα ενιαίο εργαλείο.
