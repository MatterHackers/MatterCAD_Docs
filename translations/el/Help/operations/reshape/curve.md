# Καμπύλη

Η Καμπύλη κάμπτει ένα ευθύγραμμο αντικείμενο σε τόξο ή κυκλικό σχήμα. Μπορείτε να ελέγξετε την κάμψη καθορίζοντας είτε μια γωνία είτε μια διάμετρο γύρω από την οποία θα τυλιχθεί.

## Τρόπος χρήσης

1. Επιλέξτε ένα αντικείμενο
2. Εφαρμόστε τη λειτουργία **Καμπύλη** από το μενού Αναδιαμόρφωση
3. Επιλέξτε ανάμεσα σε τύπο κάμψης Γωνία ή Διάμετρος
4. Προσαρμόστε τις παραμέτρους για να πετύχετε την επιθυμητή καμπυλότητα

## Παράμετροι

- **Τύπος κάμψης** - Επιλέξτε ανάμεσα σε:
  - **Γωνία** - Καθορίστε απευθείας τη γωνία κάμψης (1-360 μοίρες)
  - **Διάμετρος** - Καθορίστε τη διάμετρο του κύκλου γύρω από τον οποίο τυλίγεται το εξάρτημα
- **Κατεύθυνση κάμψης** - Κάμψη προς τα πάνω ή Κάμψη Προς Τα Κάτω
- **Ποσοστό Έναρξης** - Σε ποιο σημείο κατά μήκος του αντικειμένου θα ξεκινήσει η κάμψη (0-100%)
- **Διαχωρισμός πλέγματος** - Διαχωρίζει το πλέγμα για ομαλές καμπύλες (προεπιλογή: ενεργό)
- **Ελάχ. Πλευρές Ανά Περιστροφή** - Ελάχιστος αριθμός τμημάτων πλέγματος ανά πλήρη περιστροφή. Μεγαλύτερες τιμές = πιο ομαλές καμπύλες

### Παράμετροι για προχωρημένους

- **Ποσοστό έναρξης κάμψης** - Ποσοστό από τα αριστερά όπου ξεκινά η κάμψη
- **Ποσοστό Κάμψης Τέλους** - Ποσοστό από τα αριστερά όπου τελειώνει η κάμψη

## Συμβουλές

- Χρησιμοποιήστε την Καμπύλη για να δημιουργήσετε αψίδες, δακτυλίους και κυρτά στηρίγματα από ευθύγραμμα σχήματα
- Ορίζοντας τη γωνία στις 360 μοίρες, το αντικείμενο τυλίγεται σχηματίζοντας έναν πλήρη δακτύλιο
- Αυξήστε τις Ελάχ. Πλευρές Ανά Περιστροφή για ομαλότερα αποτελέσματα σε έντονες κάμψεις
- Το αντικείμενο κάμπτεται κατά μήκος του (άξονας X)
