# Λειτουργίες Αναδιαμόρφωσης
<!-- AUTO_IMAGE: type=toolbar_icons group=Reshape -->
![Reshape toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Reshape.png)

Οι λειτουργίες αναδιαμόρφωσης παραμορφώνουν και τροποποιούν τη γεωμετρία των αντικειμένων σας, επιτρέποντάς σας να δημιουργείτε οργανικές και σύνθετες μορφές από απλά σχήματα.

## Λειτουργίες

- [Καμπύλη](curve.md) - Κάμψη ενός αντικειμένου κατά μήκος μιας καμπύλης
- [Συστροφή](twist.md) - Προοδευτική περιστροφή ενός αντικειμένου κατά μήκος του ύψους του
- [Σύσφιξη](pinch.md) - Συμπίεση ενός αντικειμένου προς τον κεντρικό του άξονα
- [Ακτινικό Στένεμα](radial-pinch.md) - Ακτινική σύσφιξη ενός αντικειμένου γύρω από έναν άξονα
- [Τομή Επιπέδου](plane-cut.md) - Τεμαχισμός ενός αντικειμένου με ένα επίπεδο σε καθορισμένο ύψος
- [Κοίλανση](hollow-out.md) - Δημιουργία κοίλου κελύφους από ένα συμπαγές αντικείμενο
