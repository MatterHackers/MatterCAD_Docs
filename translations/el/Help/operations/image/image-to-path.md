# Εικόνα σε Διαδρομή

Η λειτουργία Εικόνα σε Διαδρομή ιχνηλατεί τα περιγράμματα μιας εικόνας για τη δημιουργία 2D διαδρομών. Αυτές οι διαδρομές μπορούν στη συνέχεια να εξωθηθούν, να περιστραφούν ή να χρησιμοποιηθούν με οποιαδήποτε άλλη λειτουργία διαδρομής. Είναι ιδανική για τη μετατροπή λογοτύπων, σιλουετών και απλών γραφικών σε 3D αντικείμενα.

![20260324 075521 paste 20260324 075521](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-075521-paste-20260324-075521.jpg)


## Τρόπος χρήσης

1. Επιλέξτε ένα αντικείμενο εικόνας στον χώρο εργασίας σας
2. Εφαρμόστε την **Εικόνα σε Διαδρομή** από το μενού λειτουργιών Εικόνας
3. Επιλέξτε τον τύπο ανάλυσης και προσαρμόστε το εύρος επιλογής

## Παράμετροι

- **Τύπος Ανάλυσης** - Ο τρόπος με τον οποίο αναλύεται η εικόνα για την ιχνηλάτηση:
  - **Διαφάνεια** - Ιχνηλάτηση με βάση τις διαφανείς έναντι των αδιαφανών περιοχών (ιδανικό για PNG με διαφανές φόντο)
  - **Χρώματα** - Ιχνηλάτηση με βάση τις περιοχές χρώματος
  - **Ένταση** - Ιχνηλάτηση με βάση τα επίπεδα φωτεινότητας (ιδανικό για τις περισσότερες εικόνες)
- **Επιλογή εύρους** - Ένα χειριστήριο ιστογράμματος για την επιλογή των τιμών φωτεινότητας/χρώματος που θα συμπεριληφθούν στο ίχνος
- **Ελάχ. Επιφάνεια** - Η ελάχιστη επιφάνεια ώστε ένας βρόχος διαδρομής να συμπεριληφθεί. Αυξήστε την για να φιλτράρετε μικρά τεχνουργήματα θορύβου

## Συμβουλές

- Οι καθαρές εικόνες υψηλής αντίθεσης με απλά σχήματα λειτουργούν καλύτερα
- Χρησιμοποιήστε τη λειτουργία Διαφάνεια για εικόνες PNG με διαφανές φόντο
- Χρησιμοποιήστε τη λειτουργία Ένταση για φωτογραφίες και εικόνες χωρίς διαφάνεια
- Μετά την ιχνηλάτηση, εφαρμόστε [Γραμμική Εξώθηση](../path/linear-extrude.md) για να δώσετε ύψος στη διαδρομή
- Αυξήστε την Ελάχ. Επιφάνεια για να αφαιρέσετε μικρές ανεπιθύμητες λεπτομέρειες από το ίχνος
