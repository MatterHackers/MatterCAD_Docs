# Λειτουργίες Εικόνας
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

Οι λειτουργίες εικόνας μετατρέπουν δισδιάστατες εικόνες σε τρισδιάστατα αντικείμενα ή διαδρομές, επιτρέποντάς σας να ενσωματώσετε φωτογραφίες, λογότυπα και έργα τέχνης στα σχέδιά σας.

## Λειτουργίες

- [Μετατροπέας Εικόνας](image-converter.md) - Μετατρέψτε μια εικόνα σε τρισδιάστατο ανάγλυφο με βάση τη φωτεινότητα ή το χρώμα
- [Εικόνα σε Διαδρομή](image-to-path.md) - Ιχνηλατήστε μια εικόνα για να δημιουργήσετε ένα δισδιάστατο περίγραμμα διαδρομής
- [Λιθοφάνεια](lithophane.md) - Δημιουργήστε μια λιθοφάνεια που αποκαλύπτει μια εικόνα όταν φωτίζεται από πίσω
