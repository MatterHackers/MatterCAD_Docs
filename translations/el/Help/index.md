# Καλώς ορίσατε

![paste 20260317 175249](https://matterhackers.github.io/MatterCAD_Docs/assets/paste-20260317-175249.jpg)

Καλώς ορίσατε στο MatterCAD, το επαγγελματικό λογισμικό τρισδιάστατης σχεδίασης που σας βοηθά να δημιουργείτε και να τροποποιείτε τρισδιάστατα μοντέλα. Χρησιμοποιήστε τους παρακάτω συνδέσμους για να βρείτε βοήθεια σε οποιοδήποτε θέμα.

## Ξεκινώντας

- [Ξεκινώντας](getting-started/index.md) - Μάθετε τα βασικά του χώρου εργασίας του MatterCAD
- [Πλοήγηση στο παράθυρο προβολής](getting-started/viewport-navigation.md) - Πώς να περιστρέψετε, να μετακινήσετε και να κάνετε ζουμ στην τρισδιάστατη προβολή
- [Δημιουργία νέων αντικειμένων](getting-started/creating-new-objects.md) - Προσθέστε βασικά σχήματα και ξεκινήστε τη σχεδίαση
- [Προσθήκη υπαρχόντων αντικειμένων](getting-started/adding-existing-objects.md) - Εισαγωγή αρχείων και περιεχομένου βιβλιοθήκης
- [Επεξεργασία αντικειμένων](getting-started/editing-objects.md) - Μετακινήστε, περιστρέψτε και κλιμακώστε εξαρτήματα στην τρισδιάστατη προβολή
- [Αποθήκευση και Εξαγωγή](getting-started/saving-and-exporting.md) - Αποθηκεύστε την εργασία σας και εξάγετέ την σε διαφορετικές μορφές

## Δομικά στοιχεία σχεδίασης

- [Βασικά Σχήματα](primitives/index.md) - Τρισδιάστατα σχήματα όπως κύβοι, κύλινδροι, σφαίρες, κείμενο και άλλα
- [Δισδιάστατες διαδρομές](2d-paths/index.md) - Επίπεδα σχήματα που μπορούν να εξωθηθούν ή να περιστραφούν σε τρισδιάστατα αντικείμενα
- [Μηχανικά εξαρτήματα](mechanical/index.md) - Γρανάζια, σπειρώματα και άλλα μηχανικά εξαρτήματα
