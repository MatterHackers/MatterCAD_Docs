# MatterCAD 2.2026.8

# Τι νέο υπάρχει

* **Επεξεργασία Θυγατρικών**
  * Κάντε διπλό κλικ σε οποιοδήποτε αντικείμενο για να μπείτε μέσα του και να επεξεργαστείτε τα μέρη από τα οποία αποτελείται, απευθείας πάνω στην επιφάνεια εκτύπωσης
  * Μια διαδρομή πλοήγησης δείχνει πού βρίσκεστε — κάντε κλικ σε οποιοδήποτε επίπεδο για να ενσωματώσετε ξανά τις αλλαγές σας
  * ![MatterCAD 2.2026.8](https://www.matterhackers.com/r/qgG4VA)

* **Ένα ενιαίο εργαλείο Boolean**
  * Οι λειτουργίες Συνδυασμός, Αφαίρεση, Τομή και Αφαίρεση και Αντικατάσταση είναι πλέον μία ενιαία λειτουργία — αλλάξτε λειτουργία με ένα κλικ, αντί να διαγράφετε και να εφαρμόζετε ξανά
  <!-- Boolean property panel showing the four-icon operation row with Subtract selected. ~500x350px -->
  * ![One Boolean Tool](https://matterhackers.github.io/MatterCAD_Docs/assets/20260810-181041-paste-20260810-181041.jpg)

* **Λειτουργίες Boolean που απλώς δουλεύουν**
  * Μια νέα μηχανή είναι ταχύτερη και τα καταφέρνει σε πλέγματα που παλιότερα αποτύγχαναν
  * Ο Συνδυασμός επιδιορθώνει αυτόματα εξαρτήματα με οπές και ονομάζει ό,τι δεν μπόρεσε να συγχωνεύσει· η Τομή Επιπέδου αφήνει πλέον ένα στεγανό, εκτυπώσιμο στερεό

* **Καλύτερη επεξεργασία διαδρομών 2D**
  * Λειτουργίες σημείων, ζωντανή συμμετρία με Καθρεπτισμό, προσκόλληση σε πλέγμα, επιλογή με σύρσιμο και Esc για ακύρωση του συρσίματος
  <!-- Turn on Mirror, drag a point and watch its partner follow, then drag it onto the axis to merge. ~700x450px -->
  * ![Path Edit](https://www.matterhackers.com/r/yQwWXB)

## Βελτιώσεις

* **Πλοήγηση** — Πατήστε Z με επιλεγμένη μια διαδρομή 2D για προβολή επεξεργασίας από επάνω
* **Ευκρινέστερο Κείμενο** — Η απόδοση κειμένου σε επίπεδο υποεικονοστοιχείου ενεργοποιείται πλέον αυτόματα όταν η οθόνη σας το υποστηρίζει
* **Μοντελοποίηση** — Η Γραμμική Εξώθηση μπορεί να λοξοτομήσει την κάτω ακμή με δικό της στυλ, ακτίνα και πλήθος τμημάτων

## Κορυφαίες διορθώσεις σφαλμάτων

* **Αξιοπιστία Αποθήκευσης** — Μια αποτυχημένη αποθήκευση δεν μπορεί πλέον να καταστρέψει το αρχείο που αντικαθιστούσε και σας ενημερώνει ότι απέτυχε
* **Βιβλιοθήκη Cloud** — Η αποθήκευση ενός στοιχείου cloud στον δίσκο διατηρεί το όνομα της καρτέλας του και η καρτέλα παραμένει μετά από επανεκκίνηση
* **Φόρτωση Αρχείων** — Διορθώθηκε η σιωπηλή απόρριψη εξαρτημάτων 3MF κατά τη φόρτωση
* **Επεξεργασία Διαδρομής** — Διορθώθηκε μια κατάρρευση κατά τη διαγραφή σημείου καμπύλης, καθώς και η επαναφορά της λειτουργίας που επιλέξατε στα σημεία ραφής
* **Εργασίες Παρασκηνίου** — Το κουμπί Διακοπή σε μια εργασία που εκτελείται είναι πλέον ενεργό και όντως την ακυρώνει
