# Βιβλιοθήκη

Η βιβλιοθήκη σάς επιτρέπει να οργανώνετε, να αποθηκεύετε και να κοινοποιείτε τα τρισδιάστατα σχέδιά σας. Μπορείτε να περιηγηθείτε σε τοπικά αρχεία, να αποκτήσετε πρόσβαση στον αποθηκευτικό χώρο cloud και να κοινοποιήσετε σχέδια σε άλλους.

## Θέματα

- [Τοπική βιβλιοθήκη](local-library.md) - Διαχειριστείτε τα σχέδιά σας που είναι αποθηκευμένα στον υπολογιστή σας
- [Βιβλιοθήκη Cloud](cloud-library.md) - Αποθηκεύστε και αποκτήστε πρόσβαση σε σχέδια στον λογαριασμό cloud σας MatterHackers
- [Κοινοποίηση](sharing.md) - Κοινοποιήστε σχέδια σε άλλους χρήστες του MatterCAD
