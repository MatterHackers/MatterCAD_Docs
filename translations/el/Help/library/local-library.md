# Τοπική βιβλιοθήκη

Η Τοπική βιβλιοθήκη αποθηκεύει τα 3D σχέδιά σας στον υπολογιστή σας. Μπορείτε να οργανώσετε τα σχέδια σε φακέλους, να αναζητήσετε αρχεία και να τα προσθέσετε γρήγορα στον χώρο εργασίας σας.

![20260323 210208 paste 20260323 210208](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210208-paste-20260323-210208.jpg)


## Περιήγηση στη Βιβλιοθήκη

1. Ανοίξτε τον πίνακα **Βιβλιοθήκη** από την πλαϊνή γραμμή ή την καρτέλα Βιβλιοθήκη
2. Περιηγηθείτε στους φακέλους για να βρείτε τα σχέδιά σας
3. Κάντε διπλό κλικ σε ένα σχέδιο για να το ανοίξετε ή σύρετέ το στον χώρο εργασίας σας για να το προσθέσετε στην τρέχουσα σκηνή

## Οργάνωση των αρχείων σας

- **Δημιουργία φακέλων** - Κάντε δεξί κλικ μέσα στη βιβλιοθήκη και επιλέξτε Δημιουργία φακέλου για να οργανώσετε τα σχέδιά σας
- **Μετονομασία στοιχείων** - Κάντε δεξί κλικ σε οποιοδήποτε στοιχείο και επιλέξτε Μετονομασία
- **Διαγραφή στοιχείων** - Κάντε δεξί κλικ και επιλέξτε Διαγραφή για την αφαίρεση στοιχείων
- **Μετακίνηση στοιχείων** - Σύρετε στοιχεία μεταξύ φακέλων για αναδιοργάνωση

## Επιλογές προβολής

Ο πίνακας της βιβλιοθήκης υποστηρίζει πολλαπλές λειτουργίες προβολής:

- **Προβολή λίστας** - Συμπαγής λίστα που εμφανίζει τα ονόματα των αρχείων
- **Προβολή εικονιδίων** - Μικρογραφίες προεπισκόπησης των σχεδίων σας
- **Προβολή μεγάλων εικονιδίων** - Μεγαλύτερες μικρογραφίες για ευκολότερη περιήγηση

Μπορείτε να ταξινομήσετε τα στοιχεία κατά:

- **Όνομα** - Αλφαβητική σειρά
- **Ημερομηνία δημιουργίας** - Νεότερα ή παλαιότερα πρώτα
- **Ημερομηνία τροποποίησης** - Πιο πρόσφατα τροποποιημένα πρώτα

## Συμβουλές

- Χρησιμοποιήστε τη γραμμή αναζήτησης στο επάνω μέρος της βιβλιοθήκης για να βρείτε γρήγορα σχέδια με βάση το όνομα
- Ο περιηγητής της βιβλιοθήκης εμφανίζει μια μικρογραφία προεπισκόπησης για τους περισσότερους τύπους αρχείων
- Τα σχέδια που αποθηκεύονται σε μορφή MCX διατηρούν όλες τις παραμέτρους και το δέντρο σχεδίασης για πλήρη εκ νέου επεξεργασία
