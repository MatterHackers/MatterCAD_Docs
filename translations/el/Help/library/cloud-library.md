# Βιβλιοθήκη Cloud

Η Βιβλιοθήκη Cloud αποθηκεύει τα σχέδιά σας διαδικτυακά στον λογαριασμό σας MatterHackers. Έτσι μπορείτε να έχετε πρόσβαση στα σχέδιά σας από οποιονδήποτε υπολογιστή και να διατηρείτε ένα αντίγραφο ασφαλείας στο cloud.

![20260323 210141 paste 20260323 210141](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210141-paste-20260323-210141.jpg)

## Ξεκινώντας

1. Κάντε σύνδεση στον λογαριασμό σας MatterHackers από το μενού της εφαρμογής
2. Η Βιβλιοθήκη Cloud εμφανίζεται στον περιηγητή βιβλιοθήκης σας
3. Κάντε μεταφόρτωση σχεδίων σύροντάς τα στον φάκελο cloud ή αποθηκεύστε απευθείας στο cloud

## Χαρακτηριστικά

- **Πρόσβαση από παντού** - Τα σχέδιά σας είναι διαθέσιμα σε κάθε υπολογιστή όπου κάνετε σύνδεση
- **Αντίγραφο ασφαλείας στο cloud** - Η δουλειά σας αποθηκεύεται με ασφάλεια διαδικτυακά
- **Οργάνωση σε φακέλους** - Δημιουργήστε φακέλους για να οργανώσετε τα σχέδιά σας στο cloud, όπως ακριβώς και στην τοπική βιβλιοθήκη
- **Κοινοποίηση** - Κάντε κοινοποίηση σχεδίων σε άλλους χρήστες του MatterCAD. Δείτε [Κοινοποίηση](sharing.md)

## Συμβουλές

- Τα σχέδια συγχρονίζονται αυτόματα όταν αποθηκεύετε στη βιβλιοθήκη cloud
- Χρειάζεστε σύνδεση στο διαδίκτυο για πρόσβαση στο περιεχόμενο της βιβλιοθήκης cloud
- Τα μεγάλα αρχεία ενδέχεται να χρειαστούν λίγο χρόνο για μεταφόρτωση ή λήψη
- Διατηρείτε τα σημαντικά σχέδια τόσο στην τοπική βιβλιοθήκη όσο και στη βιβλιοθήκη cloud για μεγαλύτερη ασφάλεια

- [MatterCAD Pro](../mattercad-pro.md) - Χαρακτηριστικά Pro για αποθήκευση στο cloud
