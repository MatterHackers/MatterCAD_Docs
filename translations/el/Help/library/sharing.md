# Κοινοποίηση

Το MatterCAD σάς επιτρέπει να μοιράζεστε τα σχέδιά σας με άλλους χρήστες μέσω κωδικών κοινοποίησης. Έτσι γίνεται εύκολη η συνεργασία σε σχέδια ή η διανομή της δουλειάς σας.

![20260323 210309 paste 20260323 210309](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210309-paste-20260323-210309.jpg)


## Κοινοποίηση ενός σχεδίου

1. Κάντε δεξί κλικ σε ένα σχέδιο στη [Βιβλιοθήκη Cloud](cloud-library.md)
2. Επιλέξτε **Κοινοποίηση**
3. Δημιουργείται ένας κωδικός κοινοποίησης που μπορείτε να στείλετε σε άλλους

## Λήψη ενός κοινοποιημένου σχεδίου

1. Αποκτήστε έναν κωδικό κοινοποίησης από κάποιον
2. Χρησιμοποιήστε την επιλογή **Redeem Share Code** στη βιβλιοθήκη
3. Το κοινοποιημένο σχέδιο προστίθεται στη βιβλιοθήκη σας

## Συμβουλές

- Οι κωδικοί κοινοποίησης λειτουργούν με σχέδια που είναι αποθηκευμένα στη Βιβλιοθήκη Cloud
- Ο παραλήπτης λαμβάνει ένα αντίγραφο του σχεδίου -- οι αλλαγές που κάνει δεν επηρεάζουν το πρωτότυπό σας
- Οι κωδικοί κοινοποίησης μπορούν να διανεμηθούν μέσω οποιουδήποτε καναλιού: email, συνομιλία, μέσα κοινωνικής δικτύωσης κ.λπ.
