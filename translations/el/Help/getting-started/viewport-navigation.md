# Πλοήγηση στο παράθυρο προβολής

Το παράθυρο προβολής 3D είναι ο χώρος όπου βλέπετε και αλληλεπιδράτε με τα σχέδιά σας. Το MatterCAD χρησιμοποιεί ένα μοντέλο κάμερας τύπου trackball που σας επιτρέπει να περιστρέφετε, να μετατοπίζετε και να κάνετε ζουμ ελεύθερα γύρω από τα αντικείμενά σας.

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## Χειριστήρια Ποντικιού

### Περιστροφή της προβολής

- **Δεξί κλικ + Σύρσιμο** - Περιστρέψτε την κάμερα γύρω από το σχέδιό σας
- **Ctrl + Αριστερό κλικ + Σύρσιμο** - Εναλλακτική μέθοδος περιστροφής

### Μετατόπιση της προβολής

- **Μεσαίο κλικ + Σύρσιμο** - Μετακινήστε την προβολή αριστερά, δεξιά, πάνω ή κάτω
- **Ctrl + Shift + Αριστερό κλικ + Σύρσιμο** - Εναλλακτική μέθοδος μετατόπισης

### Μεγέθυνση και Σμίκρυνση

- **Τροχός κύλισης** - Κυλήστε προς τα πάνω για μεγέθυνση, προς τα κάτω για σμίκρυνση
- **Ctrl + Alt + Αριστερό κλικ + Σύρσιμο** - Εναλλακτική μέθοδος ζουμ

## Χειριστήρια πληκτρολογίου

### Συντομεύσεις προβολής

- **W** - Επαναφορά της προβολής ώστε να χωρέσουν όλα τα αντικείμενα στο παράθυρο προβολής
- **Z** - Ζουμ στο τρέχον επιλεγμένο αντικείμενο

### Πλοήγηση με τα πλήκτρα βελών

- **Πλήκτρα βελών** - Περιστροφή της προβολής
- **Shift + Πλήκτρα βελών** - Μετατόπιση της προβολής

### Συντομεύσεις ζουμ

- **Ctrl + Συν (+)** - Μεγέθυνση
- **Ctrl + Πλην (-)** - Σμίκρυνση

## Συμβουλές

- Αν χάσετε από τα μάτια σας το μοντέλο σας, πατήστε **W** για επαναφορά της προβολής και επαναφορά όλων μέσα στο κάδρο
- Χρησιμοποιήστε το **Z** αφού επιλέξετε ένα αντικείμενο για να εστιάσετε γρήγορα σε αυτό
- Το ζουμ με τον τροχό κύλισης κεντράρεται στη θέση του δείκτη του ποντικιού σας, οπότε στοχεύστε στην περιοχή στην οποία θέλετε να κάνετε ζουμ
- Μπορείτε να συνδυάσετε την περιστροφή και τη μετατόπιση για να εξετάσετε το σχέδιό σας από οποιαδήποτε γωνία
