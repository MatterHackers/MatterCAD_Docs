# Δημιουργία Νέων Αντικειμένων

Το MatterCAD παρέχει ένα πλούσιο σύνολο εργαλείων για τη δημιουργία τρισδιάστατων αντικειμένων. Μπορείτε να ξεκινήσετε με βασικά σχήματα, να χρησιμοποιήσετε εξειδικευμένα εργαλεία όπως το κείμενο και οι κωδικοί QR, ή να κατασκευάσετε σύνθετες μορφές χρησιμοποιώντας λειτουργίες Boolean και συστοιχίες.

![20260324 081122 paste 20260324 081122](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081122-paste-20260324-081122.jpg)

## Προσθήκη Βασικών Σχημάτων

Ο ταχύτερος τρόπος για να ξεκινήσετε ένα σχέδιο είναι προσθέτοντας βασικά σχήματα. Ανοίξτε τον πίνακα Βασικά Σχήματα στη βιβλιοθήκη και κάντε κλικ σε οποιοδήποτε σχήμα για να το προσθέσετε στον χώρο εργασίας σας. Τα διαθέσιμα βασικά σχήματα περιλαμβάνουν:

- **Βασικά σχήματα** - Κύβος, Κύλινδρος, Σφαίρα, Κώνος, Δακτύλιος, Δακτύλιος, Πυραμίδα, Σφήνα και οι μισές παραλλαγές τους
- **Κείμενο και ειδικά** - Κείμενο, Braille, Κωδικός QR, Αντικείμενο Εικόνας, Αντικείμενο SVG

Κάθε βασικό σχήμα έχει παραμέτρους που μπορείτε να προσαρμόσετε στον πίνακα Ιδιότητες αφού το επιλέξετε. Για παράδειγμα, ένας Κύβος έχει χειριστήρια Πλάτος, Βάθος και Ύψος. Δείτε τα [Βασικά Σχήματα](../primitives/index.md) για λεπτομέρειες σχετικά με κάθε σχήμα.

## Η Γραμμή Εργαλείων Λειτουργιών

![20260324 081005 paste 20260324 081005](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081005-paste-20260324-081005.jpg)

Η γραμμή εργαλείων στο επάνω μέρος του παραθύρου προβολής σάς δίνει γρήγορη πρόσβαση σε κοινές λειτουργίες:

- **Αναίρεση / Επανάληψη** - Αντιστρέψτε ή επαναλάβετε αλλαγές. Μπορείτε επίσης να χρησιμοποιήσετε **Ctrl+Z** για αναίρεση και **Ctrl+Y** για επανάληψη
- **Ομαδοποίηση / Κατάργηση ομαδοποίησης** - Συνδυάστε τα επιλεγμένα αντικείμενα σε μια ομάδα που μετακινείται και λειτουργεί ως μία ενότητα, ή διασπάστε μια ομάδα
- **Αντιγραφή / Διαγραφή** - Δημιουργήστε διπλότυπο ή αφαίρεση των επιλεγμένων αντικειμένων. Λειτουργούν επίσης οι τυπικές συντομεύσεις **Ctrl+C**, **Ctrl+X** και **Ctrl+V**
- **Στοίχιση** - Τοποθετήστε πολλαπλά αντικείμενα σε σχέση μεταξύ τους
- **Λειτουργίες Boolean** - [Συνδυασμός](../operations/boolean/combine.md), [Αφαίρεση](../operations/boolean/subtract.md), [Τομή](../operations/boolean/intersect.md) και [Αφαίρεση & Αντικατάσταση](../operations/boolean/subtract-and-replace.md)
- **Συστοιχίες** - Δημιουργήστε [γραμμικά, ακτινικά, καμπύλα μοτίβα και μοτίβα μετασχηματισμού](../operations/array/array.md) από αντίγραφα αντικειμένων
- **Μετασχηματισμοί** - Εφαρμόστε [Περιστροφή](../operations/transform/rotate.md), [Κλίμακα](../operations/transform/scale.md), [Καθρεπτισμός](../operations/transform/mirror.md) και άλλες τροποποιήσεις

## Κατασκευή Σύνθετων Σχημάτων

Τα περισσότερα σχέδια στο MatterCAD κατασκευάζονται συνδυάζοντας απλά σχήματα:

1. **Ξεκινήστε με βασικά σχήματα** - Προσθέστε τα βασικά σχήματα που χρειάζεστε
2. **Τοποθετήστε τα** - Μετακινήστε και περιστρέψτε τα αντικείμενα ώστε να επικαλύπτονται εκεί που θέλετε
3. **Εφαρμόστε λειτουργίες Boolean** - Χρησιμοποιήστε τη [Συνδυασμός](../operations/boolean/combine.md) για να συγχωνεύσετε σχήματα μεταξύ τους, ή την [Αφαίρεση](../operations/boolean/subtract.md) για να κόψετε ένα σχήμα από ένα άλλο
4. **Βελτιώστε** - Χρησιμοποιήστε λειτουργίες [Αναδιαμόρφωση](../operations/reshape/index.md) όπως Λοξοτόμηση, Καμπύλη ή Συστροφή για να προσθέσετε λεπτομέρεια
