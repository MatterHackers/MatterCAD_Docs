# Προσθήκη Υπαρχόντων Αντικειμένων

Μπορείτε να εισαγάγετε υπάρχοντα τρισδιάστατα μοντέλα στο MatterCAD εισάγοντας αρχεία από τον υπολογιστή σας ή προσθέτοντας περιεχόμενο από την ενσωματωμένη βιβλιοθήκη.

## Από τον Υπολογιστή σας

![20260324 081143 paste 20260324 081143](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081143-paste-20260324-081143.jpg)

![20260324 081240 paste 20260324 081240](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081240-paste-20260324-081240.jpg)


Κάντε κλικ στο κουμπί **Άνοιγμα** στη γραμμή εργαλείων για να περιηγηθείτε και να προσθέσετε αρχεία από τον υπολογιστή σας. Το MatterCAD υποστηρίζει τις ακόλουθες μορφές εισαγωγής:

- **STL** (.stl) - Πρότυπη μορφή τρισδιάστατων μοντέλων του κλάδου, ευρέως χρησιμοποιούμενη για τρισδιάστατη εκτύπωση
- **AMF** (.amf) - Προηγμένη μορφή που υποστηρίζει χρώματα και αντικείμενα πολλαπλών υλικών
- **OBJ** (.obj) - Μορφή τρισδιάστατων γραφικών Wavefront (μόνο γεωμετρία πλέγματος)
- **3MF** (.3mf) - 3D Manufacturing Format με πλούσια υποστήριξη μεταδεδομένων
- **MCX** (.mcx) - Η εγγενής μορφή του MatterCAD, που διατηρεί όλα τα δεδομένα και τις παραμέτρους του σχεδίου
- **SVG** (.svg) - Scalable Vector Graphics, εισάγεται ως δισδιάστατες διαδρομές
- **TTF / OTF** (.ttf, .otf) - Αρχεία γραμματοσειρών για χρήση με το εργαλείο Κείμενο

## Μεταφορά και Απόθεση

Μπορείτε επίσης να μεταφέρετε και να αποθέσετε αρχεία απευθείας από την επιφάνεια εργασίας ή την εξερεύνηση αρχείων στον χώρο εργασίας του MatterCAD. Οι υποστηριζόμενοι τύποι αρχείων θα εισαχθούν αυτόματα.

## Από τη Βιβλιοθήκη

### Η Πλαϊνή γραμμή Βιβλιοθήκη

Κάντε κλικ στο κουμπί **Προσθήκη Περιεχομένου** στη γραμμή εργαλείων για να ανοίξετε τον πίνακα περιήγησης της βιβλιοθήκης. Από εδώ μπορείτε να:

- Περιηγηθείτε στα αποθηκευμένα σχέδιά σας
- Μεταβείτε στη βιβλιοθήκη Βασικά Σχήματα για ενσωματωμένα σχήματα
- Αποκτήσετε πρόσβαση στη Βιβλιοθήκη Cloud, εφόσον έχετε συνδεθεί
- Μεταφέρετε και αποθέσετε οποιοδήποτε στοιχείο από τη βιβλιοθήκη απευθείας στον χώρο εργασίας σας

![20260324 081446 paste 20260324 081446](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081446-paste-20260324-081446.jpg)

### Η Καρτέλα Βιβλιοθήκη

Μπορείτε επίσης να χρησιμοποιήσετε την καρτέλα Βιβλιοθήκη για να περιηγηθείτε στις συλλογές σας. Κάντε δεξί κλικ σε οποιοδήποτε αντικείμενο της βιβλιοθήκης και επιλέξτε **Προσθήκη στη Σκηνή** για να το εισαγάγετε στον τρέχοντα χώρο εργασίας σχεδίασης.

![20260324 081536 paste 20260324 081536](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081536-paste-20260324-081536.jpg)

## Συμβουλές

- Η μορφή MCX είναι η καλύτερη για μετέπειτα επανεπεξεργασία των σχεδίων, καθώς διατηρεί όλες τις παραμέτρους και το δέντρο σχεδίασης
- Τα αρχεία STL περιέχουν μόνο γεωμετρία πλέγματος. Αν εισαγάγετε ένα STL, μπορείτε ακόμη να εφαρμόσετε λειτουργίες σε αυτό, αλλά δεν μπορείτε να επεξεργαστείτε τις αρχικές παραμέτρους
- Κατά την εισαγωγή πολλαπλών αρχείων, το καθένα γίνεται ξεχωριστό αντικείμενο στη σκηνή σας. Χρησιμοποιήστε την [Ομαδοποίηση](../workspace/grouping.md) για να τα οργανώσετε
