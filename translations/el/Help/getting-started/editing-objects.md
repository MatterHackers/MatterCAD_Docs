# Επεξεργασία αντικειμένων

Το MatterCAD παρέχει διαισθητικά χειριστήρια, ενσωματωμένα απευθείας στην τρισδιάστατη προβολή, για τη μετακίνηση, την περιστροφή και την αλλαγή κλίμακας των αντικειμένων σας. Μπορείτε επίσης να επεξεργαστείτε τις παραμέτρους ενός αντικειμένου στον πίνακα Ιδιότητες.

## Μετακίνηση εξαρτημάτων


- **Σύρσιμο στην επιφάνεια εκτύπωσης** - Κάντε κλικ και σύρετε οποιοδήποτε αντικείμενο για να το μετακινήσετε πάνω στην επιφάνεια του χώρου εργασίας
- **Μετακίνηση πάνω και κάτω** - Χρησιμοποιήστε το κατακόρυφο χειριστήριο βέλους στο επάνω μέρος ενός επιλεγμένου αντικειμένου για να ρυθμίσετε το ύψος του (θέση Z)
- Για ακριβή τοποθέτηση, χρησιμοποιήστε τη λειτουργία [Μετακίνηση](../operations/transform/translate.md) ή πληκτρολογήστε ακριβείς τιμές στον πίνακα Ιδιότητες

## Περιστροφή εξαρτημάτων

![20260324 080843 paste 20260324 080843](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080843-paste-20260324-080843.jpg)

Κάντε κλικ σε οποιοδήποτε από τα **γωνιακά χειριστήρια περιστροφής** που εμφανίζονται όταν επιλέγετε ένα αντικείμενο. Αυτά σας επιτρέπουν να περιστρέψετε το αντικείμενο στο επίπεδο του συγκεκριμένου χειριστηρίου.

- Μετακινήστε τον δείκτη του ποντικιού πάνω από έναν από τους δείκτες γωνίας για να κουμπώσει η περιστροφή σε **βήματα 45 μοιρών**
- Για ακριβή περιστροφή, χρησιμοποιήστε τη λειτουργία [Περιστροφή](../operations/transform/rotate.md) και εισαγάγετε μια ακριβή γωνία

## Κλίμακα εξαρτημάτων

![20260324 080819 paste 20260324 080819](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080819-paste-20260324-080819.jpg)


Κάντε κλικ σε οποιοδήποτε από τα **γωνιακά χειριστήρια κλίμακας** για να αλλάξετε το μέγεθος του εξαρτήματός σας στον χώρο εργασίας.

- Σύρετε μια γωνία για αναλογική αλλαγή κλίμακας
- Για ακριβείς διαστάσεις ή μη ομοιόμορφη κλίμακα, χρησιμοποιήστε τη λειτουργία [Κλίμακα](../operations/transform/scale.md), όπου μπορείτε να ορίσετε ακριβείς διαστάσεις ή να αλλάξετε την κλίμακα κάθε άξονα ανεξάρτητα

## Επεξεργασία παραμέτρων

Όταν επιλέγετε ένα αντικείμενο, οι παράμετροί του εμφανίζονται στον πίνακα Ιδιότητες στη δεξιά πλευρά της οθόνης. Για παράδειγμα:

- Ένας **Κύβος** εμφανίζει Πλάτος, Βάθος, Ύψος και προαιρετικά χειριστήρια στρογγυλοποίησης
- Ένας **Κύλινδρος** εμφανίζει Διάμετρο, Ύψος και Πλευρές
- Ένα αντικείμενο **Κείμενο** εμφανίζει το περιεχόμενο του κειμένου, τη γραμματοσειρά, το μέγεθος και το ύψος

Μπορείτε να πληκτρολογήσετε τιμές απευθείας, να χρησιμοποιήσετε ρυθμιστικά ή να εισαγάγετε [εκφράσεις](../workspace/expressions.md) για παραμετρικές σχέσεις.

## Μενού περιβάλλοντος

Κάντε δεξί κλικ σε οποιοδήποτε αντικείμενο για πρόσβαση σε πρόσθετες επιλογές, όπως:

- Αντιγραφή, Αποκοπή, Διαγραφή
- Ομαδοποίηση / Κατάργηση ομαδοποίησης
- Διαθέσιμες λειτουργίες για το επιλεγμένο αντικείμενο
- Βοήθεια για τον συγκεκριμένο τύπο αντικειμένου (όπου είναι διαθέσιμη)

## Συμβουλές

- Κρατήστε πατημένο το **Shift** ενώ κάνετε κλικ για να επιλέξετε πολλά αντικείμενα και έπειτα μετακινήστε τα ή εφαρμόστε λειτουργίες σε αυτά μαζί
- Πατήστε **Ctrl+Z** για να αναιρέσετε οποιαδήποτε αλλαγή κάνετε
- Χρησιμοποιήστε τη [Στοίχιση](../operations/placement/align.md) για να τοποθετήσετε με ακρίβεια πολλά αντικείμενα το ένα σε σχέση με το άλλο
- Πατήστε **Space** για να καθαρίσετε την επιλογή σας
