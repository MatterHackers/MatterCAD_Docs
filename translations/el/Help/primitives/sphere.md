# Σφαίρα

Ένα στρογγυλό σχήμα μπάλας με ρυθμιζόμενη διάμετρο και επίπεδο λεπτομέρειας.

## Παράμετροι

- **Διάμετρος** - Το πλάτος κατά μήκος της σφαίρας (προεπιλογή: 20mm)
- **Πλευρές** - Αριθμός τμημάτων γύρω από την περίμετρο (προεπιλογή: 40). Περισσότερες πλευρές = πιο ομαλή επιφάνεια

### Παράμετροι για προχωρημένους

Ενεργοποιήστε τη λειτουργία **Για προχωρημένους** για πρόσθετα στοιχεία ελέγχου:

- **Αρχική Γωνία** - Η γωνία όπου ξεκινά η επιφάνεια της σφαίρας (προεπιλογή: 0)
- **Γωνία Τέλους** - Η γωνία όπου τελειώνει η επιφάνεια της σφαίρας (προεπιλογή: 360). Ορίστε τιμή μικρότερη από 360 για σχήματα μερικής σφαίρας
- **Πλευρές Πλάτους** - Αριθμός τμημάτων από πάνω προς τα κάτω (προεπιλογή: 30). Περισσότερα = πιο ομαλοί πόλοι

## Συμβουλές

- Για τρισδιάστατη εκτύπωση, οι 40 πλευρές είναι συνήθως αρκετές. Οι υψηλότερες τιμές δημιουργούν πιο ομαλές επιφάνειες αλλά μεγαλύτερα αρχεία
- Χρησιμοποιήστε την Αρχική Γωνία και τη Γωνία Τέλους για να δημιουργήσετε σχήματα μερικής σφαίρας, όπως μπολ ή θόλους
- Συνδυάστε με την [Αφαίρεση](../operations/boolean/subtract.md) για να δημιουργήσετε σφαιρικές κοιλότητες
