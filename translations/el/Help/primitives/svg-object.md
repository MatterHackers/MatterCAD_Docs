# Αντικείμενο SVG

Εισάγετε αρχεία SVG (Scalable Vector Graphics) και χρησιμοποιήστε τα ως διαδρομές 2D στο σχέδιό σας. Στη συνέχεια, τα SVG μπορούν να εξωθηθούν σε τρισδιάστατα σχήματα με τη [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) ή την [Περιστροφή](../operations/path/revolve.md).

## Τρόπος χρήσης

1. Εισαγάγετε ένα αρχείο SVG σύροντάς το στον χώρο εργασίας ή χρησιμοποιώντας το κουμπί Άνοιγμα
2. Το SVG εισάγεται ως διαδρομή 2D
3. Εφαρμόστε [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) για να του δώσετε ύψος ή χρησιμοποιήστε άλλες [Λειτουργίες Διαδρομής](../operations/path/index.md)

## Συμβουλές

- Τα αρχεία SVG θα πρέπει να περιέχουν γεμισμένα σχήματα ή κλειστές διαδρομές για καλύτερα αποτελέσματα
- Τα σύνθετα SVG με πολλές διαδρομές ενδέχεται να χρειαστούν περισσότερο χρόνο επεξεργασίας
- Χρησιμοποιήστε την [Επιλογή διαδρομών](../operations/path/select-paths.md) για να εργαστείτε με συγκεκριμένα τμήματα ενός SVG με πολλές διαδρομές
- Πολλά δωρεάν αρχεία SVG είναι διαθέσιμα online για λογότυπα, εικονίδια και διακοσμητικά μοτίβα
