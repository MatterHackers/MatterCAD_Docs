# Μισή Σφήνα

Ένα σχήμα σφήνας κομμένο στη μέση, που δημιουργεί διατομή ορθογωνίου τριγώνου. Χρήσιμο για γωνιακά στηρίγματα και μικρά κεκλιμένα χαρακτηριστικά.

## Παράμετροι

- **Πλάτος** - Μέγεθος κατά μήκος του άξονα X (προεπιλογή: 20mm)
- **Βάθος** - Μέγεθος κατά μήκος του άξονα Y (προεπιλογή: 20mm)
- **Ύψος** - Πόσο ψηλή είναι η μισή σφήνα στο υψηλότερο σημείο της (προεπιλογή: 10mm)

## Συμβουλές

- Χρησιμοποιήστε την ως γωνιακή στρογγύλευση ή στήριγμα
- Συνδυάστε την με άλλα σχήματα για να δημιουργήσετε κεκλιμένες μεταβάσεις
