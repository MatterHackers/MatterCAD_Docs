# Κύλινδρος

Ένα σχήμα στρογγυλής κολόνας με ρυθμιζόμενη διάμετρο, ύψος και αριθμό πλευρών. Ο Κύλινδρος είναι απαραίτητος για τη δημιουργία πείρων, ράβδων, οπών και στρογγυλών χαρακτηριστικών.

## Παράμετροι

- **Διάμετρος** - Το πλάτος κατά μήκος του κυλίνδρου (προεπιλογή: 20mm)
- **Ύψος** - Πόσο ψηλός είναι ο κύλινδρος (προεπιλογή: 20mm)
- **Πλευρές** - Αριθμός τμημάτων γύρω από την περίμετρο (προεπιλογή: 40). Οι χαμηλότερες τιμές δημιουργούν πολυγωνικά σχήματα (π.χ. 6 για εξάγωνο)

### Παράμετροι για προχωρημένους

Ενεργοποιήστε τη λειτουργία **Για προχωρημένους** για πρόσβαση σε πρόσθετα χειριστήρια:

- **Διάμετρος κορυφής** - Ορίστε διαφορετική διάμετρο για την κορυφή του κυλίνδρου, ώστε να δημιουργήσετε κωνικά ή κόλουρα κωνικά σχήματα (προεπιλογή: αντιστοιχεί στη Διάμετρο)
- **Αρχική Γωνία** - Η γωνία από όπου ξεκινά ο κύλινδρος (προεπιλογή: 0). Χρησιμοποιήστε την μαζί με τη Γωνία Τέλους για τη δημιουργία μερικών κυλίνδρων
- **Γωνία Τέλους** - Η γωνία όπου τελειώνει ο κύλινδρος (προεπιλογή: 360). Ορίστε τιμή μικρότερη από 360 για σχήματα φέτας πίτας

## Συμβουλές

- Ορίστε τις Πλευρές σε χαμηλό αριθμό για να δημιουργήσετε κανονικά πολύγωνα -- 6 για εξάγωνα, 8 για οκτάγωνα κ.λπ.
- Χρησιμοποιήστε διαφορετικές τιμές για τη Διάμετρο και τη Διάμετρο κορυφής για να δημιουργήσετε κόλουρους κώνους και κωνικά σχήματα
- Ορίστε την Αρχική Γωνία και τη Γωνία Τέλους για να δημιουργήσετε σχήματα φέτας πίτας ή τόξου
- Οι κύλινδροι αποτελούν εξαιρετικά εργαλεία κοπής για τη δημιουργία στρογγυλών οπών με [Αφαίρεση](../operations/boolean/subtract.md)
