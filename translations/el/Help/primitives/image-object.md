# Αντικείμενο Εικόνας

Εισαγάγετε μια εικόνα και μετατρέψτε την σε ένα τρισδιάστατο αντικείμενο ανάγλυφου, όπου οι τιμές φωτεινότητας καθορίζουν το ύψος κάθε pixel. Έτσι μπορείτε να μετατρέψετε φωτογραφίες, λογότυπα και έργα τέχνης σε αντικείμενα έτοιμα για τρισδιάστατη εκτύπωση.

## Τρόπος χρήσης

1. Προσθέστε έναν **Μετατροπέα Εικόνας** από τον πίνακα Βασικά Σχήματα ή σύρετε ένα αρχείο εικόνας απευθείας στον χώρο εργασίας
2. Επιλέξτε ή αλλάξτε την εικόνα μέσω των ιδιοτήτων
3. Ρυθμίστε το ύψος για να ελέγξετε πόσο ανυψώνονται οι φωτεινές περιοχές

## Παράμετροι

- **Ύψος** - Πόσο ψηλά είναι τα ανυψωμένα τμήματα της εικόνας
- Η προεπισκόπηση της εικόνας εμφανίζεται στον πίνακα Ιδιότητες

## Συμβουλές

- Οι εικόνες υψηλής αντίθεσης με ευκρινή σχήματα λειτουργούν καλύτερα
- Μπορείτε να σύρετε εικόνες απευθείας από την επιφάνεια εργασίας σας στον χώρο εργασίας του MatterCAD
- Χρησιμοποιήστε τα εργαλεία του μενού υπερχείλισης σε μια εισαγόμενη εικόνα για περισσότερες επιλογές μετατροπής
- Για περιγράμματα βασισμένα σε διαδρομές από εικόνες, δείτε [Εικόνα σε Διαδρομή](../operations/image/image-to-path.md)
- Για εικόνες με οπίσθιο φωτισμό, δείτε [Λιθοφάνεια](../operations/image/lithophane.md)
- Προσθέστε μια βάση συνδυάζοντας το αντικείμενο εικόνας με έναν [Κύβο](cube.md)
