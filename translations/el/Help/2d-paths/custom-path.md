# Προσαρμοσμένη διαδρομή

Σχεδιάστε τη δική σας 2D διαδρομή με σημεία ελέγχου. Αυτό σας δίνει πλήρη ελευθερία να δημιουργήσετε οποιοδήποτε 2D σχήμα, το οποίο μπορεί στη συνέχεια να υποστεί εξώθηση ή περιστροφή ώστε να γίνει 3D αντικείμενο.

## Πώς να το χρησιμοποιήσετε

1. Προσθέστε μια **Προσαρμοσμένη διαδρομή** από τη βιβλιοθήκη 2D Διαδρομών
2. Επεξεργαστείτε τα σημεία ελέγχου για να ορίσετε το σχήμα σας
3. Εφαρμόστε [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) ή άλλες λειτουργίες διαδρομής για να δημιουργήσετε ένα 3D αντικείμενο

## Ανοικτές και κλειστές διαδρομές

Το πλαίσιο ελέγχου **Κλειστό** καθορίζει αν η διαδρομή ενώνει το τελευταίο της σημείο πίσω με το πρώτο.

- Το **Κλειστό** (η προεπιλογή) κάνει τη διαδρομή να περιγράφει μια περιοχή. Αυτό είναι που γεμίζουν η [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) και η [Περιστροφή](../operations/path/revolve.md).
- Το **Άνοιγμα** κάνει τη διαδρομή γραμμή. Μια γραμμή δεν περικλείει τίποτα, οπότε εμφανίζεται στη σκηνή ως λεπτή ταινία κατά μήκος της και όχι ως γεμισμένο σχήμα. Χρησιμοποιήστε τη [Διόγκωση διαδρομής](../operations/path/inflate-path.md) για να της δώσετε πλάτος και να την ξανακάνετε κάτι στερεό.

Δύο πράγματα που πρέπει να γνωρίζετε πριν αποεπιλέξετε το **Κλειστό**:

- **Το εκ νέου κλείσιμο δεν είναι αναίρεση.** Το άνοιγμα μιας διαδρομής απορρίπτει το τμήμα που την έκλεινε. Αν εκείνο το τμήμα ήταν καμπύλο, επιλέγοντας ξανά το **Κλειστό** επανέρχεται μια ευθεία γραμμή, όχι η καμπύλη. Χρησιμοποιήστε αντ' αυτού το Ctrl+Z - η αναίρεση επαναφέρει την αρχική διαδρομή ακριβώς.
- **Ορισμένα περιγράμματα αρνούνται να ανοίξουν.** Ένα περίγραμμα που θα έμενε με λιγότερα από δύο σημεία - ένα σχήμα δακρύου σχεδιασμένο ως ένα μόνο σημείο και μια καμπύλη που επιστρέφει σε αυτό - παραμένει κλειστό αντί να καταρρεύσει σε κάτι που δεν θα μπορούσατε πλέον να δείτε ή να επιλέξετε. Το ίδιο ισχύει και για ένα περίγραμμα που περιέχει τετραγωνική καμπύλη, κάτι που μπορεί να περιέχει ένα εισαγόμενο SVG: το άνοιγμά του θα ισοπέδωνε την καμπύλη σε γωνία. Η άρνηση αφορά κάθε περίγραμμα ξεχωριστά, οπότε η υπόλοιπη διαδρομή ανοίγει κανονικά.

Αν μια διαδρομή έχει πολλά περιγράμματα και αυτά δεν συμφωνούν, το πλαίσιο ελέγχου εμφανίζεται ως ανοικτό. Επιλέγοντάς το, όλα τα περιγράμματα ευθυγραμμίζονται.

Οι λειτουργίες που χρειάζονται περιοχή θα κλείσουν μια ανοικτή διαδρομή για εσάς αντί να την απορρίψουν. Η Γραμμική Εξώθηση, η Περιστροφή, η Αφαίρεση και οι υπόλοιπες λογικές πράξεις το κάνουν όλες αυτό, οπότε μια ανοικτή διαδρομή εξωθείται στο ίδιο στερεό με την κλειστή εκδοχή της.

## Συμβουλές

- Χρησιμοποιήστε την Προσαρμοσμένη διαδρομή όταν κανένα από τα ενσωματωμένα σχήματα διαδρομής δεν ταιριάζει σε αυτό που χρειάζεστε
- Για την εισαγωγή σχημάτων από εξωτερικούς διανυσματικούς επεξεργαστές, δείτε το [Αντικείμενο SVG](../primitives/svg-object.md)
- Για να σχεδιάσετε μια γραμμή και να τη μετατρέψετε σε εξάρτημα, αποεπιλέξτε το **Κλειστό**, εφαρμόστε τη [Διόγκωση διαδρομής](../operations/path/inflate-path.md) για να της δώσετε πάχος και έπειτα τη [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) για να της δώσετε ύψος
