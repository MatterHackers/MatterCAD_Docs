# Διαδρομή Κουτιού

Μια ορθογώνια δισδιάστατη διαδρομή. Χρησιμοποιήστε την με τη [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) για να δημιουργήσετε σχήματα κουτιού ή ως βάση για άλλες λειτουργίες διαδρομής.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Παράμετροι

- **Πλάτος** - Το πλάτος του ορθογωνίου (προεπιλογή: 20mm)
- **Ύψος** - Το ύψος του ορθογωνίου (προεπιλογή: 20mm)

## Συμβουλές

- Μια Διαδρομή Κουτιού μαζί με Γραμμική Εξώθηση δημιουργεί ένα σχήμα παρόμοιο με τον [Κύβο](../primitives/cube.md), αλλά μπορείτε να εφαρμόσετε λειτουργίες διαδρομής όπως η [Διόγκωση](../operations/path/inflate-path.md) ή η [Εξομάλυνση](../operations/path/smooth-path.md) πριν από την εξώθηση

## Σχετικά

- [Διαδρομή Κύκλου](circle-path.md) - Μια κυκλική δισδιάστατη διαδρομή
- [Διαδρομή Αστεριού](star-path.md) - Μια δισδιάστατη διαδρομή σε σχήμα αστεριού
- [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) - Δώστε ύψος στις διαδρομές
