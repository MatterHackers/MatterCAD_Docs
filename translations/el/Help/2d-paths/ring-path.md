# Διαδρομή Δακτυλίου

Ένα δισδιάστατο σχήμα δακτυλίου -- ένας κύκλος με μια κυκλική οπή στο κέντρο. Χρησιμοποιήστε το με τη [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) για να δημιουργήσετε σχήματα σωλήνα ή ροδέλας.

![20260506 080211 paste 20260506 080211](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080211-paste-20260506-080211.jpg)

## Παράμετροι

- **Εξωτερική διάμετρος** - Η εξωτερική διάμετρος του δακτυλίου
- **Εσωτερική διάμετρος** - Η διάμετρος της οπής στο κέντρο

## Συμβουλές

- Το πάχος τοιχώματος του δακτυλίου είναι (Εξωτερική διάμετρος - Εσωτερική διάμετρος) / 2
- Η εξώθηση μιας Διαδρομής Δακτυλίου δημιουργεί έναν σωλήνα παρόμοιο με το πρωτόγονο σχήμα [Δακτύλιος](../primitives/ring.md)

## Σχετικά

- [Διαδρομή Κύκλου](circle-path.md) - Ένας συμπαγής κύκλος (χωρίς οπή)
- [Δακτύλιος](../primitives/ring.md) - Ένα έτοιμο τρισδιάστατο σχήμα σωλήνα
- [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) - Δώστε ύψος στις διαδρομές
