# Διαδρομή Αστεριού

Μια 2D διαδρομή σε σχήμα αστεριού με ρυθμιζόμενο αριθμό σημείων και εσωτερική/εξωτερική ακτίνα. Χρησιμοποιήστε την με τη [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) για να δημιουργήσετε τρισδιάστατα σχήματα αστεριού.

## Παράμετροι

- **Σημεία** - Αριθμός των σημείων του αστεριού
- **Εξωτερική Ακτίνα** - Απόσταση από το κέντρο έως την αιχμή κάθε σημείου
- **Εσωτερική Ακτίνα** - Απόσταση από το κέντρο έως τις κοιλάδες μεταξύ των σημείων

## Συμβουλές

- Η αναλογία μεταξύ Εσωτερικής και Εξωτερικής Ακτίνας καθορίζει πόσο "μυτερό" είναι το αστέρι. Μια μικρή Εσωτερική Ακτίνα δημιουργεί αιχμηρά, έντονα σημεία.
- Ορίστε τα Σημεία σε 5 για ένα κλασικό αστέρι, σε 6 για σχήμα Άστρου του Δαβίδ ή σε μεγαλύτερη τιμή για σχήματα που μοιάζουν με γρανάζι
- Χρησιμοποιήστε την [Εξομάλυνση Διαδρομής](../operations/path/smooth-path.md) σε μια Διαδρομή Αστεριού για να δημιουργήσετε αστέρια με στρογγυλεμένα σχήματα
