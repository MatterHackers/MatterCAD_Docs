# Διαδρομές 2D

Οι διαδρομές 2D είναι επίπεδα σχήματα που μπορείτε να χρησιμοποιήσετε ως αφετηρία για τρισδιάστατα αντικείμενα. Χρησιμοποιήστε τη [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) για να δώσετε ύψος σε μια διαδρομή ή την [Περιστροφή](../operations/path/revolve.md) για να περιστρέψετε μια διαδρομή γύρω από έναν άξονα και να δημιουργήσετε μια τρισδιάστατη μορφή.
