# Διαδρομή Κύκλου

Μια κυκλική δισδιάστατη διαδρομή. Χρησιμοποιήστε τη με τη [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) για να δημιουργήσετε κυλίνδρους ή με την [Περιστροφή](../operations/path/revolve.md) για να δημιουργήσετε σχήματα τύπου torus.

![20260506 080110 paste 20260506 080110](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080110-paste-20260506-080110.jpg)


## Παράμετροι

- **Διάμετρος** - Η διάμετρος του κύκλου (προεπιλογή: 20mm)
- **Τμήματα** - Αριθμός ευθύγραμμων τμημάτων που σχηματίζουν τον κύκλο. Περισσότερα = πιο ομαλός

## Συμβουλές

- Μια Διαδρομή Κύκλου σε συνδυασμό με τη Γραμμική Εξώθηση παράγει έναν κύλινδρο, παρόμοιο με το αρχέγονο σχήμα [Κύλινδρος](../primitives/cylinder.md) αλλά με μεγαλύτερη ευελιξία στον τρόπο που χτίζετε πάνω σε αυτόν
- Χρησιμοποιήστε τη ως βάση για την Περιστροφή ώστε να δημιουργήσετε σχήματα δακτυλίου

## Σχετικά

- [Διαδρομή Κουτιού](box-path.md) - Μια ορθογώνια δισδιάστατη διαδρομή
- [Διαδρομή Δακτυλίου](ring-path.md) - Ένας κύκλος με οπή
- [Γραμμική Εξώθηση](../operations/path/linear-extrude.md) - Δώστε ύψος στις διαδρομές
