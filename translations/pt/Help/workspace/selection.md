# Seleção

Selecionar objetos é fundamental para trabalhar no MatterCAD. Você precisa selecionar objetos antes de poder movê-los, modificá-los ou aplicar operações a eles.

## Seleção Única

- **Clique com o botão esquerdo em um objeto** para selecioná-lo. O objeto selecionado anteriormente é desmarcado.
- **Clique com o botão esquerdo em um espaço vazio** para desmarcar tudo.

## Seleção Múltipla

- **Shift + clique com o botão esquerdo** em objetos adicionais para adicioná-los à sua seleção
- **Ctrl + clique com o botão esquerdo** também adiciona objetos à sua seleção
- **Ctrl + A** seleciona todos os objetos da cena

## Seleção Elástica

Clique e arraste em uma área vazia da janela de visualização para desenhar um retângulo de seleção. Todos os objetos dentro do retângulo são selecionados.

## Limpar a Seleção

- **Clique com o botão esquerdo em um espaço vazio** limpa a seleção
- **Espaço** limpa a seleção
- **Escape** cancela uma operação de arrasto

## Trabalhando com Seleções

Depois de ter objetos selecionados:

- **Mover** os objetos arrastando-os na janela de visualização
- **Aplicar operações** a partir da barra de ferramentas (booleana, transformação, matriz, etc.)
- **Editar propriedades** no painel Propriedades (quando um único objeto está selecionado)
- **Clique com o botão direito** para acessar o menu de contexto com as ações disponíveis

## Dicas

- Quando vários objetos estão selecionados, eles são agrupados temporariamente para as operações. O painel Propriedades mostra as propriedades compartilhadas.
- Use a Árvore de Design para selecionar objetos difíceis de clicar na janela de visualização -- clicar em um item da árvore o seleciona na visualização.
