# Componentes

Componentes são grupos de objetos reutilizáveis e parametrizados. Ao criar um componente, ele se torna uma unidade autônoma que você pode inserir várias vezes no seu projeto, e editar o componente atualiza todas as instâncias.

## Como Usar

### Criando um Componente

1. Selecione um ou mais objetos
2. Clique com o botão direito e escolha **Criar Componente** (ou use o menu)
3. Os objetos selecionados são envolvidos em um contêiner de componente

### Editando um Componente

1. Selecione o componente
2. Os parâmetros expostos do componente aparecem no painel Propriedades
3. Modifique os parâmetros para alterar a forma do componente

## Dicas

- Componentes são úteis para criar blocos de construção reutilizáveis em projetos complexos
- Alterações de parâmetros são não destrutivas e podem ser ajustadas a qualquer momento
- Componentes ajudam a organizar projetos complexos agrupando objetos relacionados
- Use componentes para peças que você precisa posicionar várias vezes com pequenas variações
