# Atalhos de Teclado

Referência rápida de todos os atalhos de teclado disponíveis no MatterCAD.

## Editar

| Atalho | Ação |
|----------|--------|
| Ctrl + Z | Desfazer |
| Ctrl + Y | Refazer |
| Ctrl + Shift + Z | Refazer (alternativo) |
| Ctrl + A | Selecionar tudo os objetos |
| Ctrl + C | Copiar os objetos selecionados |
| Ctrl + X | Recortar os objetos selecionados |
| Ctrl + V | Colar objetos |
| Espaço | Limpar seleção |
| Escape | Cancelar a operação de arraste atual |
| Delete | Excluir os objetos selecionados |

## Visualizar

| Atalho | Ação |
|----------|--------|
| W | Redefinir a visualização (ajustar todos os objetos na janela de visualização) |
| Z | Ampliar até o objeto selecionado |
| Ctrl + Mais (+) | Ampliar |
| Ctrl + Menos (-) | Reduzir |
| Teclas de seta | Rotacionar a visualização |
| Shift + Teclas de seta | Deslocar a visualização |

## Controles do Mouse

| Ação | Controle |
|--------|---------|
| Rotacionar a visualização | Clique com o botão direito + Arrastar |
| Deslocar a visualização | Clique com o botão do meio + Arrastar |
| Zoom | Roda de rolagem |
| Selecionar objeto | Clique com o botão esquerdo sobre o objeto |
| Seleção múltipla | Shift + Clique com o botão esquerdo ou Ctrl + Clique com o botão esquerdo |
| Seleção por retângulo elástico | Clique com o botão esquerdo + Arrastar em um espaço vazio |
| Menu de contexto | Clique com o botão direito sobre o objeto |

## Controles Alternativos do Mouse

| Ação | Controle |
|--------|---------|
| Rotacionar a visualização | Ctrl + Clique com o botão esquerdo + Arrastar |
| Deslocar a visualização | Ctrl + Shift + Clique com o botão esquerdo + Arrastar |
| Zoom | Ctrl + Alt + Clique com o botão esquerdo + Arrastar |

## Aplicativo

| Atalho | Ação |
|----------|--------|
| Ctrl + Shift + T | Reabrir o último projeto fechado |
| F1 | Abrir a Ajuda |
