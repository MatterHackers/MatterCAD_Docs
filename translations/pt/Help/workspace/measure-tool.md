# Ferramenta de Medição

A Ferramenta de Medição permite medir distâncias entre pontos no seu design. Posicione pontos de medição em qualquer lugar da janela de visualização 3D para conferir dimensões.

<!--  Screenshot showing the Measure Tool with a distance measurement displayed between two points -->
![20260318 192711 paste 20260318 192711](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-192711-paste-20260318-192711.jpg)


## Como Usar

1. Adicione a **Ferramenta de Medição** a partir do menu de ferramentas
2. Arraste os pontos de medição até os locais entre os quais deseja medir
3. A distância é exibida na janela de visualização

## Dicas

- Use este recurso para verificar dimensões antes de exportar para impressão 3D
- A Ferramenta de Medição exibe a distância em linha reta entre os dois pontos de controle
- Você pode manter a Ferramenta de Medição no seu design enquanto trabalha e removê-la antes de exportar
