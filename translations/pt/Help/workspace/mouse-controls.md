# Controles do Mouse

Referência completa dos controles do mouse na viewport 3D do MatterCAD.

## Navegação

| Ação | Controle do Mouse |
|--------|--------------|
| **Rotacionar visualização** | Clique com o botão direito + Arrastar |
| **Deslocar visualização** | Clique com o botão do meio + Arrastar |
| **Zoom** | Roda de rolagem |

## Navegação Alternativa

| Ação | Controle do Mouse |
|--------|--------------|
| **Rotacionar visualização** | Ctrl + Clique com o botão esquerdo + Arrastar |
| **Deslocar visualização** | Ctrl + Shift + Clique com o botão esquerdo + Arrastar |
| **Zoom** | Ctrl + Alt + Clique com o botão esquerdo + Arrastar |

## Interação com Objetos

| Ação | Controle do Mouse |
|--------|--------------|
| **Selecionar objeto** | Clique com o botão esquerdo no objeto |
| **Seleção múltipla** | Shift + Clique com o botão esquerdo nos objetos adicionais |
| **Seleção múltipla** | Ctrl + Clique com o botão esquerdo nos objetos adicionais |
| **Desmarcar tudo** | Clique com o botão esquerdo em um espaço vazio |
| **Seleção por retângulo** | Clique com o botão esquerdo + Arrastar em um espaço vazio |
| **Mover objeto** | Clique com o botão esquerdo + Arrastar sobre o objeto selecionado |
| **Menu de contexto** | Clique com o botão direito no objeto |

## Controles do Objeto

Quando um objeto está selecionado, controles interativos aparecem:

| Ação | Controle |
|--------|---------|
| **Mover na mesa** | Arraste o objeto |
| **Mover para cima/baixo** | Arraste a seta vertical acima do objeto |
| **Rotacionar** | Clique e arraste um controle de rotação de canto |
| **Escala** | Clique e arraste um controle de escala de canto |

## Dicas

- O zoom com a roda de rolagem é centralizado na posição do cursor do mouse -- aponte para a área na qual deseja aplicar o zoom
- Os controles alternativos (Ctrl + Clique com o botão esquerdo) são úteis se você não tiver o botão do meio do mouse ou se o clique com o botão direito for inconveniente
- Ao rotacionar com os controles de canto, passe o cursor sobre os indicadores de ângulo para encaixar em incrementos de 45 graus
