# Navegação na Viewport

A viewport 3D é onde você visualiza e interage com seus projetos. O MatterCAD usa um modelo de câmera trackball que permite orbitar, deslocar e aplicar zoom livremente ao redor dos seus objetos.

![20260324 080636 paste 20260324 080636](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-080636-paste-20260324-080636.jpg)



## Controles do mouse

### Rotacionar a visualização

- **Clique com o botão direito + Arrastar** - Orbita a câmera ao redor do seu projeto
- **Ctrl + Clique com o botão esquerdo + Arrastar** - Método alternativo de rotação

### Deslocar a visualização

- **Clique com o botão do meio + Arrastar** - Desliza a visualização para a esquerda, direita, cima ou baixo
- **Ctrl + Shift + Clique com o botão esquerdo + Arrastar** - Método alternativo para deslocar

### Ampliar e Reduzir

- **Roda de rolagem** - Role para cima para Ampliar, role para baixo para Reduzir
- **Ctrl + Alt + Clique com o botão esquerdo + Arrastar** - Método alternativo de zoom

## Controles do teclado

### Atalhos de visualização

- **W** - Redefine a visualização para enquadrar todos os objetos na viewport
- **Z** - Aplica zoom no objeto atualmente selecionado

### Navegação com as teclas de seta

- **Teclas de seta** - Rotaciona a visualização
- **Shift + Teclas de seta** - Desloca a visualização

### Atalhos de zoom

- **Ctrl + Mais (+)** - Ampliar
- **Ctrl + Menos (-)** - Reduzir

## Dicas

- Se você perder o modelo de vista, pressione **W** para redefinir a visualização e trazer tudo de volta ao enquadramento
- Use **Z** depois de selecionar um objeto para focalizá-lo rapidamente
- O zoom da roda de rolagem é centralizado na posição do cursor do mouse, então aponte para a área na qual deseja Ampliar
- Você pode combinar rotação e deslocamento para inspecionar qualquer ângulo do seu projeto
