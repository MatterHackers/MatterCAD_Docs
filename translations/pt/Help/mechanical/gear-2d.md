# Engrenagem 2D

Um caminho de engrenagem 2D que cria apenas o perfil dos dentes da engrenagem como um caminho plano. Use-o com [Extrusão Linear](../operations/path/linear-extrude.md) ou [Revolucionar](../operations/path/revolve.md) para ter mais controle sobre como a engrenagem é transformada em uma forma 3D.

<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->
![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)

## Como Usar

1. Adicione uma **Engrenagem 2D** a partir das ferramentas mecânicas
2. Configure os parâmetros dos dentes
3. Aplique [Extrusão Linear](../operations/path/linear-extrude.md) para dar altura a ela

## Dicas

- Use a Engrenagem 2D quando precisar combinar um perfil de engrenagem com outras operações de caminho antes de extrudar
- Para uma engrenagem 3D pronta para uso, veja [Engrenagens](gears.md)
- As mesmas regras de engrenamento se aplicam: Passo Circular e Ângulo de Pressão coincidentes para engrenagens que funcionam juntas
