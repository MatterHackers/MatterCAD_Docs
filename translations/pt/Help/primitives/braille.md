# Braille

Gere texto em Braille imprimível em 3D a partir de texto padrão em inglês. A ferramenta Braille suporta a codificação Braille de Grau 1 (letra por letra) e de Grau 2 (contraído).

## Como Usar

1. Adicione uma primitiva **Braille** a partir do painel Primitivas
2. Digite o seu texto no campo **Texto a Codificar**
3. A ferramenta converte-o automaticamente para o padrão de pontos Braille correto

## Parâmetros

- **Texto a Codificar** - O texto em inglês a converter para Braille
- **Escala** - Ajusta o tamanho geral do resultado em Braille
- **Altura** - A altura dos pontos em relevo do Braille

## Dicas

- O Braille de Grau 2 utiliza contrações e abreviaturas para palavras e combinações de letras comuns, tornando-o mais compacto
- São utilizadas as dimensões padrão da célula Braille para garantir que o resultado seja legível
- Combine com uma base plana de [Cubo](cube.md) para criar uma etiqueta ou placa em Braille completa
- Para cartões em Braille com uma base integrada, consulte [Cartão em Braille](braille-card.md)
