# Cone

Um cilindro afunilado que termina em ponta no topo. Útil para criar detalhes pontiagudos, funis e chanfros.

## Parâmetros

- **Diâmetro** - A largura da base (padrão: 20mm)
- **Altura** - A altura do cone (padrão: 20mm)
- **Lados** - Número de segmentos ao redor do perímetro (padrão: 40)

## Dicas

- Para um cone truncado (topo plano em vez de ponta), use um [Cilindro](cylinder.md) com o modo Avançado e defina valores diferentes para Diâmetro e Diâmetro Superior
- Cones são úteis para criar arestas chanfradas quando combinados com [Subtrair](../operations/boolean/subtract.md)
