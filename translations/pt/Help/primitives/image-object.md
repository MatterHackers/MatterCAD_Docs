# Objeto Imagem

Importe uma imagem e converta-a em um objeto 3D em relevo, no qual os valores de brilho determinam a altura de cada pixel. Isso permite transformar fotografias, logotipos e ilustrações em objetos imprimíveis em 3D.

## Como Usar

1. Adicione um **Conversor de Imagem** a partir do painel Primitivas, ou arraste um arquivo de imagem diretamente para a área de trabalho
2. Selecione ou altere a imagem usando as propriedades
3. Ajuste a altura para controlar o quanto as áreas claras são elevadas

## Parâmetros

- **Altura** - O quanto as porções elevadas da imagem se projetam
- A pré-visualização da imagem é exibida no painel Propriedades

## Dicas

- Imagens de alto contraste com formas bem definidas funcionam melhor
- Você pode arrastar imagens diretamente da sua área de trabalho para o espaço de trabalho do MatterCAD
- Use as ferramentas do menu de opções adicionais em uma imagem importada para obter mais opções de conversão
- Para contornos baseados em caminhos a partir de imagens, consulte [Imagem para Caminho](../operations/image/image-to-path.md)
- Para exibições de imagem retroiluminadas, consulte [Litofania](../operations/image/lithophane.md)
- Adicione uma base combinando o objeto de imagem com um [Cubo](cube.md)
