# Cartão em Braille

Crie cartões em Braille com texto Braille em relevo sobre uma base integrada. Esta é uma ferramenta de conveniência que combina um objeto de texto Braille com um cartão de suporte em uma única etapa.

## Como Usar

1. Adicione um **Cartão em Braille** a partir do painel Primitivas
2. Digite o texto que deseja codificar
3. A ferramenta gera tanto os pontos em Braille quanto a base do cartão

## Dicas

- Use esta opção quando quiser uma etiqueta em Braille completa e pronta para impressão
- Para pontos em Braille sem base (para posicionar sobre sua própria superfície), use [Braille](braille.md)
