# Pirâmide

Uma forma piramidal de quatro faces com base retangular e altura ajustáveis.

<!--  Screenshot of a Pyramid primitive on the workspace -->
![20260318 183743 paste 20260318 183743](https://matterhackers.github.io/MatterCAD_Docs/assets/20260318-183743-paste-20260318-183743.jpg)


## Parâmetros

- **Largura** - Tamanho da base ao longo do eixo X (padrão: 20mm)
- **Profundidade** - Tamanho da base ao longo do eixo Y (padrão: 20mm)
- **Altura** - Altura da pirâmide, da base ao ápice (padrão: 20mm)

## Dicas

- Defina Largura e Profundidade com o mesmo valor para obter uma pirâmide regular de base quadrada
- Use valores diferentes de Largura e Profundidade para uma pirâmide de base retangular
- Útil para elementos decorativos, linhas de telhado e detalhes pontiagudos
