# Meia Esfera

O hemisfério superior de uma esfera -- um formato de cúpula. Útil para criar topos abaulados, formatos de lente e tampas arredondadas.

<!--  Screenshot of a Half Sphere primitive on the workspace -->

## Parâmetros

- **Diâmetro** - A largura da base da cúpula (padrão: 20mm)
- **Lados de Longitude** - Número de segmentos ao redor do perímetro (padrão: 40)
- **Lados de Latitude** - Número de segmentos da base até o topo (padrão: 10). Mais = cúpula mais suave

## Dicas

- Combine duas meias esferas com um cilindro para obter um formato de cápsula
- Posicione sobre um cilindro para criar uma tampa abaulada ou um botão
- Use com [Subtrair](../operations/boolean/subtract.md) para criar cavidades em formato de cúpula
