# Biblioteca Local

A Biblioteca Local armazena seus projetos 3D no seu computador. Você pode organizar os projetos em pastas, pesquisar arquivos e adicioná-los rapidamente ao seu espaço de trabalho.

![20260323 210208 paste 20260323 210208](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210208-paste-20260323-210208.jpg)


## Navegando pela Biblioteca

1. Abra o painel **Biblioteca** na barra lateral ou na aba Biblioteca
2. Navegue pelas pastas para encontrar seus projetos
3. Dê um duplo clique em um projeto para abri-lo, ou arraste-o para o seu espaço de trabalho para adicioná-lo à cena atual

## Organizando Seus Arquivos

- **Criar pastas** - Clique com o botão direito na biblioteca e escolha Criar Pasta para organizar seus projetos
- **Renomear itens** - Clique com o botão direito em qualquer item e escolha Renomear
- **Excluir itens** - Clique com o botão direito e escolha Excluir para remover itens
- **Mover itens** - Arraste itens entre as pastas para reorganizá-los

## Opções de Visualização

O painel da biblioteca oferece vários modos de visualização:

- **Visualização em lista** - Lista compacta mostrando os nomes dos arquivos
- **Visualização em ícones** - Miniaturas de pré-visualização dos seus projetos
- **Visualização em ícones grandes** - Miniaturas maiores para facilitar a navegação

Você pode ordenar os itens por:

- **Nome** - Ordem alfabética
- **Data de Criação** - Mais recentes ou mais antigos primeiro
- **Data de Modificação** - Alterados mais recentemente primeiro

## Dicas

- Use a barra de pesquisa no topo da biblioteca para encontrar projetos rapidamente pelo nome
- O navegador da biblioteca mostra uma miniatura de pré-visualização para a maioria dos tipos de arquivo
- Projetos salvos no formato MCX preservam todos os parâmetros e a árvore do projeto para uma reedição completa
