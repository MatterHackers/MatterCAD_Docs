 - **Nome:** Digite o texto que deseja exibir
 - **Tamanho do Ponto:** Define o tamanho da fonte. Esse valor é preciso quando impresso no mesmo tamanho que em uma impressora 2D.
 - **Altura:** Define a altura que você deseja que o texto alcance
 - **Fonte:** Selecione a fonte que deseja utilizar
