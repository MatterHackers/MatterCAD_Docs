O MatterCAD inclui tudo o que você precisa para criar suas ideias - já pronto para usar!

![2018-07-02 10_46_48-start](https://user-images.githubusercontent.com/1158332/42188916-c7102220-7e0a-11e8-8d7b-dc1921e304c6.png)

Com essas primitivas simples e as ferramentas incluídas, você pode criar tudo o que imaginar.

  ![](https://lh3.googleusercontent.com/XLlyBUeloa3Q1FQF8-fCD0zx036yFCLsvyUKrE9zaV-p1k4Jt4m5QK3W59c8CnwPurZ_RW2xBazi9E3AmMmhkuL_OA)
  - **Nome:** Digite o texto que você quiser exibir
  - **Tamanho do Ponto:** Define o tamanho da fonte. Esse valor é preciso quando impresso no mesmo tamanho de uma impressora 2D.
  - **Altura:** Define a altura que você deseja que o texto alcance
  - **Fonte:** Selecione a fonte que você deseja usar
- Cilindro  
  ![](https://lh3.googleusercontent.com/Gy_YL8RYVbXwPDHVgkixUC17HN8qOLLOdaVzsNfGD1uFCjlWFD8nWPB56GcCh_Wj7fXQBqCWtuxidMi26dDfxycWnvw)
  - **Diâmetro:** Define o tamanho transversal da peça
  - **Altura:** Define o tamanho em Z
  - **Lados:** Define o número de faces (ou lados) ao redor da peça
  - **Avançado:** Abre as configurações avançadas para controlar mais recursos
    - **Ângulo Inicial:** O ângulo em que a revolução do cilindro começa
    - **Ângulo Final:** O ângulo em que a revolução do cilindro termina
    - **Diâmetro Superior:** O tamanho do topo do cilindro
