# Estreitamento

O Estreitamento comprime a parte traseira de um objeto para dentro, com o efeito aumentando em direção ao topo. Isso cria uma aparência afunilada ou comprimida.

![20260506 155449 paste 20260506 155449](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-155449-paste-20260506-155449.jpg)

## Como Usar

1. Selecione um objeto
2. Aplique a operação **Estreitamento** no menu Remodelar
3. Ajuste a porcentagem de estreitamento

## Parâmetros

- **Proporção Traseira** - O quanto a parte traseira da peça é comprimida para dentro (0-300%, padrão: 50%). Valores maiores = mais compressão

## Dicas

- O Estreitamento atua de trás para frente, comprimindo a parte posterior do objeto
- Use isso para criar formas afuniladas e estreitas a partir de objetos retangulares ou cilíndricos
- Para compressão radial (em toda a volta), use o [Estreitamento Radial](radial-pinch.md)
