# Operações de Posicionamento
<!-- AUTO_IMAGE: type=toolbar_icons group=Placement -->
![Placement toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Placement.png)

As operações de posicionamento ajudam a posicionar objetos com precisão uns em relação aos outros ou dentro de limites específicos.

## Operações

- [Alinhar](align.md) - Alinha objetos entre si ao longo de qualquer eixo
- [Alinhamento de Extrusão Dupla](dual-extrusion-align.md) - Alinha objetos às suas posições de modelagem compartilhadas
- [Ajustar aos Limites](fit-to-bounds.md) - Redimensiona um objeto para caber dentro de uma caixa delimitadora especificada
- [Ajustar ao Cilindro](fit-to-cylinder.md) - Redimensiona um objeto para caber dentro de um cilindro especificado
