# Operações de Caminho
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

As operações de caminho trabalham com caminhos 2D para criar e modificar formas 3D. Use-as para extrudar, revolucionar e refinar geometrias baseadas em caminhos.

## Operações

- [Extrusão Linear](linear-extrude.md) - Dá altura a um caminho 2D para criar um objeto 3D
- [Revolucionar](revolve.md) - Gira um caminho 2D em torno de um eixo para criar um sólido de revolução
- [Suavizar Caminho](smooth-path.md) - Suaviza as curvas de um caminho
- [Inflar Caminho](inflate-path.md) - Expande um caminho para fora
- [Caminho do contorno](outline-path.md) - Cria um contorno a partir de um caminho preenchido
- [Caminho da Borda](border-path.md) - Adiciona um deslocamento de borda ao redor de um caminho
- [Selecionar caminhos](select-paths.md) - Seleciona caminhos específicos de objetos complexos com vários caminhos
