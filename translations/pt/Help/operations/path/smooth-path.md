# Suavizar Caminho

O Suavizar Caminho arredonda os cantos e as curvas de um caminho 2D, criando formas mais suaves e orgânicas a partir de entradas angulares.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Como Usar

1. Selecione um caminho 2D
2. Aplique **Suavizar Caminho** a partir do menu de operações de Caminho
3. Os cantos do caminho são suavizados em curvas

## Dicas

- Aplique antes da [Extrusão Linear](linear-extrude.md) para criar formas extrudadas com arestas suaves
- Use em um [Caminho de Estrela](../../2d-paths/star-path.md) para criar uma estrela arredondada
- Várias aplicações do Suavizar Caminho aumentam o efeito de suavização
