# Caminho do contorno

O Caminho do contorno cria uma versão de contorno de um caminho preenchido, convertendo uma forma sólida em apenas seu anel de limite com uma espessura especificada.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Como Usar

1. Selecione um caminho 2D
2. Aplique **Caminho do contorno** a partir do menu de operações de Caminho
3. Ajuste a espessura do contorno

## Dicas

- Use isto para criar formas semelhantes a molduras a partir de caminhos sólidos
- Combine com [Extrusão Linear](linear-extrude.md) para criar molduras e bordas 3D
- Um [Caminho de Círculo](../../2d-paths/circle-path.md) com contorno equivale a um [Caminho de Anel](../../2d-paths/ring-path.md)
