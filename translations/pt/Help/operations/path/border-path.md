# Caminho da Borda

O Caminho da Borda adiciona um deslocamento de borda ao redor de um caminho existente, criando uma versão maior da forma que envolve a original.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Como Usar

1. Selecione um caminho 2D
2. Aplique **Caminho da Borda** no menu de operações de Caminho
3. Ajuste a largura da borda

## Dicas

- Use isto para criar margem ou espaçamento ao redor das formas
- Combine com o caminho original e [Subtrair](../boolean/subtract.md) para criar formas de moldura
- Semelhante a [Inflar Caminho](inflate-path.md), mas projetado especificamente para a geração de bordas
