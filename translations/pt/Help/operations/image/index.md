# Operações de Imagem
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

As operações de imagem convertem imagens 2D em objetos ou caminhos 3D, permitindo incorporar fotografias, logotipos e ilustrações aos seus projetos.

## Operações

- [Conversor de Imagem](image-converter.md) - Converta uma imagem em um relevo 3D com base no brilho ou na cor
- [Imagem para Caminho](image-to-path.md) - Trace uma imagem para criar um contorno de caminho 2D
- [Litofania](lithophane.md) - Crie uma litofania que revela uma imagem quando iluminada por trás
