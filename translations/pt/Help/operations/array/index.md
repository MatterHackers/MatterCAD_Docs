# Operações de Matriz
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

A Matriz cria várias cópias de um objeto dispostas em um padrão. Isso é útil para criar recursos repetitivos, como furos de parafusos, mourões de cerca, dentes de engrenagem ou elementos decorativos.

A operação Matriz oferece suporte a quatro modos — Linear, Radial, Curva e Transformar — todos em uma única ferramenta.
