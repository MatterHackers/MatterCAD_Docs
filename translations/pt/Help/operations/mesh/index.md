# Operações de Malha
<!-- AUTO_IMAGE: type=toolbar_icons group=Mesh -->
![Mesh toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Mesh.png)

As operações de malha ajudam a limpar e otimizar a geometria de malha de triângulos dos seus modelos.

## Operações

- [Reparar](repair.md) - Corrige problemas na geometria da malha, como buracos, arestas não-manifold e faces invertidas
- [Dizimar](decimate.md) - Reduzir a contagem de polígonos de uma malha para simplificá-la, preservando a forma
