# Caminho Caixa

Um caminho 2D retangular. Use com [Extrusão Linear](../operations/path/linear-extrude.md) para criar formas de caixa, ou como base para outras operações de caminho.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parâmetros

- **Largura** - A largura do retângulo (padrão: 20mm)
- **Altura** - A altura do retângulo (padrão: 20mm)

## Dicas

- Um Caminho Caixa somado a uma Extrusão Linear cria uma forma semelhante a um [Cubo](../primitives/cube.md), mas você pode aplicar operações de caminho como [Inflar](../operations/path/inflate-path.md) ou [Suavizar](../operations/path/smooth-path.md) antes de extrudar
