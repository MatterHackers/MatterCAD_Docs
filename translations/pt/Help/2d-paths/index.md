# Caminhos 2D

Os caminhos 2D são formas planas que você pode usar como ponto de partida para objetos 3D. Use [Extrusão Linear](../operations/path/linear-extrude.md) para dar altura a um caminho, ou [Revolucionar](../operations/path/revolve.md) para girar um caminho em torno de um eixo e criar uma forma 3D.

## Caminhos disponíveis

- [Caminho Círculo](circle-path.md) - Um contorno 2D circular
- [Caminho Caixa](box-path.md) - Um contorno 2D retangular
- [Caminho Anel](ring-path.md) - Um anel 2D (círculo com um furo)
- [Caminho Estrela](star-path.md) - Um contorno 2D em forma de estrela com pontas configuráveis
- [Caminho Personalizado](custom-path.md) - Desenhe seu próprio caminho 2D com pontos de controle
