# Caminho de Círculo

Um caminho 2D circular. Use com [Extrusão Linear](../operations/path/linear-extrude.md) para criar cilindros, ou [Revolucionar](../operations/path/revolve.md) para criar formas semelhantes a um torus.

## Parâmetros

- **Diâmetro** - O diâmetro do círculo (padrão: 20mm)
- **Segmentos** - Número de segmentos de linha que formam o círculo. Mais = mais suave

## Dicas

- Um Caminho de Círculo combinado com Extrusão Linear produz um cilindro, semelhante à primitiva [Cilindro](../primitives/cylinder.md), mas com mais flexibilidade na forma como você constrói a partir dele
- Use como base para Revolucionar para criar formas de anel
