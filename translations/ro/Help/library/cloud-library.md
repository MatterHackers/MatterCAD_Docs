# Bibliotecă cloud

Biblioteca cloud stochează online modelele tale în contul MatterHackers. Astfel poți accesa modelele de pe orice computer și poți păstra o copie de rezervă în cloud.

![20260323 210141 paste 20260323 210141](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210141-paste-20260323-210141.jpg)

## Primii pași

1. Autentifică-te în contul tău MatterHackers din meniul aplicației
2. Biblioteca cloud apare în browserul de bibliotecă
3. Încarcă modele trăgându-le în folderul cloud sau salvează-le direct în cloud

## Caracteristici

- **Acces de oriunde** - Modelele tale sunt disponibile pe orice computer pe care te autentifici
- **Copie de rezervă în cloud** - Munca ta este stocată în siguranță online
- **Organizare în foldere** - Creează foldere pentru a-ți organiza modelele din cloud, exact ca în biblioteca locală
- **Partajare** - Partajează modele cu alți utilizatori MatterCAD. Vezi [Partajare](sharing.md)

## Sfaturi

- Modelele sunt sincronizate automat când salvezi în biblioteca cloud
- Ai nevoie de o conexiune la internet pentru a accesa conținutul bibliotecii cloud
- Fișierele mari pot dura un moment până se încarcă sau se descarcă
- Păstrează modelele importante atât în biblioteca locală, cât și în cea cloud, pentru siguranță
