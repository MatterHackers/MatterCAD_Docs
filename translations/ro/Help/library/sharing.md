# Partajare

MatterCAD îți permite să partajezi modelele tale cu alți utilizatori prin coduri de partajare. Astfel devine simplu să colaborezi la modele sau să îți distribui munca.

![20260323 210309 paste 20260323 210309](https://matterhackers.github.io/MatterCAD_Docs/assets/20260323-210309-paste-20260323-210309.jpg)


## Partajarea unui model

1. Fă clic dreapta pe un model din [Bibliotecă cloud](cloud-library.md)
2. Selectează **Partajare**
3. Se generează un cod de partajare pe care îl poți trimite altora

## Primirea unui model partajat

1. Obține un cod de partajare de la cineva
2. Folosește opțiunea **Revendică Cod de partajare** din bibliotecă
3. Modelul partajat este adăugat în biblioteca ta

## Sfaturi

- Codurile de partajare funcționează cu modelele stocate în Bibliotecă cloud
- Destinatarul primește o copie a modelului -- modificările făcute de el nu afectează originalul tău
- Codurile de partajare pot fi distribuite prin orice canal: e-mail, chat, rețele sociale etc.
