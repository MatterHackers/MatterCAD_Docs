# Bibliotecă

Biblioteca vă permite să organizați, să stocați și să partajați modelele dvs. 3D. Puteți răsfoi fișierele locale, accesa stocarea în cloud și partaja modele cu alte persoane.

## Subiecte

- [Bibliotecă locală](local-library.md) - Gestionați modelele stocate pe computerul dvs.
- [Bibliotecă cloud](cloud-library.md) - Stocați și accesați modele în contul dvs. cloud MatterHackers
- [Partajare](sharing.md) - Partajați modele cu alți utilizatori MatterCAD
