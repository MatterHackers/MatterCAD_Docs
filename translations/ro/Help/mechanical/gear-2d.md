# Roată dințată 2D

O cale de roată dințată 2D care creează doar profilul dinților sub forma unei căi plane. Folosiți-o împreună cu [Extrudare liniară](../operations/path/linear-extrude.md) sau [Revoluție](../operations/path/revolve.md) pentru un control mai bun asupra modului în care roata dințată este transformată într-o formă 3D.

<!-- AUTO_IMAGE: type=from_thumbnail item=gear_2d file=mechanical_gear_2d -->
![mechanical_gear_2d](https://matterhackers.github.io/MatterCAD_Docs/assets/mechanical_gear_2d.png)

## Mod de utilizare

1. Adăugați o **Roată dințată 2D** din uneltele mecanice
2. Configurați parametrii dinților
3. Aplicați [Extrudare liniară](../operations/path/linear-extrude.md) pentru a-i da înălțime

## Sfaturi

- Folosiți Roată dințată 2D atunci când trebuie să combinați un profil de roată dințată cu alte operații pe căi înainte de extrudare
- Pentru o roată dințată 3D gata de utilizat, consultați în schimb [Roți dințate](gears.md)
- Se aplică aceleași reguli de angrenare: Pas circular și Unghi de presiune identice pentru roțile dințate care funcționează împreună
