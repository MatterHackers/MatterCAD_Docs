# Adăugarea obiectelor existente

Puteți aduce modele 3D existente în MatterCAD importând fișiere de pe computer sau adăugând conținut din biblioteca încorporată.

## De pe computerul dumneavoastră

![20260324 081143 paste 20260324 081143](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081143-paste-20260324-081143.jpg)

![20260324 081240 paste 20260324 081240](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081240-paste-20260324-081240.jpg)


Faceți clic pe butonul **Deschide** din bara de instrumente pentru a răsfoi și a adăuga fișiere de pe computer. MatterCAD acceptă următoarele formate de import:

- **STL** (.stl) - Format standard în industrie pentru modele 3D, utilizat pe scară largă pentru imprimarea 3D
- **AMF** (.amf) - Format avansat care acceptă culori și obiecte din mai multe materiale
- **OBJ** (.obj) - Format grafic 3D Wavefront (doar geometrie de tip plasă)
- **3MF** (.3mf) - 3D Manufacturing Format, cu suport bogat pentru metadate
- **MCX** (.mcx) - Formatul nativ MatterCAD, care păstrează toate datele și parametrii proiectului
- **SVG** (.svg) - Scalable Vector Graphics, importat sub formă de trasee 2D
- **TTF / OTF** (.ttf, .otf) - Fișiere de font pentru utilizare cu instrumentul Text

## Glisare și plasare

De asemenea, puteți glisa și plasa fișiere direct de pe desktop sau din exploratorul de fișiere în spațiul de lucru MatterCAD. Tipurile de fișiere acceptate vor fi importate automat.

![20260324 081416 paste 20260324 081416](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081416-paste-20260324-081416.jpg)

## Din Bibliotecă

### Bara laterală Bibliotecă

Faceți clic pe butonul **Adaugă conținut** din bara de instrumente pentru a deschide panoul de navigare al bibliotecii. De aici puteți:

- Răsfoi proiectele salvate
- Naviga la biblioteca Primitive pentru forme încorporate
- Accesa Biblioteca cloud dacă v-ați autentificat
- Glisa și plasa orice element din bibliotecă direct în spațiul de lucru

![20260324 081446 paste 20260324 081446](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081446-paste-20260324-081446.jpg)

### Fila Bibliotecă

De asemenea, puteți folosi fila Bibliotecă pentru a răsfoi colecțiile. Faceți clic dreapta pe orice obiect din bibliotecă și selectați **Adaugă în scenă** pentru a-l importa în spațiul de lucru al proiectului curent.

![20260324 081536 paste 20260324 081536](https://matterhackers.github.io/MatterCAD_Docs/assets/20260324-081536-paste-20260324-081536.jpg)

## Sfaturi

- MCX este cel mai bun format pentru reeditarea ulterioară a proiectelor, deoarece păstrează toți parametrii și arborele de proiectare
- Fișierele STL conțin doar geometrie de tip plasă. Dacă importați un STL, puteți aplica în continuare operații asupra lui, dar nu puteți edita parametrii originali
- Când importați mai multe fișiere, fiecare devine un obiect separat în scenă. Folosiți [Grupează](../workspace/grouping.md) pentru a le organiza
