# Scurtături de tastatură

Referință rapidă pentru toate scurtăturile de tastatură disponibile în MatterCAD.

## Editare

| Scurtătură | Acțiune |
|----------|--------|
| Ctrl + Z | Anulează |
| Ctrl + Y | Refacere |
| Ctrl + Shift + Z | Refacere (alternativă) |
| Ctrl + A | Selectează toate obiectele |
| Ctrl + C | Copiază obiectele selectate |
| Ctrl + X | Decupare obiectele selectate |
| Ctrl + V | Lipire obiecte |
| Space | Șterge selecția |
| Escape | Anulează operațiunea curentă de tragere |
| Delete | Ștergere obiecte selectate |

## Vizualizare

| Scurtătură | Acțiune |
|----------|--------|
| W | Resetează vizualizarea (încadrează toate obiectele în fereastra de vizualizare) |
| Z | Mărire pe obiectul selectat |
| Ctrl + Plus (+) | Mărire |
| Ctrl + Minus (-) | Micșorare |
| Tastele săgeți | Rotire vizualizare |
| Shift + Tastele săgeți | Panoramare vizualizare |

## Comenzi de mouse

| Acțiune | Comandă |
|--------|---------|
| Rotire vizualizare | Clic dreapta + Tragere |
| Panoramare vizualizare | Clic mijloc + Tragere |
| Zoom | Roată de derulare |
| Selectare obiect | Clic stânga pe obiect |
| Selecție multiplă | Shift + Clic stânga sau Ctrl + Clic stânga |
| Selecție prin dreptunghi elastic | Clic stânga + Tragere în spațiu gol |
| Meniu contextual | Clic dreapta pe obiect |

## Comenzi alternative de mouse

| Acțiune | Comandă |
|--------|---------|
| Rotire vizualizare | Ctrl + Clic stânga + Tragere |
| Panoramare vizualizare | Ctrl + Shift + Clic stânga + Tragere |
| Zoom | Ctrl + Alt + Clic stânga + Tragere |

## Aplicație

| Scurtătură | Acțiune |
|----------|--------|
| Ctrl + Shift + T | Redeschide ultimul proiect închis |
| F1 | Deschide Ajutor |
