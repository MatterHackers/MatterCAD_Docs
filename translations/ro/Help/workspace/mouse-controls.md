# Comenzi mouse

Referință completă pentru comenzile de mouse în fereastra de vizualizare 3D MatterCAD.

## Navigare

| Acțiune | Comandă mouse |
|--------|--------------|
| **Rotire vizualizare** | Clic dreapta + tragere |
| **Panoramare vizualizare** | Clic mijloc + tragere |
| **Zoom** | Roata de derulare |

## Navigare alternativă

| Acțiune | Comandă mouse |
|--------|--------------|
| **Rotire vizualizare** | Ctrl + clic stânga + tragere |
| **Panoramare vizualizare** | Ctrl + Shift + clic stânga + tragere |
| **Zoom** | Ctrl + Alt + clic stânga + tragere |

## Interacțiunea cu obiectele

| Acțiune | Comandă mouse |
|--------|--------------|
| **Selectare obiect** | Clic stânga pe obiect |
| **Selecție multiplă** | Shift + clic stânga pe obiecte suplimentare |
| **Selecție multiplă** | Ctrl + clic stânga pe obiecte suplimentare |
| **Deselectare totală** | Clic stânga pe spațiul gol |
| **Selecție cu chenar** | Clic stânga + tragere pe spațiul gol |
| **Mută obiectul** | Clic stânga + tragere pe obiectul selectat |
| **Meniu contextual** | Clic dreapta pe obiect |

## Comenzi pentru obiect

Când un obiect este selectat, apar comenzi interactive:

| Acțiune | Comandă |
|--------|---------|
| **Mută pe platformă** | Trageți obiectul |
| **Mută sus/jos** | Trageți săgeata verticală de deasupra obiectului |
| **Rotire** | Faceți clic și trageți de o comandă de rotire din colț |
| **Scalare** | Faceți clic și trageți de o comandă de scalare din colț |

## Sfaturi

- Zoomul cu roata de derulare este centrat pe poziția cursorului mouse-ului -- îndreptați cursorul spre zona în care doriți să măriți
- Comenzile alternative (Ctrl + clic stânga) sunt utile dacă nu aveți buton de mouse mijlociu sau dacă clicul dreapta este incomod
- La rotirea cu ajutorul comenzilor din colț, treceți cu cursorul peste indicatorii de unghi pentru a fixa rotirea în incremente de 45 de grade
