# Cale Inel

O formă 2D de inel -- un cerc cu o gaură circulară în centru. Se folosește împreună cu [Extrudare liniară](../operations/path/linear-extrude.md) pentru a crea forme de tub sau de șaibă.

<!-- Screenshot of a Ring Path on the workspace -->
![20260506 080211 paste 20260506 080211](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080211-paste-20260506-080211.jpg)

## Parametri

- **Diametru exterior** - Diametrul exterior al inelului
- **Diametru interior** - Diametrul găurii din centru

## Sfaturi

- Grosimea peretelui inelului este (Diametru exterior - Diametru interior) / 2
- Extrudarea unei Căi Inel creează un tub similar cu primitiva [Inel](../primitives/ring.md)

## Asociate

- [Cale Cerc](circle-path.md) - Un cerc plin (fără gaură)
- [Inel](../primitives/ring.md) - O formă 3D de tub gata făcută
- [Extrudare liniară](../operations/path/linear-extrude.md) - Conferă înălțime căilor
