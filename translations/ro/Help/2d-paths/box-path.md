# Cale Cutie

O cale 2D dreptunghiulară. Folosiți-o împreună cu [Extrudare liniară](../operations/path/linear-extrude.md) pentru a crea forme de cutie sau ca bază pentru alte operații pe căi.

<!-- Screenshot of a Box Path on the workspace -->
![20260506 080026 paste 20260506 080026](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-080026-paste-20260506-080026.jpg)


## Parametri

- **Lățime** - Lățimea dreptunghiului (implicit: 20mm)
- **Înălțime** - Înălțimea dreptunghiului (implicit: 20mm)

## Sfaturi

- O Cale Cutie plus Extrudare liniară creează o formă similară cu un [Cub](../primitives/cube.md), însă puteți aplica operații pe căi precum [Umflare](../operations/path/inflate-path.md) sau [Netezire](../operations/path/smooth-path.md) înainte de extrudare
