# Căi 2D

Căile 2D sunt forme plane pe care le puteți folosi ca punct de plecare pentru obiecte 3D. Folosiți [Extrudare liniară](../operations/path/linear-extrude.md) pentru a da înălțime unei căi sau [Revoluție](../operations/path/revolve.md) pentru a roti o cale în jurul unei axe și a crea o formă 3D.

## Căi disponibile

- [Cale Cerc](circle-path.md) - Un contur 2D circular
- [Cale Cutie](box-path.md) - Un contur 2D dreptunghiular
- [Cale Inel](ring-path.md) - Un inel 2D (cerc cu gaură)
- [Cale Stea](star-path.md) - Un contur 2D în formă de stea, cu număr de vârfuri configurabil
- [Traseu personalizat](custom-path.md) - Desenați-vă propria cale 2D cu puncte de control
