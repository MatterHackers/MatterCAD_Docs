# Traseu netezit

Traseu netezit rotunjește colțurile și curbele unei căi 2D, creând forme mai fine, mai organice, pornind de la contururi unghiulare.

<!--  Before and after showing a star path with sharp points smoothed to curves -->
![20260506 102302 paste 20260506 102302](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-102302-paste-20260506-102302.jpg)


## Mod de utilizare

1. Selectați o cale 2D
2. Aplicați **Traseu netezit** din meniul de operații Cale
3. Colțurile căii sunt netezite în curbe

## Sfaturi

- Aplicați înainte de [Extrudare liniară](linear-extrude.md) pentru a crea forme extrudate cu muchii fine
- Utilizați pe o [Cale stea](../../2d-paths/star-path.md) pentru a crea o stea rotunjită
- Aplicările multiple ale operației Traseu netezit sporesc efectul de netezire

## Similare

- [Cale contur](outline-path.md) - Creează un contur dintr-o cale
