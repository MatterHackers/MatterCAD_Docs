# Traseu contur

Traseu contur adaugă un decalaj de contur în jurul unei căi existente, creând o versiune mai mare a formei care o înconjoară pe cea originală.

<!--  Before and after showing a path with a border added -->
![20260506 100533 paste 20260506 100533](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-100533-paste-20260506-100533.jpg)


## Mod de utilizare

1. Selectați o cale 2D
2. Aplicați **Traseu contur** din meniul de operații Cale
3. Reglați lățimea conturului

## Sfaturi

- Folosiți această operație pentru a crea o margine sau un spațiu în jurul formelor
- Combinați cu calea originală și [Scădere](../boolean/subtract.md) pentru a crea forme de cadru
- Similară cu [Cale umflare](inflate-path.md), dar concepută special pentru generarea de contururi

## Asociate

- [Cale umflare](inflate-path.md) - Extinde o cale spre exterior
- [Cale contur](outline-path.md) - Creează un contur dintr-o cale umplută
- [Extrudare liniară](linear-extrude.md) - Conferă înălțime căii cu contur
