# Cale contur

Cale contur creează o versiune contur a unei căi umplute, transformând o formă solidă doar în inelul său de contur, cu o grosime specificată.

<!--  Before and after showing a solid circle path converted to a ring outline -->
![20260506 101308 paste 20260506 101308](https://matterhackers.github.io/MatterCAD_Docs/assets/20260506-101308-paste-20260506-101308.jpg)

## Mod de utilizare

1. Selectați o cale 2D
2. Aplicați **Cale contur** din meniul de operații Cale
3. Ajustați grosimea conturului

## Sfaturi

- Folosiți această operație pentru a crea forme de tip cadru din căi solide
- Combinați cu [Extrudare liniară](linear-extrude.md) pentru a crea cadre și borduri 3D
- O [Cale cerc](../../2d-paths/circle-path.md) cu contur este echivalentă cu o [Cale inel](../../2d-paths/ring-path.md)
