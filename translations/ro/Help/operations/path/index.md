# Operații cu căi
<!-- AUTO_IMAGE: type=toolbar_icons group=Path -->
![Path toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Path.png)

Operațiile cu căi lucrează cu căi 2D pentru a crea și modifica forme 3D. Folosiți-le pentru a extruda, a roti prin revoluție și a rafina geometria bazată pe căi.

## Operații

- [Extrudare liniară](linear-extrude.md) - Dați înălțime unei căi 2D pentru a crea un obiect 3D
- [Revoluție](revolve.md) - Rotiți o cale 2D în jurul unei axe pentru a crea un solid de revoluție
- [Traseu netezit](smooth-path.md) - Netezește curbele unei căi
- [Cale umflare](inflate-path.md) - Extinde o cale spre exterior
- [Cale contur](outline-path.md) - Creează un contur dintr-o cale umplută
- [Traseu contur](border-path.md) - Adaugă un decalaj de contur în jurul unei căi
- [Selectare trasee](select-paths.md) - Selectați anumite căi din obiecte complexe cu mai multe căi
