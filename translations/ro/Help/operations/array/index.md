# Operații Matrice
<!-- AUTO_IMAGE: type=toolbar_icons group=Duplication -->
![Duplication toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Duplication.png)

**Matrice** creează mai multe copii ale unui obiect aranjate după un tipar. Este utilă pentru crearea de elemente repetitive precum găuri pentru șuruburi, stâlpi de gard, dinți de angrenaj sau elemente decorative.

Operația **Matrice** acceptă patru moduri — **Liniar**, **Radial**, **Curbă** și **Transformare** — toate într-un singur instrument.
