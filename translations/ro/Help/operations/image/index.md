# Operații cu imagini
<!-- AUTO_IMAGE: type=toolbar_icons group=Image -->
![Image toolbar icons](https://matterhackers.github.io/MatterCAD_Docs/assets/toolbar-icons-Image.png)

Operațiile cu imagini convertesc imaginile 2D în obiecte 3D sau căi, permițându-vă să încorporați fotografii, logouri și grafică în proiectele dumneavoastră.

## Operații

- [Convertor de imagini](image-converter.md) - Convertiți o imagine într-un relief 3D pe baza luminozității sau a culorii
- [Imagine în traseu](image-to-path.md) - Trasați o imagine pentru a crea un contur de cale 2D
- [Litofanie](lithophane.md) - Creați o litofanie care dezvăluie o imagine atunci când este iluminată din spate
