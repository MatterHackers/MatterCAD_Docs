# Obiect SVG

Importă fișiere SVG (Scalable Vector Graphics) și folosește-le ca trasee 2D în proiectul tău. Fișierele SVG pot fi apoi extrudate în forme 3D folosind [Extrudare liniară](../operations/path/linear-extrude.md) sau [Revoluție](../operations/path/revolve.md).

## Mod de utilizare

1. Importă un fișier SVG trăgându-l în spațiul de lucru sau folosind butonul Deschide
2. Fișierul SVG este importat ca traseu 2D
3. Aplică [Extrudare liniară](../operations/path/linear-extrude.md) pentru a-i da înălțime sau folosește alte [Operații pe trasee](../operations/path/index.md)

## Sfaturi

- Pentru cele mai bune rezultate, fișierele SVG ar trebui să conțină forme umplute sau trasee închise
- Fișierele SVG complexe, cu multe trasee, pot necesita mai mult timp de procesare
- Folosește [Selectare trasee](../operations/path/select-paths.md) pentru a lucra cu anumite părți dintr-un SVG cu mai multe trasee
- Online sunt disponibile multe fișiere SVG gratuite pentru logouri, pictograme și modele decorative
